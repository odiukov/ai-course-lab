Один поток против трёх вызовов с паузами

Слева — одна стрелка без разрывов: правка возможна только заново. Справа — разрывы между вызовами: результат видно и можно поправить до слияния.

Схема: слева задача → шаг 1 → шаг 2 (ошибка ×12 вместо ×11) → шаг 3 → кривой ответ, одной непрерывной стрелкой. Справа та же задача делится на три независимых вызова (числа, расчёт, вывод), между ними паузы для правки, затем слияние и проверка.
