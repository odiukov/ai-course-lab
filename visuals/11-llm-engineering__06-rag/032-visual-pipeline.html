Индексация — офлайн, запрос — онлайн

Схема: сверху офлайн-дорожка «документы → чанки → embedding → векторное хранилище» (один раз на документ, 200 страниц → 2000 чанков, минуты). Снизу онлайн-дорожка «запрос → embedding → поиск top-k → промпт → LLM» (на каждый запрос, 1 вектор, миллисекунды). Обе дорожки сходятся в хранилище, между ними — одно векторное пространство.
