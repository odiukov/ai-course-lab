# ai-course-lab

Локальная платформа для прохождения курса ai-engineering-from-scratch:
теория мелкими шагами, интерактивные визуализации, чат в контексте шага,
уточнения, которые остаются в теории навсегда, и прогресс в SQLite.

## Запуск

```bash
cp .env.example .env.local   # прописать COURSE_REPO — только для импорта
npm install
npm run import -- 01-math-foundations__02-vectors-matrices-operations
npm run dev
```

Нужны локально установленные и залогиненные `claude` и `codex` —
генерация и чат идут через них, API-ключи не используются.

Уроки переезжают в `source/` по одному, командой `npm run import`. Уже
импортированные уроки читаются без `COURSE_REPO`.

## Что где

- `source/` — материалы импортированных уроков, правятся руками
- `content/lessons/<slug>/steps/` — сгенерированные шаги, лежат в git
- `content/lessons/<slug>/clarifications/` — ответы из чата, оставленные в теории
- `data/progress.db` — прогресс, чаты и попытки; в git не лежит
- `src/lib/source` — чтение и импорт материалов урока
- `src/lib/content` — файлы шагов, планы уроков, слой уточнений
- `src/lib/agent` — запуск CLI-агентов и разбор их вывода
- `src/lib/generate` — генерация плана, тел шагов и ответов чата
- `src/lib/progress` — SQLite: состояние шагов и сессии чата
- `prompts/` — три промпта, правятся без пересборки

## Как это работает

- Позиция в уроке — в адресе (`/lesson/<slug>?step=N`). База отвечает на вопрос
  «куда открыть» только когда параметра в адресе нет.
- Шаг считается прочитанным в момент нажатия «Дальше» на нём (у последнего шага
  — «Закончить урок»). Ни таймеров, ни эвристик.
- Уточнение всегда принадлежит тому шагу, на котором задан вопрос, и дописывается
  в `clarifications/<step-id>.md`. Текст шага не меняется никогда.
- В промпт следующих шагов уходит дайджест: до 12 вопросов и одно последнее
  уточнение целиком. Урок с сорока уточнениями не раздувает промпт.
- Одновременно работает ровно один агент: чат и генерация стоят в общей очереди.
- Агенту физически нечем тронуть курс: `claude` запускается с `--tools ""` и
  `--strict-mcp-config`, `codex` — с выключенными `shell_tool`, `browser_use` и
  `computer_use` и песочницей только на чтение.

## Ограничения текущего среза

- Редактора кода, Pyright, прогона тестов и bench ещё нет (план 3).
- Квизы (`check` и `quiz`) пока не показываются: у `check` рисуются только те
  вопросы, что уже лежат во фронтматтере, без ответов и без проверки. Таблицы
  `quiz_attempts` и `test_runs` созданы, но никем не заполняются (план 3).
- Уточнение нельзя перенести на другой шаг из интерфейса — только правкой файла.
- Подбор визуализаций по номеру урока корректен только для первой фазы.
- Импорт урока — командой в терминале; кнопки в интерфейсе нет.
