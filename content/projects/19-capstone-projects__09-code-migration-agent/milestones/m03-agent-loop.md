Реализуй агентный слой поверх OpenAI Agents SDK или LangGraph, используя Claude Opus 4.7 и GPT-5.4-Codex для случаев, которые не закрылись рецептами. Агент работает внутри sandbox и получает ограниченный набор инструментов: `run_build`, `read_file`, `edit_file`, `run_test` и `git_diff`. Каждый ход должен иметь наблюдаемую последовательность: получить свежую диагностику, определить тип сбоя, выбрать узкое исправление, применить его и повторно запустить соответствующую проверку.

Классификация должна различать как минимум проблемы зависимостей, синтаксиса, тестов и системы сборки. Сохраняй решение классификатора вместе с исходным фрагментом журнала, применённым patch и новым результатом. Все агентные изменения отделяй от recipe-коммита, чтобы позднее рассчитать вклад каждого слоя. Langfuse должен собирать trace bundle с каждым ходом и фрагментом diff.

Не превращай цикл в неограниченное редактирование репозитория. Агент обязан опираться на последнюю ошибку и проверять эффект после каждого целевого изменения. Если повторный рецепт безопаснее ручного patch, цикл может выбрать рецепт, но этот выбор также должен попасть в трассу. Типичные ошибки — исправлять несколько несвязанных гипотез одновременно, классифицировать сбой без доказательства из лога, считать исчезновение одной ошибки зелёной сборкой и терять связь между изменением и наблюдаемым результатом.
