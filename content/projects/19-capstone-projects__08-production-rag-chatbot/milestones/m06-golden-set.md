Сформируй golden set из 200 пар вопрос–ответ для выбранной регулируемой области. Каждая запись должна содержать экспертный эталон ответа и ссылки на конкретные места исходных документов. Набор должен проверять не только популярные формулировки, но и границы доступа, разные типы документов и случаи, где корректное поведение зависит от нескольких источников. Разметку выполняет доменный эксперт; автоматически сгенерированные ответы без экспертной проверки не становятся ground truth.

Запускай один и тот же развернутый pipeline: policy-фильтр, hybrid retrieval, reranker, Claude, guardrails и citation enforcement. Для всех 200 вопросов вычисляй correctness ответа, exact-citation match, RAGAS faithfulness, answer relevance и context precision. Сохраняй retrieved context и итоговые цитаты, чтобы ошибку можно было отнести к ingestion, retrieval, reranking или synthesis. Не исправляй ответы вручную после прогона и не исключай неудобные вопросы из итоговой сводки.

Локальная `chat_turn` отражает форму одного прохода и возвращаемые цитаты, но конкатенация тестовых фрагментов не является оценкой агента. Типичные ошибки — отсутствие экспертных source anchors, запуск метрик на локальном stub, смешение обучающих запросов с финальной проверкой и отчёт только по среднему без анализа провалов. Итоговый отчёт должен позволять повторить прогон и проверить любую цитату непосредственно в корпусе.
