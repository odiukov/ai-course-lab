Собери Python eval-harness, который клонирует зафиксированный набор из 30 Python issues проверенной части SWE-bench Pro и запускает каждую задачу в свежей песочнице без повторных попыток и просмотра тестовых ответов. Один и тот же список задач, критерий успеха и конфигурация окружения должны использоваться для твоего агента и mini-swe-agent, иначе сравнение pass@1 теряет смысл. Live-SWE-agent используй как второй заявленный ориентир и для проверки архитектурной раскладки, сохраняя сопоставимые условия там, где выполняется прямой прогон.

Для каждой строки результата запиши идентификатор задачи, агента и модель, исход тестов, успех первой попытки, число ходов, токены и стоимость в долларах. Основной артефакт — `eval/results.jsonl`; он должен позволять пересчитать агрегаты без чтения Langfuse. Отчёт показывает pass@1, средние turns-per-task и $-per-task для твоего harness и minimal baseline.

Полный оценочный контур проекта также включает Terminal-Bench 2.0 и собственный holdout из 30 задач, как определено стеком, но они не заменяют обязательное matched-сравнение SWE-bench Pro. Не отбирай задачи после просмотра результатов и не смешивай повторные запуски с pass@1. Типичные ошибки — разные subsets у агентов, потерянные неуспешные строки, стоимость без привязки к задаче и ручное объявление успеха вместо результата официальных тестов.
