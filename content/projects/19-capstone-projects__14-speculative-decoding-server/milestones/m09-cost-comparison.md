Заверши проект экономическим сравнением. На основе фактической стоимости использованных GPU и измеренного устойчивого throughput вычисли стоимость одного миллиона токенов для baseline, EAGLE-3 и выбранной конфигурации P-EAGLE. Проведи расчёт отдельно для двух целевых моделей, поскольку их размещение, throughput и acceptance rate различаются.

Для сопоставления отправь ту же оценочную нагрузку в Anthropic Claude Sonnet 4.7 и OpenAI GPT-5.4. Используй фактическое число токенов и соответствующую стоимость API, а методику подсчёта опиши рядом с результатом. Сравнение должно опираться на один eval, а не на несвязанные рекламные показатели или пиковую скорость локального сервера. Сохрани связь между стоимостью и качеством: итоговая рубрика требует ускорения при сопоставимом качестве.

Инварианты — единая единица `$ / 1M tokens`, один набор оценки и прозрачное происхождение цены GPU и API. Не смешивай входные и выходные токены без объяснения и не экстраполируй стоимость из краткого пикового burst, если sustained throughput ниже. Типичные ошибки: игнорировать количество GPU в tensor-parallel реплике, использовать разные eval для провайдеров и публиковать только наиболее выгодный speculative-режим без baseline.

Локальный scaffold не учитывает время GPU, облачную цену или биллинг API, поэтому contract target для этапа отсутствует. Финальная таблица должна позволять перепроверить формулу из исходных токенов, длительности, числа GPU и стоимости каждого внешнего прогона.
