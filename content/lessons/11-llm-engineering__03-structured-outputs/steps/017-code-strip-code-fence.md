Ты уже видел из [шага 16](#step-16), в каком виде строка реально приходит от модели: сначала «Here's the JSON:», потом ```` ```json ````, потом сам объект, потом закрывающие обратные кавычки. Отдать это `json.loads` — получить `JSONDecodeError` на первом же символе.

Первое, что приходит в голову: `text.replace("```", "")`. Попробуй и посмотри, что останется. Слово `json` после открывающих кавычек никуда не денется — оно окажется прямо перед `{`, и парсер снова упадёт. А если модель вообще не поставила заборчик и вернула чистый объект, замена сделает ровно ничего — и это единственный случай, где наивный вариант сработал.

Значит, функции нужно уметь различать ситуации, а не слепо резать символы.

`strip_code_fence(text: str) -> str` принимает сырой ответ и возвращает строку без обёртки. Ничего не парсит и ничего не чинит — только снимает упаковку. Что она должна выдерживать:

- заборчика нет вообще — вернуть текст как есть, не упав и не откусив лишнего;
- открывающая строка бывает ```` ```json ````, ```` ```JSON ```` или просто ```` ``` ```` — метка языка необязательна;
- вокруг заборчика есть текст: преамбула сверху, иногда комментарий снизу;
- закрывающего заборчика может не быть — ответ оборвался по лимиту токенов;
- по краям остаются пробелы и переводы строк.

Удобный подход — идти по строкам, а не по символам: найти строку, которая начинается с трёх кавычек, и строку, которая их закрывает, и вернуть то, что между ними. Тогда кавычки внутри значения JSON тебя не собьют.

Проверь на четырёх входах: чистый объект, объект в ```` ```json ````, объект с преамбулой и заборчиком, объект без закрывающих кавычек. Хороший признак — идемпотентность: прогони результат через функцию второй раз, строка не должна измениться.

> 🎒 **На пальцах.** Тебе пришло письмо в конверте. Ты берёшь нож и режешь по краю: конверт вскрыт, лист цел. Режешь на сантиметр глубже — вместе с бумагой распорот текст. А если письмо принесли без конверта, резать вообще нечего, и нож надо отложить, а не полоснуть по листу наугад. `strip_code_fence` — это тот самый нож: он умеет вскрывать конверт и умеет узнавать, что конверта нет.
