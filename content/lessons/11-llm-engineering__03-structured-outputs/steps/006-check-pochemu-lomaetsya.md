check:
  - question: >-
      Ты дописал в промпт «Отвечай строго в JSON, без пояснений» и установил
      температуру 0. Почему это всё равно не даёт формальной гарантии валидного
      JSON?
    options:
      - >-
        Генерация становится более повторяемой, но самый вероятный токен всё ещё
        может оказаться несовместимым с синтаксисом JSON
      - >-
        Температура 0 автоматически разрешает модели выбирать только токены,
        допустимые по JSON-грамматике
      - >-
        Строгая инструкция в промпте автоматически преобразуется API в
        обязательную JSON Schema
    correct: 0
    explanation: >-
      Температура 0 обычно делает выбор детерминированным, но не добавляет
      проверку грамматики. Если наиболее вероятное продолжение нарушает JSON,
      модель воспроизведёт ту же ошибку. Гарантия появляется только при явном
      ограничении допустимых токенов.
  - question: >-
      Модель уже сгенерировала имя поля price и двоеточие. Почему одной
      инструкции «отвечай в JSON» недостаточно для защиты следующего шага
      генерации?
    options:
      - >-
        Модель принципиально не умеет генерировать числовые значения после
        двоеточия
      - >-
        Допустимые продолжения зависят от текущего префикса, а промпт не
        исключает из выбора несовместимые с ним токены
      - >-
        После двоеточия контекстное окно очищается и исходная инструкция
        исчезает
    correct: 1
    explanation: >-
      После такого префикса JSON-грамматика допускает лишь небольшой набор
      продолжений, тогда как словарь содержит около 100 тысяч токенов. Промпт
      повышает вероятность подходящих вариантов, но только constrained decoding
      обнуляет вероятность остальных.
---

Прежде чем идти дальше, стоит проверить одну вещь: ты должен уметь объяснить, почему добавление слов в промпт не решает задачу принципиально, а не «недостаточно хорошо». Разница между «редко ломается» и «не может сломаться» — именно та, из-за которой существует всё остальное в этом уроке.

Чаще всего спотыкаются на двух местах. Первое: кажется, что температура 0 или более строгая формулировка закрывают вопрос — но обнулить вероятности лишних токенов они не могут, только придавить. Второе: пропускают, что ограничение зависит от позиции: после `{"price":` разрешено одно, после закрытой скобки — другое, и запрет каждый раз новый.
