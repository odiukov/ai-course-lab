Сначала выбери способ разбиения: `kfold_split` из [шага 36](#step-36) или `stratified_kfold_split` из [шага 41](#step-41). Затем для каждой пары `train_idx, val_idx` собери `X_train`, `y_train`, `X_val` и `y_val`.

Особенно внимательно посмотри на создание модели. `model_fn` — это функция, которая возвращает новый, ещё не обученный объект модели. Вызывать её нужно внутри цикла: как разобрано в [шаге 44](#step-44), каждый fold должен начинаться с чистой модели. Если переиспользовать прежний объект, он может перенести знания из предыдущей итерации.

Обучай модель только на `X_train` и `y_train`, а предсказания получай только для `X_val`. Если передана `metric_fn`, вызови её с правильными ответами и предсказаниями. Если нет — посчитай accuracy тем же принципом, который ты реализовал в [шаге 15](#step-15).

Функция должна вернуть список из `k` чисел — по одной оценке для каждого fold. Не объединяй их в одно число: сейчас твоя задача — аккуратно провести все проверки и ничего не потерять.

> 🎒 **На пальцах.** Представь эстафету из пяти забегов. В каждом забеге команда тренируется на четырёх участках трассы, а время засекают на оставшемся. Перед новым забегом ты выдаёшь свежую машину, а не ту, которая уже проехала предыдущий маршрут. В итоге у тебя пять отдельных результатов — по одному для каждого проверочного участка.
