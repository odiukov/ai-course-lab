---
id: 009-leakage-check
type: check
title: 'Проверка: нашёл ли нормализатор утечку'
source_anchor: '### Common Evaluation Mistakes'
check:
  - question: >-
      Ты сначала разделил 300 объектов, а затем посчитал среднее и стандартное
      отклонение только по train. Как обработать validation и test?
    options:
      - >-
        Для каждой выборки посчитать собственные среднее и стандартное
        отклонение
      - 'Применить к обеим выборкам параметры, полученные на train'
      - Объединить все выборки и пересчитать параметры точнее
    correct: 1
    explanation: >-
      Нормализатор обучается только на train. Validation и test он преобразует с
      уже зафиксированными параметрами, поэтому информация из них не
      просачивается в обучение.
  - question: >-
      Нормализатор настроили на всех данных, а разделение сделали после этого.
      Почему оценке на test нельзя полностью доверять?
    options:
      - Нормализатор заранее использовал сведения о тестовых объектах
      - После нормализации тестовая выборка становится слишком маленькой
      - Модель обязательно запоминает ответы для каждого тестового объекта
    correct: 0
    explanation: >-
      Даже без целевых ответов параметры нормализации уже описывают test.
      Значит, тестовая информация повлияла на подготовку модели, и проверка
      перестала быть полностью независимой.
---

Здесь важно поймать не сам факт нормализации, а момент её настройки. После разделения из [шага 8](#step-8) нормализатор вычисляет параметры только по train, а validation и test лишь преобразует с этими готовыми числами.

Частая ловушка звучит разумно: «Возьму все данные — среднее получится точнее». Но точнее для всей коллекции означает, что test уже подсказал, как её обрабатывать. Проверка больше не изображает встречу с действительно незнакомыми данными.

> 🎒 **На пальцах.** Ты готовишься к турниру по дартсу и настраиваешь прицел по тренировочной мишени. Если перед выступлением тебе разрешили измерить расположение зачётной мишени и подправить прицел, результат уже нечестный. Правило простое: настройка — только на тренировочной мишени; на зачётной ты пользуешься тем, что уже настроил.
