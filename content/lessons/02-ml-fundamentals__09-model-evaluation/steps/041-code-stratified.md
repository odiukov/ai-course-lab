Перед тобой метки классов, например `[0, 1, 0, 0, 1, 0]`. Если перемешать все индексы вместе, редкие единицы могут случайно оказаться лишь в одной проверочной части. В [шаге 40](#step-40) ты разобрал идею стратификации; теперь преврати её в функцию `stratified_kfold_split(y, k=5, seed=42)`.

Сначала собери словарь, где каждой метке соответствует список исходных индексов. Для примера выше у класса `0` будут индексы `0, 2, 3, 5`, а у класса `1` — `1, 4`. Перемешивай списки отдельно, но устанавливай `seed` только один раз перед этим: так результат можно воспроизвести.

Затем подготовь `k` пустых фолдов. Каждый список класса разрежь на `k` частей. Индексы очередной части добавляй в `val` соответствующего фолда, а все остальные индексы этого же класса — в `train`. Используй `extend`, иначе внутри фолда появятся вложенные списки.

Следи за остатком от деления: последняя часть должна доходить до конца списка класса, как в [шаге 37](#step-37). Верни тот же формат, что у функции из [шага 36](#step-36): список пар `(train_idx, val_idx)`.

Проверь два свойства: ни один индекс не потерялся, а каждый объект оказался в validation ровно один раз. Если это выполнено, отдельные разрезы классов правильно собрались в общие фолды.

> 🎒 **На пальцах.** Представь билеты разных цветов и пять лотков. Ты сначала перемешиваешь билеты каждого цвета отдельно, затем раскладываешь часть каждого цвета по каждому лотку. Один лоток становится validation, а билеты из остальных лотков — train. Так ты не надеешься, что редкий цвет распределится удачно сам: ты управляешь его раскладкой напрямую.
