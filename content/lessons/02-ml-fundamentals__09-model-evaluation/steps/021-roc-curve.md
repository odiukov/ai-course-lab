title: ROC-кривая проверяет модель при разных порогах

Антифрод-модель ставит каждому платежу оценку подозрительности от 0 до 1. Ты выбираешь порог 0,9 — и блокируются только самые подозрительные операции. Из 40 мошеннических платежей модель ловит 24, а из 960 честных ошибочно останавливает 3. Кажется, результат неплохой. Но что изменится при пороге 0,4?

Теперь модель ловит уже 36 мошеннических платежей, зато блокирует 70 честных. Как и в [шаге 19](#step-19), сдвиг порога изменил два вида ошибок. Поэтому оценивать модель только при одном пороге рискованно: случайно выбранная граница может представить её слишком осторожной или слишком тревожной.

ROC-кривая перебирает разные пороги и для каждого записывает пару показателей:

- **True positive rate** — долю пойманных положительных случаев. Это уже знакомый тебе recall из [шага 17](#step-17).
- **False positive rate** — долю отрицательных случаев, которые модель ошибочно назвала положительными: $FPR = \frac{FP}{FP + TN}$. Здесь $FP$ — ложные тревоги, а $TN$ — верно распознанные отрицательные случаи из [шага 10](#step-10).

Каждый порог даёт одну такую пару. Вместе эти пары показывают, сколько дополнительных правильных срабатываний ты получаешь ценой дополнительных ложных тревог. ROC-кривая не выбирает порог за тебя — она раскрывает поведение модели во всём диапазоне возможных решений.

> 🎒 **На пальцах.** Представь судью фотоконкурса, который меняет минимальную оценку для выхода в финал. Высокая планка пропускает мало сильных снимков, но почти не допускает слабые. Снижая её, судья сохраняет больше достойных работ, одновременно пропуская больше неудачных. ROC-кривая — это запись результатов при каждой возможной планке, а не только при одной выбранной заранее.
