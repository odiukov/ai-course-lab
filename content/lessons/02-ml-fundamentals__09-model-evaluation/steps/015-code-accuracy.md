Ты проверяешь модель на восьми снимках и получаешь четыре счётчика: `tp = 3`, `tn = 3`, `fp = 1`, `fn = 1`. Теперь нужно превратить их в одно число, чтобы быстро увидеть результат: модель дала шесть верных ответов из восьми, значит accuracy равна `0.75`.

Напиши функцию `accuracy(y_true, y_pred)`. Внутри вызови `confusion_matrix` из [шага 13](#step-13) и распакуй её результат именно в том порядке, в котором функция возвращает значения: `tp`, `tn`, `fp`, `fn`.

Дальше найди общее количество проверенных примеров. Для этого сложи все четыре счётчика: каждый ответ модели обязательно попадает в один из них. Затем сложи два счётчика верных ответов и раздели результат на общее количество. Сам принцип этого расчёта разобран в [шаге 14](#step-14), поэтому здесь твоя задача — аккуратно перенести его в функцию.

Есть один крайний случай: списки могут оказаться пустыми. Тогда общее количество равно нулю, и делить на него нельзя. Пусть функция в такой ситуации возвращает `0.0`.

Проверь себя на трёх случаях: шесть верных ответов из восьми должны дать `0.75`, полностью неверные предсказания — `0.0`, а пустые списки — тоже `0.0`. Так функция будет считать результат и не сломается, когда считать пока нечего.

> 🎒 **На пальцах.** Представь сотрудника кинотеатра после сеанса: он складывает в четыре коробки правильно и ошибочно проверенные билеты. Чтобы оценить его работу, ты сначала считаешь все билеты, затем — только правильно проверенные. Но если сеанс отменили и коробки пусты, долю вычислить нельзя: разумнее записать `0.0`, чем пытаться делить на ноль.
