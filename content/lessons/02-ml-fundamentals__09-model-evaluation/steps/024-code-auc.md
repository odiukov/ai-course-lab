Ты получил от `roc_curve` три списка: значения FPR, значения TPR и пороги. Теперь нужно превратить набор точек в одно число — AUC из [шага 23](#step-23). Но складывать сами значения TPR нельзя: площадь зависит ещё и от расстояния между соседними точками по горизонтали.

Функция `auc_roc(y_true, y_scores)` сначала должна вызвать уже написанную `roc_curve`. Пороги ей дальше не понадобятся, поэтому третий результат можно принять в переменную `_` — так в Python обычно показывают: «это значение намеренно не использую».

Затем соедини каждый FPR с соответствующим TPR с помощью `zip` и отсортируй пары по FPR. Это важно: площадь нужно считать слева направо, иначе ширина очередного участка может стать отрицательной.

Теперь пройди по соседним точкам, начиная со второй. Для каждой пары вычисли:

- ширину — разницу между текущим и предыдущим FPR;
- среднюю высоту — полусумму текущего и предыдущего TPR;
- площадь участка — ширину, умноженную на среднюю высоту.

Добавляй каждый участок к переменной `area`, изначально равной `0.0`, а после цикла верни накопленное значение. Если у двух соседних точек одинаковый FPR, ширина будет нулевой — такой вертикальный участок площади не добавит.

Для самопроверки возьми `y_true = [0, 1, 0, 1]` и `y_scores = [0.1, 0.9, 0.2, 0.8]`. Положительные объекты получили более высокие оценки, поэтому результат должен быть `1.0`.

> 🎒 **На пальцах.** Представь участок земли с неровной верхней границей. Ты делишь его вертикальными линиями на узкие полосы. У каждой полосы известны ширина и две высоты по краям, поэтому берёшь среднюю высоту и находишь площадь. Складывая полосы слева направо, ты получаешь площадь всего участка — именно так `auc_roc` собирает одно число из точек ROC-кривой.
