check:
  - question: >-
      У тебя 1000 операций, из них только 20 мошеннических. Какое разбиение даст
      более надёжную оценку модели?
    options:
      - >-
        Обычное: редкие случаи обязательно равномерно распределятся после
        перемешивания
      - >-
        Стратифицированное: доля мошеннических операций будет примерно сохранена
        в каждой части
      - 'Обычное: все мошеннические операции нужно поместить только в validation'
    correct: 1
    explanation: >-
      При сильном дисбалансе стратификация распределяет объекты каждого класса
      между частями примерно в исходной пропорции. Обычное случайное разбиение
      такой гарантии не даёт.
  - question: >-
      При обычном разбиении одна validation-часть случайно получила только один
      объект редкого класса. Чем это опасно?
    options:
      - Модель не сможет обучаться на объектах распространённого класса
      - Размер validation-части автоматически станет меньше
      - >-
        Оценка качества на редком классе будет сильно зависеть от единственного
        предсказания
    correct: 2
    explanation: >-
      Если редкий класс представлен одним объектом, единственная ошибка резко
      изменит recall и другие зависящие от этого класса метрики. Такая оценка
      будет нестабильной.
---

Теперь ты должен уметь выбирать способ разбиения по распределению классов. Обычный K-fold допустим, когда классы представлены достаточно широко и случайные различия между частями не создают проблемы. При редком классе выбирай стратифицированный вариант из [шага 40](#step-40): он сохраняет его долю в каждой части. Частая ловушка — смотреть только на одинаковый размер частей. Равное число объектов ещё не означает одинаковое представительство классов.

> 🎒 **На пальцах.** Ты раскладываешь по пяти конвертам 100 билетов, среди которых лишь 10 красных. Если перемешать их без контроля, один конверт может остаться почти без красных. Если сначала распределить красные, а затем остальные, каждый конверт даст более честное представление всей пачки.
