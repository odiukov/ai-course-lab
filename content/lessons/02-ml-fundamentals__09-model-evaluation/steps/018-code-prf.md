Ты получил предсказания модели и хочешь вывести рядом три числа: precision, recall и F1. Если для каждого числа заново собирать матрицу ошибок, одни и те же пары ответов придётся проверять несколько раз. Удобнее один раз получить четыре счётчика с помощью функции из [шага 13](#step-13), а затем рассчитать все три результата.

Напиши функцию с такой заготовкой:

```python
def precision_recall_f1(y_true, y_pred):
    # твой код
```

Функция должна вернуть кортеж именно в порядке `precision, recall, f1`. Формулы уже разобраны в [шаге 17](#step-17), поэтому сосредоточься на последовательности вычислений и пограничных случаях.

На что смотреть:

- вызови `confusion_matrix` только один раз;
- если у precision знаменатель равен нулю, прими precision за `0.0`;
- так же поступи с recall;
- вычисляй F1 из уже найденных precision и recall;
- если их сумма равна нулю, верни F1 как `0.0`.

Проверь функцию на таком примере:

```python
y_true = [1, 1, 1, 0, 0]
y_pred = [1, 0, 1, 1, 0]
```

Здесь `TP = 2`, `FP = 1`, `FN = 1`, поэтому все три метрики получатся примерно равны `0.67`. Затем попробуй случай, где модель ни разу не предсказала класс `1`: функция не должна падать из-за деления на ноль.

Главная проверка — не только правильные числа, но и правильный порядок возвращаемых значений.

> 🎒 **На пальцах.** Представь прибор с тремя индикаторами. Сначала ты один раз снимаешь четыре показания с датчиков — `TP`, `TN`, `FP` и `FN`. Затем каждый индикатор использует нужные ему показания. Если для расчёта не хватает ни одного подходящего случая, прибор показывает ноль, а не выдаёт ошибку.
