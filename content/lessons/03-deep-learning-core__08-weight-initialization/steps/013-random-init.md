Перед тобой заготовка `random_init(fan_in, fan_out, scale=1.0)`. Она должна собрать такую же по форме матрицу, как `zero_init` из [шага 7](#step-7): `fan_out` строк, в каждой — `fan_in` чисел. Но теперь вместо нулей каждая ячейка получает отдельное случайное значение.

Для одного веса вызови `random.gauss(0, scale)`. Первый аргумент `0` задаёт центр распределения: положительные и отрицательные веса появляются вокруг нуля. Второй аргумент — знакомый из [шага 12](#step-12) `scale`, то есть стандартное отклонение. Не подставляй вместо него постоянное число, иначе параметр функции перестанет что-либо менять.

Здесь легко случайно создать одно число, а затем повторить его во всей строке или матрице. Такой результат выглядит случайным, но нейроны снова получают одинаковые веса. Поэтому вызов `random.gauss` должен происходить заново для каждой ячейки.

После реализации проверь три вещи: при `fan_in=3` и `fan_out=2` получаются две строки по три числа; соседние строки обычно различаются; вызов с маленьким `scale` даёт значения, которые держатся ближе к нулю. Не жди конкретных чисел — при каждом запуске они могут быть другими.

Твоя задача — сохранить форму `fan_out × fan_in`, но наполнить каждую позицию самостоятельным случайным весом.

> 🎒 **На пальцах.** Представь поднос с шестью стаканами: два ряда по три. Ты бросаешь отдельную щепотку специй в каждый стакан, причём `scale` регулирует размер щепотки. Если один раз отмерить специи и разложить ту же порцию повсюду, стаканы снова окажутся одинаковыми. Поэтому новое случайное значение нужно получать для каждого стакана отдельно.
