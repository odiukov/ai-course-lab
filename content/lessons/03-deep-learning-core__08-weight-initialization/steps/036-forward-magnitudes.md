Ты запускаешь сеть из 50 слоёв и хочешь получить не тысячи активаций, а 50 понятных чисел — по одному для каждого слоя. Именно такой список должна вернуть `forward_magnitudes`.

Сначала функция создаёт `n_samples` случайных входов ширины `width`. Затем на каждом слое она:

1. создаёт новую матрицу весов через `init_fn(width, width)` и нулевые смещения;
2. прогоняет каждый вход через слой, используя написанную в [шаге 21](#step-21) функцию `matvec`;
3. применяет `activation_fn` к каждому полученному значению;
4. сохраняет выходы как входы следующего слоя.

После этого нужно измерить величину активаций, как обсуждалось в [шаге 34](#step-34). Для одного образца возьми модули всех его значений и найди их среднее. Потом усредни результаты по всем образцам и добавь одно получившееся число в `layer_magnitudes`.

Следи за порядком действий: метрика считается **после** функции активации, а следующий слой получает уже преобразованные выходы предыдущего. Матрицу весов тоже нужно создавать заново внутри цикла слоёв — иначе все уровни случайно будут использовать один набор весов.

В конце длина возвращённого списка должна совпадать с `n_layers`. Каждый его элемент отвечает ровно одному слою.

> 🎒 **На пальцах.** Представь эстафету из 50 пунктов. На каждом пункте команда проходит новое испытание, а судья записывает средний уровень энергии участников. Участники затем бегут дальше уже с оставшейся энергией. `forward_magnitudes` не хранит подробный дневник каждого бегуна: она возвращает 50 записей судьи, чтобы ты увидел, как менялся общий масштаб по пути.
