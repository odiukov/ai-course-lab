Ты создаёшь слой с 3 входами и 5 нейронами. Какой формы должна получиться матрица весов? Пять строк по три числа: одна строка на каждый нейрон, один столбец на каждый вход. Но заполнить её просто случайными числами недостаточно — нужен масштаб Xavier.

Допиши `xavier_init(fan_in, fan_out)` в два действия. Сначала вычисли `std` по формуле из [шага 26](#step-26): используй `math.sqrt`, сумму `fan_in + fan_out` и вещественное число `2.0`. Затем создай список из `fan_out` строк, в каждой из которых находится `fan_in` случайных весов. Каждый вес получай через `random.gauss`: среднее должно быть нулевым, а стандартным отклонением служит вычисленный `std`.

Ориентируйся на устройство `random_init` из [шага 13](#step-13), но не принимай `scale` снаружи. Здесь масштаб однозначно определяется размерами слоя.

Особенно внимательно проверь порядок размеров. Внешний цикл отвечает за строки, поэтому повторяется `fan_out` раз. Внутренний отвечает за столбцы и повторяется `fan_in` раз. Для вызова с `fan_in=3` и `fan_out=5` результат должен содержать ровно пять списков по три случайных числа. Значения при повторных вызовах будут отличаться — постоянными остаются форма матрицы и правило выбора их разброса.

> 🎒 **На пальцах.** Представь раскрой ткани для пяти одинаковых флажков: на каждый нужны три детали. Сначала ты выбираешь ширину допустимого разброса размеров по правилам Xavier, затем вырезаешь пять наборов по три детали. Детали немного различаются случайно, но не выходят в совершенно другой масштаб. Число наборов задаёт `fan_out`, а деталей в наборе — `fan_in`.
