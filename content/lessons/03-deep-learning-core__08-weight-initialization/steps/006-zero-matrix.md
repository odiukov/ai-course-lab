Ты задаёшь слою два числа: `fan_in = 4` и `fan_out = 3`. Как понять, где строки, а где столбцы? Посмотри на один выходной нейрон. Он получает четыре входных значения, поэтому ему нужны четыре веса — по одному для каждого входа. Эти четыре веса занимают одну строку. Выходных нейронов три, значит таких строк будет три.

Получается матрица размером `fan_out × fan_in`: 3 строки по 4 значения. `fan_out` отвечает за количество нейронов на выходе слоя, а `fan_in` — за количество входящих связей у каждого из них.

При нулевой инициализации все двенадцать ячеек получают значение `0.0`. Проверь строки по очереди: у первого нейрона четыре нуля, у второго — те же четыре нуля, у третьего — снова они же. Матрица имеет правильный размер, но внутри неё нет ничего, что отличало бы настройки одного нейрона от настроек другого.

Именно так проблема одинаковых весов из [шага 5](#step-5) выглядит на уровне матрицы: каждый нейрон занимает отдельную строку, однако все эти строки начинаются одинаково. Разные места в матрице ещё не означают разные начальные настройки.

> 🎒 **На пальцах.** Представь пульт для трёх прожекторов. У каждого прожектора есть четыре регулятора — по одному для четырёх управляющих сигналов. Поэтому на пульте три ряда по четыре ручки. Если каждую ручку выставить в ноль, ряды физически разные, но настроены совершенно одинаково: ни один прожектор пока не получил собственной комбинации настроек.
