check:
  - question: 'Четыре нейрона выдали 0,5 на одном входе. Какой вывод обоснован?'
    options:
      - Сеть здорова и готова к обучению
      - Параметры всех нейронов обязательно одинаковы
      - >-
        На этом входе выходы совпали, но для проверки симметрии нужно
        исследовать параметры нейронов
    correct: 2
    explanation: >-
      Совпадение четырёх выходов описывает поведение только на выбранном входе.
      Разные строки весов тоже могут дать одинаковые значения z и одинаковые
      выходы.
  - question: >-
      Строки весов четырёх нейронов различаются, но на нулевом входе все они
      выдали 0,5. Что это означает для симметрии параметров?
    options:
      - 'Симметрия нарушена, поскольку строки весов различаются'
      - 'Симметрия сохранена, поскольку выходы совпали'
      - Это можно определить только после первого обновления весов
    correct: 0
    explanation: >-
      На нулевом входе вклад любых весов в z равен нулю, поэтому различия
      параметров могут не проявиться в выходах. Различающиеся строки весов уже
      нарушают симметрию между нейронами.
---

Здесь важно не перепутать наблюдение с диагнозом. Четыре значения 0,5 говорят только о поведении сети на одном входе. Проверять внутреннее различие нейронов нужно по строкам весов, как в [шаге 8](#step-8); для этого ты написал `is_symmetry_broken` в [шаге 9](#step-9). Частая ошибка — принять одинаковый результат за доказательство одинакового устройства.

> 🎒 **На пальцах.** Четыре весы показали ровно 1 кг для одной гири. Это не доказывает ни их исправность, ни одинаковую поломку: на других предметах показания могут разойтись. Один результат описывает только эту проверку; чтобы понять, одинаково ли устроены приборы, нужно заглянуть внутрь.
