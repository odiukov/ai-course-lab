Ты вызываешь `zero_init(3, 2)` и ожидаешь матрицу для двух нейронов, каждый из которых принимает три входа. Здесь легко машинально перепутать параметры и построить три строки по два элемента. Поэтому сначала зафиксируй ожидаемый результат: **2 строки, в каждой по 3 значения `0.0`**.

```python
def zero_init(fan_in, fan_out):
    # создай и верни матрицу нужной формы
    pass
```

Как разобрано в [шаге 6](#step-6), `fan_out` задаёт количество строк, а `fan_in` — количество элементов внутри каждой строки. Значит, внешний повтор создаёт строки, а внутренний наполняет каждую строку нулями.

Функция должна:

- вернуть список строк, а не одно число и не плоский список;
- создать ровно `fan_out` строк;
- поместить ровно `fan_in` значений `0.0` в каждую строку;
- создать строки как отдельные списки.

Последний пункт пригодится, если позже ты изменишь один вес: изменение элемента в первой строке не должно внезапно менять остальные строки. Поэтому не размножай одну и ту же готовую строку ссылками — создавай каждую заново.

Для самопроверки возьми неравные размеры, например `fan_in=3` и `fan_out=2`: так перестановка аргументов сразу станет заметна. Если получились две независимые строки по три нуля, контракт функции выполнен.

> 🎒 **На пальцах.** Представь лоток с двумя рядами по три пустые ячейки. `fan_out` говорит, сколько сделать рядов, а `fan_in` — сколько ячеек выдавить в каждом. Недостаточно изготовить один ряд и дважды приклеить на него одну этикетку: нужны два самостоятельных ряда, даже если сейчас все их ячейки выглядят одинаково.
