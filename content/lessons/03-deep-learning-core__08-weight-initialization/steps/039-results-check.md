Перед тобой шесть строк измерений, и главная ловушка — выбрать победителя только по последнему числу. Используй признаки из [шага 38](#step-38): стабильный средний модуль ещё не доказывает, что внутри слоя сохранилось разнообразие сигналов.

Сначала отдели мёртвую константу Zero init + Sigmoid от настоящей стабильности. Затем найди две противоположные аварии: большой случайный масштаб с ReLU разгоняет значения, маленький — постепенно стирает их. Наконец, сравни Xavier и Kaiming не по одному слою, а по всей траектории: здоровый запуск удерживает управляемый масштаб без превращения всех нейронов в одинаковые копии.
