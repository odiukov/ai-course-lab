Ты подаёшь функции две фразы с почти одинаковыми словами: «Кот спит на диване» и «Кот не спит на диване». Лексическое пересечение высокое, но итогом должно стать противоречие. Значит, `nli_scores` нельзя строить только вокруг одного удачного сигнала: ей предстоит собрать результаты нескольких уже написанных функций и согласовать их.

Функция принимает `premise` и `hypothesis`. Сначала обработай обе строки через `tokenize` из [шага 11](#step-11). Затем вычисли пересечение функцией из [шага 15](#step-15) и отдельно проверь отрицание в каждом наборе токенов с помощью `has_negation` из [шага 13](#step-13). Важно сравнить два результата проверки: противоречие усиливается именно тогда, когда отрицание есть только с одной стороны.

Из этих сигналов составь три сырые оценки по правилу из [шага 19](#step-19): для entailment, contradiction и neutral. После этого передай все три оценки одним списком в `softmax` из [шага 18](#step-18) и верни полученное распределение в порядке, указанном в заготовке.

Не применяй `softmax` к каждой оценке отдельно и не округляй результат внутри функции. При самопроверке посмотри, что возвращаются три числа от 0 до 1, а их сумма близка к 1. Высокое пересечение должно поднимать entailment, несовпадение отрицаний — contradiction, а слабое пересечение без явного конфликта — neutral.

> 🎒 **На пальцах.** Представь пульт с тремя лампами. Пересечение слов поворачивает регулятор в сторону зелёной лампы, несовпавшее отрицание — в сторону красной, а нехватка общих деталей оставляет преимущество жёлтой. `nli_scores` сначала выставляет регуляторы, а затем `softmax` распределяет между лампами один общий запас яркости. Поэтому каждую лампу нельзя настраивать изолированно.
