Ты передаёшь модели контекст и одно атомарное утверждение, а в ответ получаешь три элемента: например, `neutral` — 0,06, `entailment` — 0,81 и `contradiction` — 0,13. Теперь программе нужен не список вероятностей, а простой ответ: утверждение подтверждено или нет.

Напиши `is_faithful`, которая принимает `claim`, `context` и необязательный `threshold` со значением 0,5. Контекст отправляй как `text`, то есть premise, а утверждение — как `text_pair`, то есть hypothesis. Почему роли именно такие, можно сверить с [шагом 2](#step-2).

NLI-пайплайн возвращает внешний список с результатом для каждой входной пары. Поскольку пара одна, тебе нужен первый результат. Внутри найди элемент с меткой `entailment` и сравни его `score` с порогом, как в [шаге 31](#step-31). Если оценка строго больше порога, функция возвращает `True`; иначе — `False`. При оценке ровно 0,5 и пороге 0,5 результат будет `False`.

Не полагайся на позицию `entailment` в списке: порядок меток у разных моделей может отличаться. Ищи нужный словарь по значению поля `label`. Проверь функцию хотя бы на двух случаях: подтверждённом утверждении с высокой оценкой entailment и неподтверждённом — с низкой.

Здесь проверяется ровно одно атомарное утверждение из [шага 29](#step-29). Поэтому результат булевый: либо контекст прошёл проверку для этого факта, либо нет.

> 🎒 **На пальцах.** Представь лаборанта, который получает три пробирки с подписями, стоящими каждый раз в разном порядке. Ему нужна пробирка `entailment`, поэтому брать вторую по счёту опасно — сначала надо прочитать этикетку. Затем он сверяет показание с допустимой отметкой: выше порога — ставит зелёный штамп, не выше — красный. `is_faithful` делает ровно такой один штамп.
