Перед тобой метки трёх объектов: `0, 1, 0`. Сеть не должна принять их за обычные числа, где `1` будто «больше» или «сильнее» `0`. Поэтому твоя функция `one_hot` должна заменить каждую метку вектором-переключателем, который мы разобрали на [шаге 5](#step-5).

Для двух классов результат должен содержать две позиции: у класса `0` включена первая, у класса `1` — вторая. Значит, для меток `0, 1, 0` получится три вектора: `[1, 0]`, `[0, 1]`, `[1, 0]`.

Допиши заготовленную функцию. Она должна:

- создать для каждой метки вектор длиной по числу классов;
- сначала заполнить все позиции нулями;
- поставить единицу только на позиции, номер которой совпадает с меткой;
- сохранить порядок входных меток.

Проверь не только отдельные числа, но и форму результата. Если на входе пакет из трёх меток и классов два, на выходе нужны три строки по два числа. Частая ошибка — вернуть один общий вектор для всего пакета или поставить единицы по номерам строк, а не по значениям меток.

После реализации попробуй мысленно поменять одну метку `0` на `1`: в соответствующей строке единица должна перескочить из первой позиции во вторую, а остальные строки — остаться прежними.

> 🎒 **На пальцах.** Представь гардероб с двумя ячейками для жетонов. Число на жетоне не измеряет его ценность, а указывает нужную ячейку. Метка `0` кладёт жетон в первую ячейку, метка `1` — во вторую. `one_hot` записывает состояние гардероба: занятая ячейка получает `1`, свободная — `0`.
