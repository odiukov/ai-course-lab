Клетка агента хранится одним числом: например, `5`. Но если передать сети просто пятёрку, она может принять номер клетки за величину: будто клетка `10` «вдвое больше» клетки `5`. Нам нужна форма из [шага 7](#step-7), где номер лишь выбирает активную позицию.

Напиши функцию `one_hot`, которая принимает номер состояния и общее количество состояний. Она должна вернуть список нужной длины, заполненный нулями, а на позиции состояния поставить единицу.

Проверь результат на конкретных примерах:

- для состояния `0` единица стоит в самом начале;
- для состояния `5` — на шестой позиции, потому что Python считает позиции с нуля;
- для состояния `15` при длине `16` — в самом конце.

У результата всегда должны выполняться три условия: длина равна числу состояний, единица ровно одна, сумма всех элементов равна `1`. Особенно внимательно проверь границы: состояние `16` уже не помещается в вектор длины `16`.

Не записывай единицу в позицию `state + 1`: номер состояния уже совпадает с индексом списка. Когда эти проверки проходят, функция действительно кодирует клетку, а не случайно сдвигает весь мир на одну позицию.

> 🎒 **На пальцах.** Представь ряд из 16 почтовых ящиков. Номер состояния — это не количество писем, а адрес нужного ящика. Для состояния `5` ты кладёшь одну открытку в ящик с индексом `5`, а остальные оставляешь пустыми. Если положить открытку в следующий ящик, адрес изменится — сеть получит уже другую клетку.
