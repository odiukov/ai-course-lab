Тебе нужно выбрать исправление не по слову «артефакт», а по наблюдаемому поведению. Неподвижная яркая капля указывает на проблему нормализации: здесь помогает демодуляция весов из [шага 34](#step-34). Текстура, которая при движении объекта цепляется за пиксели, выдаёт алиасинг: это случай alias-free операций из [шага 35](#step-35).

Частая ловушка — поменять эти решения местами. Проверь причинную связь: демодуляция не учит свёртку понимать движение объекта, а фильтрация пиксельной сетки не устраняет способ спрятать экстремальный сигнал в карте признаков. Один симптом — одно соответствующее вмешательство.
