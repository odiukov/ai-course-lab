У тебя есть два вектора стиля — `w_a` и `w_b` — и, например, 18 точек их применения. Соблазнительно усреднить векторы, но тогда каждый слой получит одну и ту же смесь. Нужен другой результат: до выбранной границы слои должны получать только A, после неё — только B, как описано в [шаге 23](#step-23).

Функция `style_mixing` должна собрать последовательность стилей для всех слоёв синтеза. Договоримся: слой с индексом меньше `cutoff` получает `w_a`, а слой с индексом `cutoff` и все последующие — `w_b`. Значит, при `cutoff = 0` вся последовательность состоит из B, а при `cutoff = num_layers` — из A. Эти крайние случаи особенно полезны для проверки ошибки «на один слой».

Не изменяй сами `w_a` и `w_b` и не вычисляй их среднее. На каждой позиции ты лишь выбираешь один из двух готовых векторов. Результат должен содержать ровно `num_layers` элементов и сохранять размерность каждого `w`, чтобы его можно было передать соответствующей точке управления стилем. Если заготовка функции ожидает тензор, собери выбранные векторы вдоль новой оси слоёв; если список — сохрани тот же порядок позиций.

Проверь себя на маленьком примере: пять слоёв и `cutoff = 2` должны дать два вектора A, затем три вектора B. Граница — это первая позиция нового источника, а не последняя позиция старого.

> 🎒 **На пальцах.** Представь монтаж пяти сцен, для которых есть две версии цветокоррекции: A и B. Ты ставишь метку перед третьей сценой. Первые две берёшь целиком из версии A, остальные — целиком из B. Ты не накладываешь две плёнки друг на друга: метка лишь сообщает, в какой момент переключить источник.
