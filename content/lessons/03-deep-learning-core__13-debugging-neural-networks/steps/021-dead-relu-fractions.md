После прохода батча у тебя остались активации двух ReLU-слоёв. В первом нулей 3 из 12, во втором — 10 из 12. Просматривать каждый тензор вручную неудобно, поэтому ты пишешь `dead_relu_fractions`: функция должна превратить такие наборы чисел в короткий отчёт по слоям.

На вход функция получает словарь: ключ — имя слоя, значение — тензор его активаций после ReLU. На выходе нужен новый словарь с теми же именами и долями точных нулей от `0.0` до `1.0`. Например, для тензора из четырёх элементов `[0, 2, 0, 5]` результат равен `0.5`.

Смотри на три детали:

- считай нули среди **всех** элементов тензора, независимо от числа измерений;
- сравнивай именно с нулём, а не с «очень маленьким числом»: после ReLU отрицательные входы становятся точными нулями;
- возвращай обычное число для каждого слоя, чтобы отчёт было удобно печатать и сравнивать.

Пустой словарь должен дать пустой результат. А вот тензор без элементов лучше обработать явно: доля с нулевым знаменателем не определена. Функция пока не ставит диагноз отдельным нейронам и не меняет модель — она лишь автоматизирует сигнал из [шага 20](#step-20). Если слой вернул 10 нулей из 12 значений, в отчёте должно появиться примерно `0.833`, а не догадка «много».

> 🎒 **На пальцах.** Представь табло с лампочками для нескольких залов. Ты не выясняешь, какая конкретно лампочка сломана: просто считаешь, какая доля табло не загорелась в каждом зале. `dead_relu_fractions` делает такой же общий снимок — отдельно для каждого слоя, но сразу по всем значениям его тензора.
