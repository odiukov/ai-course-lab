Допустим, сеть выдала число 3,7. Для прогноза цены это может быть нормальным ответом. Но если ты спрашивал: «На фото есть кошка?», число 3,7 нельзя назвать вероятностью. А при выборе между кошкой, собакой и лисой одного числа вообще недостаточно.

Значит, последний слой должен не просто передать вычисленный сигнал, а привести его к форме ответа.

Для бинарной классификации — выбора между двумя вариантами — ставят sigmoid из [шага 5](#step-5). Она превращает один логит в число от 0 до 1: например, 0,8 можно прочитать как высокую уверенность в выбранном классе.

Для многоклассовой классификации используют softmax из [шага 39](#step-39). Здесь сеть выдаёт отдельный логит для каждого класса, а softmax превращает весь вектор в вероятности, которые конкурируют между собой и в сумме дают 1. Если вероятность «собаки» растёт, другим классам остаётся меньшая доля.

В регрессии сеть предсказывает величину: цену, температуру или время доставки. Обычно выход оставляют линейным, то есть не применяют активацию. Так ответ не зажимается в диапазон от 0 до 1 и может принимать любые нужные значения. Это не делает всю сеть линейной: в скрытых слоях остаются нелинейные активации, выбранные по принципам из [шага 55](#step-55).

Выходная активация определяется не архитектурой внутри, а тем, ответ какого вида ты ждёшь снаружи.

> 🎒 **На пальцах.** Представь электронное табло на вокзале. Для вопроса «поезд опаздывает?» нужен один индикатор от «нет» до «да». Для выбора пути нужны несколько долей, распределённых между платформами. Для времени задержки нужен обычный счётчик без верхнего ограничения. Вычисления внутри табло могут быть одинаковыми — меняется формат последнего показания.
