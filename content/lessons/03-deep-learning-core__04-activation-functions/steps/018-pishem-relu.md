Ты запускаешь функцию на трёх значениях и получаешь: для `-3.0` — `0.0`, для `0.0` — `0.0`, для `2.5` — `2.5`. Именно такое поведение было задано в [шаге 17](#step-17). Теперь перенеси его в функцию `relu(x)`.

Функция принимает одно число `x`. Сначала определи, по какую сторону от нуля оно находится. Если число отрицательное, результатом должен стать ноль. Во всех остальных случаях верни само число без округления, масштабирования и других изменений.

Обрати внимание на тип результата: для отрицательного входа лучше получать `0.0`, а не целое `0`. Численно они равны, но `0.0` яснее показывает, что функция работает с числами с плавающей точкой.

Проверь себя на разных входах:

- `relu(-8.0)` должно дать `0.0`;
- `relu(0.0)` должно дать `0.0`;
- `relu(1.7)` должно дать `1.7`.

Частая ошибка — использовать модуль числа. Тогда `-8.0` превратится в `8.0`, хотя отрицательный сигнал нужно остановить, а не развернуть. Если три проверки совпали, твоя ReLU делает ровно одно: отсекает отрицательные значения и не трогает положительные.

> 🎒 **На пальцах.** Представь лоток для монет с односторонней заслонкой. Монеты, которые катятся вперёд, проходят без задержки. Попытка прокатить их в обратную сторону упирается в заслонку — на выходе ничего. Заслонка не разворачивает обратное движение вперёд, поэтому отрицательное число становится нулём, а не положительным числом той же величины.
