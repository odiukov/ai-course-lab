Дальше тебе понадобится смотреть на активацию сразу с двух сторон: какую форму сигнала она создаёт при прямом проходе и какой градиент пропускает назад. Главная ловушка — судить только по красивой кривой или только по максимальной производной. Как показал [шаг 49](#step-49), в глубине важен весь путь градиента, а не один слой. Для скрытых слоёв сверяйся с архитектурой и измерениями из [шага 57](#step-57), для выходного — с постановкой задачи из [шага 56](#step-56). Хороший выбор активации — это проверяемая гипотеза, а не привычка.
