Ты переносишь знакомые активации в PyTorch и вдруг не находишь `swish`. А GELU встречается то как `F.gelu(x)`, то как `nn.GELU()`. Это не разные функции: PyTorch просто предлагает два способа их вызвать.

Если нужно сразу преобразовать тензор, используй функцию:

```python
import torch
import torch.nn.functional as F

x = torch.randn(4, 10)

relu_out = F.relu(x)
gelu_out = F.gelu(x)
sigmoid_out = torch.sigmoid(x)
swish_out = F.silu(x)
```

`x` содержит 4 строки по 10 чисел, и активация применяется к каждому числу отдельно. `SiLU` — официальное имя Swish в PyTorch; математически это та же активация из [шага 34](#step-34).

Когда собираешь модель из последовательных слоёв, удобнее модульная запись:

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(10, 64),
    nn.GELU(),
    nn.Linear(64, 5),
)
```

Здесь `nn.GELU()` — объект-слой, который можно поставить внутрь `nn.Sequential`. Скобки важны: они создают модуль.

С softmax появляется дополнительный выбор. Для логитов формы «4 объекта на 5 классов» пиши:

```python
probs = F.softmax(logits, dim=1)
```

`dim=1` означает: превратить пять чисел внутри каждой строки в распределение из [шага 39](#step-39). Если указать другое измерение, код может выполниться, но единица получится не по классам.

> 🎒 **На пальцах.** Представь набор кухонных насадок. `F.gelu(x)` — ты берёшь насадку и сразу обрабатываешь продукты. `nn.GELU()` — устанавливаешь такую же насадку внутрь кухонного комбайна, чтобы она стала этапом программы. А `dim=1` у softmax указывает, какие продукты лежат в одной порции: перепутаешь направление — смешаешь соседние заказы.
