Ты подаёшь модели фразу «Корабль вошёл в…» и получаешь логиты. Кажется, продолжение уже почти готово — но модель сделала лишь один прогноз. Она не пишет текст целиком: следующий токен нужно выбрать, добавить к исходной фразе и снова отправить всё в модель.

При каждом таком проходе появляются логиты для всех позиций, хотя для продолжения нужны только логиты последней. Их делят на temperature: при значении около нуля выбор становится почти неизменным, при единице сохраняется исходное распределение модели, а при большем значении редкие варианты получают больше шансов. Затем можно применить фильтрацию из [шага 7](#step-7) и маску из [шага 8](#step-8).

После softmax логиты превращаются в вероятности. Из них выбирается один токен методом multinomial — представь жеребьёвку, где у каждого кандидата не один билет, а количество билетов пропорционально его вероятности. Победивший токен присоединяется к контексту. Теперь последняя позиция уже другая, поэтому модель запускается снова.

Именно добавление результата назад во вход замыкает авторегрессионный цикл: каждый новый выбор становится условием для следующего. Модель не держит готовый рассказ за кулисами — она раз за разом отвечает на вопрос: «Какой токен вероятнее теперь?»

> 🎒 **На пальцах.** Представь игру, где ты сочиняешь историю, вытягивая по одной карточке из меняющейся колоды. После фразы «Дверь открылась, и» чаще лежат карточки «там» и «внутри», но может выпасть «внезапно». Ты кладёшь выбранную карточку в рассказ, а ведущий собирает новую колоду уже с учётом получившейся фразы. Один розыгрыш даёт одно слово; история возникает из повторения розыгрышей.
