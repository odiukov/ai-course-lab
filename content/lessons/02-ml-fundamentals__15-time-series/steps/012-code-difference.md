Перед тобой показания электросчётчика за четыре дня: `120`, `125`, `123`, `130`. Функция `difference(series)` должна превратить их в изменения между соседними наблюдениями: `5`, `-2`, `7`. Именно такие разности разбирались на [шаге 11](#step-11).

Обрати внимание: результат короче исходного ряда на один элемент. Для первого числа нельзя вычислить изменение — у него нет предыдущего значения. Не добавляй вместо него ноль: ноль означал бы, что изменения не было, хотя на самом деле оно просто неизвестно.

Напиши функцию, которая:

- принимает одномерный массив `series`;
- для каждого элемента начиная со второго вычитает предыдущее значение;
- возвращает новый массив разностей;
- не изменяет исходный массив.

Проверь её не только на растущем ряду. Для входа `[8, 8, 5, 9]` ожидается `[0, -3, 4]`: ноль означает отсутствие изменения, отрицательное число — снижение, положительное — рост. Для массива из одного значения результат должен быть пустым, потому что ни одной пары соседей нет.

Главное место для ошибки — перепутать порядок вычитания. Считай «текущее минус предыдущее», иначе рост превратится в падение.

> 🎒 **На пальцах.** Представь счётчик пробега автомобиля: вечером он показывает 12 000 км, затем 12 040 и 12 095. Сами показания говорят, где оказался счётчик, а разности — сколько машина проехала за день: 40 и 55 км. Для первого вечера дневной пробег неизвестен, потому что вчерашнего показания у тебя нет.
