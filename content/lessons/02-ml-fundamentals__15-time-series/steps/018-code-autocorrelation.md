У тебя есть ряд `[4, 7, 5, 8, 6]`, и нужно посчитать его сходство с собой не для одного лага, а сразу для всех лагов от `0` до `max_lag`. Вручную повторять вычисления неудобно, поэтому ты напишешь функцию `autocorrelation`.

Смысл лага уже разобран в [шаге 17](#step-17). Здесь сосредоточься на том, как правильно совместить пары наблюдений. Для лага `2` начало ряда без двух последних значений сравнивается с тем же рядом без двух первых: `[4, 7, 5]` и `[5, 8, 6]`. Так обе части имеют одинаковую длину, а каждое число сопоставляется с наблюдением через два момента.

Функция должна:

- найти среднее и дисперсию всего исходного ряда;
- подготовить результат длиной `max_lag + 1`, потому что лаг `0` тоже учитывается;
- для каждого лага взять две совместимые части ряда;
- вычесть из обеих частей общее среднее, усреднить произведения отклонений и разделить результат на дисперсию.

При лаге `0` ряд сравнивается с самим собой, поэтому для непостоянного ряда результат должен быть равен `1`. Если дисперсия равна нулю, делить нельзя: предусмотренный результат — `0`. Для упражнения считай, что `max_lag` меньше длины ряда.

> 🎒 **На пальцах.** Представь две одинаковые ленты с цветными бусинами. Сначала ты кладёшь их ровно друг на друга — совпадение максимальное. Затем сдвигаешь верхнюю ленту на одну, две и следующие позиции, каждый раз сравнивая только бусины, под которыми осталась пара. Функция делает такие сдвиги автоматически и записывает степень совпадения после каждого из них.
