В редакторе уже есть результаты нескольких агентов на одном наборе задач. Для каждого агента хранится последовательность значений: `True` означает решённую задачу, `False` — нерешённую. Тебе нужно дописать `rank_agents`, чтобы превратить эти результаты в рейтинг.

Сначала функция должна вычислить долю успехов каждого агента. Используй готовую `pass_rate` из [шага 6](#step-6): так расчёт останется единым, а логика не будет дублироваться. Затем собери пары из имени агента и его оценки и отсортируй их по убыванию оценки. Агент с большей долей решённых задач должен оказаться раньше.

Обрати внимание на формат возвращаемого значения в заготовке: функция должна вернуть весь рейтинг, а не только имя победителя. Это позволит дальше сравнивать не одну верхнюю позицию, а порядок всех участников.

Есть и важная граница ответственности: `rank_agents` ничего не знает о сложности задач и не отбрасывает лёгкие примеры. Она честно ранжирует переданные результаты. Поэтому сравнение имеет смысл только тогда, когда все агенты решали один и тот же набор — условие из [шага 10](#step-10).

Проверь себя на маленьком примере: если оценки равны `0.75`, `0.5` и `1.0`, первой должна стоять запись с `1.0`, а последней — с `0.5`.

> 🎒 **На пальцах.** Представь конкурс меткости: у каждого участника есть карточка с попаданиями и промахами по одинаковым мишеням. Ты сначала считаешь долю попаданий, затем раскладываешь карточки от большей доли к меньшей. `rank_agents` делает именно это: не меняет испытание и не назначает бонусы, а только упорядочивает уже сопоставимые результаты.
