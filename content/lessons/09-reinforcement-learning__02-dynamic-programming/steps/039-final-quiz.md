Перед тобой новый GridWorld, и нужно не просто получить стрелки, а понять, можно ли им доверять. Ты проверяешь доступ к модели из [шага 3](#step-3), не путаешь два бэкапа из [шага 7](#step-7), следишь за сходимостью по критерию из [шага 18](#step-18) и выбираешь подходящий цикл по сравнению из [шага 34](#step-34). Дальше эти различия помогут замечать, где метод считает точное ожидание, а где учится по случайным наблюдениям.

> 🎒 **На пальцах.** Представь экзамен по вождению: карта дорог — это модель, пересчёт маршрута — бэкап, уменьшающаяся ошибка навигатора — сходимость, а выбор между тщательным планом и частыми быстрыми поправками — выбор алгоритма. Надёжный результат требует, чтобы совпали все четыре части.
