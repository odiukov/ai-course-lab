Ты получил два словаря ценностей. Для состояния `A` было `0.20`, стало `0.25`; для `B` было `0.70`, стало `0.69`; для терминального состояния осталось `0`. Как одним числом описать весь проход?

Напиши функцию `sup_norm`, которая принимает старые и новые ценности и возвращает самое большое абсолютное изменение. В этом примере изменения равны `0.05`, `0.01` и `0`, поэтому результат — `0.05`. Это именно величина \(\Delta\), разобранная в [шаге 18](#step-18).

Проходи по состояниям одного словаря, для каждого бери значение того же состояния из второго, находи абсолютную разницу и сохраняй наибольшую из увиденных. Не сравнивай просто два списка значений: порядок элементов может различаться, и тогда рядом окажутся ценности разных состояний.

Обрати внимание на три проверки:

- одинаковые словари должны дать `0`;
- уменьшение `0.8 → 0.3` должно дать `0.5`, а не отрицательное число;
- если одно состояние изменилось сильнее всех, именно оно определяет результат — среднее здесь не подходит.

Считай, что оба словаря содержат одинаковый набор состояний. Терминальное состояние тоже можно сравнивать: при корректных ценностях его изменение останется нулевым. Когда функция готова, у тебя появляется честный ответ на вопрос «насколько сильно изменился самый нестабильный участок?».

> 🎒 **На пальцах.** Ты проверяешь натяжение струн на гитаре после настройки: пять почти не сдвинулись, а шестая заметно ушла. Среднее отклонение успокоит тебя слишком рано. `sup_norm` будто выбирает струну с самым большим расхождением: пока она не настроена, инструмент в целом ещё не готов.
