Ты стоишь в клетке GridWorld и оцениваешь действие «вправо». Из-за скольжения оно может привести не в одну, а в несколько клеток. Если просто взять ценность клетки справа, получится оценка мира без случайности — не того, который задан функцией `transitions`.

Напиши `q_value(s, a, V, gamma=0.99)`, которая возвращает одно число: ожидаемую ценность выбранного действия `a` в состоянии `s`. Используй Q-бэкап из [шага 16](#step-16), не меняя сам словарь `V`.

Для каждого исхода, полученного из `transitions(s, a)`, тебе доступны следующая клетка, мгновенная награда и вероятность. Сначала соедини награду сейчас с дисконтированной ценностью следующей клетки. Затем умножь получившийся результат на вероятность именно этого исхода. В конце сложи вклады всех исходов.

Следи за порядком: `gamma` уменьшает только будущую ценность, но не мгновенную награду. Вероятность, напротив, относится ко всему результату исхода. Частая ошибка — сложить значения разных исходов без учёта их вероятностей: редкое скольжение тогда повлияет на ответ так же сильно, как основное направление.

Функция оценивает только одну пару «состояние — действие». Позже её можно будет вызывать для каждого доступного действия и сравнивать результаты, но сейчас твоя цель проще: аккуратно превратить список вероятных исходов в одно средневзвешенное число.

> 🎒 **На пальцах.** Представь лотерейный билет с несколькими призами. Джекпот в 1000 рублей звучит впечатляюще, но при шансе 1% его вклад в оценку билета — лишь 10 рублей. Ты так же оцениваешь каждый возможный исход действия: учитываешь его результат и шанс, а затем складываешь вклады. `q_value` — это честная цена такого «билета-действия».
