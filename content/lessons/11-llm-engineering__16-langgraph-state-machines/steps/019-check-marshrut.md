Ты только что собрал весь цикл ReAct из [шага 16](#step-16) и научился читать маршрутизатор из [шагов 17](#step-17)–[18](#step-18). Проверим главное умение: взять конкретное сообщение и сказать, в какой узел граф шагнёт следующим.

Спотыкаются обычно на двух вещах. Первая: кажется, будто три вызова инструментов означают три прохода через `tools` — нет, узел за один заход выполняет все вызовы из последнего сообщения. Вторая: ищут условие там, где его нет. Развилка в этом графе одна — после `agent`. Обратная стрелка из `tools` ничего не проверяет и не может увести в `END`.
