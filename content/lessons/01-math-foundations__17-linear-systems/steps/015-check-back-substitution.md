title: 'Проверка: восстановить три неизвестные из верхнего треугольника'
source_anchor: '### Gaussian elimination'
check:
  - question: >-
      Верхняя строка: x1 + 2x2 − x3 = 8. Средняя: x2 + x3 = 5. Нижняя: 2x3 = 4.
      Какую тройку ты получишь?
    options:
      - 'x1 = 4, x2 = 3, x3 = 2'
      - 'x1 = 0, x2 = 3, x3 = 2'
      - 'x1 = 4, x2 = 7, x3 = 2'
      - 'x1 = 2, x2 = 3, x3 = 4'
    correct: 0
    explanation: >-
      Снизу получаешь x3 = 2, затем из средней строки x2 = 3. Подстановка обоих
      чисел в верхнюю строку даёт x1 = 4.
---

Проверь, можешь ли ты вручную выполнить тот же путь, который функция из [шага 14](#step-14) проходит в цикле. Начинай с нижней строки: только там одна неизвестная. Найденное число подставь строкой выше, затем поднимись ещё на одну строку.

Чаще всего ошибка возникает не в порядке действий, а в знаке: например, при переносе отрицательного слагаемого через знак равенства. Не пытайся найти все три числа одновременно — после каждого подъёма неизвестных становится на одну меньше. Если итоговая тройка выполняет каждую строку, обратная подстановка завершена.
