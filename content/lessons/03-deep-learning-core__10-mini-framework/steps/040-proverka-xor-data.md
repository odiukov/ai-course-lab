Проверь результат функции из [шага 39](#step-39) не только по значениям, но и по форме каждой пары. У XOR четыре примера: каждый вход содержит два числа, а цель — одно число внутри списка. Частая ошибка — записать цель просто числом или случайно дать ей два элемента. Тогда данные перестают совпадать с одним выходом модели.

> 🎒 **На пальцах.** Представь карточки для сортировщика посылок: на лицевой стороне стоят два переключателя, а на обороте — одна отметка «да» или «нет». Если оборот пустой либо на нём две отметки, сортировщик уже не понимает, с каким единственным ответом сравнивать результат.
