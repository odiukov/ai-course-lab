Она должна вернуть список градиентов — по одному элементу для каждой пары `предсказание — цель`. Используй выражение из [шага 24](#step-24), не выводя его заново.

На что обратить внимание:

- найди `n` как количество предсказаний;
- сопоставь элементы `predicted` и `target` по порядку;
- вычисли отдельный градиент для каждой пары;
- раздели каждый результат на одно и то же `n`;
- верни список той же длины и в том же порядке, что и `predicted`.

Здесь легко случайно вернуть сумму или среднее всех градиентов. Это будет одно число, а модели нужен целый список: первый элемент запустит исправление первого выхода, второй — второго и так далее.

Для этой задачи считай, что оба входных списка имеют одинаковую длину и не пусты. Проверки входных данных пока не нужны — сосредоточься на связи между каждой парой значений.

> 🎒 **На пальцах.** Представь судью на соревновании по стрельбе. Он не пишет команде одну общую записку «стреляйте точнее», а выдаёт каждому стрелку свою поправку: одному сместить прицел вправо, другому — влево. `mse_loss` похож на общий счёт команды, а `mse_grad` готовит отдельную поправку для каждого выстрела.
