Ты запускаешь модель на двух примерах и получаешь предсказания `[0.9, 0.2]`. Правильные ответы — `[1.0, 0.0]`. Теперь нужно превратить две пары чисел в одну оценку ошибки, чтобы позже использовать её при обучении.

Напиши функцию `mse_loss(predicted, target)`. Она принимает два непустых списка одинаковой длины: предсказания модели и соответствующие им правильные ответы. Вернуть функция должна одно число — среднюю квадратичную ошибку из [шага 22](#step-22).

Работай с элементами попарно: первое предсказание сравнивается с первым правильным ответом, второе — со вторым. Для каждой пары найди разницу и возведи её в квадрат. Затем сложи получившиеся ошибки и раздели сумму на количество предсказаний.

Для примера выше квадраты ошибок равны `0.01` и `0.04`, поэтому результат должен быть `0.025`. Обрати внимание именно на усреднение: если вернуть только сумму `0.05`, величина потерь начнёт зависеть от количества элементов.

Функция не должна изменять входные списки или возвращать отдельную ошибку для каждой пары. Её результат — одно число, которым можно сравнивать качество разных предсказаний на одинаковых данных.

Проверь себя ещё на точном совпадении: для `[0.3, 0.7]` и `[0.3, 0.7]` результат должен быть равен нулю.

> 🎒 **На пальцах.** Представь судью на соревновании по метанию колец. Он измеряет промах каждого броска, усиливает большой промах возведением в квадрат, а затем делит общий штраф на число бросков. Поэтому десять одинаково точных бросков получают ту же среднюю оценку, что и два: судья оценивает типичный промах, а не длину серии.
