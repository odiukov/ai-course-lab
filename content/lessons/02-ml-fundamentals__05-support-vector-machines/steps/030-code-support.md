После обучения ты видишь три значения signed margin: `0.9996`, `1.04` и `1.0008`. Какие точки считать опорными? Проверка на точное равенство единице отбросит даже первую: вычисления с дробными числами дают небольшую погрешность.

Напиши `find_support_vectors(X, y, w, b, tol=1e-3)`. Функция должна пройти по всем строкам `X` и вернуть список **индексов** опорных векторов — не сами строки.

Для каждой точки:

1. Посчитай её балл с помощью весов `w` и смещения `b`, как в функции из [шага 5](#step-5).
2. Умножь балл на соответствующую метку `y[i]`. Это важно: проверять только балл нельзя, потому что у класса `−1` правильная сторона имеет отрицательный знак.
3. Сравни полученный signed margin с единицей по критерию из [шага 29](#step-29).
4. Если отклонение меньше `tol`, добавь индекс `i` в результат.

При `tol=0.001` значения `0.9996` и `1.0008` подходят, а `1.04` — нет. Обрати внимание: условие использует строгое «меньше». Точка с отклонением ровно `0.001` не проходит.

Именно допуск превращает хрупкое сравнение дробных чисел в практический поиск точек около границы margin.

> 🎒 **На пальцах.** Представь контролёра, который отбирает монеты толщиной около 2 мм. Электронный штангенциркуль показывает `1.9996` или `2.0008`, хотя монеты подходят. Контролёр не требует показания ровно `2.0000`, а задаёт узкий допустимый коридор. `tol` — ширина этого коридора, а список индексов — номера прошедших монет.
