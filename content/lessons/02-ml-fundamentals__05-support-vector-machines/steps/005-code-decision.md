Перед тобой сразу три объекта, и здесь легко перепутать их роли: `X` содержит несколько примеров, `w` — по одному весу для каждого признака, а `b` — одно общее смещение. Если функция вернёт единственное число для всей таблицы, определить класс каждой строки уже не получится.

Напиши `decision_function(X, w, b)`, которая рассчитывает для каждой строки `X` отдельный балл со знаком по правилу из [шага 3](#step-3). Результатом должен быть одномерный массив: сколько строк пришло в `X`, столько чисел функция и возвращает.

Сначала проверь формы данных. Если в `X` пять примеров с двумя признаками, форма таблицы будет `(5, 2)`, у `w` должно быть два элемента, а у результата — пять. Каждый пример использует один и тот же набор весов и одно и то же смещение.

Не пиши цикл по строкам: попробуй выполнить вычисление сразу для всей матрицы. Матричное умножение сопоставит признаки каждой строки соответствующим весам, а прибавление `b` применится ко всем полученным баллам.

Посмотри именно на знаки результата: положительное число отправляет пример на одну сторону границы, отрицательное — на другую, ноль означает попадание точно на неё. Величину пока не называй геометрическим расстоянием — для этого понадобится следующий шаг.

> 🎒 **На пальцах.** Представь турникеты на вокзале: через каждый проходит отдельный пассажир, но правило проверки у всех одно. `X` — очередь пассажиров, `w` — список проверок, `b` — общая поправка. На выходе нужен не один итог для всей очереди, а отдельный сигнал для каждого человека. Так и `decision_function` возвращает по одному баллу на строку.
