После обучения у тебя есть веса `w` и смещение `b`, а перед моделью лежат новые объекты `X`. Для каждого объекта нужно получить числовой балл, а затем превратить его в метку класса. Эту последнюю операцию и выполнит `svm_predict`.

Используй написанную в [шаге 5](#step-5) функцию `decision_function`: она сразу рассчитает баллы для всех строк `X`. Затем пройди по результатам и примени правило из [шага 27](#step-27): неотрицательный балл означает класс `1`, отрицательный — класс `-1`.

Дополни функцию:

```python
def svm_predict(X, w, b):
    scores = decision_function(X, w, b)
    predictions = []

    for score in scores:
        # Добавь в predictions метку 1 или -1
        ...

    return predictions
```

Обрати внимание именно на ноль. Условие должно относить `score == 0` к классу `1`, поэтому простая проверка «балл положительный» здесь даст неверный результат на самой границе.

Проверь функцию на готовых баллах мысленно: значения `2.4`, `0.0` и `-0.7` должны превратиться в список `[1, 1, -1]`. Результат должен содержать по одной метке для каждой строки `X`, а не сами баллы и не значения `True` и `False`.

Здесь модель больше ничего не обучает и не меняет `w` или `b`. Она только рассчитывает, по какую сторону границы оказался каждый новый объект, и выдаёт принятую в уроке метку.

> 🎒 **На пальцах.** Представь судью на фотофинише с линией на экране. Координата участника справа от линии положительная — судья поднимает табличку `1`; слева отрицательная — табличку `-1`. Если участник оказался точно на линии, действует заранее установленное правило: тоже `1`. `svm_predict` — это судья, который переводит координаты в таблички, не передвигая саму линию.
