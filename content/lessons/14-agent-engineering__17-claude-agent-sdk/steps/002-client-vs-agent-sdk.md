Открываешь терминал, чтобы поставить библиотеку, и находишь две. `pip install anthropic` и `pip install claude-agent-sdk`. Обе от Anthropic, обе про Claude, названия почти соседние. Какую брать?

Похоже на выбор между старой и новой версией — а это вообще не он. `anthropic` — это Client SDK, тонкая обёртка вокруг сырого Messages API: один запрос, один ответ, ровно та ситуация из [шага 1](#step-1). Цикл, разбор запросов на инструменты, склейка состояния между шагами — всё это остаётся твоей работой. `claude-agent-sdk` — Agent SDK: тот же цикл, но уже написанный и отлаженный, плюс подключение внешних инструментов по MCP, хуки, запуск субагентов, хранилище сессий. По сути — цикл Claude Code, упакованный в библиотеку.

Разница честно измеряется строками. Рабочий агентный цикл на Client SDK — это 150–300 строк, и ты будешь их не писать, а отлаживать неделю: модель просит инструмент, которого нет; ответ инструмента вернулся не в том формате; на пятом шаге потерялся контекст. На Agent SDK те же возможности — конфиг и несколько вызовов.

За это ты платишь. Цикл теперь чужой. Захочешь вклиниться между «модель решила вызвать инструмент» и «инструмент вызвался» — сможешь только там, где библиотека оставила точку входа. Не оставила — либо обходной путь, либо возвращаешься к `anthropic` и пишешь свои двести строк.

То есть выбираешь ты не мощность, а кто держит руль внутри цикла.

> 🎒 **На пальцах.** Механическая коробка — это `anthropic`: каждое переключение твоё, можно вытянуть передачу до отказа на подъёме, но и глохнуть будешь тоже ты. Автомат — Agent SDK: жмёшь газ и едешь, пятьдесят мелких решений в минуту приняли за тебя. Пока едешь как все — выигрыш огромный. А захочешь придержать третью на серпантине — доступны только те режимы, которые завод заложил в селектор.
