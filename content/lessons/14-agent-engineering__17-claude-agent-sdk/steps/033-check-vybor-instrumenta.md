Четыре строки на выбор выглядят похоже, но развилка тут одна: кто решает, что делать на следующем шаге. Отдаёшь это решение модели — берёшь Agent SDK с его готовым циклом и инструментами из [шага 4](#step-4). Хочешь нарисовать переходы сам — берёшь граф.

После этого куска ты должен уметь по формулировке задачи сказать, какая из четырёх строк подходит, и объяснить почему. Спотыкаются обычно на двух вещах. Первая: путают «хочу удобно» с «хочу управляемо» — Managed Agents из [шага 31](#step-31) снимают инфраструктуру, но не возвращают контроль над переходами. Вторая: думают, что хуки из [шагов 9](#step-9)–[11](#step-11) делают прогон детерминированным. Хук говорит «нет» одному вызову, а не задаёт маршрут.
