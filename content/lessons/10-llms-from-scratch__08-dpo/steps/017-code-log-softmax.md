Перед тобой массив `logits`: каждая строка относится к отдельной позиции, а каждый столбец — к возможному токену. Например, форма `(2, 3)` означает две независимые позиции и три варианта токена в каждой. Если случайно нормировать весь массив целиком, строки начнут влиять друг на друга — получится правдоподобный, но неверный результат.

Напиши функцию с таким интерфейсом:

```python
def log_softmax(logits):
    # верни массив той же формы
    pass
```

Используй формулу из [шага 16](#step-16), выполняя все операции по последней оси (`axis=-1`). Для каждой строки тебе понадобятся её собственный максимум и сумма экспонент. При вычислении этих промежуточных значений сохрани ось через `keepdims=True`: тогда NumPy сможет вычесть один результат из каждого элемента соответствующей строки без ручных циклов.

Готовое вычисление проверь так:

```python
logits = np.array([
    [4.0, 2.0, 1.0],
    [0.0, -1.0, 3.0],
])

result = log_softmax(logits)
```

У `result` должна остаться форма `(2, 3)`. Затем вычисли `np.exp(result).sum(axis=-1)`: для каждой строки должна получиться единица с учётом небольшой погрешности чисел с плавающей точкой. Все значения `result` будут не больше нуля, поскольку это логарифмы вероятностей.

Если форма изменилась или единица получилась только одна на весь массив, проверь `axis` и `keepdims`.

> 🎒 **На пальцах.** Представь две отдельные коробки с жетонами разных цветов. Тебе нужно посчитать долю каждого цвета внутри своей коробки. Если высыпать обе коробки в одну кучу, доли изменятся. `axis=-1` оставляет коробки раздельными, а `keepdims=True` сохраняет для каждой коробки место под её собственный итог.
