title: Добавляем CLS и позиции без смешивания батча

На монтажном столе лежат три киноплёнки — батч из трёх изображений. После [шага 7](#step-7) в каждой уже по 196 кадров-патчей. Теперь перед каждой плёнкой нужно поставить служебный кадр CLS, а затем пометить все 197 мест позиционными сигналами. Здесь легко ошибиться: приклеить один CLS перед всем батчем или выстроить три изображения в одну длинную последовательность.

Правильный ориентир — форма данных. Если последовательность патчей имеет форму `(3, 196, 768)`, то после добавления CLS должна получиться форма `(3, 197, 768)`. Число изображений осталось равным трём; выросла только длина каждой отдельной последовательности. Один обучаемый вектор CLS используется для всех изображений, но присутствует внутри каждого элемента батча.

Позиционный сигнал готовят сразу для 197 мест: отдельное место для CLS и 196 мест для сетки патчей из [шага 5](#step-5). Его можно хранить в форме `(1, 197, 768)`: первая единица означает «один общий шаблон позиций». При сложении он автоматически применяется к каждой из трёх последовательностей. Это не смешивание изображений — значения одного изображения не попадают в другое; всем лишь выдают одинаковую координатную разметку.

Проверяй ось, вдоль которой растёт тензор: CLS добавляется к длине последовательности, а не к размеру батча. Тогда каждое изображение сохраняет собственную плёнку из 197 токенов.

> 🎒 **На пальцах.** Представь три киноплёнки в отдельных коробках. В начало каждой ты вклеиваешь одинаковый служебный кадр «о чём весь фильм», а поверх кадров наносишь номера мест от 0 до 196 по одному трафарету. Общий трафарет не склеивает фильмы: он лишь ставит одинаковые метки внутри каждой коробки.
