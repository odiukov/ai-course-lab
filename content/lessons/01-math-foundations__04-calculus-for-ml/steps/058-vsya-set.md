Всё, что ты собирал по кусочкам, теперь складывается в один цикл — тот самый, который крутится внутри любой обученной сети. Полезно увидеть его целиком: дальше в курсе любая новая идея будет вставляться в один из трёх шагов этого цикла, а не заменять его.

**Прямой проход.** Входные данные идут слева направо через слои: умножение на веса первого слоя, нелинейность, умножение на веса второго слоя, превращение в предсказание. В конце — потери, число, которое говорит, насколько предсказание разошлось с правильным ответом.

**Обратный проход.** Из этого числа градиенты текут справа налево по той же цепочке, перемножая локальные производные — ровно то цепное правило, которое ты разбирал на шагах 34–41. Итог: у каждого веса, будь их десяток или миллиард, появляется своя частная производная потерь по нему.

**Шаг по весам.** Каждый вес независимо применяет правило обновления из шага 21: вычесть из себя learning rate, умноженный на свой градиент. Никакой координации между весами не нужно — у каждого свой градиент, каждый двигается сам.

Три шага, потом снова с новой порцией данных. Миллионы повторений. Это и есть обучение нейросети — больше ничего в нём не происходит.

> 🎒 **На пальцах.** Заказ проходит через цепочку подрядчиков: заготовка, покраска, сборка. Клиент возвращает деталь с претензией — это потери. Претензия идёт назад по цепочке, и каждый подрядчик узнаёт, какая доля брака его. Не «виноват кто-то», а конкретное число вины на каждого. Получив его, каждый чуть подкручивает свой станок — самостоятельно, не спрашивая соседей. Следующий заказ выходит немного лучше.
