У тебя есть три признака: возраст, сумма покупки и случайный номер клиента. Функция должна проверить каждый столбец отдельно и вернуть три MI-оценки в том же порядке. Одного общего числа здесь недостаточно: связь с целевой переменной у каждого признака своя.

Начни с заготовки:

```python
def mutual_information(X, y, n_bins=10):
    ...
```

`X` — таблица размера «число строк × число признаков», `y` — целевая переменная для тех же строк. Создай массив нулей длиной в число признаков — в него будут записываться результаты.

Сначала один раз найди уникальные значения `y`, посчитай их частоты и преврати частоты в вероятности делением на число строк. Затем перебирай столбцы `X`. Каждый столбец перед подсчётом преврати в корзины функцией из [шага 21](#step-21). Для получившихся номеров корзин тоже найди уникальные значения и их вероятности.

Теперь перебери все сочетания «корзина признака — значение цели». Для каждого сочетания создай логическую маску строк, посчитай совместную вероятность и добавь вклад по правилу из [шага 23](#step-23). Если совместная вероятность равна нулю, пропусти сочетание: логарифм нуля не определён, а пустая клетка всё равно не даёт вклада.

Накопленную сумму запиши в позицию текущего признака. После обработки всех столбцов верни массив оценок. Проверь две детали: постоянный столбец корректно обработает `discretize`, а длина результата должна всегда совпадать с числом столбцов `X`.

> 🎒 **На пальцах.** Представь сортировочный центр: посылки раскладывают по секциям веса, а затем смотрят, в какие города они едут. Ты проходишь по каждой паре «секция — город» и сравниваешь реальную долю посылок с долей при случайном распределении. Пустую пару просто пропускаешь. Чем сильнее заполнение секций выдаёт направление отправки, тем больше итоговая оценка.
