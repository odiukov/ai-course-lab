Возьми матрицу из четырёх строк: первый столбец содержит `5, 5, 5, 5`, а второй — `0, 0, 1, 1`. Первый признак совсем не меняется, второй меняется заметно. Функция должна превратить это наблюдение в два массива: значения дисперсии и решение «оставить или убрать».

Напиши функцию `variance_threshold(X, threshold=0.01)`. В ней нужны три действия:

1. Посчитать дисперсию отдельно для каждого столбца с помощью `np.var`. Обрати внимание на `axis=0`: строки — это объекты, поэтому вычисление должно идти сверху вниз по каждому признаку.
2. Поэлементно сравнить полученные дисперсии с `threshold`. Если значение **строго больше** порога, в маске появляется `True`, иначе — `False`.
3. Вернуть сначала булеву маску, затем сами дисперсии. Они пригодятся, чтобы увидеть не только решение функции, но и числа, на которых оно основано.

Для примера выше дисперсии должны получиться равными `0` и `0.25`. При пороге `0.01` ожидаемая маска — `False, True`. Проверь и границу: при пороге `0.25` второй столбец тоже не проходит, потому что сравнение строгое.

Смысл низкой дисперсии мы разобрали в [шаге 8](#step-8). Здесь главное — аккуратно перевести его в операции над столбцами: одна дисперсия на признак, одно логическое решение на дисперсию.

> 🎒 **На пальцах.** Представь линию контроля бутылок: датчик измеряет, насколько различается их вес. Для каждого конвейера он записывает число, затем сверяет его с порогом. Если различие выше порога, загорается зелёная лампа `True`; если нет — красная `False`. Функция возвращает и лампы, и показания датчика, чтобы решение можно было проверить.
