Перед тобой уже лежат четыре готовые детали: `normalize` из [шага 9](#step-9), `sample_index` из [шага 11](#step-11), `accept` из [шага 13](#step-13) и `residual` из [шага 16](#step-16). Ни одна из них не знает, что происходит вокруг: каждая берёт списки чисел и возвращает число или список. Новой математики в этом шаге нет вообще — есть порядок сборки, и именно в нём люди ошибаются.

Напиши `spec_step`: она проводит один спекулятивный цикл целиком, по схеме из [шага 22](#step-22). Сначала `N` раз подряд спрашиваешь черновик, каждый раз про уже удлинившийся префикс, сэмплируешь `d_1 … d_N` и сохраняешь **и** сами токены, **и** распределения `p_1 … p_N`, из которых они вышли — без `p_i` проверять будет нечем. Потом один вызов verifier на `префикс + d_1 + … + d_N` даёт `q_1 … q_{N+1}`.

Дальше цикл слева направо: на позиции `i` сравниваешь `q_i(d_i)` с `p_i(d_i)` через `accept`. Принял — кладёшь `d_i` в результат и идёшь дальше. Отказал — кладёшь токен из `residual(q_i, p_i)` и **выходишь немедленно**, не проверяя хвост: он построен на префиксе, которого больше нет.

Три места, куда стоит посмотреть глазами. Первое — выравнивание индексов: `q` длиннее `p` на единицу, и `q_1` относится к первому черновому токену, а не к последнему токену префикса. Второе — бонусный токен из `q_{N+1}` берётся только если цикл дошёл до конца без единого отказа ([шаг 21](#step-21)). Третье — верни ещё и число принятых черновых токенов: дальше вызывающему коду понадобится знать, насколько далеко ты продвинулся.

Проверь на крайнем случае: отказ на самой первой позиции. Функция обязана вернуть ровно один токен — не ноль. Иначе цикл генерации зависнет на месте.

> 🎒 **На пальцах.** Это как собрать шкаф из готовых деталей: полки выпилены, петли отштампованы, ничего вытачивать не надо. Вся работа — в инструкции: какую стенку прикрутить первой и какой стороной. Перепутаешь порядок — детали те же, шкаф не закроется. `spec_step` и есть эта инструкция: четыре знакомые функции, но в неверном порядке они дают текст, который выглядит правдоподобно и при этом сэмплирован не из того распределения.
