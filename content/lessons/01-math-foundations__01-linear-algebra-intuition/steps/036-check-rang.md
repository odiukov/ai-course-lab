Связка терминов теперь такая:

$$\text{зависимость} \Rightarrow \text{лишний столбец} \Rightarrow \text{ранг меньше числа столбцов}.$$

А **базис столбцов** — это набор без лишних столбцов, который сохраняет все доступные направления. Число столбцов в этом базисе равно рангу.

Для линейной регрессии точный повтор признака означает, что одинаково хороших наборов коэффициентов может быть бесконечно много: предсказание определено, а вклад каждого из повторяющих друг друга признаков — нет.

После этого куска ты должен уметь взять маленькую матрицу и проверить: есть ли строка или столбец, который собирается из остальных. Если есть, его можно убрать без потери доступных направлений.

Спотыкаются обычно на двух вещах. Первая: считают ранг равным количеству строк — раз строк две, значит ранг два. Нет, ранг считает только независимые строки. Вторая: ищут нули. Матрица без единого нуля может иметь ранг 1, а матрица с нулями — полный ранг. Смотри на пропорции между строками, а не на сами числа.
