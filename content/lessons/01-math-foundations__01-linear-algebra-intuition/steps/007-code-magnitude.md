Пока длина вектора живёт только на бумаге, ею нельзя пользоваться. Чтобы сравнивать embeddings, нормировать векторы и считать похожесть, длина нужна как функция, которую можно вызвать миллион раз. Напишем её сами — это первый кирпич, на котором держится всё остальное.

Задача: функция `magnitude(v)` принимает список чисел и возвращает одно число — длину этого вектора.

Что она должна делать внутри:

1. Пройти по всем компонентам списка, а не только по первым двум. Вектор может быть длиной 2, а может — 768.
2. Каждую компоненту возвести в квадрат и всё сложить.
3. Из суммы взять квадратный корень.

$$\|v\| = \sqrt{v_1^2 + v_2^2 + \dots + v_n^2}$$

Здесь $\|v\|$ — длина вектора, $v_1 \dots v_n$ — его числа, $n$ — сколько их всего.

На что смотреть при проверке:

- `magnitude([3, 4])` должно дать ровно `5.0`. Это классический прямоугольный треугольник, удобно для отладки.
- `magnitude([0, 0])` — ноль, без ошибок и деления.
- `magnitude([-3, -4])` — тоже `5.0`. Длина никогда не бывает отрицательной: квадрат съедает минус.
- `magnitude([1, 1, 1])` — примерно `1.732`. Если функция игнорирует третье число и выдаёт `1.414`, значит, цикл жёстко зашит под 2D.

Возведение в квадрат в Python — `x ** 2`, корень — `math.sqrt` из модуля `math`.

> 🎒 **На пальцах.** Ты не измеряешь один конкретный забор, ты делаешь рулетку. Рулетку можно приложить к любому забору: к короткому из двух досок, к длинному из семисот шестидесяти восьми. Если твоя рулетка умеет мерить только двухдосочные заборы — это не рулетка, а линейка под один случай. Поэтому и проверяем на трёхмерном векторе: ловим момент, когда инструмент оказался заточен под одну-единственную ситуацию.
