Ты выбираешь проверку для трёх продуктов и видишь одинаковую надпись: «длинный контекст». Но общий размер входа ещё не определяет нужный навык. Для чата бери MRCR из [шага 32](#step-32), для выбора сведений среди документов — HELMET, а для скрытой цепочки рассуждений — BABILong из [шага 34](#step-34). Частая ошибка — заменить все три NIAH: он подтвердит поиск одного факта, но не соответствие реальной задаче.

> 🎒 **На пальцах.** Представь кастинг в театр. Актёру для импровизации нужно помнить реплики партнёров, библиотекарю в пьесе — быстро выбрать нужную папку, сыщику — связать улики в цепочку. Один экзамен на хорошую память не выберет всех троих: испытание должно повторять действие, ради которого ты нанимаешь исполнителя.
