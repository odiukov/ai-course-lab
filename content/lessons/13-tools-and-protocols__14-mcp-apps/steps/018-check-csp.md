check:
  - question: >-
      В `_meta.ui.csp.connectSrc` указан только адрес
      `https://notes.example.com`. Скрипт внутри UI выполняет `fetch` к
      `https://analytics.other.com`. Что произойдёт?
    options:
      - >-
        Запрос выполнится, потому что `connectSrc` регулирует только загрузку
        JavaScript
      - >-
        Браузер заблокирует этот запрос, но остальные части интерфейса продолжат
        работать
      - Хост полностью остановит отрисовку iframe
      - >-
        Браузер автоматически добавит адрес в список разрешённых после первого
        запроса
    correct: 1
    explanation: >-
      `connectSrc` ограничивает адреса для сетевых соединений UI. Нарушение
      блокирует конкретный запрос, а не весь интерфейс.
  - question: >-
      UI-бандл внутри изолированного iframe пытается прочитать токен, который
      клиент хранит в `localStorage` своего origin. Какой результат
      соответствует модели безопасности MCP Apps?
    options:
      - 'Токен доступен, поскольку sandbox разрешает выполнение скриптов'
      - 'Токен недоступен, потому что хранилище origin хоста изолировано от UI'
      - Токен станет доступен после добавления любого элемента в `permissions`
      - Браузер скопирует токен в собственное хранилище iframe
    correct: 1
    explanation: >-
      UI не получает cookies и хранилища origin хоста. Иначе HTML стороннего
      MCP-сервера мог бы читать сессионные данные и токены клиента.

После [шагов 14](#step-14)–[17](#step-17) ты должен уметь смотреть на CSP и сандбокс-атрибуты и заранее говорить, что у твоего интерфейса отвалится: какой запрос не уйдёт, какое хранилище окажется пустым, какой внешний скрипт не загрузится.

Спотыкаются обычно на двух вещах. Первая — путают уровни: думают, что сетевой вызов режет `sandbox`, хотя за адреса отвечает `connect-src` в CSP. Вторая — ждут, что при нарушении сломается весь бандл. Нет: браузер блокирует ровно то действие, что нарушило правило, остальной интерфейс продолжает жить. Именно поэтому такие поломки тихие — кнопка нажимается, а данных нет.
