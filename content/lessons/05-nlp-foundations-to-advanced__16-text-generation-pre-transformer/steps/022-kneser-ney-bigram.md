Ты передаёшь функции корпус, где каждое предложение уже разбито на токены. На выходе нужна не таблица, а функция `prob(context, word)`: позже её можно будет вызывать так же, как `raw_probability` из [шага 12](#step-12) и `laplace_probability` из [шага 16](#step-16).

Сначала собери статистику по предложениям с `<s>` и `</s>`. Тебе понадобятся:

- счётчик появлений каждой биграммы;
- общее число продолжений каждого предыдущего слова;
- множество разных предыдущих слов для каждого следующего слова;
- множество разных продолжений для каждого предыдущего слова.

Обрати внимание: именно множества убирают повторы. Если одна биграмма встретилась десять раз, для числа уникальных связей она всё равно считается один раз.

Затем вычисли `continuation_prob`, используя функцию из [шага 20](#step-20) или ту же логику внутри новой модели. После этого верни вложенную функцию `prob`. Она берёт последний токен из `context`, находит счётчик биграммы и применяет две части Kneser–Ney из [шага 21](#step-21): уменьшенный основной вклад и долю освобождённой массы, умноженную на continuation probability.

Проверь отдельно невиданный контекст. У него нет знаменателя и невозможно рассчитать скидку, поэтому функция должна сразу откатиться к continuation probability. Для неизвестного слова можно оставить крошечное положительное значение вроде `1e-9`, чтобы не получить абсолютный ноль.

Главная ловушка — случайно использовать обычную частоту слова. В этой модели младший уровень смотрит только на разнообразие его предшественников.

> 🎒 **На пальцах.** Представь диспетчера авиалиний. Он отмечает не общее число пассажиров, а число разных городов, из которых они прилетали. Постоянный пассажир из одного города создаёт много поездок, но только один маршрут. Когда данных о новом направлении нет, диспетчер доверяет пассажирам с широкой географией — так здесь работает continuation probability.
