Возьми корпус из трёх предложений: `red fox`, `blue fox` и снова `red fox`. Слово `fox` встретилось три раза, но для continuation probability важны не повторы, а разные слова слева: `red` и `blue`. Поэтому второй экземпляр `red fox` не должен увеличить результат.

Напиши функцию `continuation_probability(corpus_tokens)`. Она получает список токенизированных предложений и возвращает словарь вероятностей для встреченных продолжений. Каждое предложение сначала дополняй токенами начала и конца, как в [шаге 8](#step-8), а затем рассматривай соседние пары.

Для каждого правого слова собирай множество его левых соседей. Именно множество здесь критично: если использовать обычный счётчик, частая биграмма снова начнёт влиять сильнее, и идея из [шага 19](#step-19) потеряется.

Знаменатель общий для всех слов — количество разных биграмм во всём корпусе. Его удобно получить, сложив размеры всех множеств предшественников. В примере различаются пять пар: `<s> red`, `red fox`, `<s> blue`, `blue fox` и `fox </s>`. У `fox` два разных предшественника, поэтому функция должна вернуть для него `2 / 5`. Для неизвестного слова записи в словаре не будет; вызывающий код сможет взять ноль через `get`.

Проверь главное свойство: добавление ещё одного `red fox` не меняет вероятность `fox`, а добавление `green fox` меняет — появился новый контекст.

> 🎒 **На пальцах.** Представь музей и журнал входов. Один посетитель пришёл через северную дверь десять раз, другой — по одному разу через восточную и западную. Ты считаешь не посещения, а двери, через которые человек умеет появляться. Повторная отметка «север» ничего не добавляет, зато новая дверь сразу расширяет его набор контекстов.
