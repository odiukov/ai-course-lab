После `cross_entropy` у тебя в руках одно число — например, `5.42`. Но модель не может исправить тысячи логитов по одному общему числу: ей нужна отдельная подсказка для каждого логита. Именно такой массив должна вернуть `d_cross_entropy`.

Функция получает `logits` формы `(batch, seq_len, vocab_size)` и `targets` формы `(batch, seq_len)`. Её результат должен иметь ту же форму, что и `logits`: для каждой позиции и каждого токена словаря — свой градиент.

Сначала объедини batch и позиции последовательности, как в функции из [шага 38](#step-38). Получится таблица, где каждая строка относится к одному предсказанию. Преврати логиты каждой строки в вероятности с помощью стабильного softmax из [шага 17](#step-17).

Теперь примени результат [шага 39](#step-39): в каждой строке найди столбец, указанный соответствующим `target`, и вычти `1` только из этой вероятности. У правильного токена градиент обычно станет отрицательным — при обновлении это подтолкнёт его логит вверх. У остальных он останется положительным, подталкивая их логиты вниз.

Есть важная деталь: `cross_entropy` возвращает среднее по всем позициям. Поэтому и градиенты нужно разделить на количество строк, то есть на `batch * seq_len`. В конце восстанови исходную трёхмерную форму. Проверь также, что ты не изменяешь входной массив `logits` на месте.

> 🎒 **На пальцах.** Представь пачку экзаменационных бланков: в каждой строке ученик распределил уверенность между вариантами ответа. Ты отмечаешь правильную клетку красным и корректируешь оценки всех вариантов. Но итоговый штраф был усреднён по всей пачке, поэтому каждую отдельную поправку тоже нужно уменьшить пропорционально числу строк.
