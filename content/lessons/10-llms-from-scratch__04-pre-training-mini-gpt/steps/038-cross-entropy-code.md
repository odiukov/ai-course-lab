Перед тобой `logits` формы `(2, 3, 5)` и `targets` формы `(2, 3)`. Модель сделала шесть предсказаний, а для каждого предложила пять токенов. Но как выбрать шесть правильных оценок из трёхмерного массива, не смешав примеры и позиции?

В `cross_entropy_loss` сначала объедини измерения batch и sequence. Тогда логиты превратятся в таблицу формы `(6, 5)`: одна строка — одно предсказание следующего токена. Targets должны стать вектором формы `(6,)` в том же порядке. Значение target в каждой строке — это номер столбца с правильным токеном.

Затем посчитай `log_softmax`. Не вызывай сначала обычный `softmax`, а потом `log`: очень маленькая вероятность может округлиться до нуля, и логарифм сломает результат. Используй устойчивый приём с вычитанием максимума из [шага 16](#step-16), но сразу получай логарифмы вероятностей.

Теперь для каждой строки выбери ровно одно значение — столбец, указанный соответствующим target. Примени штраф из [шага 37](#step-37) и усредни его по всем строкам. Функция должна вернуть одно число, а не отдельный loss для каждой позиции.

Для быстрой проверки подай нулевые логиты с размером словаря 4. Все токены получат равные вероятности, поэтому результат должен быть близок к `1.386`. Если вышел массив или число зависит от выбранных targets, проверь индексацию и ось усреднения.

> 🎒 **На пальцах.** Представь шесть экзаменационных бланков с пятью вариантами ответа. Рядом лежит ключ: для каждого бланка он называет один правильный столбец. Ты находишь оценку только в этой ячейке, превращаешь её в штраф и в конце считаешь среднее по шести бланкам. Остальные столбцы нужны для сравнения, но напрямую в итог не выбираются.
