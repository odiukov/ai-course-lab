  - question: >-
      Максимум по модулю в тензоре равен 1,27, наибольший целый код — 127. Какой
      scale и какой код получит значение 0,043?
    options:
      - 'Scale = 0,01, код 4'
      - 'Scale = 0,01, код 5'
      - 'Scale = 0,02, код 2'
    correct: 0
    explanation: >-
      Scale = 1,27 / 127 = 0,01. Далее 0,043 / 0,01 = 4,3, и округление до
      ближайшего целого даёт 4, а не 5: дробная часть меньше половины шага.
  - question: >-
      Почему предел ошибки одного значения равен половине scale, а не полному
      шагу сетки?
    options:
      - >-
        Потому что округление идёт к ближайшей ступеньке, и дальше середины
        между соседними ступеньками значение оказаться не может
      - Потому что половина кодов диапазона всегда остаётся неиспользованной
      - Потому что ошибка делится поровну между квантизацией и деквантизацией
    correct: 0
    explanation: >-
      Ступеньки стоят через scale, и любое вещественное число лежит не дальше
      половины этого расстояния от ближайшей из них. Отсюда предел scale / 2;
      фактическая ошибка обычно меньше.

Теперь соедини вычисления из [шага 10](#step-10) со шкалой из [шага 11](#step-11): сначала найди `scale`, затем раздели исходное значение на него и округли результат до целого кода. После обратного восстановления сравни полученное число с исходным.

Чаще всего здесь спотыкаются в двух местах: округляют 25,4 до 26 или называют максимальной ошибкой целую ширину ступеньки. Но ближайший код — 25, а значение может находиться не дальше середины между соседними ступеньками. Поэтому предел ошибки одного числа — половина `scale`, хотя фактическая ошибка часто меньше.
