После `quantize_symmetric` из [шага 12](#step-12) у тебя остались две части: тензор целых кодов и `scale`. Если передать функции только коды, восстановить значения не получится: число `25` само по себе не говорит, какой вещественной величине оно соответствует.

Напиши функцию с такой заготовкой:

```python
def dequantize_symmetric(quantized, scale):
    # восстанови приближённые вещественные значения
    pass
```

Функция должна применить сохранённый масштаб ко всему тензору, как было разобрано в [шаге 13](#step-13). Здесь не нужно снова искать максимум, округлять результат или ограничивать его целочисленным диапазоном. Эти действия относятся к квантизации; сейчас ты движешься в обратную сторону.

Обрати внимание на тип результата. `quantized` содержит целые числа, но восстановленный тензор должен быть вещественным: дальше модель будет выполнять с ним обычные вычисления. Форма тензора при этом не меняется — если на входе была матрица 2 на 3, на выходе тоже должна быть матрица 2 на 3.

Для проверки сначала возьми небольшой тензор, пропусти его через функцию из [шага 12](#step-12), а затем передай полученные коды и тот же `scale` в `dequantize_symmetric`. Значения должны стать близкими к исходным, но не обязаны совпасть с ними: потерянные при округлении дробные части уже нельзя угадать.

> 🎒 **На пальцах.** Представь мозаику, где вместо координат каждой плитки записали номера клеток и отдельно — ширину одной клетки. Номер `7` без ширины ничего не сообщает о расстоянии. Умножив номер на сохранённую ширину, ты вернёшь плитку в нужную точку сетки, но не узнаешь, где именно внутри клетки она лежала до округления.
