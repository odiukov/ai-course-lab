Перед тобой три бюллетеня: `["Лиса", "Сова", "Кит"]`, `["Кит", "Лиса", "Сова"]` и `["Лиса", "Кит", "Сова"]`. Список кандидатов уже можно получить функцией из [шага 6](#step-6), но сам по себе он не показывает победителя. Теперь важно посмотреть только на первые позиции: у Лисы их две, у Кита одна, у Совы ни одной.

Напиши `plurality_winner(ballots)`, которая принимает список бюллетеней и возвращает кандидата с наибольшим числом первых мест — именно такое правило мы разобрали в [шаге 7](#step-7).

Удобно разделить работу на два действия. Сначала подготовь счётчик для всех кандидатов. Затем пройди по бюллетеням и увеличивай результат только того кандидата, который стоит первым. Остальные позиции пока не влияют на итог: они понадобятся позже для другого способа подсчёта.

После подсчёта найди кандидата с самым большим значением и верни его имя. Проверь себя на примере выше: функция должна вернуть `"Лиса"`. Обрати внимание, что она возвращает не число голосов и не весь словарь результатов, а именно победителя.

На этом экране используй входные данные, где один кандидат набрал больше первых мест, чем каждый из остальных. Особые случаи мы разберём отдельно. Сейчас главное — не начать случайно начислять голоса за второе и третье места: в plurality каждый бюллетень отдаёт ровно один голос.

> 🎒 **На пальцах.** Представь забег игрушечных машинок, для которого сохранили несколько фотографий финиша. На каждой фотографии тебя интересует только машинка, пересёкшая линию первой. Ты ставишь по одной отметке рядом с её цветом, а затем выбираешь цвет с наибольшим числом отметок. Положение остальных машинок на снимке здесь ничего не добавляет.
