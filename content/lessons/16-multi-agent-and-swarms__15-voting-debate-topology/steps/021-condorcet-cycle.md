title: Почему коллективные предпочтения образуют цикл
source_anchor: '### Multi-agent vote, the heterogeneous extension'
---

Ты запускаешь трёх разных агентов и получаешь вполне аккуратные бюллетени:

- первый: A выше B, B выше C;
- второй: B выше C, C выше A;
- третий: C выше A, A выше B.

Ни один агент себе не противоречит. Но сравни кандидатов попарно, используя перевес из [шага 17](#step-17). A побеждает B со счётом 2:1: его предпочитают первый и третий агенты. B так же побеждает C благодаря первому и второму. А C побеждает A голосами второго и третьего.

Кого теперь назвать сильнейшим? Выберешь A — его обыгрывает C. Выберешь C — его обыгрывает B. Выберешь B — его обыгрывает A.

Так возникает **цикл коллективных предпочтений**: направления попарных побед замыкаются в круг. Это не означает, что агенты рассуждают циклически. Для каждой пары большинство складывается из другой коалиции: за A против B голосуют одни двое, за B против C — другие, за C против A — третьи. Поэтому логичный порядок каждого отдельного участника не гарантирует логичного общего порядка.

Именно форма этих связей — кто кого побеждает — называется здесь топологией дебатов. В такой топологии нет кандидата, удовлетворяющего требованию из [шага 19](#step-19): каждый проигрывает хотя бы одному сопернику.

> 🎒 **На пальцах.** Три жильца выбирают зону для двора: сад, мастерскую или спортплощадку. Для каждой пары собирается своя коалиция из двух жильцов. Одна ставит сад выше мастерской, другая — мастерскую выше площадки, третья — площадку выше сада. У каждого личный список последователен; круг появляется только на общем табло.
