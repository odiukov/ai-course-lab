В мастерской выбирают краску для общей вывески. Три человека одобрили зелёную, двое — синюю, а один из них отметил обе. Если смотреть только на первый элемент бюллетеня, часть одобрений исчезнет: здесь нужно учитывать все варианты, отмеченные каждым участником.

Напиши `approval_winner`. Функция получает бюллетени в формате из [шага 14](#step-14) и возвращает кандидата с наибольшим числом одобрений. Сначала подготовь счётчик для всех кандидатов — их уже умеет находить функция `candidates` из [шага 6](#step-6). Затем пройди по каждому бюллетеню и увеличь счёт каждого указанного в нём кандидата на единицу.

Следи за важным отличием от `plurality_winner` из [шага 8](#step-8): позиция имени внутри approval-бюллетеня ничего не меняет. Если агент одобрил `A` и `C`, по одному голосу получают оба. Пустой бюллетень не добавляет голосов никому.

После подсчёта найди максимальный результат и проверь, единственный ли он. При равенстве используй то же соглашение о ничьей, что и в уже написанных функциях-победителях. Отдельно сохрани их поведение для случая, когда кандидатов вообще нет.

Главная проверка проста: один бюллетень может увеличить несколько счётчиков, но каждый выбранный кандидат получает от него ровно одно одобрение.

> 🎒 **На пальцах.** Представь стену мастерской с наклейками возле образцов краски. Каждый человек может приклеить по одной наклейке к нескольким подходящим цветам. Ты считаешь все наклейки, а не только наклейку возле первого выбранного цвета. Побеждает образец с самой большой стопкой — если такая стопка одна.
