Чтобы что-то делать с картинкой в коде — менять яркость, вырезать кусок, искать на ней объекты — сначала надо перестать думать о ней как о картинке. Для компьютера это просто таблица чисел. И первое, что стоит проверить, открыв любое изображение: какого размера эта таблица и какими числами она заполнена.

Pillow — библиотека, которая умеет читать JPEG и PNG (как программа-просмотрщик, только без окошка). NumPy — библиотека для работы с большими таблицами чисел; такую таблицу называют **массивом**. Переводим одно в другое и смотрим:

```python
arr = synthetic_rgb()
print(arr.shape)   # (128, 192, 3)
print(arr.dtype)   # uint8
print(arr.min(), arr.max())
```

`shape` — форма массива, то есть его размеры по каждому измерению. Здесь: 128 строк, 192 столбца и 3 значения в каждой клетке. Строки — это высота, столбцы — ширина. Обрати внимание на порядок: сначала высота, потом ширина. В графических редакторах пишут наоборот («1920×1080»), и на этом спотыкаются постоянно.

`dtype` — тип чисел. `uint8` значит «целые от 0 до 255»: 0 — темнота, 255 — максимальная яркость. Больше 255 в такой массив просто не влезет.

> 🎒 **На пальцах.** Представь миллиметровую бумагу, натянутую поверх фотографии. В каждой клеточке ты записываешь карандашом, насколько там ярко: от 0 до 255. Фотографию убрали — остались только цифры в клетках, и по ним картинку можно собрать заново. `shape` отвечает на вопрос «сколько клеток вниз, сколько вправо», а `dtype` — «в каком диапазоне цифры я разрешил себе писать».
