Теперь у тебя есть все детали по отдельности: список правил из [шага 9](#step-9), регулярные выражения, шаблоны ответов и функция `reflect` из [шага 8](#step-8). Осталось собрать диспетчера, который примет одну реплику и выберет ответ.

Напиши `rule_based_respond(user_input)`. Сначала убери пробелы по краям ввода. Затем перебирай `PATTERNS` сверху вниз и для каждого правила проверяй совпадение с началом строки через `pattern.regex.match(...)`.

Результат проверки сохрани в переменную. Это важно: при успехе там лежит не просто «да», а объект совпадения с захваченными группами. Получи их методом `.groups()` и передай в `pattern.template.format(...)`. Звёздочка перед группами распакует их по позициям: первая попадёт в `{0}`, вторая — в `{1}`.

Как только правило подошло, сразу возвращай готовую реплику. Цикл продолжать нельзя: иначе более позднее правило сможет вмешаться, хотя порядок уже определил победителя.

Если цикл закончился без ответа, верни `FALLBACK`. Размести этот возврат после цикла, а не внутри него: иначе подстраховка сработает уже после первой неудачной проверки, и остальные правила никогда не получат шанс.

Проверь функцию на трёх случаях: совпадение с одной группой, совпадение с двумя группами и строка, которой не подходит ни одно правило.

> 🎒 **На пальцах.** Представь ряд турникетов в аэропорту. Ты подходишь к ним по очереди: первый проверяет один тип посадочного талона, второй — другой. Подходящий турникет пропускает тебя сразу. Если поставить стойку справочной после первого турникета, туда отправятся даже пассажиры, которым подошёл бы второй. Поэтому справочная ждёт только в самом конце ряда.
