Здесь ты проверяешь не память на семь названий, а умение собрать минимальный набор по правилам из [шага 14](#step-14). Главная ловушка — выбрать один фреймворк по ярлыку компании: «это банк, значит достаточно GDPR». Смотри на все триггеры одновременно и добавляй только вызванные ими требования. Затем сравни результат с `required_frameworks`, который ты писал на [шаге 15](#step-15).

> 🎒 **На пальцах.** Представь связку ключей. SOC 2 Type II открывает общий вход для корпоративных клиентов. Для кабинета с медицинскими картами нужен ключ HIPAA, для европейского отделения — GDPR и EU AI Act, для комнаты с карточными данными — PCI-DSS. Ты берёшь ключи от тех дверей, которые действительно собираешься открыть.
