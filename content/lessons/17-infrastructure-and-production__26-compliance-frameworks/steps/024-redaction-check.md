    options:
      - Когда приложение сохранило ответ модели
      - Когда исходный промпт был отправлен во внешний API

      - 'Передачи не было, потому что в ответе номер скрыт'
    correct: 1
    explanation: >-
      Передача произошла в момент, когда внешний провайдер получил исходный

  - question: Какое действие не даст внешнему API получить PII?
    options:
      - Распознать и заменить PII до отправки запроса
      - Удалить PII из ответа модели
      - Очистить журнал запросов после вызова
      - Попросить пользователя удалить ответ
    correct: 0
    explanation: >-
      Только обработка до вызова модели меняет данные, которые фактически
      покидают твою систему.

Здесь важно поймать не место, где данные позже хранятся или показываются, а границу системы. Как только запрос с PII покинул твою инфраструктуру и попал во внешний API, передача уже состоялась — даже если провайдер обещает ничего не сохранять, а ответ приходит очищенным.

Частая ошибка — принять безопасный на вид результат за безопасный процесс. Но проверять нужно именно исходящий запрос. Поэтому затирание из [шага 23](#step-23) ставят перед этой границей: после неё исправлять уже нечего — внешний получатель данные увидел.
