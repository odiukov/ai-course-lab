Возьми карту признаков, где в одном канале лежат разные числа, и мысленно вырежи из неё рамку-кандидат. Как превратить этот фрагмент в сетку, например, `2 × 2`, если сама рамка занимает `7 × 5` клеток? Именно это предстоит собрать в `roi_pool`.

Функция получает карту признаков, набор рамок и требуемый размер результата. Координаты каждой рамки сначала переводятся в целые границы по правилу из [шага 15](#step-15). Затем область делится на заданное число ячеек. Границы этих ячеек тоже округляются и ограничиваются размерами карты, чтобы индекс не оказался снаружи.

Внутри каждой ячейки нужно оставить максимальное значение. Обрабатывай каналы независимо: максимум из канала с контурами не должен смешиваться с максимумом из канала с текстурой. Для нескольких рамок функция возвращает несколько фрагментов одинаковой формы — даже если исходные рамки заметно различаются по ширине и высоте.

Особенно внимательно проверь три случая: рамка касается края карты, после округления ячейка получается пустой, а две соседние ячейки захватывают граничные клетки. Полезные тесты здесь маленькие: на карте с последовательными числами максимум каждой области легко проверить глазами. Ещё один хороший тест — заполнить канал одной константой: весь результат должен сохранить её.

Если разные по размеру рамки дают одинаковую форму выхода, а значения в каждой позиции действительно являются максимумами своей области, механизм собран правильно.

> 🎒 **На пальцах.** Представь тепловизор над складом. Ты выделяешь прямоугольный участок, делишь его на одинаковое число секторов и из каждого записываешь только самую горячую точку. Большой и маленький участки превращаются в таблицы одного размера. `roi_pool` делает то же самое с каждым каналом признаков, только границы секторов обязан проводить по целым клеткам.
