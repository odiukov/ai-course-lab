Перед тобой пять рамок: оценки высокие у всех, но три почти совпадают. Если просто взять лучшие оценки, один объект попадёт в результат несколько раз. Логику отбора мы разобрали в [шаге 11](#step-11), теперь собери её в функцию:

```python
def nms(boxes, scores, iou_threshold):
    # верни индексы рамок, которые нужно оставить
    pass
```

`boxes` имеет форму `[N, 4]`, `scores` — `[N]`, а результатом должен быть одномерный тензор индексов. Важно вернуть индексы исходных рамок, а не сами координаты: следующему коду понадобятся и рамки, и связанные с ними оценки.

Начни с сортировки индексов по `scores` от большей оценки к меньшей. Затем повторяй три действия:

1. Бери первый индекс — он указывает на лучшую из ещё не рассмотренных рамок.
2. Добавляй его в результат.
3. Сравнивай выбранную рамку со всеми оставшимися через `box_iou` из [шага 10](#step-10) и убирай кандидатов, у которых IoU выше `iou_threshold`.

Следи за формами тензоров: одна выбранная рамка должна временно стать набором формы `[1, 4]`. Тогда `box_iou` вернёт строку сравнений, из которой нужно убрать лишнее измерение.

Проверь два края: при пустом `boxes` функция должна вернуть пустой тензор индексов, а рамка с IoU, равным порогу, должна остаться — подавляются только значения выше порога. Итоговые индексы сохраняй в порядке убывания оценок.

> 🎒 **На пальцах.** Представь прослушивание дублей одной реплики. Ты сначала оставляешь запись с самой высокой оценкой, а затем убираешь слишком похожие на неё дубли. После этого берёшь лучшую из оставшихся и повторяешь отбор. В финальном списке сохраняются номера записей: по ним можно достать и звук, и имя актёра, и остальные данные.
