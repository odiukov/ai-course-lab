Зачем это нужно: когда сеть учится, ей постоянно приходится «разворачивать» таблицы чисел задом наперёд и быстро выхватывать из них одно короткое резюме. Два приёма делают это почти бесплатно.

Представь матрицу как шахматную доску с числами. **Главная диагональ** — клетки, идущие из левого верхнего угла в правый нижний, наискосок. Это как складка на листе бумаги, сгибающая его пополам.

```
[ 2  7  1 ]
[ 4  5  9 ]      диагональ: 2, 5, 3
[ 8  6  3 ]
```

**Транспонирование** — берёшь ту самую складку и перекидываешь через неё всё содержимое: строки становятся столбцами. Как если бы ты перевернул расписание из «дни по строкам» в «дни по столбцам» — данные те же, взгляд другой. Обозначают буквой T сверху: $A^T$ — это «А, перевёрнутая по диагонали».

```
    A            Aᵀ
[ 1  2 ]      [ 1  3 ]
[ 3  4 ]  →   [ 2  4 ]
```

Число на диагонали остаётся на месте — оно лежит на самой складке.

```
[ 2  7  1 ]        [ 2  4  8 ]
[ 4  5  9 ]   →    [ 7  5  6 ]
[ 8  6  3 ]        [ 1  9  3 ]
     ↑ 2, 5, 3 не сдвинулись
```

Отсюда простой факт: транспонирование не трогает диагональ. А раз диагональ — устойчивая часть матрицы, по ней удобно считать краткую сводку о таблице целиком.
