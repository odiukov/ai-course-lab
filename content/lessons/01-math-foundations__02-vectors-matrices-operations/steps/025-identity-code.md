Все остальные методы `Matrix` работают с уже существующими данными: сложить, перемножить, транспонировать. А единичную матрицу нужно уметь создавать с нуля — под любой размер, какой понадобится. Печатать её руками для 128 строк никто не будет, поэтому пишем генератор.

`identity(n)` помечен как `@staticmethod` — это метод, который живёт внутри класса, но не привязан ни к какому конкретному объекту. Ему не нужен `self`, потому что исходной матрицы нет: он её и делает. Вызывать так: `Matrix.identity(3)`, прямо от класса.

Что метод должен вернуть: объект `Matrix` размера n на n, где элемент на пересечении строки $i$ и столбца $j$ равен 1, если $i = j$ (номер строки совпал с номером столбца — это диагональ), и 0 во всех остальных случаях. Собирается это одним вложенным перебором: внешний пробегает строки, внутренний — столбцы внутри строки.

На что смотреть при проверке:

- возвращается именно `Matrix`, а не голый список списков — иначе результат нельзя будет передать в `matmul`;
- `Matrix.identity(3).shape` даёт `(3, 3)`;
- единицы идут по диагонали из левого верхнего угла в правый нижний, а не наоборот;
- `Matrix.identity(2).matmul(A)` возвращает ту же `A`, если у `A` две строки.

> 🎒 **На пальцах.** Представь классную комнату, где каждому ученику раздают тетради. Правило простое: ученик номер 3 получает тетрадь номер 3, ученик номер 5 — тетрадь номер 5, и никто не получает чужую. Ты обходишь всех по списку и каждому кладёшь единицу только в его собственную ячейку, а во все остальные — ноль. Получившаяся таблица «кто что получил» и есть единичная матрица.
