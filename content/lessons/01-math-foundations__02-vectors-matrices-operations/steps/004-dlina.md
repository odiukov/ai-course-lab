Зачем это нужно: компьютеру постоянно надо отвечать на вопрос «насколько это далеко / насколько это много». Длина вектора — и есть его ответ. Посмотри, как она получается, на самой простой картинке.

Возьми вектор `[3, 4]` — стрелку из точки (0, 0) в точку (3, 4).

```
  4 ┤        ● (3,4)
    │      ╱ │
  3 ┤     ╱  │
    │    ╱   │  4  ← второе число, шаг вверх
  2 ┤   ╱    │
    │  ╱     │
  1 ┤ ╱      │
    │╱       │
  0 ┼────────┴──
    0  1  2  3
        3  ← первое число, шаг вправо
```

Стрелка — это гипотенуза (длинная сторона) прямоугольного треугольника. Катеты (две короткие стороны) — сами числа вектора: 3 вправо и 4 вверх.

Дальше работает школьная теорема Пифагора:

$$\lVert v \rVert = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

Здесь $\lVert v \rVert$ — длина вектора $v$ (две палочки по бокам читаются как «длина»), $\sqrt{\ }$ — квадратный корень, то есть обратная операция к возведению в квадрат.

Обрати внимание на порядок действий: каждое число возводим в квадрат, складываем, из суммы берём корень. Не «складываем и потом возводим» — 3 + 4 = 7, а длина всё-таки 5.

Треугольник рисуется только для двух чисел. Но сама формула не знает, сколько их: для вектора из 768 чисел компьютер так же возведёт в квадрат все 768, сложит и извлечёт корень.
