Когда что-то не сходится в расчётах, первый вопрос всегда один: какой формы у тебя данные? Форма — это как размер коробки: пока не посмотришь на неё, не поймёшь, влезет ли содержимое куда надо. Поэтому полезно научиться видеть форму глазами, а не выводить её по памяти.

Возьми список из трёх чисел. Его можно поставить вертикально — тогда это **столбец**:

```
[ 2 ]
[ 5 ]     форма: 3 x 1
[ 1 ]     три строки, один столбец
```

А можно положить горизонтально — тогда это **строка**:

```
[ 2  5  1 ]     форма: 1 x 3
                одна строка, три столбца
```

Числа те же самые. Форма — разная. Запись $(m \times n)$ читается так: $m$ — сколько строк (этажей сверху вниз), $n$ — сколько столбцов (колонок слева направо). Всегда в этом порядке: сначала высота, потом ширина.

Теперь то же для таблицы:

```
[ 1  0  4 ]
[ 7  2  9 ]     форма: 2 x 3
                две строки, три столбца
```

Полезная привычка: чтобы назвать форму, не считай все числа подряд. Посчитай, сколько горизонтальных рядов — это первое число. Потом посчитай, сколько чисел в одном ряду — это второе.

Попробуй прямо сейчас: какая форма у `[ 8 ]`? Одна строка, один столбец — $1 \times 1$. Одинокое число тоже имеет форму.
