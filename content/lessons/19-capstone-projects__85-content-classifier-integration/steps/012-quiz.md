  - question: >-
      Какой интерфейс позволяет заменить реализацию выходного классификатора, не
      добавляя в роутер специальную ветку для неё?
    options:
      - 'Метод, возвращающий только строку с названием severity'
      - >-
        Метод classify, возвращающий структурированный ClassifierVerdict, и
        метод redact, возвращающий обработанный текст
      - 'Метод, который самостоятельно выбирает итоговое действие роутера'
      - 'Функция, возвращающая только список найденных фрагментов'
    correct: 1
    explanation: >-
      Единые методы classify и redact позволяют роутеру одинаково получать
      вердикты и применять редакторы разных классификаторов.
  - question: >-
      Один выход модели независимо проверяют несколько классификаторов. Что даёт
      их параллельный запуск при отсутствии зависимостей между проверками?
    options:
      - Общая задержка приближается к времени самого медленного классификатора
      - Общая задержка всегда равна сумме времени всех классификаторов
      - Роутер получает вердикт только от завершившегося первым классификатора
      - Численные score автоматически становятся сопоставимыми
    correct: 0
    explanation: >-
      Все классификаторы читают один и тот же исходный текст и не зависят друг
      от друга, поэтому проверки можно выполнять одновременно.
  - question: >-
      Все классификаторы вернули severity none. Как роутер должен обработать
      выход модели?
    options:
      - 'Выбрать log, записать вердикты в трассу и оставить текст без изменений'
      - Выбрать warn и добавить предупреждение
      - Выбрать redact и вызвать все редакторы
      - Выбрать block и заменить текст отказом
    correct: 0
    explanation: >-
      Уровню none соответствует действие log: результат классификации
      сохраняется для наблюдаемости, а исходный текст отправляется без
      изменений.
  - question: >-
      Роутер выбрал redact, причём одновременно сработали классификаторы PII и
      утечки инструкции. Что делать с текстом?
    options:
      - Запустить только редактор классификатора с большим score
      - Запустить только PII-редактор
      - Применить оба сработавших редактора последовательно
      - Вернуть исходный текст и только записать событие в журнал
    correct: 2
    explanation: >-
      Каждый редактор скрывает находки своего типа, поэтому безопасный результат
      получается после последовательного применения всех сработавших редакторов.

Дальше по курсу тебе понадобится привычка собирать несколько сигналов в предсказуемый конвейер. Следи за тремя стыками: единым контрактом вердикта, сведением severity по максимуму и выбором действия после сведения. Частая ошибка прячется в финале: взять первый сигнал или применить один редактор, хотя сработали несколько. Вопросы проверяют весь путь — от классификации до безопасного результата.
