Внутри `sync_grads` у модели может быть много параметров, и у каждого — свой буфер градиента. Твоя задача — пройти по ним и заменить локальные значения общими: после вызова каждый ранг должен видеть одинаковый усреднённый градиент для каждого участвующего параметра.

Сначала проверь, существует ли градиент. Значение `None` означает, что параметр не участвовал в текущем вычислении; такой параметр нужно пропустить, иначе распределённая операция получит не тензор.

Для существующего градиента запусти коллективное суммирование между рангами, а затем раздели полученный буфер на `world_size`. Почему нужны обе операции, разобрано в [шаге 4](#step-4): сеть складывает значения, а оптимизатору требуется среднее. Изменяй градиент на месте — оптимизатор позже прочитает именно этот буфер.

Следи и за контрактом из [шага 2](#step-2): все ранги должны обрабатывать параметры в одном порядке и входить в соответствующие коллективные операции. Иначе один процесс будет ждать операцию, до которой другой не дошёл.

После функции локальный градиент перестаёт быть мнением одного ранга: он становится общей поправкой модели.

> 🎒 **На пальцах.** Представь редакторов, которые независимо предлагают числовую поправку к каждой строке рукописи. Для строки с замечаниями ты собираешь все поправки и находишь среднюю; строку без замечаний просто пропускаешь. Затем одинаковую среднюю записываешь в экземпляр каждого редактора. Теперь дальнейшая правка у всех начинается с одного решения, а не с четырёх разных версий.
