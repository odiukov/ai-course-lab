Перед тобой четыре списка векторов: две группы и два набора атрибутов. Косинусные сходства уже считаются правильно, но при ручном сложении легко перевернуть вычитание — и получить отрицательное число там, где ожидалось положительное. Поэтому сначала зафиксируй порядок из [шага 9](#step-9), а затем перенеси его в `weat_like_score`.

Для каждого термина первой группы найди его среднее сходство с атрибутами A и отдельно — с атрибутами B. Вычти второе среднее из первого. Это одна оценка ассоциации термина. Повтори расчёт для остальных терминов обеих групп, используя `cosine_similarity` из [шага 8](#step-8).

Теперь усредни оценки внутри каждой группы. Итог функции — средняя оценка первой группы минус средняя оценка второй. Важно сохранять именно эту последовательность: сначала средние по атрибутам для отдельного термина, затем среднее по терминам группы, и только потом разность групп.

Посмотри и на знак, и на величину результата. Положительное число означает, что первая группа сильнее связана с A относительно B, чем вторая; отрицательное — обратное. Значение около нуля говорит, что зонд почти не видит разницы. На игрушечных данных до дебиасинга ожидается примерно `+0.8906`, поэтому это удобная проверка направления вычитания. После преобразования получится около `+0.2212`: функция та же, изменились только векторы.

> 🎒 **На пальцах.** Представь две музыкальные группы и две комиссии слушателей. Для каждого музыканта ты сначала сравниваешь среднюю оценку комиссии A со средней оценкой комиссии B. Потом находишь средний перевес для каждой группы и сравниваешь эти два перевеса. Если перепутать порядок хотя бы одного вычитания, итоговый знак сменится — словно победителем объявили команду с меньшим счётом.
