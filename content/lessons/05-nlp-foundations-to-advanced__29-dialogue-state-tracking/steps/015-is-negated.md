Фраза «не нужен север, ищи в центре» содержит отрицание, но оно относится только к району. Если `is_negated` заметит одно слово «не» и вернёт `True` для любого slot, система заодно очистит кухню и цену. Получится та самая опасная ошибка из [шага 14](#step-14): пользователь отменил одну настройку, а исчезли другие.

Тебе нужно дописать `is_negated(utterance, slot)`. Она отвечает на узкий вопрос: есть ли в реплике явная отмена именно переданного slot? Результат — `True` или `False`, а состояние функция не меняет.

Сначала приведи реплику к нижнему регистру. Затем для каждого slot задай связанные с ним слова: например, для района это могут быть `район`, `север`, `центр`, а для кухни — `кухня`, `итальянская`, `японская`. Ищи не просто отрицание, а сочетание сигнала отмены со словом нужной группы: «не нужен север», «убери район», «забудь про кухню».

Проверь три случая:

- явная отмена нужного slot даёт `True`;
- отрицание другого slot даёт `False`;
- реплика без отмены даёт `False`.

Не вызывай здесь `extract_slots` из [шага 12](#step-12) и не записывай `None` в состояние. У этой функции одна работа: распознать адресованную конкретному slot отмену. Чем уже вопрос, тем меньше случайных очисток.

> 🎒 **На пальцах.** Представь теплицу с отдельным краном для каждой грядки. Команда «перекрой воду у помидоров» не означает «закрой главный вентиль». `is_negated` сначала смотрит, есть ли команда перекрыть, а затем проверяет табличку нужной грядки. Совпали и действие, и адрес — возвращает `True`. Совпал только запрет без адреса — кран трогать рано.
