check:
  - question: >-
      В журнале команд все приёмочные проверки завершились нулевым кодом, но
      отчёт области изменений обнаружил запись в запрещённый файл. Какой вердикт
      возможен?
    options:
      - >-
        Гейт пропустит задачу, потому что результат команд важнее остальных
        свидетельств
      - 'Гейт не пропустит задачу: запрещённая запись — блокирующая находка'
      - Гейт сам повторит команды и возьмёт результат нового запуска
    correct: 1
    explanation: >-
      Успешные команды подтверждают только свою часть проверки. Запрещённая
      запись из отчёта области изменений отдельно блокирует положительный
      вердикт, и гейт ничего не перезапускает.
  - question: >-
      Вместо кода завершения приёмочной команды гейт встретил `null`. В каком
      артефакте нужно искать это свидетельство?
    options:
      - В журнале `feedback_record.jsonl`
      - В отчёте `scope_report.json`
      - В отчёте `rule_report.json`
      - В итоговом `verification_report.json`
    correct: 0
    explanation: >-
      Сведения о запуске приёмочных команд и их коды завершения записаны в
      `feedback_record.jsonl`; остальные отчёты отвечают за другие виды
      свидетельств, а итоговый отчёт — уже результат работы гейта.
---

Теперь тебе важно не просто помнить четыре входа из [шага 3](#step-3), а различать их обязанности. Журнал команд сообщает, что запускалось и с каким кодом завершилось. Отчёт области изменений показывает запрещённые и посторонние записи. Отчёт правил хранит результаты обязательных правил, а diff позволяет сверить реально затронутые файлы с разрешёнными. Частая ошибка — считать один успешный отчёт доказательством всей готовности. Гейт читает каждый источник только по его предмету и ничего не измеряет заново.

> 🎒 **На пальцах.** Представь приёмку квартиры: электрик подтверждает проводку, сантехник — трубы, а замерщик — соответствие плану. Справная розетка не доказывает, что стена стоит на разрешённом месте. Ты берёшь каждое свидетельство у того специалиста, который действительно мог его получить.
