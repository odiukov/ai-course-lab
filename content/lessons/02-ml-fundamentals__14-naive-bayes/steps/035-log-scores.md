Ты подаёшь модели сразу три письма и ожидаешь для каждого по одному баллу на каждый класс. Если классов два, результат должен иметь форму «3 строки на 2 столбца»: строка соответствует письму, столбец — классу.

Твоя задача — написать `log_scores(X, model)`. Функция получает матрицу счётчиков слов `X` и обученную модель из [шага 31](#step-31). В модели уже лежат:

- `log_feature_probs` — вклад каждого слова для каждого класса;
- `log_class_priors` — начальный вклад каждого класса.

Сначала объедини счётчики слов с их логарифмическими весами матричным умножением, разобранным в [шаге 34](#step-34). Проверь ориентацию матрицы весов: строки результата должны соответствовать документам, а столбцы — классам. Затем прибавь `log_class_priors` ко всем строкам. NumPy сделает это автоматически: один и тот же вектор классов будет добавлен к каждому документу.

Функция должна вернуть всю матрицу баллов, не выбирая из неё победителей. Следующий шаг займётся выбором класса; здесь важно сохранить баллы каждого класса для каждого документа.

Перед завершением посмотри на формы массивов. Если в `X` пять документов и сто признаков, а модель знает три класса, результат обязан иметь форму `(5, 3)`. Несовпадение обычно означает, что матрицу весов забыли транспонировать.

> 🎒 **На пальцах.** Представь три счета из кафе и двух бухгалтеров, которые оценивают каждую позицию по своим тарифам. После подсчёта у каждого счёта появляются две суммы — по одной от каждого бухгалтера. Затем каждый бухгалтер добавляет к своей сумме постоянную надбавку. `log_scores` возвращает таблицу всех итогов, но ещё не решает, чей итог считать главным.
