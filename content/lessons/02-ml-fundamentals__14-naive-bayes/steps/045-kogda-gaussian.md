title: Gaussian NB описывает непрерывный признак средним и дисперсией

Ты сортируешь апельсины двух сортов по массе. У первого в обучающих данных чаще встречаются плоды около 150 г, у второго — около 190 г. Но хранить вероятность для каждого возможного веса нельзя: между 150 и 151 есть ещё 150,1, 150,01 и бесконечно много значений.

Gaussian NB сворачивает измерения каждого класса в два числа: **среднее** показывает типичный уровень признака, а **дисперсия** — насколько широко значения разбросаны вокруг него. Затем модель мысленно накрывает данные «колоколом»: возле среднего он высокий, а по мере удаления плавно опускается.

Для значения признака \(x_i\) правдоподобие внутри класса считается так:

$$
P(x_i\mid c)=\frac{1}{\sqrt{2\pi\sigma_{ic}^{2}}}
\exp\left(-\frac{(x_i-\mu_{ic})^2}{2\sigma_{ic}^{2}}\right)
$$

Здесь \(x_i\) — измеренное значение признака, \(c\) — проверяемый класс, \(\mu_{ic}\) — среднее этого признака в классе, а \(\sigma_{ic}^{2}\) — его дисперсия. Чем ближе значение к среднему, тем выше полученный балл. При большой дисперсии колокол шире: заметное отклонение выглядит нормальным. При малой — уже, поэтому такое же отклонение сильнее говорит против класса.

Для каждого непрерывного признака и каждого класса модель запоминает свою пару «среднее плюс дисперсия». Дальше отдельные оценки признаков объединяются по тому же наивному допущению, которое обсуждалось в [шаге 9](#step-9). Значит, апельсин массой 155 г окажется правдоподобнее для того сорта, чей колокол лучше накрывает это значение.

> 🎒 **На пальцах.** Представь две кучки апельсинов на весах. Ты отмечаешь центр каждой кучки и ширину её разброса. Новый плод не обязан весить ровно столько же, сколько один из прежних: ты проверяешь, насколько естественно его масса смотрится внутри каждой кучки. Gaussian NB хранит не все взвешивания, а только центр и разброс.
