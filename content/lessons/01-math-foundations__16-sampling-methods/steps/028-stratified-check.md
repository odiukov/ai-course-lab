title: 'Проверка: почему стратификация снижает дисперсию для гладкой функции'
source_anchor: '### Stratified Sampling'
check:
  - question: >-
      Обычное и стратифицированное сэмплирование используют одинаковое число
      точек для оценки среднего гладкой функции. Почему стратифицированная
      оценка обычно стабильнее?
    options:
      - >-
        Каждая часть области представлена, а случайное смещение точки внутри
        узкой страты мало меняет значение функции
      - Стратификация увеличивает число вычисленных значений функции
      - Из каждой страты выбирается точка с минимальным значением функции
      - После разбиения области случайность полностью исчезает
    correct: 0
    explanation: >-
      Выигрыш возникает не из-за большего числа точек. Гладкость уменьшает
      разброс значений внутри каждой страты, а обязательное представительство
      всех страт устраняет случайные сгущения и пробелы.
  - question: >-
      Что произойдёт с преимуществом стратификации, если функция начнёт резко и
      часто меняться даже внутри каждой узкой страты?
    options:
      - >-
        Преимущество обычно уменьшится, потому что значения внутри одной страты
        больше не будут близкими
      - >-
        Преимущество обязательно возрастёт, поскольку резкие изменения легче
        интегрировать
      - Оценка станет точной независимо от положения случайных точек
      - 'Дисперсия исчезнет, потому что границы страт сгладят функцию'
    correct: 0
    explanation: >-
      Стратификация особенно эффективна, когда функция мало меняется внутри
      слоя. Если близкие точки могут давать сильно разные значения,
      внутристратовая дисперсия остаётся большой и выигрыш ослабевает.
---

Здесь важно связать устройство выборки из [шага 26](#step-26) с разбросом результата. Стратификация не угадывает правильный ответ и не отменяет случайность: она ограничивает её внутри узких слоёв. Если функция гладкая, точки одного слоя дают близкие значения, поэтому их случайное положение мало меняет итог. Чаще всего спотыкаются именно здесь, приписывая выигрыш большему числу точек, хотя их количество остаётся тем же.

> 🎒 **На пальцах.** Ты проверяешь оттенок длинного рулона ткани с плавным переходом цвета. Случайные пробы могут скучиться у одного края. Если взять по пробе из каждого участка, весь рулон будет представлен, а небольшое смещение пробы внутри участка почти ничего не изменит: соседние оттенки похожи.
