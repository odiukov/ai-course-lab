type: check
title: 'Проверка: почему стратификация снижает дисперсию для гладкой функции'
source_anchor: '### Stratified Sampling'
check:
  - question: >-
      Ты оцениваешь среднее гладкой функции одинаковым числом точек. Почему одна
      точка из каждого слоя обычно даёт более стабильный результат?
    options:
      - >-
        Внутри узкого слоя значения функции близки, а обязательное покрытие
        слоёв не оставляет больших случайных дыр
      - Стратификация выбирает только точки с небольшими значениями функции
      - Точки в слоях перестают быть случайными
      - Каждая точка автоматически становится точным значением интеграла
    correct: 0
    explanation: >-
      У гладкой функции соседние точки дают похожие значения. Поэтому
      случайность внутри слоя влияет слабо, а представительство всех слоёв
      убирает разброс из-за кластеров и дыр.
  - question: В каком случае преимущество стратификации будет заметнее?
    options:
      - Функция плавно меняется по всему отрезку
      - Значения функции случайно скачут даже между очень близкими точками
      - Все точки намеренно берутся из одного слоя
      - Число слоёв равно одному
    correct: 0
    explanation: >-
      При плавном изменении значения внутри каждого узкого слоя почти одинаковы,
      поэтому неопределённость остаётся небольшой. Резкие частые скачки
      ослабляют этот эффект.
---

Здесь важно связать устройство выборки из [шага 26](#step-26) с разбросом результата. Стратификация не угадывает правильный ответ и не отменяет случайность: она ограничивает её внутри узких слоёв. Если функция гладкая, точки одного слоя дают близкие значения, поэтому их случайное положение мало меняет итог. Чаще всего спотыкаются именно здесь, приписывая выигрыш большему числу точек, хотя их количество остаётся тем же.

> 🎒 **На пальцах.** Ты проверяешь оттенок длинного рулона ткани с плавным переходом цвета. Случайные пробы могут скучиться у одного края. Если взять по пробе из каждого участка, весь рулон будет представлен, а небольшое смещение пробы внутри участка почти ничего не изменит: соседние оттенки похожи.
