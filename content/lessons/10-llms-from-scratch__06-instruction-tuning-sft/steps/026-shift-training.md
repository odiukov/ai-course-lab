У тебя есть четыре токена и маска той же длины:

```python
tokens = [41, 72, 18, 99]
mask   = [0,  0,  0,  1]
```

Модель не получает всю последовательность целиком как готовый ответ. По правилу из [шага 25](#step-25) первые три токена становятся входом, а последние три — целями для предсказания. Значит, функция `shift_for_training` должна вернуть три массива одинаковой длины:

- `input_ids` — последовательность без последнего токена;
- `target_ids` — последовательность без первого токена;
- `loss_mask` — маску, выровненную именно с `target_ids`.

Перед сдвигом обрежь `tokens` и `mask` до `seq_len`. Обрезать их нужно по одной границе: иначе позиции перестанут соответствовать друг другу. Затем преобразуй результаты в NumPy-массивы и добавь размер батча. Даже один пример модель ожидает в форме «одна строка на несколько позиций», то есть `(1, длина)`.

Дополни заготовку:

```python
def shift_for_training(tokens, mask, seq_len=64):
    """Готовит входы, цели и маску потерь для одного SFT-примера."""
    assert len(tokens) == len(mask)

    # Обрежь обе последовательности до seq_len.
    # Создай input_ids и target_ids со сдвигом на один токен.
    # Сдвинь loss_mask вместе с target_ids.
    # Добавь всем массивам размер батча.

    return input_ids, target_ids, loss_mask
```

После выполнения проверь не только значения, но и формы: все три результата должны иметь одинаковые два измерения. Если `tokens` после обрезки содержит $n$ элементов, в каждом результате останется $n-1$ позиций.

> 🎒 **На пальцах.** Представь киноплёнку и лист проверки кадров. Ты кладёшь рядом два экземпляра плёнки, но второй сдвигаешь на один кадр: слева виден предыдущий кадр, справа — следующий. Лист проверки прикреплён к правой плёнке, поэтому едет вместе с ней. Иначе отметка окажется под чужим кадром.
