Ты собираешь слой с `in_c=3`, `out_c=64` и ядром `3`, но между пространственной и временной свёртками нужно указать ещё одно число — `mid_c`. Если поставить его наугад, разбиение может неожиданно сделать модель тяжелее исходной 3D-свёртки.

Напиши функцию:

```python
def conv2plus1d_mid_channels(in_c, out_c, kernel_size):
    # вычисли число промежуточных каналов
    pass
```

Используй правило подбора из [шага 27](#step-27). Здесь не нужны тензоры или слои PyTorch: функция получает три целых числа и возвращает одно целое число. Для округления вниз пригодится оператор `//`.

Проверь себя на примере:

```python
mid_c = conv2plus1d_mid_channels(
    in_c=3,
    out_c=64,
    kernel_size=3,
)

assert mid_c == 23
assert isinstance(mid_c, int)
```

Следи за скобками: сначала должны сложиться две части знаменателя, и лишь затем числитель делится на их сумму. Если убрать скобки, Python выполнит операции в другом порядке — результат уже не будет соответствовать подсчёту параметров.

Полученное `23` затем можно передать пространственной свёртке как число выходных каналов, а временной — как число входных. Так две части состыкуются, сохранив примерно тот же бюджет параметров, что и единое 3D-ядро.

> 🎒 **На пальцах.** Представь, что мастерская заменяет один большой станок двумя последовательными. Между ними нужен склад полуфабрикатов: слишком маленький создаст тесное место, слишком большой займёт лишнюю площадь. `mid_c` — размер этого склада, а функция рассчитывает его по размерам старого станка, чтобы новая линия не раздула мастерскую.
