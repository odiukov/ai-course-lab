Перенеси в неё правило из [шага 18](#step-18). Если достигнута хотя бы одна веха, раздели общую стоимость на их количество. Не округляй результат внутри функции: точность может понадобиться для дальнейшего сравнения.

Отдельно обработай случай, когда `achieved_milestones` равно нулю. В этом упражнении возвращай `float("inf")` — бесконечность. Это не попытка буквально назначить цену несуществующей вехе, а практическое правило: система, которая потратила ресурсы и не добилась прогресса, не должна случайно выглядеть выгодной. Бесконечность удобно сравнивается с обычными числами и окажется хуже любой конечной стоимости.

Проверь себя на трёх случаях:

- стоимость `24`, вех `6` → `4.0`;
- стоимость `10`, вех `4` → `2.5`;
- стоимость `10`, вех `0` → `float("inf")`.

Главное место для ошибки — выполнить деление раньше, чем проверить ноль. Сначала реши, допустим ли знаменатель, и только затем считай стоимость.

Если изделий нет, писать «0 евро за штуку» нельзя: это сделало бы бесполезный абонемент самым выгодным. Бесконечная стоимость ставит его на правильное место — в конец сравнения.
