    options:
      - 'До усреднения: 3 строки на 512 столбцов; после: 12 строк на 512 столбцов'
      - 'До усреднения: 12 строк на 512 столбцов; после: 3 строки на 512 столбцов'

    explanation: >-

  - question: >-
      У каждого из 5 классов есть по 3 embedding от разных шаблонов. Как нужно
      выполнять усреднение?
    options:
      - Объединить все 15 embedding в один общий вектор
      - Усреднить пять классов отдельно внутри каждого шаблона
      - Для каждого класса отдельно усреднить его три embedding

    explanation: >-
      Шаблоны дают разные описания одного класса, поэтому объединять нужно

Здесь проверь, связываешь ли ты результат `build_prompts` из [шага 23](#step-23) с усреднением из [шага 25](#step-25). Чаще всего путают две оси: количество классов и количество шаблонов. До усреднения строк столько, сколько всех prompts; после — столько, сколько классов. Размерность каждого embedding при этом не меняется.

> 🎒 **На пальцах.** Представь три цвета краски и четыре пробных карточки для каждого цвета. Сначала у тебя двенадцать измерений оттенка. Затем ты отдельно сводишь четыре карточки синей краски, четыре зелёной и четыре красной. Получаются три итоговых образца — по одному на цвет, а не один средний цвет всей коробки.
