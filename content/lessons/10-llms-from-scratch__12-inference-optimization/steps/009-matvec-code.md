В редакторе тебя ждёт матрица из нескольких строк и один вектор. Нужно написать `matvec(matrix, vector)`: функция умножает каждую строку матрицы на вектор и возвращает по одному числу для каждой строки.

Возьми матрицу:

```text
[
  [2, 1, -1],
  [0, 3,  4]
]
```

и вектор `[5, 2, 1]`. Для первой строки попарно перемножь элементы с одинаковыми позициями и сложи результаты: `2×5 + 1×2 − 1×1`, получится `11`. Для второй строки получится `0×5 + 3×2 + 4×1 = 10`. Значит, функция должна вернуть `[11, 10]`.

Здесь понадобятся два уровня обхода. Внешний проходит по строкам матрицы, а внутренний — по элементам текущей строки и вектора. Для каждой новой строки заводи отдельную сумму с нуля. Если оставить сумму от предыдущей строки, результаты начнут накапливаться друг на друга — это самая частая ошибка.

Следи и за размерами: длина вектора должна совпадать с количеством элементов в каждой строке. Саму матрицу и вектор изменять не нужно; результат собирай отдельно.

В [шаге 8](#step-8) matvec был формой работы decode. Теперь ты буквально собираешь эту операцию: одна строка весов даёт одно выходное число.

> 🎒 **На пальцах.** Представь несколько чемоданов. Каждая строка показывает, сколько в чемодане футболок, книг и ботинок, а вектор хранит вес одной вещи каждого типа. Ты отдельно вычисляешь вес каждого чемодана: перемножаешь количества и веса, затем складываешь. Список итоговых весов и есть результат matvec.
