Напиши функцию `elo_update(rating_a, rating_b, score_a, k=32)`. Она получает текущие рейтинги двух моделей, результат модели A и коэффициент чувствительности `k`, а возвращает пару обновлённых рейтингов.

Результат `score_a` кодируется числом: `1.0` для победы A, `0.0` для поражения и `0.5` для ничьей. Результат B отдельно передавать не нужно: дополни результат A до единицы.

Внутри используй `expected_score` из [шага 49](#step-49). Сначала вычисли ожидания обеих моделей по **старым** рейтингам. Только после этого обновляй оба значения по правилу из [шага 50](#step-50). Если изменить рейтинг A раньше, а затем рассчитать ожидание B уже с новым значением A, один матч будет словно сыгран при двух разных стартовых условиях.

Проверь три свойства функции:

- победитель получает рейтинг, проигравший теряет;
- при ничьей фаворит теряет рейтинг, а аутсайдер получает;
- сумма двух рейтингов до и после матча не меняется.

Последнее свойство особенно удобно для поиска ошибок: сколько пунктов прибавилось у одной модели, столько же должно исчезнуть у другой. Не округляй числа внутри функции — округление пригодится только при показе результата.

> 🎒 **На пальцах.** Представь два конверта с фишками рейтинга. После матча ты перекладываешь некоторое количество фишек из одного конверта в другой. Сначала смотришь, сколько лежало в обоих конвертах до перекладывания, и определяешь размер перевода. Если после первого движения пересчитать второй перевод, фишки начнут появляться или исчезать. Один матч — один снимок исходных рейтингов.
