Здесь проверяется одна связка: по описанию агента собрать имя спана и выбрать вид. Имя — из [шага 8](#step-8), вид — по границе процесса из [шага 9](#step-9).

Спотыкаются обычно на двух вещах. Первая: забывают префикс `invoke_agent` и пишут в имя просто «Researcher» — тогда спан не состыкуется с остальными по договору из [шага 2](#step-2). Вторая: путают «агент удалённый» с «агент сложный». Вид спана не про сложность и не про длительность, а ровно про то, ушёл ли вызов из твоего процесса по сети. Локальный ReAct-цикл может молотить полминуты и всё равно остаётся INTERNAL.
