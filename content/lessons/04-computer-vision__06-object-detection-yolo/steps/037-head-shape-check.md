Проверь, можешь ли ты связать перестройку каналов из [шага 36](#step-36) с параметрами задачи. Частая ошибка — оставить только число классов и потерять пять предсказаний рамки и objectness. Другая ловушка — записать число anchor box в последнее измерение: оно занимает отдельное место перед набором признаков.

> 🎒 **На пальцах.** Представь автомат, который печатает по одному талону на каждый anchor box. В талоне всегда есть пять служебных полей, а затем по одному полю для каждого класса. Три талона по 25 полей требуют 75 печатных ячеек; если классов станет меньше, талонов останется три, но каждый станет короче.
