  - question: >-
      Модель вернула для всего изображения несколько вероятностей классов, но не
      указала координаты объектов. Почему это ещё не ответ детектора?
    options:
      - >-
        Детектор должен связать каждый найденный экземпляр с отдельной рамкой и
        классом
      - Детектор может возвращать только один класс для всего изображения
      - Детектор обязан перечислить все возможные классы модели
      - Детектор отличается от классификатора только форматом вероятностей
    correct: 0
    explanation: >-
      Несколько названий или вероятностей классов могут быть результатом
      многометочной классификации. Детекция дополнительно локализует отдельные
      экземпляры объектов рамками.
  - question: >-
      На изображении нет объектов, которые должен находить детектор. Какой
      итоговый результат корректен?
    options:
      - Пустой список обнаруженных объектов
      - Рамка вокруг всего изображения с наиболее вероятным классом
      - Специальная рамка нулевого размера
      - Обязательная метка «фон» без координат
    correct: 0
    explanation: >-
      Число обнаружений зависит от содержимого изображения. Если подходящих
      объектов нет, после отбрасывания неподходящих предсказаний детектор может
      вернуть пустой список.

Положи рядом ответы двух моделей на один снимок. У классификатора ожидай одну общую оценку содержимого кадра. У детектора ищи список, где у каждого найденного объекта есть собственные класс и рамка; список может содержать ноль, один или несколько элементов. Главная ловушка — принять несколько названий классов за детекцию: без положения объектов это всё ещё не полноценный ответ детектора. Связь рамки, класса и objectness разбиралась на [шаге 3](#step-3).

> 🎒 **На пальцах.** Классификатор похож на наклейку на грузовике: «внутри книги». Детектор выдаёт опись: «учебник — на верхней полке, словарь — у задней двери». Если грузовик пуст, опись тоже пуста. Разница не только в количестве названий, а в том, что каждый предмет получил своё место.
