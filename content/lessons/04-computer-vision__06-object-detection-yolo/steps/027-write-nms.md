После детектора у тебя есть десятки рамок, и самая уверенная ещё не обязательно единственная: рядом с ней лежат почти такие же дубли. Твоя функция `nms` должна вернуть индексы рамок, которые останутся после отбора из [шага 26](#step-26).

На вход она получает:

- `boxes` — массив рамок в формате `(x1, y1, x2, y2)`;
- `scores` — уверенность для каждой рамки;
- `iou_threshold` — порог сходства.

Сначала расположи индексы по убыванию `scores`. Важно сортировать именно индексы: в конце нужно вернуть позиции рамок в исходном массиве, а не сами координаты.

Дальше повторяй один цикл. Бери индекс первой, самой уверенной рамки и добавляй его в `keep`. Затем сравнивай эту рамку со всеми оставшимися с помощью функции IoU из [шага 23](#step-23). Из дальнейшего рассмотрения убирай рамки, у которых IoU **больше** порога: они считаются дублями выбранной.

Обрати внимание на границу. При `iou_threshold=0.45` рамка с IoU ровно `0.45` должна выжить, поэтому оставляй значения `<= 0.45`.

Не забудь два коротких случая: пустой вход сразу даёт пустой результат, а при одной оставшейся рамке сравнивать уже не с чем. Верни `keep` как массив целых индексов типа `int64`.

> 🎒 **На пальцах.** Представь редактора, разбирающего подписи на карте. Он сначала берёт самую заметную подпись, оставляет её и убирает остальные, почти закрывающие то же место. Затем переходит к самой заметной из уцелевших. Редактор хранит номера выбранных подписей, поэтому после каждого удаления связь с исходным списком терять нельзя.
