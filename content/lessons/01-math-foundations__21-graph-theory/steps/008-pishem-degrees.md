Перед тобой список связей: `(0, 1)`, `(1, 2)`, `(1, 3)`. Если считать только первые числа, узел `1` будто участвует в одной связи. Но он встречается ещё и справа — значит, такой подсчёт теряет часть рёбер.

Функция `degrees` должна получить количество узлов и список рёбер, а вернуть степени узлов по порядку их номеров. Начни с массива нулей: отдельная ячейка для каждого узла. Затем разбирай рёбра по одному.

Для неориентированного графа ребро `(u, v)` увеличивает сразу два счётчика: у `u` и у `v`. Поэтому для списка выше результатом будет `[1, 3, 1, 1]`. Узел `1` соединён с тремя другими, а каждый из остальных — только с ним.

Если в задании используется ориентированный граф, вспомни различие из [шага 7](#step-7): один массив считает входящие рёбра, другой — исходящие. Для стрелки из `u` в `v` исходящий счётчик увеличивается у `u`, а входящий — у `v`. Не смешивай их в один результат, если функция должна вернуть обе величины.

Проверь себя на треугольнике: три ребра соединяют каждую пару узлов, поэтому ответ должен быть `[2, 2, 2]`. Если получилось `[1, 1, 1]`, ты, вероятно, обновляешь только один конец ребра.

> 🎒 **На пальцах.** Представь список сцен спектакля: в каждой строке записана пара актёров, которые выходят вместе. Ты кладёшь перед каждым актёром пустую чашку и за каждую сцену бросаешь по жетону в чашки обоих участников. Число жетонов показывает, во скольких парных сценах занят актёр. Если класть жетон только первому имени, итог будет зависеть от порядка записи, а не от спектакля.
