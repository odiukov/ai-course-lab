На карте отмечены три горных приюта: 0, 1 и 2. Между каждой парой есть прямая тропа. Если соединить эти точки, получится треугольник. Но как перенести именно этот рисунок в матрицу из [шага 10](#step-10), ничего не потеряв?

Сначала зафиксируй порядок узлов: 0, 1, 2. Он одинаков для строк и столбцов. Теперь мысленно пройди по строке узла 0: тропы из 0 в самого себя нет, зато есть тропы к 1 и 2. Поэтому первая строка содержит 0, 1, 1. Для узла 1 получается 1, 0, 1, а для узла 2 — 1, 1, 0.

На иллюстрации хорошо видны две особенности. Все числа на главной диагонали равны нулю: в этом графе узел не соединён сам с собой. Остальные клетки заполнены единицами, потому что каждая пара разных узлов связана.

Посмотри также на клетки по разные стороны диагонали: они повторяют друг друга. Тропа между 0 и 2 работает в обе стороны, поэтому единица появляется и в строке 0, столбце 2, и в строке 2, столбце 0. Так симметричный треугольник превращается в симметричную таблицу.

> 🎒 **На пальцах.** Представь журнал смотрителя горных троп. Ты выбираешь приют по строке и пункт назначения по столбцу, а затем ставишь отметку, если между ними есть прямой путь. У трёх приютов каждый ведёт к двум другим, поэтому вне диагонали журнал заполнен отметками. Диагональ остаётся пустой: отправляться из приюта в него же по отдельной тропе не нужно.
