На маленьком графе из пяти узлов ты мог проверить каждое ребро глазами. Теперь перед тобой архив клуба карате: 34 участника и 78 связей. Пересчитывать строки матрицы вручную уже неудобно, но сами операции не меняются. NetworkX берёт эту рутину на себя:

```python
import networkx as nx
import numpy as np

G = nx.karate_club_graph()

A = nx.adjacency_matrix(G)
L = nx.laplacian_matrix(G)

eigenvalues = np.linalg.eigvalsh(L.toarray().astype(float))
print(eigenvalues[:5])
print(nx.number_connected_components(G))
```

`G` хранит знаменитый Karate Club — наблюдавшуюся сеть знакомств, участники которой позже разделились на две группы. `A` соответствует матрице смежности из [шага 10](#step-10), а `L` — лапласиану из [шага 15](#step-15). Малые собственные значения помогают читать связность так же, как в [шагах 35](#step-35)–[36](#step-36). Функция `number_connected_components` выполняет готовую версию поиска из [шага 29](#step-29).

Можно попросить библиотеку сделать ещё два анализа:

```python
communities = nx.community.greedy_modularity_communities(G)
pr = nx.pagerank(G)

top_nodes = sorted(
    pr.items(), key=lambda item: item[1], reverse=True
)[:5]
```

Первый вызов ищет группы с особенно плотными внутренними связями. PageRank присваивает узлам влияние: связь с заметным участником весит больше, чем связь с периферийным. NetworkX не понимает человеческую ссору — он видит только структуру сети, но этого уже хватает, чтобы обнаружить её след.

Для 34 узлов удобно превращать матрицу в обычный массив через `toarray()`. На больших графах лучше сохранять разреженный формат: нули не должны занимать память.

> 🎒 **На пальцах.** Представь реставратора с набором одинаковых измерительных приборов. Сначала он проверяет учебную модель моста из пяти деталей, затем настоящий мост с десятками соединений. Приборы не приходится изобретать заново: меняется размер объекта, но измерения остаются теми же. NetworkX — такой набор приборов для графов.
