Ты запускаешь обход от станции `A` и видишь слои из [шага 20](#step-20). Но теперь нужен не весь слой целиком, а точное число переходов до каждой найденной станции: для `A` — `0`, для её соседей — `1`, для следующего слоя — `2`.

Напиши функцию `bfs_distances(graph, start)`, которая возвращает словарь вида `{узел: расстояние}`. Расстояние здесь — количество рёбер от стартового узла, как в [шаге 22](#step-22).

```python
from collections import deque

def bfs_distances(graph, start):
    distances = {start: 0}
    queue = deque([start])

    while queue:
        node = queue.popleft()

        for neighbor in graph.neighbors(node):
            # Если сосед ещё не найден:
            # 1. вычисли его расстояние
            # 2. добавь его в очередь
            pass

    return distances
```

Отдельный `visited` не обязателен: наличие узла в `distances` уже означает, что он обнаружен. Новому соседу присваивай расстояние текущего узла плюс один.

Особенно следи за моментом записи: сосед должен попасть в `distances` сразу при добавлении в очередь. Иначе другой узел успеет добавить того же соседа повторно. Узлы, до которых нельзя добраться из `start`, в итоговый словарь не попадут.

Проверь функцию на маленьком графе вручную: старт должен получить `0`, его непосредственные соседи — `1`, а один и тот же узел не должен обрабатываться дважды.

> 🎒 **На пальцах.** Представь систему пропусков на фестивале. У входа выдают браслет с номером `0`, затем этот человек приводит знакомых, и им выдают номер `1`. Их знакомые получают `2`. Полученный браслет нельзя выдать повторно: он одновременно хранит расстояние до входа и показывает, что человек уже учтён.
