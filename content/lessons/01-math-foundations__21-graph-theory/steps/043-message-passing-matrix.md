Представь три кофейни, которые сравнивают спрос на два напитка. У каждой есть пара чисел: спрос на кофе и чай. Кофейня A связана с B и C. У B признаки `[0, 1]`, у C — `[1, 1]`. Как A получить краткое описание своего окружения? Она усредняет признаки соседей и получает `[0.5, 1]`.

Это и есть один раунд **message passing**: каждый узел принимает «сообщения» от соседей и объединяет их. Но пересчитывать среднее отдельно для сотен узлов неудобно. Здесь помогает матрица смежности из [шага 10](#step-10).

$$H_{\text{avg}}=A_{\text{norm}}H$$

Здесь $H$ — матрица, где каждая строка хранит признаки одного узла. $A_{\text{norm}}$ — нормированная матрица смежности: ненулевые числа в каждой строке задают доли соседей, а их сумма равна 1. Результат $H_{\text{avg}}$ содержит новые строки — усреднённые признаки соседей для каждого узла.

Для кофейни A строка матрицы отдаст B и C по половине веса. При умножении получится $0.5[0,1]+0.5[1,1]=[0.5,1]$. То же умножение одновременно выполнит такой расчёт для всех остальных кофеен. Затем модель может преобразовать полученные признаки, но сбор соседской информации уже завершён одной матричной операцией.

После одного раунда узел знает ближайшее окружение; следующий раунд принесёт сведения ещё на одну связь дальше.

> 🎒 **На пальцах.** Представь, что каждая кофейня раз в день получает сводки от связанных с ней заведений. Если соседей двое, голос каждого весит половину; если четверо — четверть. Нормированная матрица заранее хранит эти доли, а умножение собирает все сводки сразу. Поэтому одна операция заменяет множество отдельных разговоров между соседями.
