Здесь важно применить обещание версии из [шага 11](#step-11), а не судить по названию файла. Изменение чекера само по себе ещё не означает мажор: спроси, вынуждает ли оно мигрировать уже установленные паки. Именно это различие должна распознавать функция из [шага 12](#step-12). Частая ошибка — считать любое изменение кода несовместимым, а любое изменение схемы безопасным. Решает не тип файла, а последствия для существующей установки.
