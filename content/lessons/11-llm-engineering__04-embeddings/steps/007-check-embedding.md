check:
  - question: >-
      В эмбеддинге обращения одна координата равна 0.023. Какой вывод из этого
      значения корректен?
    options:
      - Эта координата обозначает тему обращения
      - 'Модель уверена в своём представлении текста на 2,3 процента'
      - >-
        Изолированная координата не имеет человекочитаемого значения;
        использовать нужно отношения между целыми векторами
      - Это вес конкретного слова из обращения
    correct: 2
    explanation: >-
      Число 0.023 — лишь одна координата распределённого представления.
      Отдельные координаты не сопоставлены словам или темам; полезный результат
      получают при сравнении целых эмбеддингов.
  - question: >-
      Нужно найти обращения о той же проблеме, что и исходный тикет. Как следует
      использовать его эмбеддинг?
    options:
      - Найти координату с наибольшим модулем и определить по ней тему
      - >-
        Сравнить целый эмбеддинг с эмбеддингами других тикетов и ранжировать их
        по близости
      - Перевести каждую координату обратно в отдельное слово
      - Сравнивать только первые координаты всех векторов
    correct: 1
    explanation: >-
      Эмбеддинг предназначен для сравнения как единое целое. Мера близости между

Тут проверим одну вещь, на которой спотыкаются почти все: соблазн прочитать вектор глазами.

После [шага 4](#step-4) и [шага 6](#step-6) ты должен уметь спокойно ответить на вопрос «а что означает 0.023 в этом векторе» — и ответ будет «сам по себе ничего». Типичная ошибка — искать за каждым числом человеческое свойство: «это про доставку», «это про раздражение клиента». Так с координатами из [шага 5](#step-5) не работает: они не размечены по темам и не переводятся обратно в слова по одной.

Второе место, где легко застрять: путать «нечитаемо» с «бессмысленно». Числа осмысленны — просто их смысл живёт в сравнении, а не в отдельной клетке.
