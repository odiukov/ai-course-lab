  - question: В том же графе установили x1 = 2 и x2 = 5. Почему градиент по x1 равен 5?
    options:
      - Потому что градиент по входу всегда равен значению этого же входа
      - Потому что производная произведения по x1 равна соседнему множителю x2
      - Потому что градиент равен произведению x1 и x2
      - >-
        Потому что relu заменяет любой положительный градиент значением своего
        входа
    correct: 1
    explanation: >-
      Для a = x1 · x2 локальная производная da/dx1 равна x2. Поэтому при x2 = 5
      малое изменение x1 меняет произведение в 5 раз.
  - question: Почему прибавление b = 1 после умножения не изменяет градиент по x1?
    options:
      - >-
        Локальная производная сложения по его входу равна 1, поэтому градиент
        проходит назад без изменения
      - При обратном проходе узлы сложения полностью пропускаются
      - Значение b умножается на градиент и случайно сохраняет его
      - Сложение влияет только на градиент по x2
    correct: 0
    explanation: >-
      Если c = a + b, то dc/da = 1. По цепному правилу входящий градиент
      умножается на 1 и доходит до узла умножения без изменения.

Этот навык нужен, чтобы не считать градиенты в уме заново каждый раз, а читать их прямо с графа. После разбора обратного прохода на графе `2 × 3 + 1 = 7` ты должен уметь ответить на один вопрос без вычислений: в узле умножения градиент по входу равен значению **другого** входа.

$$\frac{dy}{dx_1} = x_2$$

Здесь $x_1$ и $x_2$ — два множителя, $y$ — выход сети. Градиент по первому множителю равен значению второго — то есть 3, а не 2.

Спотыкаются обычно тут: подставляют значение самого $x_1$ («градиент по x1 — значит про x1»), либо ищут в ответе произведение 6. Проверяй себя вопросом «на что умножается этот вход?» — ответ и будет градиентом.

> 🎒 **На пальцах.** Ты платишь за такси: цена = километры × тариф. Едешь 2 км по тарифу 3 рубля. Проехал на километр больше — счёт вырос на 3 рубля, то есть на величину тарифа, а не на километраж. А поднялся тариф на рубль — счёт вырос на 2, на число километров. Чувствительность к одному сомножителю всегда равна значению второго.
