check:
  - question: >-
      Почему максимальный learning rate не всегда безопасно применять с самого
      начала обучения через AdamW?
    options:
      - >-
        Оценки моментов оптимизатора ещё наполняются, поэтому ранние обновления
        могут оказаться нестабильными
      - До первого validation-прогона модель не умеет вычислять градиенты
      - Максимальный learning rate автоматически отключает weight decay
      - AdamW начинает обновлять только параметры смещения
    correct: 0
    explanation: >-
      Warmup постепенно поднимает learning rate, пока внутренние оценки моментов
      AdamW выходят на рабочий режим.
  - question: >-
      Зачем при каждой контрольной оценке использовать один и тот же
      фиксированный набор validation-батчей?
    options:
      - >-
        Чтобы изменения validation loss отражали состояние модели, а не
        случайную смену примеров
      - Чтобы validation loss обязательно совпал с training loss
      - Чтобы во время оценки продолжал работать dropout
      - Чтобы оптимизатор обновлял веса по валидационным данным
    correct: 0
    explanation: >-
      Если состав проверочных батчей меняется, разница между оценками смешивает
      изменение модели с изменением данных. Фиксированный набор делает
      контрольные точки сопоставимыми.
  - question: >-
      Loss выглядит правдоподобно, но модель при генерации зацикливается на
      одном токене. Какой элемент наблюдения за обучением помогает заметить
      проблему?
    options:
      - Качественная проба с генерацией из фиксированного промпта
      - Случайное распределение параметров между группами AdamW
      - Удаление validation-выборки
      - Постоянное увеличение learning rate
    correct: 0
    explanation: >-
      Короткие генерации обнаруживают повторения и коллапс, которые одно
      значение loss может скрывать.
  - question: >-
      Что может произойти, если применить weight decay к обучаемому scale в
      LayerNorm?
    options:
      - Scale будет тянуться к нулю и начнёт подавлять нормализованные активации
      - Таблица эмбеддингов автоматически станет замороженной
      - Learning rate перестанет следовать расписанию
      - Validation-батчи начнут перемешиваться между проверками
    correct: 0
    explanation: >-
      Scale задаёт амплитуду выхода LayerNorm. Регулярное стягивание этого
      параметра к нулю ослабляет сигнал, поэтому такие масштабы оставляют без
      decay.

Дальше тебе понадобится воспринимать цикл обучения как единый контракт. Сдвиг входов и целей из [шага 2](#step-2), честная оценка из [шагов 4](#step-4)–[5](#step-5), группы AdamW из [шагов 6](#step-6)–[7](#step-7), расписание из [шагов 8](#step-8)–[9](#step-9) и наблюдаемый прогон из [шагов 10](#step-10)–[11](#step-11) должны работать вместе. Частая ловушка — проверить каждый фрагмент отдельно и пропустить ошибку на стыке.
