id: 003-checkgraf
type: check
title: 'Проверка: это воркфлоу или агент'
source_anchor: '### Workflows vs agents'
check:
  - question: >-
      Ты собираешь обработку входящих заявок: сначала классифицировать тему,
      потом по теме отправить в один из трёх заранее прописанных обработчиков,
      потом собрать ответ. Никаких других путей в коде нет. Что это?
    options:
      - 'Агент: модель ведь сама решает, какая тема у заявки'
      - >-
        Воркфлоу: развилки и порядок шагов написал ты, модель только заполняет
        решение внутри шага
      - 'Ни то ни другое: пока есть классификация, это просто вызов функции'
    correct: 1
    explanation: >-
      Модель выбирает значение внутри шага, но сам набор шагов и развилок
      фиксирован в твоём коде — граф принадлежит инженеру, значит воркфлоу.
  - question: >-
      Что-то сломалось в проде. По какому признаку ты сразу поймёшь, что
      отлаживать будет тяжелее?
    options:
      - >-
        Модель сама выбирала, какой инструмент вызвать следующим, и порядок
        вызовов каждый раз разный
      - В системе больше пяти шагов и три вызова модели
      - 'Модель формулировала ответ свободным текстом, а не выбором из списка'
    correct: 0
    explanation: >-
      Когда путь выбирает модель, воспроизводимого маршрута нет: вместо чтения
      своего кода ты читаешь трассу и восстанавливаешь, почему на этот раз она
      свернула не туда.
