Тебе нужно восстановить маршрут из [шага 25](#step-25) по зависимостям между действиями. Детектор должен получить подготовленный тензор, классификатор — только отобранные crop, а его ответы нельзя присоединять без сохранённых индексов. Частая ошибка — считать, что номер ответа классификатора всегда совпадает с номером детекции. Если один crop пропущен, это соответствие сдвигается.

> 🎒 **На пальцах.** Представь монтаж концерта: сначала записывают сцену, затем отмечают удачные фрагменты и сохраняют номера песен. Звукорежиссёр обрабатывает только выбранные записи, а готовый звук возвращают по сохранённым номерам. Если приклеивать его просто «по порядку», после первого пропуска чужая дорожка попадёт не к той песне.
