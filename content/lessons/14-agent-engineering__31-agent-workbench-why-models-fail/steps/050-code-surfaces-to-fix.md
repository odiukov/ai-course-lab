В аудите обнаружены сразу три проблемы: `scope` отсутствует, `feedback` реализована частично, а сбой проверки ещё и указывает на `verification`. Если просто вернуть все три названия в случайном порядке, список будет формально верным, но чинить по нему неудобно: работа может начаться со следствия, пока причина остаётся на месте.

Твоя задача — дописать `surfaces_to_fix`. Посмотри на её параметры и ожидаемый результат в тестах. Функция должна собрать упорядоченный список поверхностей, которым действительно нужна починка.

Сначала включай полностью отсутствующие поверхности: без них соответствующий участок цикла вообще не защищён. Затем добавляй частично реализованные поверхности, используя оценку аудита из [шага 23](#step-23). Наконец, учитывай поверхности, связанные с обнаруженными режимами отказа из функции `classify_failures`, написанной на [шаге 39](#step-39).

Одна поверхность может встретиться несколько раз: например, иметь низкую оценку и одновременно объяснять два сбоя. В результате она должна появиться только однажды. Не превращай число свидетельств в повторы списка.

Особенно внимательно проверь порядок. При равном приоритете он должен быть детерминированным: один и тот же вход всегда даёт один и тот же результат, независимо от порядка элементов во входных коллекциях. Для разрешения ничьей используй канонический порядок семи поверхностей из [шага 5](#step-5), а не алфавитную сортировку. Не добавляй поверхности с полной оценкой только ради заполнения списка.

Прогони тесты и посмотри прежде всего на случаи с дублями, переставленными входными данными и полностью здоровым workbench. Последний должен вернуть пустой список: если чинить нечего, функция не должна выдумывать работу.

> 🎒 **На пальцах.** Представь приёмное отделение после небольшой аварии: у одного человека сильное кровотечение, у другого ушиб, а имя первого записали в двух журналах. Врач не лечит запись дважды и не начинает с ушиба. `surfaces_to_fix` делает такой же список приоритетов: объединяет сигналы, убирает дубли и ставит системную дыру раньше её последствий.
