check:
  - question: >-
      Пусть offsets = [0, 135, 319, 731]. Какой картинке принадлежит токен под
      номером 135?
    options:
      - 'Первой: 135 — это её последний токен'
      - 'Второй: её токены идут с 135 по 318 включительно'
      - 'Ни одной: 135 — это разделитель между картинками'
      - 'Третьей: отсчёт внутри упаковки начинается с единицы'
    correct: 1
    explanation: >-
      Границы интерпретируются как «слева включительно, справа не включительно».
      Первая картинка занимает позиции 0–134, поэтому позиция 135 уже относится
      ко второй.
  - question: >-
      Для offsets = [0, 135, 319, 731] сколько токенов у третьей картинки и
      сколько чисел будет в offsets для пяти картинок?
    options:
      - 412 токенов; шесть чисел
      - 319 токенов; пять чисел
      - 731 токен; шесть чисел
      - 596 токенов; пять чисел
    correct: 0
    explanation: >-
      Размер третьего блока равен 731 − 319 = 412. Для пяти картинок требуется
      шесть границ: начальный ноль, по одной границе между соседними блоками и
      общий конец.

Ты собрал упаковку в [шаге 16](#step-16), и на выходе получился один длинный тензор плюс скромный список чисел. Теперь проверь, умеешь ли ты по этому списку восстановить, где чья картинка — без него дальше не сдвинуться.

Самое частое место, где спотыкаются: граница читается как «включительно слева, не включительно справа». Число 576 в списке не значит «последний токен первой картинки», оно значит «здесь первая уже кончилась». И второе: чисел в списке всегда на одну больше, чем картинок — нужен и ноль в начале, и полная длина в конце. Длина любого блока — просто разность двух соседних границ.
