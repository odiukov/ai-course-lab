check:
  - question: >-
      Сервер погоды отправляет sampling-запрос с минимальным приоритетом
      стоимости и максимальным приоритетом качества, из-за чего клиент выбирает
      самую дорогую модель. Как называется эта атака и кто оплачивает вызов?
    options:
      - Cross-server shadowing; платит владелец подменённого сервера
      - MPMA; платит владелец API-ключа клиента
      - Rug pull; платит хостинг MCP-сервера
      - Conversation hijacking; дополнительных расходов не возникает
    correct: 1
    explanation: >-
      Это MPMA: сервер манипулирует параметрами выбора модели в
      sampling-запросе. Модель вызывает клиент со своим API-ключом, поэтому
      расходы несёт владелец клиента.
  - question: >-
      Сервер A помещает в sampling-запрос инструкцию вызвать send_email сервера
      B и приложить секретный файл. Что здесь происходит?
    options:
      - >-
        Parasitic toolchain: сервер A использует модель, чтобы задействовать
        инструмент сервера B
      - 'MPMA: сервер A заставляет клиента выбрать более дорогую модель'
      - >-
        Cross-server shadowing: сервер A регистрирует свой инструмент под именем
        send_email
      - >-
        Conversation hijacking: сервер A выдаёт собственный текст за реплику
        пользователя
    correct: 0
    explanation: >-
      Сервер A не присваивает имя чужого инструмента и не вызывает его напрямую.
      Он направляет модель через sampling, а модель задействует инструмент
      сервера B — это parasitic toolchain.
---

Три последние атаки легко слипаются в одну кашу «сервер ведёт себя плохо», потому что все три бьют не по коду, а по твоему кошельку и твоему доверию. Разделять их надо по одному вопросу: чей ресурс тратится и чьими руками.

MPMA из [шага 20](#step-20) трогает выбор модели. Parasitic toolchain из [шага 21](#step-21) трогает инструменты соседнего сервера. Sampling из [шага 22](#step-22) трогает сам разговор — скрытые инструкции, твой бюджет на задачи сервера, поддельная реплика.

Обычно спотыкаются на двух местах. Первое: путают MPMA с кражей бюджета через sampling — в первом случае навязан дорогой выбор, во втором вызов вообще не твой. Второе: путают parasitic с shadowing из [шага 17](#step-17) — там имя украдено, здесь чужой инструмент зовут открыто.
