После одного прогона случайной политики ты можешь получить удачный маршрут, после другого — долгий и дорогой. Но тебе нужна не отдельная история, а ценность каждого состояния с учётом всех действий, которые политика может выбрать.

Напиши `policy_evaluation(policy, gamma=0.99, tol=1e-6)`. Она должна вернуть словарь: каждому состоянию соответствует оценка \(V^\pi\).

Начни с нулевых значений для всех состояний. Затем повторяй полный проход по ним:

- терминальное состояние пропускай — его ценность остаётся нулевой;
- для обычного состояния заново собирай `v`;
- перебирай пары «действие — вероятность» из `policy(s)`;
- вызывай `step(s, a)` и добавляй к `v` результат одного шага из уравнения Беллмана с весом `pi_a`;
- после перебора действий записывай получившееся значение в `V[s]`.

Связь «награда за один шаг плюс ценность продолжения» уже разобрана в [шаге 30](#step-30), а причина повторять проходы — в [шаге 31](#step-31). Здесь твоя задача — аккуратно превратить эту процедуру в цикл.

На каждом проходе также сохраняй самое большое изменение значения среди состояний. Когда оно станет меньше `tol`, верни `V`. Пока достаточно реализовать это условие; смысл такого измерения разберём дальше.

Частая ошибка — прибавлять новый результат к прежнему `V[s]`. Значение нужно пересчитать с нуля, а старое использовать только в продолжении через `V[s_next]`. Ещё проверь, что вероятности действий умножают всю оценку соответствующего исхода, а не только награду.

> 🎒 **На пальцах.** Представь оценщика квартир: цена каждой квартиры зависит от того, куда можно переехать дальше и насколько вероятен каждый вариант. Сначала в его таблице везде нули. Он пересчитывает все строки, затем делает новый круг уже с обновлёнными соседними ценами. Когда очередной круг почти ничего не меняет, таблицу можно вернуть как готовую оценку.
