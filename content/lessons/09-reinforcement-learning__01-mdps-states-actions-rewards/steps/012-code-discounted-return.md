Ты запускаешь эпизод и получаешь награды `[2, 0, 5]`. Обычная сумма равна `7`, но при `gamma = 0.5` функция должна вернуть `3.25`: первая награда сохраняет вес `1`, вторая умножается на `0.5`, третья — на `0.25`. Именно этот порядок дисконтирования был задан в [шаге 11](#step-11).

Напиши `discounted_return(rewards, gamma)`. Функция принимает последовательность наград в хронологическом порядке — от ближайшей к самой далёкой — и коэффициент дисконтирования. Она должна пройти по наградам, прибавляя каждую с текущим весом, а после каждого шага уменьшать вес умножением на `gamma`.

Обрати внимание на границу: дисконтирование начинается не с первой, а со второй награды. Частая ошибка — сразу поставить вес `gamma`, превратив результат примера в `1.625`. Другая ловушка — случайно развернуть список: тогда далёкая награда получит наибольший вес.

Проверь три характерных случая:

- при `gamma = 0` остаётся только первая награда;
- при пустом списке результат равен `0`;
- отрицательные награды не исчезают и не меняют знак — уменьшается лишь их вклад по мере удаления.

Не округляй результат внутри функции: дробная часть нужна последующим вычислениям. Если примеры сходятся, значит код действительно считает отдачу, а не просто сумму наград.

> 🎒 **На пальцах.** Ты оцениваешь три купона: один действует сегодня, второй — через неделю, третий — через две. Каждый следующий для тебя вдвое менее ценен. Ты кладёшь первый в корзину целиком, затем дважды уменьшаешь текущий вес. Главное — не обесценить сегодняшний купон раньше времени: первый вес всегда равен единице.
