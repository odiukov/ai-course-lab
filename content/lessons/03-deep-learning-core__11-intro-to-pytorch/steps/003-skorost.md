title: Векторные ядра C++ и GPU заменяют медленные циклы Python

---

Допустим, тебе нужно умножить слой на пакет из 1 000 примеров. В самодельном фреймворке Python идёт по примерам, затем по нейронам, затем по отдельным числам. Каждый виток цикла требует проверить инструкцию, найти объекты в памяти и выполнить очередное маленькое действие. Математика простая, но Python тратит много времени на организацию работы.

В PyTorch ты передаёшь весь пакет одной тензорной операции. Python только формулирует крупную команду, а считать её отправляется **векторное ядро** — заранее скомпилированная и тщательно оптимизированная программа на C++. Слово «векторное» здесь означает, что она работает сразу с массивами чисел, а не просит Python перебирать их по одному.

Если тензоры находятся на GPU и для операции есть CUDA-ядро, работа дробится ещё сильнее: множество вычислительных блоков одновременно перемножают и складывают разные элементы. Один отдельный блок GPU не обязательно быстрее мощного процессорного ядра. Выигрыш появляется потому, что одинаковых независимых действий очень много и их можно выполнять параллельно.

Знакомая модель из [шага 2](#step-2) при этом не меняется: ты по-прежнему вызываешь слой и получаешь результат. Меняется масштаб команды — вместо тысяч мелких поручений Python выдаёт одно крупное. Именно исчезновение вложенных Python-циклов и массовый параллелизм превращают разрыв в сотни раз из загадки в закономерность.

> 🎒 **На пальцах.** Представь склад с тысячей одинаковых коробок. Можно каждый раз звать диспетчера, чтобы он лично перенёс одну коробку. А можно одним поручением запустить конвейер, где коробки одновременно разбирают десятки работников. PyTorch оставляет тебе роль диспетчера, но перенос чисел поручает такому конвейеру — ядрам C++ или GPU.
