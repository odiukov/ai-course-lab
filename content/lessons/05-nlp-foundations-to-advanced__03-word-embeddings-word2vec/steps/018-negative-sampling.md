title: Negative sampling заменяет многоклассовое предсказание бинарным

---

В тексте встретилась пара «кошка — спит». Полный softmax заставил бы модель сравнить слово «спит» со всем словарём и решить, какое слово должно быть соседом «кошки». На [шаге 17](#step-17) ты видел, почему такой многоклассовый выбор становится слишком дорогим.

Но для обучения не обязательно каждый раз искать победителя среди всех слов. Можно задать гораздо более узкий вопрос: «Эта конкретная пара действительно встретилась рядом?»

Для «кошка — спит» ответ будет **да**, то есть метка 1. Это положительная пара из текста. Затем к той же «кошке» подставляют несколько случайных слов, которых в данном контексте не было: например, «трактор», «теорема», «балкон». Каждая такая искусственная пара получает метку 0 и называется отрицательной.

Теперь модель решает не одну огромную задачу с множеством возможных ответов, а несколько бинарных: для каждой пары отдельно отвечает «да» или «нет». Скалярное произведение embeddings показывает совместимость слов, а sigmoid из [шага 15](#step-15) превращает её в оценку от 0 до 1. При обучении положительную пару модель старается оценивать ближе к 1, отрицательные — ближе к 0.

Так **negative sampling** заменяет поиск правильного слова во всём словаре проверкой небольшой группы пар. Модель больше не обязана рассматривать слова, которые не участвовали в текущем вопросе.

> 🎒 **На пальцах.** Представь викторину с фотографией человека. Трудный вариант — назвать его имя, перебрав справочник всех жителей города. Negative sampling меняет формат: ведущий предлагает несколько имён, а ты для каждого отвечаешь «он» или «не он». Одно имя настоящее, остальные подставные. Ты учишься узнавать правильное лицо, не просматривая весь справочник.
