Ты написал перцептрон целиком: взвешенную сумму, ступеньку, обновление весов по ошибке, цикл по эпохам. Это было нужно, чтобы внутри не осталось чёрных ящиков. Но каждый раз писать это заново не надо — то же самое лежит готовым в библиотеке `sklearn`.

```python
from sklearn.linear_model import Perceptron as SkPerceptron
import numpy as np

X = np.array([[0,0],[0,1],[1,0],[1,1]])
y = np.array([0, 0, 0, 1])

clf = SkPerceptron(max_iter=100, tol=1e-3)
clf.fit(X, y)
print([clf.predict([x])[0] for x in X])
```

Читается это ровно как то, что ты делал руками. `X` — четыре примера AND, `y` — правильные ответы к ним. `max_iter=100` — максимум сто эпох, то есть сто проходов по всем примерам. `tol=1e-3` — порог, ниже которого улучшение считается нулевым и обучение останавливается; это та же идея, что и в шаге про сходимость, только вместо «ноль ошибок» здесь «изменения стали крошечными». `fit` — обучение, тот самый цикл с подкруткой весов. `predict` — прогон входа через сумму и ступеньку.

Внутри `sklearn` больше кода: другие функции потерь, обработка разреженных данных, аккуратные проверки. Но главный цикл тот же самый, что ты набрал сам.
