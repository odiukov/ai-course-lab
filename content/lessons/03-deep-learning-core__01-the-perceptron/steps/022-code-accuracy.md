После обучения у тебя есть перцептрон с какими-то весами — но пока нет ни одной цифры, по которой можно сказать, хорошо он работает или нет. Печать «Converged» говорит только о том, что цикл обучения закончился, а не о том, насколько правильны ответы. Нужна отдельная функция, которая честно посчитает результат.

Мера, которую мы напишем, называется **accuracy** (точность) — это просто доля правильных ответов, как оценка за контрольную: пять задач из пяти решил верно — сто процентов, четыре из пяти — восемьдесят.

Что должна делать функция `accuracy(model, data)`:

- пройти по всем парам «входы — правильный ответ» из `data`;
- для каждой пары получить предсказание через `model.predict(inputs)`;
- сравнить предсказание с правильным ответом и посчитать, сколько раз они совпали;
- вернуть число совпадений, поделённое на общее количество примеров.

На что смотреть при проверке:

- сравнивай через `==`, а не через вычитание: здесь тебе нужен факт «совпало / не совпало», а не величина ошибки;
- деление должно давать дробь: в Python 3 `4 / 5` даёт `0.8`, а `4 // 5` даёт `0`;
- на пустом списке деление на ноль упадёт — реши, что вернуть в этом случае;
- проверь на данных, которые перцептрон точно выучил: там должно получиться ровно `1.0`.

> 🎒 **На пальцах.** Обучение — это когда ты сидишь с учебником и исправляешь себя по ходу. Accuracy — это когда работу проверяет преподаватель: он не смотрит, сколько раз ты зачёркивал и переписывал, он просто считает галочки и делит на число задач. Одно число вместо всей истории твоих исправлений — зато его можно сравнить с числом другого ученика.
