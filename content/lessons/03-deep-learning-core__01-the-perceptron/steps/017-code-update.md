Правило обновления записано словами — теперь нужно, чтобы машина применяла его сама и много раз. Этим займётся `update_once`: одна функция, один проход по всем обучающим примерам. Такой проход называют **эпохой** — как один сборник задач, прочитанный от первой задачи до последней.

Что она должна делать: принять примеры (входы и правильные ответы), текущие веса, смещение и learning rate. Дальше по каждому примеру по очереди — получить предсказание через уже готовую `predict`, посчитать ошибку, поправить каждый вес и смещение. Поправка применяется сразу, внутри цикла: следующий пример считается уже с новыми весами, а не со старыми.

На что смотреть, когда пишешь:

- каждый вес обновляется по своему входу: первый вес — по первому числу примера, второй — по второму. Перепутать индексы здесь легче всего.
- смещение обновляется без умножения на вход — у него входа нет.
- отдельная проверка «а вдруг ошибка нулевая» не нужна: при нуле формула и так ничего не меняет.
- полезно вернуть количество ошибок за проход. Когда оно станет нулём, учить больше нечему.

Проверь на AND: после одного прохода веса и смещение уже не должны быть все нулевыми.

> 🎒 **На пальцах.** Представь репетитора, который проверяет задачи по одной: сказал про ошибку — и следующую задачу ты решаешь уже с учётом замечания. Не «сдал весь сборник, через неделю получил разбор». Именно так работает `update_once`: правка весов происходит сразу после каждого примера, поэтому внутри одного прохода сеть успевает поумнеть несколько раз.
