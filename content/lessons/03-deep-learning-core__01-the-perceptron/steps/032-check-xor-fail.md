Этот шаг нужен, чтобы ты отличал две очень похожие снаружи ситуации: «модель ещё не доучилась» и «модель не может доучиться никогда». Снаружи они выглядят одинаково — ошибка не падает, но лечатся противоположно. В первом случае помогают эпохи, данные, шаг обучения. Во втором ничего из этого не поможет: у одной прямой просто нет положения, при котором два нуля XOR оказываются с одной стороны, а две единицы — с другой.

Обычно спотыкаются на том, что «1000 эпох» звучит как «мало старались». Отсюда рефлекс: добавить эпох, подкрутить настройки, дать больше примеров. Для XOR все три хода бесполезны — четыре примера и есть вся задача целиком, а прямая всё равно одна.
