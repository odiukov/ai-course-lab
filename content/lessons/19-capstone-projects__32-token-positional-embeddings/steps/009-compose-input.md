Ты передаёшь батч из четырёх последовательностей длиной 16, а на выходе внезапно получаешь ошибку сложения — или, хуже, тензор допустимой формы с перепутанным смыслом осей. Теперь нужно собрать части из [шагов 3](#step-3), [4](#step-4) и [8](#step-8) в один аккуратный входной шов.

Функция принимает `ids` строго формы `(B, T)`: несколько последовательностей, в каждой по `T` идентификаторов. Сначала проверь число измерений. Если их не два, остановись с понятным `ValueError`, указав фактическую форму — так ошибка обнаружится у входа, а не внутри таблицы эмбеддингов.

Длину последовательности бери из второй оси. Затем передай все `ids` токенной таблице: получится `tok` формы `(B, T, D)`. Позиционному модулю нужны не сами идентификаторы, а только `T`; его результат имеет форму `(T, D)`.

Перед сложением добавь позиционному тензору ведущую ось размером один: `(1, T, D)`. Тогда PyTorch применит броадкаст — мысленно использует одну и ту же позиционную таблицу для каждого элемента батча — и вернёт сумму формы `(B, T, D)`. Явная ось здесь фиксирует намерение: позиции повторяются по батчу, а не по времени или признакам.

> 🎒 **На пальцах.** Представь стопку из `B` одинаково размеченных анкет. Содержание строк у каждой анкеты своё — это токенные векторы, — но прозрачная плёнка с номерами строк одна. Размер `(1, T, D)` означает: плёнка подготовлена в одном экземпляре, однако при наложении используется для всей стопки. Итог сохраняет размер стопки и разметку каждой анкеты.
