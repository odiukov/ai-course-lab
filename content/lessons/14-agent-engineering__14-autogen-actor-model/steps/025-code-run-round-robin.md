На репетиции три участника сидят по пронумерованным местам: Аня, Борис, Вера. Первый круг проходит без сюрпризов, но после Веры легко ошибиться: остановиться, выйти за границу списка или снова позвать Веру. `run_round_robin` должна повторять один и тот же порядок столько кругов, сколько попросили.

Если список акторов — `["anna", "boris", "vera"]`, а кругов два, ожидаемая последовательность адресатов такая: `anna`, `boris`, `vera`, затем снова `anna`, `boris`, `vera`. Один круг означает, что каждый актор получил ровно один ход.

Допиши функцию так, чтобы она:

- проходила по именам в том порядке, в котором они переданы;
- повторяла полный проход заданное число раз;
- для каждого хода отправляла сообщение через `send` из [шага 14](#step-14);
- запускала обработку письма через `deliver_one` из [шага 19](#step-19);
- после ошибки одного актора всё равно переходила к следующему.

Не вызывай обработчик актора напрямую: тогда исчезнут ящик и изоляция ошибок, ради которых строился рантайм. Имя из списка используй как адрес — эту связь ты настроил в [шаге 11](#step-11).

Проверь функцию на трёх акторах и двух кругах. Смотри не только на число сообщений, но и на их порядок. Если один актор падает, очередь выступлений не пересчитывается: следующий участник уже известен заранее.

> 🎒 **На пальцах.** На репетиции по кругу передают один микрофон. Участник говорит или роняет микрофон со стойки — организатор всё равно поднимает его и передаёт следующему месту. Ему не нужно каждый раз решать, кому говорить: порядок записан в списке, а новый круг просто возвращает микрофон к первому участнику.
