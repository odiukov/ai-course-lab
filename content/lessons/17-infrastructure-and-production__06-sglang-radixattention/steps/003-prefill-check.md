title: 'Какая часть prefill полезна, а какая повторяется 4 999 раз?'
source_anchor: '## The Problem'
check:
  - question: >-
      Почему повторный prefill неизменившегося общего префикса можно исключить
      после его первой обработки?
    options:
      - >-
        Сохранённый KV-кэш уже содержит вычисленное состояние для той же
        последовательности токенов
      - >-
        Любые два системных промпта создают одинаковый KV-кэш независимо от
        токенов
      - >-
        Уникальное продолжение запроса позволяет восстановить состояние префикса
        без вычислений
    correct: 0
    explanation: >-
      Первый проход создаёт KV-кэш точного общего префикса. Пока
      последовательность токенов совпадает, следующие запросы могут использовать
      это состояние вместо повторного prefill.
  - question: >-
      Почему уникальное продолжение запроса всё равно требует prefill, даже если
      общий префикс взят из кэша?
    options:
      - >-
        Кэш общего префикса содержит состояния только для уже обработанных
        токенов, а состояния нового продолжения ещё нужно вычислить
      - После переиспользования префикса модель обязана удалить его KV-кэш
      - >-
        KV-кэш применим только к уникальным продолжениям, но не к общим
        префиксам
    correct: 0
    explanation: >-
      Переиспользование покрывает только совпавшее начало. Для новых токенов
      продолжения сохранённых KV-состояний нет, поэтому их необходимо
      обработать.
---

Возьми результат из [шага 2](#step-2) и раздели работу по смыслу. Первый prefill общих 2 000 токенов полезен: он создаёт KV-кэш, который можно сохранить. Повторять тот же prefill ещё 4 999 раз незачем — вход не изменился, поэтому GPU снова получает тот же результат.

Но не называй бесполезным весь prefill последующих запросов. После общего начала у каждого может быть собственный вопрос или найденный фрагмент, и эту новую часть обработать необходимо. Спотыкаются обычно именно здесь: повторяется не «весь запрос», а известная общая часть. Значит, экономия касается общего префикса, а новый хвост остаётся полезной работой.
