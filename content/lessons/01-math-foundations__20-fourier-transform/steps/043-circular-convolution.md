Возьми `x = [1, 2, 3, 4]` и фильтр `h = [1, 0, 0, 0]`. Результат должен совпасть с `x`: фильтр выбирает каждый отсчёт без изменений. Если функция выдаёт другое, значит ошибка спряталась в индексах.

Напиши `circular_convolution(x, h)` для двух массивов одинаковой длины. Она должна вернуть новый массив из `N` чисел, не изменяя входные данные. Формулу циклической свёртки мы разобрали на [шаге 42](#step-42); теперь нужно аккуратно превратить её во вложенные циклы.

Сначала подготовь результат длины `N`, заполненный нулями. Внешний цикл выбирает позицию результата `n`. Для неё заведи сумму и внутренним циклом перебери все `m` от `0` до `N - 1`. На каждом проходе умножай `x[m]` на элемент `h` с завёрнутым индексом и добавляй произведение к сумме. После внутреннего цикла запиши сумму в `result[n]`.

Главная ловушка — отрицательный остаток. В JavaScript выражение `(n - m) % N` может дать отрицательное число, а это не индекс массива. Поэтому сначала добавь `N`: используй индекс `(n - m + N) % N`.

Проверь функцию ещё одним коротким примером: для `h = [0, 1, 0, 0]` и того же `x` должен получиться результат `[4, 1, 2, 3]`. Четвёрка не исчезает за левым краем — она возвращается справа в начало массива. Именно это отличает циклическую свёртку.

> 🎒 **На пальцах.** Представь браслет из четырёх бусин с числами. Ты совмещаешь с ним второй браслет, перемножаешь числа напротив друг друга и складываешь результаты. Затем поворачиваешь один браслет на одну бусину. У браслета нет края: после последней бусины снова идёт первая. Операция `% N` в функции делает ровно такой переход.
