Возьми восемь отсчётов. Если внутри `fft(x)` просто вызвать `dft(x)`, ответ получится правильным — но разбиение из [шага 25](#step-25) останется неиспользованным. Твоя функция должна дойти до того же спектра другим путём.

Сначала обработай остановку рекурсии: для одного отсчёта спектр состоит из него самого. Верни его как `Complex`, даже если на входе было обычное число. Затем проверь длину: если она нечётная, используй `dft` из [шага 12](#step-12), потому что разделить такой список на две равные половины не получится.

Для чётной длины собери два списка: элементы с индексами `0, 2, 4, ...` и элементы с индексами `1, 3, 5, ...`. Рекурсивно вызови `fft` для каждого. Обрати внимание: результаты этих вызовов — уже спектры половин, а не исходные отсчёты.

Теперь подготовь список из `N` комплексных нулей. Для каждого `k` от `0` до `N // 2 - 1` получи поворачивающий множитель тем же способом, что в `twiddle` из [шага 9](#step-9), и умножь его на `odd[k]`. Получившееся значение `t` используй дважды:

- в позиции `k` сложи `even[k]` и `t`;
- в позиции `k + N // 2` вычти `t` из `even[k]`.

Это и есть две ветви бабочки из [шага 26](#step-26). Проверь функцию на длинах `1`, `2`, `4` и `8`, сравнивая результат с `dft`.

> 🎒 **На пальцах.** Представь застёжку-молнию: зубцы двух половин лежат отдельно, но бегунок соединяет их попарно. Для каждой пары ты один раз готовишь значение `t`, а затем направляешь его в два места: в одно со знаком плюс, в другое со знаком минус. Так две короткие «молнии»-спектра превращаются в одну длинную.
