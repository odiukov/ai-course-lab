title: 'Проверка: найти DC, Найквист и частоту заданной корзины'
source_anchor: '### What each coefficient means'
check:
  - question: >-
      Сигнал содержит 16 отсчётов. Какие корзины соответствуют DC и частоте
      Найквиста?
    options:
      - 'DC — корзина 0, Найквист — корзина 8'
      - 'DC — корзина 1, Найквист — корзина 16'
      - 'DC — корзина 0, Найквист — корзина 16'
    correct: 0
    explanation: >-
      DC всегда находится в корзине 0. При чётном числе отсчётов частоте
      Найквиста соответствует корзина N/2, то есть 8.
  - question: >-
      Частота дискретизации равна 1000 Гц, а число отсчётов — 20. Какую
      физическую частоту представляет корзина k = 3?
    options:
      - 50 Гц
      - 150 Гц
      - 3000 Гц
      - 600 Гц
    correct: 1
    explanation: >-
      Шаг между корзинами равен 1000 / 20 = 50 Гц. Третья корзина соответствует
      частоте 3 · 50 = 150 Гц.
---

Перед тобой три короткие проверки одной карты спектра. Не перепутай DC с нулевой амплитудой: это корзина `k = 0`, где хранится постоянная составляющая. Для чётного `N` Найквист сидит ровно посередине, в `k = N/2`. А номер любой другой корзины превращай в герцы по правилу из [шага 13](#step-13). Частая ошибка — принять `k` за готовую частоту, хотя это лишь номер.

> 🎒 **На пальцах.** Представь круговую беговую дорожку с пронумерованными отметками. Нулевая отметка — DC, противоположная ей — Найквист, а остальные номера ещё не метры. Чтобы узнать настоящую дистанцию, умножь номер отметки на длину одного промежутка.
