Ты передаёшь функции два множества шинглов и ожидаешь число от `0.0` до `1.0`. Но при пустых множествах обычное деление ломается: объединение тоже пусто, а делить на ноль нельзя.

Напиши функцию `jaccard`, которая:

- принимает два множества шинглов;
- находит их пересечение и объединение операциями над множествами;
- возвращает отношение их размеров по правилу из [шага 17](#step-17);
- возвращает `0.0`, если объединение пустое.

Последнее условие — договорённость именно для нашего пайплайна: документы без шинглов не считаются найденными дублями. Оно заодно защищает функцию от ошибки деления на ноль.

Проследи, чтобы функция не изменяла входные множества. Быстро проверить поведение можно по границам: одинаковые непустые множества дают `1.0`, множества без общих элементов — `0.0`, а частичное совпадение — значение между ними.

> 🎒 **На пальцах.** Представь два прозрачных листа с отмеченными точками. Наложив их, ты видишь совпавшие точки; собрав все отметки с обоих листов — общее число разных точек. Доля совпавших среди всех и есть результат. Если оба листа чистые, сравнивать нечего, поэтому функция спокойно возвращает `0.0`, а не падает с ошибкой.
