У тебя есть пачка документов, но простого списка похожих пар недостаточно: нужно вернуть очищенный корпус и число удалений. Напиши функцию `deduplicate(documents, threshold=0.8, num_hashes=128, bands=16)`, которая сохраняет более ранний документ, а его найденную копию исключает.

Сначала для каждого текста получи множество функцией из [шага 16](#step-16), затем построй MinHash-подпись функцией из [шага 22](#step-22). Эти результаты лучше сохранить в двух списках: шинглы понадобятся для точной проверки, а подписи — для быстрого поиска кандидатов.

Дальше раздели каждую подпись на `bands` одинаковых полос. При стандартных параметрах 128 компонентов дают 16 полос по 8 чисел. Для каждой полосы вычисли хеш и положи индекс документа в словарь по ключу `(номер_полосы, хеш_полосы)`. Документы, встретившиеся в одной корзине, становятся кандидатами. Собирай пары в `set`, иначе одна пара может повториться из-за совпадения нескольких полос.

Теперь пройди по кандидатам. Если один из документов уже удалён, пару можно пропустить. Для остальных вычисли точный Jaccard функцией из [шага 18](#step-18). При результате не ниже `threshold` добавь индекс второго документа в множество удалённых. Пустые множества шинглов не сравнивай: два слишком коротких текста не должны считаться дублями лишь из-за одинаково пустого представления.

Верни пару: список оставшихся документов в исходном порядке и количество удалённых. Проверь себя на двух почти одинаковых текстах и одном явно другом: функция должна сохранить порядок и убрать только более поздний дубль.

> 🎒 **На пальцах.** Представь архивариуса с папками заявлений. Сначала он раскладывает листы по нескольким коротким фрагментам штампа — так быстро собираются подозрительно похожие папки. Затем каждую такую пару он читает внимательнее. Если совпадение достаточно велико, первый экземпляр остаётся в архиве, а более поздний отправляется в коробку повторов. Корзина лишь находит, куда посмотреть; решение принимает точная проверка.
