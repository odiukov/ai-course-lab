Возьми строку «Модель читает много полезных текстов» и поставь `k=3`. Первое окно захватит «модель читает много», затем сдвинется на одно слово и даст «читает много полезных», потом — «много полезных текстов». Тебе нужно превратить это движение окна в функцию `get_shingles(text, k=5)`.

Опирайся на представление из [шага 15](#step-15): результатом должно быть **множество строк**, а не список. Поэтому одинаковый шингл, встретившийся несколько раз, останется в результате один раз.

Внутри функции последовательно сделай три вещи:

1. Переведи текст в нижний регистр и разбей его по пробельным символам.
2. Если слов меньше `k`, верни пустое множество: ни одного полного окна собрать нельзя.
3. Передвигай окно длиной `k` по одному слову и соединяй слова каждого окна пробелами.

У документа из `n` слов получится `n - k + 1` положений окна. Например, четыре слова при `k=2` дают три положения. Следи именно за правой границей цикла: типичная ошибка — потерять последний шингл или попытаться собрать ещё один, уже неполный.

Проверь функцию на таких случаях:

```python
get_shingles("Кот спит кот спит", k=2)
# {"кот спит", "спит кот"}

get_shingles("Всего три слова", k=5)
# set()
```

Первый результат содержит лишь два элемента: повторное «кот спит» множество не дублирует. Дополнительную очистку здесь не прячь — её выполняет `clean_text` из [шага 9](#step-9). Эта функция отвечает только за одинаковое разбиение документов на окна.

> 🎒 **На пальцах.** Представь ожерелье из слов и короткую трубку, в которой одновременно видны три бусины. Ты записываешь видимую тройку, сдвигаешь трубку ровно на одну бусину и записываешь следующую. Если такая тройка уже была, вторую карточку не заводишь. А когда бусин меньше длины трубки, записывать просто нечего.
