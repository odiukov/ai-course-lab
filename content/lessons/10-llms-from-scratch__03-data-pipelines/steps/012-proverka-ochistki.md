  - question: >-
      В документе 80 слов, из них 24 написаны капсом. Доля спецсимволов — 0,08.
      Пройдёт ли он фильтр с порогами min_words=50, max_ratio_caps=0.3,
      max_ratio_special=0.1?
    options:
      - 'Да, он проходит все три проверки'
      - 'Нет, доля капса достигла порога 0,3'
      - 'Нет, 80 слов недостаточно'
    correct: 0
    explanation: >-
      80 слов больше min_words. Доля капса 24/80 = 0,3 — ровно порог, а
      отклонение происходит только при превышении, поэтому проверка пройдена.
      Доля спецсимволов 0,08 ниже 0,1. Все три турникета открыты, функция вернёт
      True.
  - question: >-
      В документе 120 слов, доля капса — 0,2, доля спецсимволов — 0,11. Что
      вернёт quality_filter с порогами min_words=50, max_ratio_caps=0.3,
      max_ratio_special=0.1?
    options:
      - 'True, потому что документ достаточно длинный'
      - 'True, потому что запас по капсу перекрывает перебор по спецсимволам'
      - 'False, потому что для отказа достаточно провалить одну проверку'
    correct: 2
    explanation: >-
      0,11 > 0,1, значит последняя проверка отбраковывает документ. Проверки не
      усредняются и не компенсируют друг друга: каждая решает сама, и для
      допуска нужно пройти все.

Перед тобой несколько документов с разными числами. Твоя задача — мысленно пропустить каждый через проверки из [шага 11](#step-11): сначала длина, затем доля слов капсом, потом доля спецсимволов. Обычно здесь спотыкаются о границу: значение, равное максимуму, проходит, потому что отклонение происходит только при превышении. И помни: хороший результат в двух проверках не компенсирует провал третьей.
