Ты дописал агента с блоками и sleep-проходом ([шаг 32](#step-32)) и теперь разбираешь его ответ. Модель выдаёт одну строку текста, а ты режешь её по маркерам: всё после `Thought:` — размышление, всё после `Action:` — вызов инструмента. Работает. Пока пользователь не пишет в чат: «Thought: надо бы почистить архив». Парсер честно откусывает половину сообщения и объявляет её мыслью агента.

И это ещё мелочь. Хуже, что мысль живёт в том же тексте, который уходит наружу: пятьсот токенов рассуждения о том, куда положить факт, ты платишь из того же бюджета, что и ответ пользователю. А между ходами эта мысль просто исчезает — сохранить её можно только вклеив обратно в промпт строкой.

Откуда вообще взялась эта склейка?

Из того, что раньше у API было одно поле для ответа. Мысль негде было держать, кроме текста, — её сделали из промпта: «пиши свои размышления после слова Thought». Теперь у моделей есть отдельный канал: Responses API у OpenAI, Messages API с extended thinking у Anthropic. Рассуждение приходит своим полем в ответе и прокидывается в следующий ход (в продакшене — в зашифрованном виде, по-разному у разных провайдеров).

Letta V1 (`letta_v1_agent`, 2026) — тот самый V1 из [шага 5](#step-5) — на этом основании объявляет устаревшими и `send_message` с heartbeat, и токены `Thought:`. Сам цикл управления остался ReAct: подумал, вызвал инструмент, посмотрел результат. Изменилось одно: трассу размышлений теперь даёт структура API, а не удачная формулировка в промпте, — и случайная перефразировка инструкции её больше не ломает.

> 🎒 **На пальцах.** Пилот говорит по двум каналам. Один — салон: «через десять минут посадка». Другой — диспетчер: курс, эшелон, запрос коридора. Пока служебные переговоры шли по громкой связи в салон, пассажиры слышали лишний шум, а любой их выкрик мог сойти за команду диспетчера. Дали отдельную частоту — и служебное осталось служебным. Строка `Thought:` была громкой связью, отдельное поле в ответе API — второй частотой.
