Когда грузится каждый слой: три полосы времени сессии

AGENTS.md читается при старте сессии, каждый раз, и платит токенами всю сессию. SKILL.md до вызова показывает только description (десяток слов), тело едет в промпт в момент вызова навыка. MCP-сервер живёт в отдельном процессе, не в промпте, и стоит токенов только на вызов инструмента.
