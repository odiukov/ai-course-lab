Твой мини-рантайм устроен так: пришёл запрос от человека, ты пробежал три папки ([шаг 14](#step-14)), выбрал подходящий навык по описанию ([шаг 18](#step-18)), склеил его тело в системный промпт ([шаг 25](#step-25)). Всё начинается с фразы, которую кто-то напечатал.

Теперь представь, что навык надо запустить без этой фразы. Ночной прогон в CI, кнопка в интерфейсе, другой кусок кода. Что ты напишешь? «Притвориться, что пользователь попросил проверить релиз»? Подсовывать самому себе поддельные реплики — так себе способ строить программу.

Здесь и появляется Claude Agent SDK: `@anthropic-ai/claude-agent-sdk` для TypeScript и `claude-agent-sdk` для Python. Он грузит навыки один раз, при старте сессии, и выставляет их внутри рантайма как вызываемых «агентов» — у каждого есть имя, по которому к нему можно обратиться напрямую. Цикл агента передаёт управление в навык, когда навык позвали, — примерно как вызов функции: пока он работает, его тело и есть действующая инструкция.

Ключевое слово тут — «вызываемых». Навык перестаёт быть текстом, который ты копируешь в чат руками, и становится штукой с именем, до которой дотягивается код. Автоматический подбор по `description` из [шага 6](#step-6) никуда не делся — просто рядом с ним появился второй вход, явный.

Пока навык — это текст, его можно только прочитать вслух. Как только у него есть имя в рантайме, его можно нажать.

> 🎒 **На пальцах.** У кофемашины на стене висел листок: две ложки, 92 градуса, 25 секунд. Работает, но кто-то должен стоять рядом и читать. Потом ту же программу вывели на панель кнопкой «эспрессо». Ничего в рецепте не поменялось — поменялось то, что теперь до него дотягивается не только рука, но и таймер, который жмёт кнопку в семь утра.
