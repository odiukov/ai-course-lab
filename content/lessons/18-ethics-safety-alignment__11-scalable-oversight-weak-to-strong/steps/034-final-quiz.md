  - question: >-
      Почему scalable oversight не следует понимать как обязательную замену
      слабого судьи более крупной моделью?
    options:
      - >-
        Это семейство механизмов, повышающих способность надзирающего оценивать
        более сильную модель
      - Этот термин обозначает только увеличение числа параметров судьи
      - Он относится исключительно к вычислению PGR
      - Он требует полностью отказаться от человеческой оценки
    correct: 0
    explanation: >-
      Scalable oversight описывает функцию механизмов — сделать сигнал надзора
      пригодным для оценки более способной модели. Для этого могут применяться
      дебаты, декомпозиция или рекурсивное моделирование награды, а не только
      усиление самого судьи.
  - question: Когда должна завершаться рекурсивная декомпозиция сложной задачи?
    options:
      - >-
        Когда полученные подзадачи становятся доступными для надёжной проверки
        человеком
      - Сразу после первого разбиения независимо от сложности частей
      - Когда все подзадачи имеют одинаковый размер
      - Только после обучения новой сильной модели для каждой части
    correct: 0
    explanation: >-
      Смысл декомпозиции — свести трудную для прямой оценки задачу к проверяемым
      подзадачам. Если часть всё ещё нельзя надёжно проверить, её требуется
      разложить дальше.
  - question: Что строго показывает высокий PGR в эксперименте W2SG?
    options:
      - >-
        Обученная на слабых метках модель вернула значительную часть измеряемого
        разрыва производительности
      - Модель гарантированно усвоила намерение надзирающего
      - Слабые метки не содержали систематических ошибок
      - Модель безопасна на любых задачах вне распределения
    correct: 0
    explanation: >-
      PGR характеризует восстановление измеряемой производительности
      относительно слабой базовой линии и сильного потолка. Сам по себе он не
      устанавливает, какое правило усвоила модель, и не доказывает её
      безопасность.
  - question: Почему Superalignment и debate — не синонимы?
    options:
      - >-
        Superalignment — исследовательская повестка, а debate — один из
        механизмов масштабируемого надзора
      - 'Superalignment — метрика, а debate — её числовое значение'
      - >-
        Superalignment применяется только к слабым моделям, а debate — только к
        людям
      - >-
        Debate включает все возможные методы выравнивания сверхчеловеческих
        моделей
    correct: 0
    explanation: >-
      Superalignment охватывает проблему выравнивания моделей, которые человек
      не способен непосредственно оценить. Debate — лишь один возможный механизм
      получения более качественного сигнала надзора в рамках этой повестки.

Дальше тебе понадобится держать вместе две проверки из [шага 22](#step-22): насколько надёжным стал сигнал надзора и сколько сильная модель смогла из него извлечь. Чаще всего здесь спотыкаются, принимая высокий PGR за доказательство правильного намерения или одинаковую точность меток — за одинаково безопасные ошибки.
