title: Выбрать Пирсона или Спирмена для трёх наборов данных
source_anchor: '### Correlation: How Variables Move Together'
check:
  - question: >-
      Три набора данных: A — рост и вес без заметных выбросов, точки лежат
      примерно вдоль прямой; B — места участников в двух рейтингах; C — нагрузка
      и задержка, которая всё время растёт, но по кривой. Какой выбор подходит?
    options:
      - A — Пирсон; B — Спирмен; C — Спирмен
      - A — Спирмен; B — Пирсон; C — Пирсон
      - Для всех трёх — Пирсон
      - Для всех трёх — Спирмен
    correct: 0
    explanation: >-
      Пирсон подходит для линейной связи непрерывных величин без сильных
      выбросов. Рейтинги и монотонную нелинейную связь лучше сравнивать по
      рангам с помощью Спирмена.
  - question: >-
      Ты видишь почти линейное облако точек, но одна крайне далёкая точка резко
      меняет результат. Как разумнее поступить?
    options:
      - 'Сразу выбрать Пирсона: линейность важнее выброса'
      - Выбрать Спирмена и отдельно разобраться с причиной выброса
      - Удалить точку без проверки и выбрать Пирсона
    correct: 1
    explanation: >-
      Спирмен менее чувствителен к величине крайнего значения, потому что
      работает с рангами. Но сам выброс всё равно нужно проверить: он может быть
      ошибкой или важным наблюдением.
---

Здесь ты выбираешь не «более сильный» коэффициент, а подходящий вопрос к данным. Для прямолинейного движения непрерывных величин без крайних точек бери Пирсона из [шага 13](#step-13). Если данные — места или оценки, порядок важнее расстояний между значениями: нужен Спирмен из [шага 16](#step-16). Он же подходит, когда одна величина стабильно растёт вслед за другой, но не по прямой, или когда результат Пирсона перетягивает выброс.

Частая ловушка — смотреть только на тип чисел. Сначала посмотри на форму связи и крайние точки, затем выбирай меру.
