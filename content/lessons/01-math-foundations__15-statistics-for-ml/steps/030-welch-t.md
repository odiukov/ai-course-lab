Ты получил результаты двух моделей на независимых тестовых выборках: у первой пять оценок, у второй — восемь. Просто вычесть средние недостаточно: группы разного размера, а результаты одной модели могут колебаться сильнее. Напиши `welch_t`, которая соберёт эти свойства в одну t-статистику.

Функция принимает два набора чисел и возвращает одно число. Сначала найди среднее каждой группы с помощью `mean` из [шага 4](#step-4), а выборочные дисперсии — с помощью `variance` из [шага 11](#step-11). Здесь нужна именно поправка `n − 1`: каждая группа считается выборкой, а не всей совокупностью.

Дальше раздели разность средних на её стандартную ошибку по формуле из [шага 29](#step-29). Обрати внимание на порядок вычитания: если из среднего первой группы вычитаешь среднее второй, положительный результат означает, что первая группа в среднем выше. Если поменять группы местами, модуль t сохранится, а знак изменится.

Проверь функцию на двух важных случаях. Одинаковые средние должны дать `0`, если знаменатель не равен нулю. Перестановка аргументов должна менять только знак результата. Также подумай о входных данных: для выборочной дисперсии в каждой группе нужны хотя бы два значения, а при нулевой дисперсии обеих групп делить будет не на что. Такой случай лучше явно отклонить, а не возвращать загадочную бесконечность.

Пока функция вычисляет только t-статистику. Превращать её в p-значение здесь не требуется.

> 🎒 **На пальцах.** Представь две чаши весов, на которые кладут результаты моделей. Разность средних показывает, какая чаша перевесила. Но шкала прибора учитывает дрожание грузов и их количество: сильный перевес среди стабильных измерений выглядит убедительнее той же разницы среди скачущих. `welch_t` показывает перевес уже с поправкой на этот шум.
