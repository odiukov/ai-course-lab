---
id: 005-check-parallel
type: check
title: 'Проверка: почему параллельные головы не годятся в черновик'
source_anchor: '## The Problem'
check:
  - question: >-
      Ты взял параллельный MTP с четырьмя головами и хочешь склеить их выходы в
      черновик из четырёх токенов подряд. Что тут ломается?
    options:
      - >-
        Каждая голова угадывает свой сдвиг, ничего не зная о выходах остальных,
        поэтому токены могут не образовать связную причинную цепочку
      - >-
        Каждой голове нужен отдельный проход по backbone, поэтому черновик
        неизбежно медленнее обычной генерации
      - >-
        Все головы обучаются только на ближайшем токене, поэтому дальние позиции
        не получают supervision
      - >-
        Speculative decoding принимает черновики только от отдельной модели с
        другим токенизатором
    correct: 0
    explanation: >-
      Все головы одновременно читают одно скрытое состояние: предсказание t+2 не
      обусловлено выбранным t+1. Для черновика speculative decoding нужна
      последовательность, где каждый следующий токен строится с учётом
      предыдущих.
  - question: >-
      Почему отсутствие причинной связи между параллельными головами не отменяет
      пользу такого MTP при обучении?
    options:
      - >-
        Истинные будущие токены уже содержатся в обучающей последовательности,
        поэтому loss каждой головы можно вычислить независимо
      - >-
        Во время обучения головы становятся последовательными, а параллельный
        режим включается только на инференсе
      - >-
        Градиент вычисляется лишь для ближайшей головы, а остальные используются
        только для оценки качества
      - >-
        Backbone заранее генерирует правильные будущие токены и передаёт их
        головам как собственные ответы
    correct: 0
    explanation: >-
      При обучении цель для каждого смещения берётся из корпуса. Головам не
      требуется обмениваться собственными ответами, чтобы дать backbone
      несколько корректных обучающих сигналов.
---

После этого куска ты должен уметь разделить два разных вопроса про параллельный MTP из [шага 4](#step-4): даёт ли он более плотный обучающий сигнал (да) и годится ли он как черновик для speculative decoding (нет). Обычно спотыкаются именно здесь — из «предсказания не сцепляются» делают вывод «значит, и учить так бесполезно». Держи разницу в голове: на обучении будущие токены известны заранее и берутся из корпуса, каждая голова тянет свой сдвиг сама по себе. На инференсе такой опоры нет — второй токен черновика приходится строить на первом, а параллельные головы этого не умеют по устройству.
