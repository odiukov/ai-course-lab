В [шаге 12](#step-12) матрично-векторное умножение уже появилось как работа замороженной базы. Теперь тебе нужно превратить эту запись в функцию `matmul_mat_vec(matrix, vector)`.

Возьми матрицу из двух строк:

```text
[
    [2, -1, 0],
    [1,  3, 2]
]
```

и вектор `[4, 5, -2]`. Функция должна обработать каждую строку отдельно: перемножить числа на одинаковых позициях и сложить результаты. Для первой строки получится `2 × 4 + (-1) × 5 + 0 × (-2) = 3`, для второй — `1 × 4 + 3 × 5 + 2 × (-2) = 15`. Значит, ожидаемый ответ — `[3, 15]`.

Организуй вычисление так:

- создай пустой список результатов;
- для каждой строки начинай новую сумму с нуля;
- проходи по позициям строки и вектора, добавляя произведение пары к сумме;
- после обработки строки добавляй её сумму в результат;
- верни получившийся список.

Обрати внимание на две частые ошибки. Сумму нужно обнулять перед каждой новой строкой, иначе результат предыдущей строки попадёт в следующую. Кроме того, длина каждой строки должна совпадать с длиной вектора: если это не так, функция должна сообщить об ошибке, а не молча пропустить лишние числа.

Проверь себя ещё на единичной матрице: при умножении на неё входной вектор должен остаться неизменным.

> 🎒 **На пальцах.** Представь мастерскую по смешиванию красок. Вектор хранит количество трёх базовых пигментов, а каждая строка матрицы — отдельный рецепт смеси. Ты умножаешь количество каждого пигмента на долю из рецепта и складываешь вклад. Один рецепт даёт одно итоговое число, поэтому число строк определяет длину результата.
