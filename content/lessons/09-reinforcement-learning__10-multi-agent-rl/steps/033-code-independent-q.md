Ты запускаешь первый эпизод: оба агента стоят в начальных клетках, но их Q-таблицы пока пусты. Функция `train_independent_q` должна провести много таких эпизодов и вернуть две обученные таблицы — отдельную для каждого агента.

Сначала создай `Q1` и `Q2` с тем же значением по умолчанию, которое использовалось в предыдущих заданиях. В начале каждого эпизода сбрасывай среду и обязательно устанавливай `done = False`: без этого условие цикла либо обратится к ещё не созданной переменной, либо случайно сохранит значение от прошлого эпизода.

На каждом шаге оба агента смотрят на одно совместное состояние, но выбирают действия независимо. Для этого дважды вызови `epsilon_greedy` из [шага 29](#step-29): один раз с `Q1`, второй — с `Q2`. Затем передай пару выбранных действий среде и получи `s_next`, общую награду `r` и признак завершения `done`.

Теперь обнови обе таблицы через `q_learning_update` из [шага 31](#step-31). Переход у агентов общий, однако обновляемые ячейки разные: в `Q1` это действие первого агента, а в `Q2` — второго. Особенно внимательно передай `done`, чтобы терминальный переход обрабатывался правильно. После двух обновлений замени текущее состояние на следующее.

Цикл эпизода заканчивается при `done`, а вся функция после обучения возвращает обе таблицы. Один маршрут среды — две независимые записи опыта.

> 🎒 **На пальцах.** Представь двух стажёров, которые вместе проходят полосу препятствий. После каждого участка судья объявляет один общий результат. У каждого стажёра свой блокнот: первый записывает результат рядом со своим манёвром, второй — рядом со своим. Они видели один и тот же участок и услышали одну оценку, но записи и будущие решения у них остаются раздельными.
