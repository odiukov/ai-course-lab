title: Экспоненциальный рост пространства совместных действий

Ты настраиваешь команду дронов: каждый может лететь вперёд, назад, влево или вправо. Для одного дрона нужно оценить всего четыре варианта. Кажется, что десяти дронам понадобится оценить сорок. Но команда действует одновременно, поэтому важен не отдельный выбор каждого, а их сочетание — совместное действие из [шага 2](#step-2).

У двух дронов уже 16 сочетаний: первый выбрал одно из четырёх направлений, и для каждого его выбора у второго есть ещё четыре. У трёх получается 64, у пяти — 1024, у десяти — 1 048 576. Добавление одного дрона не прибавляет четыре варианта, а умножает прежнее число на четыре.

В общем виде размер пространства совместных действий равен $m^n$, где $m$ — число доступных действий у каждого агента, а $n$ — число агентов. Такой рост называют **экспоненциальным**: каждый новый участник создаёт новую комбинацию со всеми уже существующими.

Почему это мешает обучению? Представь таблицу, где для каждого состояния записана ценность каждого совместного действия. Даже если состояний немного, миллион столбцов для десяти агентов уже трудно заполнить опытом: большинство сочетаний команда почти никогда не попробует. С двадцатью агентами вариантов будет больше триллиона. Поэтому хранить отдельную оценку для каждой комбинации удаётся лишь в маленьких учебных задачах; в больших системах ценность приходится приближать, используя общие закономерности между похожими ситуациями.

Беда не в том, что каждый агент выбирает из четырёх действий. Беда в числе способов выбрать их одновременно.

> 🎒 **На пальцах.** Представь пульт концертного освещения: у каждого прожектора четыре режима. Пять прожекторов — это не двадцать световых сцен, а 1024 сочетания. Добавив шестой, ты не дописываешь четыре сцены: каждую из прежних 1024 приходится повторить с четырьмя его режимами. Так один новый участник умножает весь каталог решений.
