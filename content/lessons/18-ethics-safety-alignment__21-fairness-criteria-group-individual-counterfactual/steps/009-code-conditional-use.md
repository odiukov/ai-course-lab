У тебя есть прогнозы двух моделей: «дождь» и «без дождя». После проверки выясняется, что отметка «дождь» у первой модели верна в 80% случаев, а у второй — в 60%. Но одной этой разницы мало: отметки «без дождя» тоже могут иметь разную надёжность.

Напиши функцию, которая получает истинные исходы, решения модели и принадлежность к группе. Для каждого возможного решения \(y\) она должна повторить направление сравнения из [шага 8](#step-8):

1. Оставить только объекты, которым модель выдала решение \(y\).
2. Разделить их по защищённым группам.
3. В каждой группе найти долю случаев, где истинный исход совпал с выданным решением.
4. Посчитать разрыв между наибольшей и наименьшей долей.

Проверь отдельно оба решения. Для \(y=1\) получится разрыв положительной предсказательной ценности: насколько различается надёжность положительного решения. Для \(y=0\) — разрыв отрицательной предсказательной ценности. Итоговый разрыв можно взять как максимум из этих двух чисел: тогда ноль означает равенство для обоих решений, а большое значение сразу указывает на худшее расхождение.

Обрати внимание на пустую выборку. Если в какой-то группе модель ни разу не выдала одно из решений, знаменатель равен нулю. Не подставляй вместо результата ноль: это выглядело бы как измеренная точность. Верни неопределённое значение или явно сообщи, что критерий для этого решения вычислить нельзя.

> 🎒 **На пальцах.** Две метеостанции клеят на дни ярлыки «дождь» и «сухо». Ты сначала берёшь только дни с ярлыком «дождь» и сравниваешь, как часто он подтвердился у каждой станции. Потом повторяешь проверку для ярлыка «сухо». Разрыв показывает не то, сколько ярлыков выдали, а насколько одинаково им можно доверять.
