Обрати внимание на три детали:

- `z` должен содержать ровно `z_dim` чисел — столько координат ожидает декодировщик;
- для каждой координаты нужно отдельно вызвать `rng.gauss(0, 1)`;
- в функции не должно быть ни входного `x`, ни вызова кодировщика.

Параметр `rng` передаётся явно, чтобы генерацию можно было повторить с тем же состоянием генератора случайных чисел. А `dec` — уже обученные параметры декодировщика из [шага 15](#step-15).

Если функция сначала создаёт случайный `z`, а затем возвращает результат `decode(z, dec)`, генеративный маршрут собран.

> 🎒 **На пальцах.** Представь автомат с сувенирами и барабан с пронумерованными шариками. Во время настройки мастер использовал измерительные приборы — это кодировщик. Но покупателю они не нужны: барабан случайно выдаёт набор чисел, а автомат по ним изготавливает сувенир. `rng` крутит барабан, `z_dim` задаёт число шариков, а декодировщик превращает выпавшую комбинацию в новый объект.
