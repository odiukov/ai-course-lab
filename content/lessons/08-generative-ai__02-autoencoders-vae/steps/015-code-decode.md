После репараметризации у тебя в руках короткий список `z`, но восстановить нужно целый объект — например, сотни значений пикселей. Одного полносвязного преобразования может не хватить: декодировщику сначала полезно собрать промежуточное представление, а уже из него получить реконструкцию.

Допиши функцию:

```python
def decode(z, dec):
    # Получи скрытое представление h
    h = ...

    # Преобразуй h в восстановленный вектор x_hat
    x_hat = ...

    return x_hat
```

Для первой строки используй знакомые по [шагу 5](#step-5) операции: умножь `dec["W1"]` на `z`, прибавь `dec["b1"]`, а затем пропусти результат через `tanh`. Так декодировщик переводит координаты латента в более богатое скрытое представление `h`.

Во второй строке снова сделай полносвязное преобразование: умножь `dec["W_out"]` на `h` и прибавь `dec["b_out"]`. Получится `x_hat` — попытка восстановить исходный `x`.

Обрати внимание на две детали. Параметры нужно брать из `dec`, а не из словаря кодировщика: у этих частей модели разные веса. После выходного слоя `tanh` добавлять не нужно — в данном варианте функция возвращает результат линейного преобразования без дополнительного ограничения.

Проверь себя по смыслу: `h` должно зависеть от `z`, а `x_hat` — от `h`. Если случайно передать `z` сразу в `W_out`, скрытый слой окажется просто пропущен.

> 🎒 **На пальцах.** Представь гончарную мастерскую. `z` — короткая карточка заказа: высота, ширина и степень округлости. Первый мастер по карточке лепит заготовку `h`, а второй превращает её в детальную чашку `x_hat`. Если отдать карточку сразу второму мастеру, ему не с чем работать: описание слишком короткое, сначала нужна заготовка.
