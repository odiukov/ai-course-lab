title: VQ-VAE и RVQ заменяют непрерывное облако дискретной кодовой книгой

Ты сжимаешь звук, а кодировщик каждый раз выдаёт немного разные векторы: один — рядом с другим, третий — между ними. Хранить все такие значения точно дорого. Можно ли заставить модель пользоваться ограниченным набором кодов?

В VQ-VAE после кодировщика находится **кодовая книга** — обучаемый набор, например из 32 векторов. Для каждого выхода кодировщика модель ищет ближайшую запись и передаёт декодировщику именно её. Непрерывный вектор всё ещё нужен как черновик, но сохранённый результат становится дискретным номером: например, 7 или 19. В отличие от гауссова латента VAE из [шага 6](#step-6), здесь объект выбирает один из готовых кодов, а не точку из непрерывного облака.

Есть затруднение: выбор ближайшего кода недифференцируем — через него нельзя напрямую провести обычный градиент. Поэтому при обратном проходе используют приближение: временно считают квантование прозрачным. Дополнительные части потери тем временем подтягивают записи книги к выходам кодировщика и не дают самому кодировщику постоянно перескакивать между ними.

**RVQ**, residual vector quantization, уточняет код несколькими книгами. Первая выбирает грубое приближение, затем вычисляется оставшаяся ошибка — остаток. Вторая книга кодирует этот остаток, третья исправляет то, что осталось после второй. Итог складывается из нескольких выбранных записей: больше книг — точнее описание, но длиннее дискретный код.

Если используются лишь две записи из 32, произошёл коллапс кодовой книги: заявленная ёмкость есть, а фактической нет.

> 🎒 **На пальцах.** Представь набор штампов для печати узора. VQ-VAE выбирает один штамп, наиболее похожий на нужную деталь. RVQ сначала ставит грубый штамп, затем вторым добавляет недостающие линии, а третьим — мелкие штрихи. Если мастер всё время берёт только два штампа из коробки с 32, остальные места в коробке ничего не дают.
