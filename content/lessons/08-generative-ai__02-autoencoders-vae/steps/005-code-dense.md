Перед тобой список из 8 чисел. Нужно превратить его, например, в 4 числа — так, чтобы каждое новое число учитывало весь вход, а не только одну позицию. Именно это полносвязный слой делал в [шаге 4](#step-4); теперь ты собираешь эту операцию сам.

Функция получает вход `x`, таблицу весов `W` и смещения `b`. Смотри на `W` построчно: одна строка отвечает за одно выходное число. Умножь каждый элемент этой строки на соответствующий элемент `x`, сложи результаты и прибавь одно смещение из `b`. Затем повтори для остальных строк.

Размеры помогут поймать ошибку раньше запуска. Если в `x` восемь чисел, а нужны четыре результата, у `W` должно быть 4 строки по 8 весов, а у `b` — 4 числа. Функция вернёт список длины 4.

Частая ловушка — перепутать строки и столбцы. Проверка простая: количество строк `W` должно совпадать с количеством выходов. После линейного преобразования кодировщик может отдельно применить `tanh`, но не прячь её внутрь функции, если задание просит только умножение и смещение: выходным слоям активация может быть не нужна.

> 🎒 **На пальцах.** Представь четыре кассы, на каждой лежит свой чек-лист из восьми коэффициентов. Один и тот же набор из восьми товаров проходит через все кассы, но каждая считает собственный итог и добавляет свою фиксированную надбавку. Четыре кассы — четыре строки весов, поэтому из восьми входных чисел получаются четыре разных результата.
