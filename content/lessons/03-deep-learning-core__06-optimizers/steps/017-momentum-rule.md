title: Momentum хранит скорость и накапливает согласованные градиенты

---

Посмотри на траекторию из [шага 16](#step-16): несколько обновлений подряд толкают параметры вдоль долины, но каждое новое обновление SGD из [шага 7](#step-7) учитывает только текущий градиент. Для него устойчивое направление и случайное одиночное отклонение выглядят одинаково важными.

Momentum добавляет каждому параметру память — число, которое называют **скоростью**. Это не физическая скорость, а накопленное направление прошлых обновлений. В начале она равна нулю. Затем каждый новый градиент немного меняет её, а параметр обновляется уже по скорости, а не напрямую по одному свежему градиенту.

Допустим, градиент несколько раз подряд равен `0.5`. Скорость последовательно становится `0.5`, затем `0.95`, затем `1.355`. Согласованные сигналы складываются, поэтому движение в устойчивом направлении разгоняется. Если же градиенты чередуются — например, сначала положительный, потом отрицательный, — они частично гасят друг друга. Так momentum ослабляет метания поперёк долины, но сохраняет полезное движение вдоль неё.

Цена этой памяти проста: для каждого параметра теперь нужно хранить ещё одно число — его скорость. Momentum помнит не весь список прошлых градиентов, а их сжатый след.

> 🎒 **На пальцах.** Ты раскачиваешь тяжёлые качели. Несколько толчков в одну сторону складываются: качели идут всё быстрее, хотя каждый толчок небольшой. Если один раз толкнуть против движения, они не развернутся мгновенно — прежний разгон частично погасит этот толчок. Скорость хранит общий результат недавних усилий, а не реагирует на каждое из них с нуля.
