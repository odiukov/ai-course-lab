Представь два последовательных вызова `momentum_step` с одинаковым градиентом. Если во втором вызове функция снова начнёт с нулевой скорости, результат почти не будет отличаться от `sgd_step` из [шага 8](#step-8). Значит, главная задача здесь — не потерять состояние между шагами.

Для каждого параметра нужна отдельная скорость. При первом вызове создай список нулей той же длины, что и `params`. Затем проходи по параметрам, градиентам и скоростям с одинаковым индексом. На каждой позиции действия идут строго в таком порядке:

1. Возьми прежнюю скорость.
2. Оставь от неё долю, заданную `beta`, и прибавь текущий градиент.
3. Сохрани получившуюся новую скорость.
4. Обнови параметр, используя `lr` и именно новую, а не прежнюю скорость.

Проверь три частые ошибки. Скоростей должно быть столько же, сколько параметров. У каждого параметра должна быть своя скорость — одно общее число смешает независимые направления. Инициализацию нельзя повторять при каждом вызове: иначе накопление, ради которого нужен momentum из [шага 17](#step-17), исчезнет.

После вызова должны сохраниться обе изменившиеся части состояния: параметры и скорости. Именно сохранённые скорости сделают следующий шаг продолжением предыдущего.

> 🎒 **На пальцах.** Представь кассира, который ведёт отдельный текущий итог для каждой кассы. Новая сумма не записывается на чистом листе: кассир берёт часть прошлого итога и добавляет сегодняшнюю выручку. Если каждый вечер выбрасывать лист или складывать все кассы в одну строку, история станет бесполезной. `velocities` — такие отдельные строки накопительного журнала.
