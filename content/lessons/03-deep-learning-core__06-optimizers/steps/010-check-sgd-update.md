check:
  - question: >-
      Вес равен 2, learning rate — 0,01, а градиент — 0,5. Каким станет вес
      после одного шага SGD?
    options:
      - '1,995'
      - '2,005'
      - '1,5'
    correct: 0
    explanation: >-
      Масштабированный градиент равен 0,01 × 0,5 = 0,005. По правилу SGD
      получаем: 2 − 0,005 = 1,995.
  - question: >-
      Вес равен 1, learning rate — 0,1, а градиент — минус 0,4. Каким станет вес
      после одного шага SGD?
    options:
      - '0,96'
      - '1,04'
      - '1,4'
    correct: 1
    explanation: >-
      Масштабированный градиент равен −0,04. По правилу SGD вес станет равен 1 −
      (−0,04) = 1,04.
---

Здесь тебе нужно уверенно выполнить один шаг SGD вручную: умножить градиент на learning rate, а затем обновить вес по правилу из [шага 1](#step-1). Размер изменения и новое значение веса — не одно и то же: сначала ты находишь, насколько вес сдвинется, и только потом применяешь этот сдвиг.

Чаще всего ошибка появляется при отрицательном градиенте. Знак минус не исчезает: вычитание отрицательного изменения увеличивает вес. Также следи за десятичной запятой — learning rate масштабирует градиент, как разобрано в [шаге 7](#step-7), а не заменяет его.
