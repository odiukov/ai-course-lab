Ты запускаешь обучение с большим learning rate: momentum быстро разгоняется, Adam двигает одни параметры заметнее других, а редкий огромный градиент внезапно отправляет loss в `NaN`. Уменьшить learning rate можно, но тогда спокойные участки будут проходиться медленнее. Здесь помогают три надстройки, каждая — в своём месте.

Нестеров меняет момент измерения градиента. Обычный momentum сначала смотрит на склон в текущей точке, хотя накопленная скорость уже несёт параметры дальше. Нестеров мысленно делает упреждающий шаг по этой скорости и вычисляет градиент там, где параметры вот-вот окажутся. Если впереди подъём или поворот, оптимизатор начинает тормозить раньше и реже проскакивает удачную область.

У Adam один общий learning rate не означает одинаковых обновлений. В формуле из [шага 32](#step-32) исправленный первый момент задаёт направленную силу, а корень второго момента меняет её масштаб отдельно для каждого параметра. Поэтому полезно отслеживать **эффективный шаг** — фактическую величину, которая вычитается из конкретного веса. Два параметра при одном learning rate могут пройти совсем разные расстояния.

Clipping из [шага 53](#step-53) работает как аварийный ограничитель. Если общая норма всех градиентов превышает порог, например 1, их совместно уменьшают, сохраняя пропорции и направление. Он не чинит постоянно завышенный learning rate, зато не даёт единичному всплеску разрушить накопленное обучение.

> 🎒 **На пальцах.** Ты едешь на электросамокате по извилистой дорожке. Нестеров смотрит не под переднее колесо, а туда, куда тебя уже несёт скорость. Эффективный шаг показывает, насколько сильно мотор крутит каждое колесо с учётом сцепления. Clipping — ограничитель мощности: при резком скачке он ослабляет весь импульс, не поворачивая руль.
