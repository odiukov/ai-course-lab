  - question: >-
      Ты собираешь помощника для службы поддержки. Он должен всегда отвечать не
      длиннее трёх предложений и никогда не обещать возврат денег — независимо
      от вопроса клиента. Куда положить эти правила?
    options:
      - 'В system-сообщение, поскольку это постоянные правила поведения и вывода'
      - >-
        В начало каждого user-сообщения, поскольку постоянные правила нельзя
        задавать отдельно
      - В assistant prefill в виде просьбы соблюдать ограничения
      - 'Никуда: модель должна вывести правила из предыдущих ответов'
    correct: 0
    explanation: >-
      Постоянные ограничения, действующие для разных пользовательских запросов,
      относятся к system-сообщению. Prefill задаёт начало ответа, а не
      формулирует правила.
  - question: >-
      Тебе нужен чистый JSON без вступления вроде «Конечно, вот ваш результат».
      Что сработает надёжнее всего в API Anthropic?
    options:
      - Добавить в user-сообщение просьбу отвечать только JSON
      - >-
        Задать в assistant prefill начало ответа, заканчивающееся открывающей
        фигурной скобкой
      - Повторить требование о JSON несколько раз в system-сообщении
      - Отправить пустой assistant prefill
    correct: 1
    explanation: >-
      Prefill становится уже заданным началом ответа модели. После открывающей
      скобки модель продолжает JSON-объект, поэтому перед ним не остаётся места
      для вежливого вступления.

После [шага 5](#step-5), [шага 7](#step-7) и [шага 8](#step-8) у тебя есть три места, куда можно положить текст, — и главное умение здесь не в терминах, а в сортировке: взять любое требование и понять, чьё оно.

Спотыкаются обычно на двух вещах. Первое — всё сваливают в user-сообщение: и правила тона, и запреты, и саму задачу. Работает, пока диалог короткий, а дальше правила тонут среди реплик. Второе — путают prefill с указанием. «Ответь JSON-ом» в assistant-сообщении не даёт ничего: prefill не просьба, а буквально первые символы ответа, которые модель обязана продолжить.

Проверь себя на двух ситуациях ниже.
