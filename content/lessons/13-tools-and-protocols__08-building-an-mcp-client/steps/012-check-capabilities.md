check:
  - question: >-
      После initialize в session.capabilities есть только поле resources. Как
      клиент должен поступить с запросом tools/list?
    options:
      - 'Отправить его и обработать ошибку, если сервер её вернёт'
      - 'Не отправлять его: сервер не объявил возможность tools'
      - >-
        Самостоятельно добавить tools в локальный объект capabilities и
        отправить запрос
      - 'Сначала отправить tools/call, чтобы проверить поддержку на практике'
    correct: 1
    explanation: >-
      Capabilities — объявленный сервером контракт. Если tools отсутствует,
      клиент не должен отправлять методы этого семейства.
  - question: >-
      Вызов supports(session, "tools") вернул True. Следует ли из этого, что
      список инструментов уже находится в session.tools?
    options:
      - 'Да, capabilities и tools всегда заполняются одним ответом'
      - >-
        Нет, список появится только после отдельного успешного запроса
        tools/list
      - 'Да, True означает, что клиент уже автоматически запросил список'
      - 'Да, если в карте pending сейчас нет ожидающих запросов'
    correct: 1
    explanation: >-
      Supports проверяет только объявленную возможность. Поле session.tools
      содержит последний результат tools/list и заполняется отдельным ответом
      сервера.
---

После [шага 11](#step-11) у тебя есть две вещи, которые легко перепутать: заявление сервера и его содержимое. `capabilities` заполняется один раз — ответом на `initialize`, и говорит только «такая рубрика у меня есть». `tools` заполняется позже, отдельным ответом, и говорит «вот что в этой рубрике лежит».

Спотыкаются обычно на порядке. Тянет написать «попробуем `tools/call`, а если сервер ответит ошибкой — обработаем». Но ты уже видел из [шага 9](#step-9), что каждый отправленный запрос занимает номерок в `pending` и кто-то будет ждать ответа. Проверка через `supports` дешевле любой ошибки: она смотрит в память, а не в трубу.

Ответь на два вопроса — и дальше займёмся тем, что модель видит все три сервера одним плоским списком.
