У тебя уже есть confusion matrix, но сравнивать классы по десяткам ячеек неудобно. Напиши `class_report(cm)`, которая сожмёт матрицу в три показателя для каждого класса: precision, recall и F1 из [шага 47](#step-47).

Функция получает квадратный тензор размера `C × C` и возвращает три тензора длины `C`. Для каждого класса собери:

- `TP` — значение на диагонали;
- `FP` — сумму его столбца без диагонального значения;
- `FN` — сумму его строки без диагонального значения.

Здесь особенно легко перепутать направления. По соглашению из [шага 46](#step-46) строка содержит реальные объекты класса, поэтому её сумма нужна для recall. Столбец содержит все предсказания этого класса, поэтому его сумма нужна для precision.

Перед делением преобразуй значения в вещественный тип: целочисленный тензор хранит количества, а отчёту нужны дроби. Учти и класс, которого нет в выборке или который модель ни разу не предсказала. Нулевой знаменатель не должен превращать результат в `NaN`: ограничь знаменатель снизу безопасным значением. Для F1 используй маленькую положительную границу, например `1e-9`.

Проверь результат на небольшой матрице вручную: длины трёх выходов должны совпасть с числом классов, а все значения — оставаться между `0` и `1`.

> 🎒 **На пальцах.** Представь библиотекаря, который раскладывает книги по жанровым полкам. Диагональ — книги на правильной полке. Для precision ты осматриваешь одну полку и спрашиваешь, сколько чужих книг туда попало. Для recall берёшь один жанр и ищешь, сколько его книг унесли на другие полки. `class_report` превращает такую ревизию в три коротких оценки для каждой полки.
