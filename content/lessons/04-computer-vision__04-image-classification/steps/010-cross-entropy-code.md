Перед тобой батч из 32 изображений. Для каждого есть строка логитов и один номер правильного класса. Функция `cross_entropy` должна вернуть одно число — среднюю ошибку по всему батчу.

Сначала проверь формы данных: у `logits` должно быть 32 строки и по одному столбцу на класс, а у `y` — 32 номера. Затем для каждой строки возьми логит именно правильного класса. Здесь легко случайно выбрать целый столбец: тебе нужны разные столбцы для разных изображений, потому что их правильные ответы могут отличаться.

Softmax из [шага 8](#step-8) вызывать заранее не надо. Вычисляй потерю прямо из логитов: из каждого логита строки вычти её максимум, возьми экспоненты и сложи их. После логарифма этой суммы прибавь обратно максимум, а затем вычти логит правильного класса. Вычитание максимума не меняет результат, но не даёт экспонентам превратиться в бесконечность на больших значениях.

Ты получишь отдельную потерю для каждого изображения. Усредни эти значения и верни обычное число. Обрати внимание: среднее берётся только после расчёта всех индивидуальных потерь.

Для самопроверки попробуй батч из одной строки, а затем из нескольких строк с разными правильными классами. Потеря должна быть конечной даже при очень больших логитах.

> 🎒 **На пальцах.** Представь ведомость с 32 участниками и несколькими оценками в каждой строке. У каждого участника отмечена своя правильная колонка. Ты сначала считаешь штраф отдельно по каждой строке, не путая отметки между участниками, а потом находишь средний штраф группы. Сдвиг всех оценок строки на одно число меняет их запись, но не сравнительный результат.
