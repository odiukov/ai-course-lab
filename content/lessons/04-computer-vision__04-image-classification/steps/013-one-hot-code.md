В батче пришли метки `[2, 0, 3]`, а классов всего четыре. Одно число на изображение удобно хранить, но его нельзя спутать с оценкой: класс `3` не «в три раза больше» класса `1`. Поэтому функция `one_hot` должна заменить каждый номер строкой из нулей с одной единицей, как в [шаге 12](#step-12):

```text
[2, 0, 3]  →  [[0, 0, 1, 0],
                [1, 0, 0, 0],
                [0, 0, 0, 1]]
```

Твоя функция получает список меток и количество классов. На выходе должно быть по одной строке на каждую входную метку и по одному столбцу на каждый класс. Порядок строк сохраняется: первая выходная строка относится к первому изображению батча.

Сначала создай результат нужного размера, заполненный нулями. Затем в каждой строке поставь единицу в столбец, номер которого записан в соответствующей метке. Не зашивай число классов в функцию: сегодня их четыре, а в следующем наборе может быть десять.

После реализации проверь три вещи: форма результата равна «число меток × число классов», сумма каждой строки равна `1`, а единица стоит ровно на позиции метки. Особенно внимательно посмотри на классы `0` и `num_classes - 1`: на границах чаще всего возникает сдвиг на один столбец. И не изменяй исходный массив меток — функция должна создать новое представление, а не испортить входные данные.

> 🎒 **На пальцах.** Представь кинотеатр с четырьмя залами. Для каждого билета ты заполняешь отдельную строку ведомости: ставишь отметку только под номером нужного зала, остальные клетки оставляешь пустыми. Три билета дают три строки, даже если два ведут в один зал. Номер на билете выбирает клетку, но сам отметкой не является.
