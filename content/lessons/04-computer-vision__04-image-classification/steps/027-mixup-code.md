Перед тобой батч из 32 изображений и 32 номеров классов. После mixup изображений по-прежнему должно быть 32, но обычные номера классов уже не подходят: смешанной картинке нужна смешанная метка. Поэтому `mixup_batch` возвращает два тензора одинаковой длины — изображения и мягкие цели для них.

Собери функцию по этапам:

1. Проверь `alpha`. Если оно не положительное, не смешивай изображения, но всё равно преврати `y` в `float`-версию one-hot из [шага 13](#step-13). Тогда следующий код всегда получает метки одной формы.
2. Возьми одно значение `lam` через `rng.beta(alpha, alpha)`. Переданный `rng`, как в [шаге 21](#step-21), позволяет повторить выбор.
3. Создай случайную перестановку индексов батча. Обрати внимание: индексы должны находиться на том же устройстве, что и `x`, иначе GPU-тензор нельзя будет ими индексировать.
4. Смешай `x` с `x`, переставленным по этим индексам, используя правило из [шага 26](#step-26).
5. Точно с теми же `lam` и индексами смешай one-hot-метки. Не создавай для меток новую перестановку: тогда картинка и её цель перестанут соответствовать друг другу.

На выходе проверь формы: `x_mixed` совпадает по форме с `x`, а `y_mixed` имеет размер батча на `num_classes`. Сумма значений в каждой строке `y_mixed` остаётся равной единице, поэтому результат подходит для `soft_cross_entropy` из [шага 15](#step-15).

> 🎒 **На пальцах.** Представь танцевальный класс: преподаватель перемешал список партнёров и для каждой пары назначил доли участия — например, 70% Алисы и 30% Бориса. На бейдже пары должны стоять те же имена и те же доли. Если отдельно перемешать бейджи, танцоры останутся на месте, а подписи начнут описывать совсем другие пары.
