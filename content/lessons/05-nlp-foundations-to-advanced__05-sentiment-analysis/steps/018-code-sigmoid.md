Проверь себя:

```python
print(sigmoid(0.0))

values = np.array([-1000.0, 0.0, 1000.0])
probs = sigmoid(values)

print(probs)
print(np.isfinite(probs).all())
```

Первый вывод должен быть `0.5`. В массиве ты увидишь три конечные вероятности: очень близкую к нулю, `0.5` и очень близкую к единице. Последняя проверка должна вернуть `True`.

Особенно внимательно посмотри, где стоит минус: экспонента получает отрицательное ограниченное значение. Если потерять этот минус, большие logits начнут давать вероятности около нуля — направление шкалы перевернётся.

> 🎒 **На пальцах.** Представь турникет с ручкой, которую можно повернуть только от `-20` до `20`. Значения `-1000` и `1000` упираются в ограничители, а `0` остаётся на месте. После этого механизм сигмоиды работает без поломки: крайние положения всё равно означают почти нулевую и почти единичную вероятность, но шестерёнки экспоненты больше не пытаются провернуться на невозможную величину.
