Ты передаёшь пайплайну новые строки и замечаешь ловушку: недостаточно один раз вызвать `apply_step`. После первого преобразования данные изменились, поэтому следующий шаг должен получить именно этот результат, а не исходную таблицу.

В `transform_pipeline` создай рабочую копию входных данных. Затем пройди по обученным шагам в том же порядке, в котором их сохранил `fit_pipeline` из [шага 12](#step-12). На каждой итерации применяй `apply_step`, написанный в [шаге 9](#step-9), и записывай результат обратно в рабочую переменную. Когда шаги закончатся, верни преобразованную таблицу.

Обрати внимание на три детали:

- функция получает уже обученные шаги с сохранёнными параметрами;
- внутри нельзя вызывать `fit_step` или заново вычислять медианы;
- исходный `X` лучше не изменять — работай с его копией.

Порядок тоже нельзя переставлять. Если один шаг подготовил значения для следующего, смена очередности даст уже другое преобразование. Здесь ты буквально реализуешь режим инференса из [шага 13](#step-13): данные движутся вперёд, а состояние пайплайна остаётся прежним.

> 🎒 **На пальцах.** Представь линию проявки фотографий с заранее выставленными ванночками: сначала проявитель, затем закрепитель, потом промывка. Ты пропускаешь новый снимок через каждую ванночку по порядку, не меняя состав растворов под этот снимок. `transform_pipeline` делает то же самое: передаёт результат дальше по цепочке, используя сохранённые настройки каждого этапа.
