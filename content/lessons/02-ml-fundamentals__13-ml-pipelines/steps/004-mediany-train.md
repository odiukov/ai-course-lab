Ты открываешь таблицу клиентов и видишь пропуски: у кого-то не указан возраст, у кого-то — доход. Можно заменить каждый пропуск медианой столбца. Например, для возрастов 22, 29, 34, 41 и 68 медиана равна 34 — это значение посередине упорядоченного списка.

Но откуда шаг предобработки возьмёт число 34, когда позже получит новую строку с пустым возрастом?

Сначала шаг смотрит на доступные ему данные и вычисляет отдельную медиану для каждого нужного столбца: допустим, 34 для возраста и 52 000 для дохода. Затем сохраняет эти числа внутри себя. Такое сохранённое знание называют **обучаемым состоянием**: шаг уже не просто выполняет неизменную команду, а запоминает параметры, найденные по данным.

После этого новая таблица не заставляет его вычислять всё заново. Он берёт сохранённую медиану возраста и подставляет её только в пропуски столбца «возраст», а сохранённую медиану дохода — в пропуски «доход». Значения без пропусков остаются прежними.

Получается, у предобработки есть две разные задачи: один раз узнать и запомнить подходящие числа, а затем многократно применять именно их. Если каждый раз искать новые медианы, один и тот же шаг начнёт вести себя по-разному в зависимости от очередной таблицы. Сохранённое состояние фиксирует правило замены.

> 🎒 **На пальцах.** Представь мастера, который подбирает стандартные шнурки для разных моделей ботинок. Сначала он измеряет образцы и записывает: для низких ботинок — 90 см, для высоких — 140 см. Когда приходит новая пара без шнурков, мастер не измеряет всю витрину заново, а использует подходящее число из своей записи. Эта запись и есть обучаемое состояние.
