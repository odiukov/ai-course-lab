После `fit_step` из [шага 7](#step-7) у тебя сохранены медианы, например `[5, 100]`. Теперь приходят новые строки: `[[None, 120], [7, None]]`. Их нельзя использовать для вычисления новых медиан — иначе нарушится правило из [шага 8](#step-8).

Напиши `apply_step`, которая принимает строки и уже обученное состояние шага. Для каждой пропущенной ячейки она должна взять медиану того же столбца: в первом столбце подставить `5`, во втором — `100`. На выходе получится `[[5, 120], [7, 100]]`.

Следи за тремя вещами. Значения без пропусков должны остаться прежними. Число строк и столбцов не должно измениться. И главное: внутри `apply_step` не вызывай `column_medians` и не вычисляй никакую статистику по входным строкам. Здесь нет обучения — функция только применяет параметры, которые получила.

Проверь себя на наборе, где целый столбец новых данных состоит из пропусков. Результат всё равно должен появиться: нужное число уже сохранено после обучения.

> 🎒 **На пальцах.** Представь мастерскую, где для каждого оттенка краски записан точный рецепт. Когда приходит новый заказ, ты открываешь карточку и смешиваешь краску по сохранённым пропорциям. Ты не выводишь рецепт заново по цветам соседних заказов. `apply_step` действует так же: берёт готовые настройки и последовательно применяет их к новым строкам.
