Ты передаёшь функции таблицу из трёх квартир:

- площадь: 40, 55, 300;
- цена: 6, 8, 50.

Если собрать все шесть чисел вместе, получится одна бессмысленная медиана: квадратные метры смешаются с миллионами рублей. Нужен другой результат — отдельное число для каждого столбца. Для этого примера функция должна вернуть медианы `55` и `8`.

Напиши `column_medians(X)`, которая принимает двумерную таблицу `X` и возвращает одномерный массив. Его длина должна совпадать с количеством столбцов: первый элемент относится к первому признаку, второй — ко второму и так далее. Медиана здесь работает именно так, как мы разобрали в [шаге 4](#step-4).

Главное место, где легко ошибиться, — направление вычисления. Тебе нужно брать значения сверху вниз внутри каждого столбца, а не считать медиану слева направо для каждой строки. Проверь форму результата: для таблицы из 100 строк и 4 столбцов правильный ответ содержит 4 числа, а не 100.

Добавь проверки на примерах с нечётным и чётным количеством строк. Во втором случае медианой будет среднее двух центральных значений. Сама функция пока лишь вычисляет характеристики переданной ей таблицы — выбор данных остаётся за вызывающим кодом.

> 🎒 **На пальцах.** Представь прилавок с отдельными ящиками для яблок, груш и слив. Ты находишь типичный вес фруктов в каждом ящике, не сваливая всё на одни весы. `column_medians` делает то же самое со столбцами: проходит по каждому «ящику» и возвращает по одному числу на категорию. Поэтому число ответов всегда равно числу столбцов.
