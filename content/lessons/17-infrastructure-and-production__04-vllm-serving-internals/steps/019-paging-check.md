title: >-
  Сколько блоков по 16 нужно для 1500 токенов и сколько слотов останется
  пустыми?
source_anchor: '### PagedAttention as a virtual memory system'
check:
  - question: >-
      Как правильно вычислять число пустых токен-слотов при блочном выделении
      KV-кэша?
    options:
      - >-
        Округлить отношение длины последовательности к размеру блока вниз и
        вычесть длину последовательности
      - >-
        Округлить отношение длины последовательности к размеру блока вверх,
        найти полную вместимость выделенных блоков и вычесть фактическую длину
      - Умножить дробную часть отношения на длину последовательности
      - 'Всегда считать пустыми все слоты последнего блока, кроме одного'
    correct: 1
    explanation: >-
      Неполный блок выделяется целиком, поэтому сначала нужно округлить число
      блоков вверх. Для 1500 токенов при блоке на 16 токенов выделяются 94 блока
      вместимостью 1504 слота, из которых пустуют 4.
---

Примени округление вверх из [шага 12](#step-12): неполный последний блок всё равно выделяется целиком. Для 1500 токенов получаются 94 блока общей вместимостью 1504 токен-слота. Значит, пустуют 4 слота — не 15. Число 15 из [шага 16](#step-16) обозначает максимально возможную потерю в последнем блоке, а не потерю для любой последовательности.

Частая ошибка — округлить 93,75 вниз или принять дробную часть за число пустых слотов. Сначала найди целое число блоков, затем сравни их полную вместимость с фактической длиной.
