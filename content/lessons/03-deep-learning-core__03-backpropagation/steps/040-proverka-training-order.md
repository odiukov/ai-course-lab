В цикле из [шага 38](#step-38) один прямой проход получил предсказания при конкретном наборе параметров. Затем backward должен целиком выяснить, какую долю ошибки создал каждый из них. Если обновить один вес посреди обратного прохода, оставшиеся вычисления могут использовать уже изменённое число. Получится странная смесь: loss был получен старой сетью, а часть градиентов — будто сеть уже новая.

Поэтому сначала backward заполняет все градиенты, и лишь затем `sgd_step` из [шага 36](#step-36) одновременно переводит параметры в следующее состояние.

> 🎒 **На пальцах.** Представь расследование дорожного происшествия. Ты сначала фиксируешь положения всех машин и по этой единой картине определяешь вклад каждого водителя. Если передвинуть одну машину, пока замеры ещё идут, поздние измерения уже не будут относиться к исходной сцене. Сначала закончи все замеры — потом меняй обстановку.
