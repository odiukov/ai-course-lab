title: SGD сдвигает каждый параметр в сторону уменьшения ошибки
source_anchor: '### Step 6: Train on XOR'
---

После `backward` у тебя есть два числа: для одного веса градиент равен \(+0{,}8\), а для другого — \(-0{,}3\). Оставить параметры как есть нельзя: сеть снова даст ту же ошибку. Но в какую сторону двигать каждый из них?

Знак уже знаком по [шагу 24](#step-24). Положительный градиент говорит: увеличение параметра увеличит ошибку — значит, параметр нужно уменьшить. Отрицательный говорит обратное: параметр стоит увеличить. Поэтому SGD вычитает градиент:

\[
\theta \leftarrow \theta-\eta\frac{\partial L}{\partial\theta}
\]

Здесь \(\theta\) — любой вес или смещение, \(L\) — ошибка, а \(\eta\) — общий множитель, определяющий величину сдвига. При градиенте \(+0{,}8\) вычитается положительное число, и параметр уменьшается. При градиенте \(-0{,}3\) вычитание отрицательного числа превращается в прибавление, и параметр растёт.

Так обрабатывается каждый параметр сети. Градиенты, полученные одним `backward`, описывают одну и ту же текущую версию сети, поэтому сначала находят их все, а затем сдвигают параметры. После этого прямой проход выполняется заново: изменившиеся веса дают другие предсказания и новую ошибку. Один такой цикл — ещё не обучение целиком, а один шаг вниз.

> 🎒 **На пальцах.** Представь шарик на мятом листе металла. В каждой точке поверхность наклонена по-разному: влево-вправо, вперёд-назад. Градиент описывает эти наклоны, а SGD толкает шарик против каждого из них. Один толчок не доставит его в самую низкую точку, но после каждого нового измерения склон направляет следующий толчок.
