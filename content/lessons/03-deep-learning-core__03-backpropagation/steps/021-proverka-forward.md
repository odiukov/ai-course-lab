Проверь, можешь ли ты мысленно собрать «набор для дороги назад». Для каждого слоя нужен его вход: именно с ним было связано влияние весов. Для сигмоиды пригодится уже найденный выход — это следует из [шага 14](#step-14). В сети из [шага 18](#step-18) такими значениями становятся вход сети и активации слоёв.

Частая ошибка — сохранять только последний ответ: кажется, что остальные числа уже отработали. Но тогда обратному проходу нечем вычислять локальные градиенты, и часть прямого прохода придётся повторить. Поэтому сохранённые активации из [шага 20](#step-20) — не архив, а рабочие данные для движения назад.
