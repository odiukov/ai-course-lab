    options:

      - В точке f(g(x))

    correct: 0
    explanation: >-
      Сначала внутренняя функция превращает x в g(x), и именно это значение

  - question: >-
      Параметр w раннего слоя влияет на промежуточное значение z, а через него —
      на функцию потерь L. Какая производная описывает полное влияние малого
      изменения w на итоговую ошибку?
    options:
      - dL/dw
      - dz/dw
      - dL/dz
      - dw/dL
    correct: 0
    explanation: >-
      Полное влияние должно связывать начало зависимости w с её концом L,
      поэтому искомая величина — dL/dw. Производные dz/dw и dL/dz описывают
      только отдельные участки пути.

Тебе нужно проследить влияние самого первого звена до конца цепочки. Бери локальные влияния из [шага 5](#step-5) и перемножай их — не складывай. Особенно внимательно следи за отрицательным значением: оно меняет направление влияния. Нулевое значение полностью обрывает его передачу дальше, сколько бы звеньев ни оставалось.

> 🎒 **На пальцах.** Представь линию копировальных аппаратов. Первый делает две копии каждого листа, второй из каждой пары оставляет половину, третий печатает по четыре экземпляра. Чтобы узнать, сколько финальных листов породил один исходный, ты последовательно перемножаешь коэффициенты всех аппаратов. Один выключенный аппарат обнулит результат всей линии.
