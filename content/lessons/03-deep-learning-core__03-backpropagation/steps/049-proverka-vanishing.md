check:
  - question: >-
      Почему даже sigmoid-нейроны вне сильного насыщения не гарантируют
      сохранение градиента в глубокой сети?
    options:
      - Каждый слой заново обнуляет градиенты предыдущего слоя
      - >-
        Локальные производные sigmoid меньше единицы и последовательно
        перемножаются
      - Sigmoid запрещает обновлять веса входного слоя
    correct: 1
    explanation: >-
      Производная sigmoid не превышает 0,25. Поэтому после пяти таких множителей
      верхняя граница сигнала составляет 0,25^5 ≈ 0,000977 от исходного
      градиента.
  - question: >-
      Backward вернул раннему слою почти нулевой градиент, хотя ошибка сети
      остаётся заметной. Какое объяснение наиболее вероятно для глубокой
      sigmoid-сети?
    options:
      - Ранний слой уже обязательно достиг оптимальных значений
      - Любой почти нулевой градиент доказывает ошибку в реализации backward
      - >-
        Сигнал ослаб при прохождении через множество sigmoid, особенно через
        насыщенные
    correct: 2
    explanation: >-
      Малый градиент может быть корректным результатом цепного правила:
      локальные производные перемножаются, а насыщенные sigmoid дополнительно
      уменьшают сигнал. Сам по себе такой градиент не доказывает ни сходимость
      слоя, ни поломку backprop.
---

Тебе нужно отличать ошибку в backprop от правильного, но почти исчезнувшего сигнала. По расчёту из [шага 47](#step-47) ранний слой получает крошечную поправку даже в лучшем случае, а насыщение из [шага 48](#step-48) ослабляет её сильнее. Частая ловушка — решить, будто маленький градиент означает, что слой уже обучен.

> 🎒 **На пальцах.** Представь пять регуляторов громкости подряд, каждый оставляет четверть входящего звука. После пятого музыка едва слышна. Провода исправны, и каждый регулятор работает точно — просто их ослабление накопилось. Так и backprop может считать без ошибки, пока ранний слой почти не получает команды измениться.
