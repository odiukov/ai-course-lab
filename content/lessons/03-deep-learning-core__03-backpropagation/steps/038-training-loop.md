В начале сеть смотрит на четыре пары XOR и почти везде отвечает около \(0{,}5\). Суммарная ошибка получается примерно \(1{,}0\). Один сдвиг параметров немного улучшит ответы, но не научит сеть: новые параметры создадут уже другие предсказания и другую ошибку. Значит, всю работу нужно повторять по кругу.

Один такой круг называют **эпохой**: сеть один раз обрабатывает весь набор из четырёх примеров. Сначала для каждой пары выполняется forward из [шага 18](#step-18): сеть получает вход и выдаёт предсказание. Ошибки четырёх ответов складываются в общий loss. Так одно число показывает, насколько хорошо текущие параметры справляются со всей задачей XOR, а не с одной строкой таблицы.

Затем backward из [шага 29](#step-29) вычисляет градиенты всех параметров относительно этой общей ошибки. После этого SGD, разобранный в [шаге 35](#step-35), немного сдвигает каждый параметр. К следующей эпохе сеть приходит уже изменённой, поэтому снова нужны свежие forward, loss и backward.

Цикл повторяется много раз: предсказать, измерить ошибку, найти ответственность параметров, поправить их. Если обучение идёт удачно, общий loss постепенно падает, а ответы приближаются к \(0, 1, 1, 0\). Сеть не запоминает готовое правило XOR — она шаг за шагом настраивает параметры так, чтобы четыре ответа одновременно становились точнее.

> 🎒 **На пальцах.** Представь четыре мишени и лучника, который каждый круг делает по одному выстрелу в каждую. Сначала ты записываешь все четыре промаха, затем разбираешь их общую причину и только потом немного меняешь стойку. После изменения нужны новые выстрелы: старые отметки описывали прежнюю стойку. Так круг за кругом попадания собираются ближе к центрам.
