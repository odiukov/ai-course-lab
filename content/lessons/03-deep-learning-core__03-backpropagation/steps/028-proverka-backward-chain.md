Здесь важно проследить один конкретный путь назад от loss до выбранного веса скрытого слоя. В числах из [шага 27](#step-27) легко случайно перескочить через вес выходного слоя или взять активацию вместо производной сигмоиды.

Проверяй путь по операциям: ошибка проходит через выходную сигмоиду, связь между слоями, скрытую сигмоиду и только затем достигает скрытого веса через входной признак. Каждый участок добавляет свой множитель. Если хотя бы один из них равен нулю, влияние веса на loss по этому пути тоже становится нулевым.
