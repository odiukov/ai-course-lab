title: Backward за один проход возвращает градиент каждого параметра

Ты получил один ответ сети и одну ошибку. Теперь представь, что перед тобой четыре группы параметров: \(W_1\), \(b_1\), \(W_2\) и \(b_2\). Как понять, какой элемент каждой группы и насколько повлиял на эту ошибку? Проверять их по одному слишком дорого — именно с этого начался [шаг 1](#step-1).

Backward использует сохранённые значения из прямого прохода и движется от ошибки к параметрам. Сначала он находит влияние выходного слоя, затем передаёт сигнал скрытому слою — этот маршрут ты разобрал в [шагах 25](#step-25)–[28](#step-28). Важная деталь: пройдя этот маршрут один раз, backward получает результаты сразу для всех параметров сети.

Для каждого параметра результатом становится градиент той же формы. У \(W_1\) это таблица градиентов, у \(b_1\) — набор градиентов, и так далее. Каждый элемент отвечает на практический вопрос: «Если чуть увеличить именно это число при неизменных остальных, как изменится ошибка?» Знак показывает направление влияния, как в [шаге 24](#step-24), а величина — его силу около текущей точки.

«Один проход» не означает одно арифметическое действие. Операций внутри много, но сеть не запускается заново ради каждого веса. Общие промежуточные вычисления используются совместно, поэтому миллионы отдельных проверок превращаются в одно согласованное движение назад.

> 🎒 **На пальцах.** Представь расследование расходов после большого фестиваля. Итоговый перерасход уже известен, а тебе нужно оценить вклад сцены, света, охраны и рекламы. Ты не проводишь фестиваль заново без каждой отдельной покупки. Ты один раз идёшь назад по общей смете, распределяя итог по разделам и строкам. В конце у каждой суммы есть своя оценка влияния — как у каждого параметра после backward.
