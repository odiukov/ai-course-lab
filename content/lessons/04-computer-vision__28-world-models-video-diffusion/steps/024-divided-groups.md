Ты получил плоскую последовательность из восьми токенов для сетки `T=2, H=2, W=2`. Если просто разрезать её пополам, пространственные группы получатся правильно, а временные — нет: соседние моменты одной позиции лежат далеко друг от друга.

Напиши `divided_attention_groups(grid)`, которая возвращает два набора групп индексов:

- временные группы: одинаковые `(h, w)`, меняется только `t`;
- пространственные группы: одинаковое `t`, меняются `(h, w)`.

Используй порядок токенов из [шага 15](#step-15) и функцию `flat_index` из [шага 16](#step-16), чтобы не дублировать правило нумерации вручную.

Для сетки `(2, 2, 2)` результат должен описывать такие группы:

```text
time_groups  = [[0, 4], [1, 5], [2, 6], [3, 7]]
space_groups = [[0, 1, 2, 3], [4, 5, 6, 7]]
```

Обрати внимание: функция пока ничего не вычисляет над самими токенами. Она лишь составляет «списки участников» для двух проходов attention из [шага 23](#step-23). Сохраняй устойчивый порядок: сначала перебирай пространственные координаты для временных групп, затем моменты времени для пространственных.

Проверь три свойства результата: каждый индекс находится в диапазоне последовательности, внутри группы нет повторов, а каждый токен встречается ровно один раз в каждом наборе групп. Если токен потерялся или попал в набор дважды, значит перепутан порядок осей.

> 🎒 **На пальцах.** Представь спортивный лагерь. Сначала ты собираешь команды по номеру домика: жители одного домика встречаются в разные дни — это временные группы. Затем собираешь всех участников одного дня, независимо от домика, — это пространственные группы. Люди те же, но правило рассадки меняется. `divided_attention_groups` как раз печатает оба списка рассадки.
