Напиши `flat_index`, которая превращает координаты токена `(t, h, w)` в одно целое число. Правило обхода уже разобрано в [шаге 15](#step-15): сначала меняется `w`, после конца строки — `h`, а после целого кадра — `t`.

```python
def flat_index(t, h, w, grid_h, grid_w):
    # верни позицию токена в плоской последовательности
    pass
```

`grid_h` и `grid_w` задают число строк и столбцов. Размер временной оси для вычисления не требуется: координата `t` показывает, сколько полных временных слоёв нужно пропустить.

Проверь себя на сетке `(2, 3, 4)`. В ней один временной слой содержит 12 токенов:

```python
assert flat_index(0, 0, 0, 3, 4) == 0
assert flat_index(0, 0, 3, 3, 4) == 3
assert flat_index(0, 1, 0, 3, 4) == 4
assert flat_index(1, 0, 0, 3, 4) == 12
assert flat_index(1, 2, 3, 3, 4) == 23
```

Обрати внимание на переходы: увеличение `h` пропускает целую строку шириной `grid_w`, а увеличение `t` — целый слой размером `grid_h × grid_w`. Если эти два масштаба перепутать, первые несколько тестов пройдут, но токены следующих строк или кадров окажутся не на своих местах.

> 🎒 **На пальцах.** Представь архив с ящиками фотографий: в каждом ящике несколько конвертов, а в каждом конверте несколько снимков. Номер конкретного снимка получается так: сначала ты пропускаешь все снимки в предыдущих ящиках, затем снимки в предыдущих конвертах текущего ящика и только потом отсчитываешь позицию внутри конверта. `flat_index` делает ровно такой подсчёт.
