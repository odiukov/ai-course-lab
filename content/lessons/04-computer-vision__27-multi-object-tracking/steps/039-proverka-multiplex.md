title: 'Проверка: почему общая память выгодна при большом числе объектов'
source_anchor: '### SAM 3.1 Object Multiplex'
check:
  - question: >-
      Какая особенность общей памяти даёт основную экономию при переходе от
      нескольких объектов к плотной толпе?
    options:
      - >-
        Одни и те же пространственно-временные признаки памяти переиспользуются
        всеми экземплярами
      - >-
        Для каждого экземпляра создаётся отдельная копия признаков с меньшей
        точностью
      - Query-токены перестают обрабатываться после добавления объектов в память
    correct: 0
    explanation: >-
      Вместо отдельного memory bank для каждого экземпляра Object Multiplex
      хранит общие признаки совместно. Поэтому значительная часть работы не
      повторяется для каждого нового объекта.
  - question: >-
      Почему нельзя считать, что после объединения памяти tracking толпы стоит
      столько же, сколько tracking одного объекта?
    options:
      - >-
        Каждому экземпляру соответствует query-токен, который требует
        дополнительных вычислений
      - >-
        Общую память приходится полностью копировать при добавлении каждого
        экземпляра
      - >-
        Объединение памяти отключает совместную обработку признаков в плотных
        сценах
    correct: 0
    explanation: >-
      Общая память устраняет дублирование memory bank, но не всю работу на
      уровне экземпляров. Новые query-токены требуют ресурсов, поэтому стоимость
      растёт, хотя и медленнее числа объектов.
---

Ты запускаешь tracking сначала для нескольких людей, а затем для плотной толпы. В варианте с отдельными memory bank почти каждый новый человек приносит ещё одну полноценную память. В общей памяти из [шага 38](#step-38) значительная часть работы переиспользуется, а query-токены из [шага 37](#step-37) не дают людям слиться в один объект.

Здесь легко сделать слишком сильный вывод: общая память не превращает 50 объектов в стоимость одного. Query-токены тоже нужно обрабатывать. Выгода в другом — стоимость растёт медленнее числа объектов, потому что общие пространственно-временные признаки не дублируются для каждого экземпляра. Чем плотнее сцена, тем заметнее эта экономия.
