Ты получил короткий rollout: награды `[2, 0, 4]`. Нужно подготовить для критика цель на каждом шаге, но простая сумма наград не подойдёт: далёкое будущее должно ослабляться через `gamma`, а после обрезанного rollout может оставаться ценность следующего состояния.

Напиши `discounted_returns`, которая принимает награды, `gamma` и `last_value`, а возвращает список отдач той же длины. Расчёт из [шага 17](#step-17) выполняй с конца: сначала положи в накопитель `last_value`, затем двигайся по наградам справа налево. Каждая новая отдача использует уже рассчитанное будущее.

Проверь себя на примере: для наград `[2, 0, 4]`, `gamma = 0.5` и `last_value = 10` результат должен быть `[4.25, 4.5, 9.0]`. Последняя позиция получает `4 + 0.5 · 10`, предыдущая — `0 + 0.5 · 9`, первая — `2 + 0.5 · 4.5`.

Обрати внимание на две частые ошибки. Во-первых, обход идёт с конца, но вернуть значения нужно в исходном временном порядке. Во-вторых, `last_value` — не дополнительная награда: оно тоже дисконтируется. Для действительно завершившегося эпизода передавай `0.0`, а для обрезанного rollout — оценку критика на его границе.

> 🎒 **На пальцах.** Представь ряд закрытых конвертов: на каждом написана текущая выплата плюс половина суммы из следующего конверта. Заполнить первый конверт сразу нельзя — сумма следующего ещё неизвестна. Ты начинаешь с известной записки за границей ряда, заполняешь конверты справа налево, а затем раскладываешь их обратно по порядку шагов.
