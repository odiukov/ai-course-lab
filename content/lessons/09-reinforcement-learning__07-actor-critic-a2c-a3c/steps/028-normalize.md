Пусть в функцию приходят преимущества `[-2, 0, 2]`. После обработки среднее должно стать близким к нулю, а стандартное отклонение — к единице. Именно такое поведение нормализации мы разобрали в [шаге 27](#step-27); теперь тебе нужно аккуратно перенести его в функцию `normalize`.

Сначала найди среднее всех переданных значений и вычти его из каждого элемента. Затем вычисли стандартное отклонение исходного набора и раздели центрированные значения на него. Не изменяй входной массив на месте: верни новый массив той же формы.

Проверь себя на трёх свойствах:

- результат сохраняет порядок и форму элементов;
- его среднее практически равно нулю;
- его стандартное отклонение практически равно единице.

Есть неприятный крайний случай: преимущества могут оказаться одинаковыми, например `[5, 5, 5]`. Их разброс равен нулю, поэтому обычное деление даст неопределённые значения. Добавь к знаменателю маленькую константу `epsilon`, например `1e-8`. Тогда функция вернёт числа, близкие к нулю, и обучение не испортят `NaN`.

Не округляй результат и не вычисляй статистики отдельно для каждого элемента. Среднее и разброс должны описывать весь переданный набор. Для проверки попробуй также `[10, 20, 30]`: центральный элемент станет нулём, крайние получат одинаковые по модулю значения с разными знаками.

> 🎒 **На пальцах.** Представь три детали длиной 98, 100 и 102 миллиметра. Ты сначала переносишь ноль линейки на среднюю длину: получаешь −2, 0 и +2. Затем меняешь единицу измерения так, чтобы типичный разброс стал равен единице. Детали не поменялись — изменилась только удобная шкала их сравнения.
