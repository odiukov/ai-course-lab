Перед тобой пять точек, и нужно выбрать корень дерева. Взять первую удобно, но опасно: почти все остальные точки могут оказаться с одной стороны, и дерево вытянется в длинную цепочку. Поэтому `build_kdtree` должна выбирать медианную точку — ту, которая после сортировки стоит посередине.

На каждом уровне функция работает с одной координатой. Номер оси зависит от `depth`: на первом уровне сравнивается координата 0, на следующем — координата 1, затем оси повторяются. Это продолжает идею рекурсивного деления из [шага 38](#step-38).

Твоя функция должна:

- определить текущую ось по глубине и числу признаков;
- отсортировать переданные индексы точек по этой координате;
- взять средний индекс как точку текущего узла;
- рекурсивно построить левую часть из элементов до медианы;
- так же построить правую часть из элементов после неё;
- вернуть пустую ветвь, если точек больше не осталось.

Следи, чтобы в узле сохранялся исходный индекс точки, а не её место в отсортированном списке. Иначе дерево построится, но позже найденного соседа нельзя будет правильно связать с исходными данными.

Ещё одна частая ловушка — передать обеим ветвям саму медиану. Тогда одна точка будет появляться снова и снова, и рекурсия не закончится. Корень забирает медиану себе; детям достаются только части слева и справа.
