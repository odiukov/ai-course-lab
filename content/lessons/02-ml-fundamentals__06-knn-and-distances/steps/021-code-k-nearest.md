Она должна вернуть индексы `k` ближайших строк из `X_train` к точке `query`. Считай, что `k` — положительное число и не превышает размер тренировочного набора.

Собери внутри функции полный перебор из [шага 20](#step-20):

1. Для каждой строки `X_train` вызови `distance_fn(query, row)`.
2. Сохрани вместе расстояние и индекс строки. Сам индекс важен: позднее по нему можно будет взять правильный ответ из `y_train`.
3. Отсортируй пары по расстоянию от меньшего к большему.
4. Оставь первые `k` пар и верни только их индексы.

Проверь себя на четырёх расстояниях выше: при `k=3` функция должна выбрать индексы точек с расстояниями `0.7`, `0.9` и `1.6`, причём именно в порядке близости. Не зашивай внутрь `l2_distance`: параметр `distance_fn` позволяет подставить функции, написанные на [шагах 7](#step-7), [9](#step-9), [11](#step-11) и [13](#step-13).
