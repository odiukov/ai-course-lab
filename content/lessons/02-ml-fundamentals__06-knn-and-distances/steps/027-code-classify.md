У тебя уже есть список ближайших объектов из функции `k_nearest`, написанной на [шаге 21](#step-21). Теперь представь, что она вернула три пары: расстояние и индекс строки. Расстояния сами по себе не отвечают на вопрос «какой это класс» — нужно по индексам достать метки из `y_train` и собрать голоса.

Напиши функцию `knn_classify`. Она должна получить новую точку, обучающие данные, метки, значение `k`, функцию расстояния и флаг `weighted`. Внутри сначала вызови `k_nearest`, а затем заведи словарь: ключом будет класс, значением — набранный им голос.

При `weighted=False` каждый сосед добавляет своему классу единицу. При `weighted=True` вклад зависит от расстояния: используй правило из [шага 25](#step-25). Не забудь маленькое `epsilon`, иначе сосед с нулевым расстоянием приведёт к делению на ноль.

После обхода соседей верни класс с наибольшей суммой голосов. Обрати внимание: искать максимум нужно по значениям словаря, а вернуть — соответствующий ключ. На этом месте легко случайно вернуть вес победителя вместо его названия.

Проверь функцию на маленьком примере, где метки соседей видны глазами. Затем приблизь одного соседа другого класса и включи взвешивание: результат должен измениться только тогда, когда его усиленный голос действительно перевесит остальные.

> 🎒 **На пальцах.** Представь диспетчера службы доставки. Курьеры рядом с адресом называют подходящий район, а диспетчер записывает ответы в журнал по районам. В обычном режиме каждый голос — одна отметка. Во взвешенном режиме курьер через дорогу влияет сильнее курьера в нескольких кварталах. Функция должна заполнить журнал и назвать район с самой большой итоговой суммой.
