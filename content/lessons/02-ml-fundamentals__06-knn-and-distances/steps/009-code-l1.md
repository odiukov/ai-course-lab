Возьми две точки: `a = [2, -1, 4]` и `b = [5, 3, 4]`. Тебе нужно превратить правило L1 из [шага 8](#step-8) в функцию. По координатам получаются разности `-3`, `-4` и `0`. Если сложить их сразу, отрицательные числа погасят часть расстояния. Поэтому сначала нужны модули: `3`, `4`, `0`, а уже затем сумма `7`.

Допиши тело функции:

```python
def l1_distance(a, b):
    # твой код здесь
    pass
```

Функция должна пройти по двум спискам одновременно. Для этого пригодится `zip(a, b)`: он составляет пары из элементов с одинаковыми позициями. Для каждой пары найди разность, передай её в `abs`, а затем сложи все результаты через `sum`.

Проверь себя на примерах:

```python
assert l1_distance([2, -1, 4], [5, 3, 4]) == 7
assert l1_distance([1, 2], [1, 2]) == 0
assert l1_distance([-2], [3]) == 5
```

Обрати внимание на два частых промаха: нельзя складывать разности без `abs`, и нельзя брать модуль только после общей суммы. В этом задании считай, что оба списка имеют одинаковую длину.

> 🎒 **На пальцах.** Представь две ленты с числами, лежащие одна под другой. Ты соединяешь числа напротив, записываешь величину разрыва между ними без знака и складываешь записи. `zip` совмещает ленты, `abs` убирает направление разрыва, а `sum` собирает отдельные разрывы в одно расстояние.
