Внутри воспроизведи вычисление из [шага 6](#step-6). Сначала соедини соответствующие координаты с помощью `zip(a, b)`: первая из `a` должна встретиться с первой из `b`, вторая — со второй. Для каждой пары найди разность и возведи её в квадрат. Затем сложи получившиеся значения через `sum`, а из суммы извлеки квадратный корень с помощью `math.sqrt`.

Обрати внимание: функция должна вернуть число через `return`, а не просто напечатать его. Иначе результат нельзя будет использовать при поиске ближайших соседей.

Проверь себя на двух случаях:

```python
print(l2_distance([1, 2], [4, 6]))  # ожидается 5.0
print(l2_distance([7, 3], [7, 3]))  # ожидается 0.0
```

В этом задании считай, что оба списка имеют одинаковую длину. `zip` остановится на более коротком списке и молча отбросит лишние координаты — это может скрыть ошибку во входных данных.

> 🎒 **На пальцах.** Представь кассира, который сверяет две корзины по позициям. Для каждой пары товаров он записывает разницу, усиливает крупные расхождения возведением в квадрат, а затем собирает всё в один чек. Квадратный корень превращает итог чека обратно в обычное расстояние. Твоя функция автоматизирует именно эту последовательность действий.
