На панели три таймера уже заполнены: запрос провёл 200 мс в очереди, 50 мс в сети и 800 мс на prefill. Но поле TTFT пока пустое. Тебе нужно написать функцию, которая соберёт эти измерения в одну задержку — ту, которую пользователь ощущает до появления первого токена.

Используй заготовку:

```python
def ttft_ms(queue_ms, network_request_ms, prefill_ms):
    """Возвращает время до первого токена в миллисекундах."""
    pass
```

Замени `pass` вычислением по формуле из [шага 3](#step-3). Все три аргумента уже выражены в миллисекундах, поэтому переводить их в секунды или умножать на 1000 не нужно. Функция должна вернуть число, а не напечатать его: так результат можно будет использовать в отчётах и следующих вычислениях.

Проверь себя на конкретных данных:

```python
result = ttft_ms(
    queue_ms=200,
    network_request_ms=50,
    prefill_ms=800,
)

print(result)  # ожидается 1050
```

Обрати внимание на единицы измерения: суффикс `_ms` напоминает, что и входные значения, и результат измеряются в миллисекундах. Не округляй их внутри функции — иначе небольшие потери незаметно накопятся при анализе множества запросов.

> 🎒 **На пальцах.** Ты нажимаешь кнопку запуска кинопроектора. Сначала ждёшь, пока освободится аппарат, затем сигнал проходит по кабелю, после чего проектор готовит плёнку. Первый кадр появится только после всех трёх ожиданий. Функция `ttft_ms` работает как секундомер, который складывает эти отрезки и показывает полное время до первого кадра.
