У тебя уже есть `shared_mlp` из [шага 9](#step-9). После него каждая точка описана набором признаков, но тензор всё ещё хранит отдельную запись для каждой из них. Например, форма `(4, 1024, 800)` означает: 4 облака, 1024 признака и 800 точек.

Обрати внимание на оси. После MLP точки находятся в последнем измерении, поэтому исчезнуть должна именно последняя ось. Каналы признаков сохраняются: для каждого канала выбирается своё максимальное значение.

Проверь функцию на формах:

```python
x = torch.randn(4, 3, 800)
mlp = shared_mlp([3, 64, 128, 1024])

feature = pointnet_global_feature(x, mlp)
print(feature.shape)  # ожидается: (4, 1024)
```

Если получилось `(4, 800)`, ты случайно сжал каналы. Если осталось три измерения, значит измерение точек ещё не убрано. Правильный результат хранит один вектор длины 1024 на каждое облако.

> 🎒 **На пальцах.** Представь пульт со множеством датчиков и 1024 индикаторами. Каждая точка на мгновение поднимает некоторые индикаторы. Для каждого индикатора пульт запоминает только самый высокий подъём среди всех точек. В конце отдельные показания исчезают, а остаётся одна панель пиков — компактная характеристика всего облака.
