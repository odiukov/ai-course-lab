Ты решил проверить NeRF на городских улицах и скачал KITTI: машин много, сцены настоящие, данные трёхмерные. Но вместо набора фотографий одной сцены с известными положениями камер находишь в основном уличные LiDAR-облака. Датасет — учебный набор примеров — хороший, просто он отвечает на другой вопрос.

Сначала выбери задачу и представление данных из [шага 3](#step-3). Если нужно распознавать форму объекта или выделять его части в облаке точек, подойдёт ShapeNet: там собраны 3D-модели, созданные в САПР. Для сегментации настоящих помещений полезнее ScanNet — реальные сканы комнат сложнее аккуратных цифровых моделей. KITTI подходит задачам автономного вождения: его LiDAR фиксирует улицы, автомобили и окружающие объекты как облака точек, знакомые тебе по [шагу 7](#step-7).

Для NeRF из [шага 15](#step-15) нужен другой тип примеров: несколько снимков одной сцены и поза камеры для каждого снимка — то есть откуда и в каком направлении снимали. NeRF Synthetic удобен для первой проверки: позиции камер известны точно, поэтому ошибка калибровки не маскируется под ошибку модели. Blended MVS тоже содержит многовидовые снимки с позами. А Mip-NeRF 360 используют, когда важны реальные сцены, продолжающиеся вокруг камеры, а не компактный объект на пустом фоне.

Название датасета вторично: решает совпадение его примеров с тем, что модель должна получать и предсказывать.

> 🎒 **На пальцах.** Представь кладовую с реквизитом для разных спектаклей. Для сцены про космос нужны макеты планет, для детектива — уличные декорации, для балета — свободная площадка. Самая большая кладовая не станет лучшей автоматически: если внутри нет нужного реквизита, репетировать твою постановку всё равно не получится.
