check:
  - question: >-
      Ты дважды вызываешь jax.random.normal с одним ключом и одинаковой формой.
      Что произойдёт?
    options:
      - Будут созданы два одинаковых массива
      - Будут созданы два независимых массива
      - JAX сообщит об ошибке повторного использования ключа
    correct: 0
    explanation: >-
      Ключ не изменяется и не расходуется автоматически. Одинаковые ключ,
      операция и форма приводят к одинаковому результату.
  - question: >-
      Тебе нужны независимые случайные веса для двух слоёв. Как правильно
      использовать исходный ключ?
    options:
      - 'Передать один ключ обоим слоям, выполнив вызовы по очереди'
      - Разделить ключ и передать каждой инициализации отдельный подключ
      - 'Использовать один ключ, изменив только форму второго массива'
    correct: 1
    explanation: >-
      Последовательность вызовов сама по себе не изменяет ключ. Для независимых
      инициализаций каждой случайной операции передают отдельный подключ,
      полученный через split.
---

Ты создаёшь веса двух слоёв и случайно передаёшь обоим один ключ. JAX не выдаст ошибку и не «продвинет» генератор: при одинаковой операции и форме массивы совпадут. Здесь легко спутать повторный вызов с новой случайностью. После [шага 12](#step-12) тебе важно узнавать эту скрытую ошибку и выбирать `split` перед независимыми операциями.

> 🎒 **На пальцах.** Представь фонтан с карточкой программы: она задаёт точную последовательность струй. Если дважды вставить одну карточку, фонтан повторит тот же рисунок, а не придумает новый. Для двух разных представлений нужны две отдельные карточки, полученные разделением исходной. Повторный запуск сам по себе новой случайности не создаёт.
