title: Pytree хранит параметры модели во вложенной структуре

Допустим, ты собрал модель из трёх слоёв. У каждого слоя есть матрица весов `w` и вектор смещений `b`. Можно передать функции шесть отдельных массивов, но тогда её вызов быстро превращается в длинный список аргументов: легко перепутать веса второго слоя со смещениями третьего.

Удобнее сохранить параметры так:

```python
params = {
    "layer1": {
        "w": jnp.zeros((784, 256)),
        "b": jnp.zeros(256),
    },
    "layer2": {
        "w": jnp.zeros((256, 128)),
        "b": jnp.zeros(128),
    },
    "layer3": {
        "w": jnp.zeros((128, 10)),
        "b": jnp.zeros(10),
    },
}
```

Такая вложенная структура называется **pytree**. Словари, списки и кортежи образуют её ветви, а массивы в самом низу — листья. Глубина и названия ветвей могут быть разными: JAX важно, что он умеет отделить форму дерева от хранящихся в нём значений.

Это состыкуется с моделью из [шага 3](#step-3): `params` остаётся явным входом чистой функции, просто теперь все параметры аккуратно упакованы в один аргумент. При этом не нужен объект со скрытым списком параметров, метод `.parameters()` или специальная регистрация каждого массива. JAX-преобразования умеют обходить pytree и находить его листья.

Значит, модель описывается не классом-контейнером, а самой структурой данных и функцией, которая её принимает.

> 🎒 **На пальцах.** Представь чемодан с органайзерами: большой отсек подписан `layer1`, внутри лежат карманы `w` и `b`; рядом такие же отсеки для других слоёв. Чемодан целиком — pytree, отсеки и карманы — ветви, а вещи в самых маленьких карманах — листья. Ты передаёшь один чемодан, но JAX знает, где внутри лежит каждый массив.
