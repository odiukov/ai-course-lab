В [шаге 21](#step-21) ты превратил `f` в `df` и вызвал результат как обычную функцию. Теперь представь, что тебя интересует не сам наклон `f`, а то, как быстро этот наклон меняется. Нужна вторая производная — но отдельной команды для неё нет.

Она и не нужна. Результат `jax.grad(f)` — функция, а `jax.grad` как раз принимает функцию. Значит, один результат можно сразу передать следующему преобразованию:

```python
import jax

def f(x):
    return x ** 2

df = jax.grad(f)
d2f = jax.grad(df)

d2f(3.0)
```

Последние две строки можно записать короче:

```python
d2f = jax.grad(jax.grad(f))
```

Читай выражение изнутри наружу. Внутренний `grad` создаёт функцию первой производной. Внешний `grad` получает эту функцию и создаёт функцию уже её производной. Для `f` из примера вызов `d2f(3.0)` вернёт `2.0`: наклон меняется с постоянной скоростью, поэтому аргумент здесь уже не влияет на ответ.

По тому же принципу можно добавить ещё один `grad` и получить третью производную. Важен не особый синтаксис для каждого порядка, а одинаковая форма входа и выхода: функция входит, функция выходит. Именно поэтому преобразования естественно вкладываются друг в друга.

> 🎒 **На пальцах.** Представь карту горной тропы, где каждой точке сопоставлена высота. Первый прибор превращает её в карту уклона: где подъём крутой, а где пологий. Получившаяся карта подходит тому же прибору, поэтому второй проход показывает уже изменение уклона — где склон становится резче или выравнивается. Каждый раз прибор получает карту и возвращает новую карту.
