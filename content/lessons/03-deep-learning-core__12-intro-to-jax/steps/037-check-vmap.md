      Параметры params общие для всего батча, поэтому для них указано None.

  - question: 'Что означает ось 0 для params в записи in_axes=(0, 0)?'
    options:
      - Один набор параметров будет применён ко всему батчу
      - JAX будет ожидать отдельный набор параметров для каждого примера

    explanation: >-
      Значение 0 сообщает vmap, что аргумент батчирован по первой оси. Поэтому
      вдоль оси 0 в params должны находиться отдельные наборы параметров,
      сопоставленные примерам.

Здесь важно уверенно прочитать `in_axes`, а не просто узнать знакомую запись из [шага 35](#step-35). Для каждого аргумента спроси себя: он один на весь батч или меняется вместе с примерами? Чаще всего путаются именно с `None`: это не пустой аргумент, а указание не добавлять ему батчевую ось. Ноль же означает, что очередной пример берётся вдоль первой оси массива.

> 🎒 **На пальцах.** Представь типографию: печатная форма одна для всего тиража, а листы идут стопкой. Форме соответствует `None` — её не меняют между отпечатками. Листам соответствует `0` — типография последовательно различает их по положению в стопке. Если поставить `0` и форме, пришлось бы подготовить отдельную форму для каждого листа.
