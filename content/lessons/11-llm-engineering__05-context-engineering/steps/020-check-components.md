    options:
      - Один раз — при запуске агента
      - 'Каждый вызов, то есть все 24 раза'
      - Только при первом вызове инструмента
    correct: 1
    explanation: >-
      Окно собирается заново перед каждым вызовом, поэтому определения

  - question: >-
      Из перечисленных частей окна какая ближе всего к фиксированной

    options:
      - Найденные документы из базы
      - История диалога
      - System prompt
      - Зарезервированное место под ответ

    explanation: >-
      System prompt задаёт постоянные инструкции и обычно входит в каждый вызов.

После [шагов 14](#step-14)–[19](#step-19) ты должен уметь делить окно на две неравные части: то, за что платишь всегда, и то, чем управляешь по ситуации. System prompt и определения инструментов — первая группа: их размер умножается на число вызовов. Найденный контекст, история и примеры — вторая: их можно резать, фильтровать, подбирать под запрос.

Чаще всего спотыкаются на двух местах. Первое — кажется, что инструменты «загружаются один раз». Нет: окно собирается заново перед каждым вызовом. Второе — забывают, что бюджет генерации тоже занимает место, и набивают вход под самый край.
