На [шаге 29](#step-29) ты увидел степень, которая появляется при движении градиента назад по цепочке. Теперь преврати эту идею в маленький эксперимент: функция `vanishing_factor` должна вычислять, во сколько раз изменится градиент после нескольких одинаковых умножений.

Функция получает два числа:

- количество последовательных умножений;
- рекуррентный вес, на который градиент умножается каждый раз.

Вернуть нужно один общий множитель. Для вычисления степени используй `math.pow`: первым аргументом передаётся рекуррентный вес, вторым — количество умножений. Не добавляй начальный или конечный градиент — функция моделирует только изменение его масштаба.

Особенно внимательно посмотри на смысл длины. Если между ранним и поздним токенами 99 переходов, умножений тоже 99. Само количество токенов может быть на единицу больше, поэтому здесь легко получить ошибку «плюс один».

После реализации попробуй менять оба аргумента и наблюдай за результатом. Значение меньше единицы означает, что ранний сигнал ослаб; больше единицы — что он усилился. Так длинная цепочка превращает небольшое отклонение рекуррентного веса от единицы в заметный эффект.

> 🎒 **На пальцах.** Представь печать, которую последовательно переносят через стопку копировальной бумаги. Каждый лист сохраняет лишь некоторую долю предыдущего отпечатка. `vanishing_factor` не оценивает исходную яркость печати — он показывает, какая её доля доберётся через всю стопку. Чем больше переносов, тем сильнее проявляется качество каждого отдельного копирования.
