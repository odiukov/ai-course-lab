После шести токенов RNN вернула шесть hidden states, в каждом по четыре числа. Классификатор же ждёт один вектор из четырёх чисел. В [шаге 23](#step-23) ты разобрал три способа сжать последовательность; теперь собери их в функции `pool_hidden`.

Функция получает:

- `hidden_states` — массив формы `(длина_текста, hidden_size)`;
- `mode` — строку `"last"`, `"mean"` или `"max"`.

Она должна вернуть вектор формы `(hidden_size,)`. Для `"last"` возьми последнюю строку. Для `"mean"` усредни строки вдоль оси текста. Для `"max"` найди максимум по той же оси отдельно для каждого компонента.

Последний случай легко понять неверно: выбирать целиком одну «лучшую» строку не нужно. Если максимальные значения находятся в разных hidden states, итоговый вектор соберётся из разных строк.

Обрати внимание именно на ось свёртки. Исчезнуть должна длина текста, а размер hidden state — сохраниться. Например, вход формы `(6, 4)` при любом режиме превращается в `(4,)`. Для неизвестного значения `mode` функция должна явно сообщить об ошибке, а не молча выбирать один из вариантов.

> 🎒 **На пальцах.** Представь таблицу наблюдений метеостанции: шесть строк по времени и четыре столбца — температура, ветер, влажность и давление. `last` оставляет последние показания, `mean` считает среднее каждого столбца, а `max` берёт его пик. Какой бы способ ты ни выбрал, шесть моментов исчезают, но четыре вида показаний остаются.
