    options:
      - >-

        уменьшение многократно накапливается
      - 'RNN автоматически обнуляет градиенты, полученные на ранних позициях'
      - >-

    correct: 0
    explanation: >-
      Градиент проходит через цепочку из 99 умножений на 0.9. Повторяющееся

  - question: >-

      - >-

    correct: 0
    explanation: >-
      При весе 1.1 каждый из 99 переходов увеличивает масштаб градиента.

      в сильный общий рост.

Запусти функцию из [шага 30](#step-30) для 99 переходов с весами 0.9 и 1.1. Здесь легко смотреть только на близость обоих весов к единице и недооценить повторение: небольшое изменение на одном переходе превращается в огромную разницу на длинной цепочке.

> 🎒 **На пальцах.** Представь копировальный аппарат, который перед каждой новой копией меняет масштаб. При 90% надпись понемногу сжимается и через 99 копий почти исчезает. При 110% она каждый раз чуть растёт и вскоре перестаёт помещаться на листе. Дело не в одном изменении, а в том, сколько раз оно повторилось.
