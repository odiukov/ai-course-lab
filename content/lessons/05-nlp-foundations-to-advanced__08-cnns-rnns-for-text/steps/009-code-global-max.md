После `conv1d` из [шага 6](#step-6) у тебя получилась карта признаков: каждая строка соответствует окну текста, а каждый столбец — отдельному фильтру. Например:

```python
feature_map = [
    [0.2,  0.9, -0.1],
    [0.8,  0.3,  0.4],
    [0.1, -0.2,  0.7],
    [0.5,  0.6,  0.2],
]
```

Напиши `global_max_pool(feature_map)`, которая реализует идею из [шага 8](#step-8): для каждого фильтра оставляет его самую сильную активацию среди всех окон. Для примера выше результат должен быть таким:

```python
[0.8, 0.9, 0.7]
```

Обрати внимание: нужен максимум **по каждому столбцу**, а не по каждой строке. Если взять максимум строки, получится по одному числу на окно. Если найти максимум всей таблицы, останется единственное число. В обоих случаях потеряется информация о других фильтрах.

Длина результата должна совпадать с количеством фильтров, а число окон на неё не влияет. Считай, что карта непустая и все её строки одной длины. Не начинай максимумы с нуля: если все активации некоторого фильтра отрицательные, функция всё равно должна вернуть наибольшую из них, например `-0.1`, а не выдуманный `0`.

> 🎒 **На пальцах.** Представь фотоловушки вдоль лесной тропы: каждая строка — новый снимок, а каждый столбец — отдельный датчик, например «похож на лису» или «похож на зайца». Тебе не нужен лучший снимок вообще. Для каждого датчика ты отдельно сохраняешь его самое убедительное срабатывание — независимо от того, на каком снимке оно появилось.
