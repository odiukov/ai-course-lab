Представь, что ты вызываешь `roots_of_unity(8)`, а функция возвращает только семь чисел — или девять, причём последнее совпадает с первым. Здесь легко ошибиться не в комплексных числах, а в границах обычного цикла.

Начни с заготовки:

```python
def roots_of_unity(N):
    # Собери и верни список из N корней
    pass
```

Функция получает `N` — количество корней — и должна вернуть список комплексных чисел. Формулу для корня с номером `k` ты уже видел на [шаге 35](#step-35), поэтому сейчас твоя задача — аккуратно переложить её на Python.

Перебери `k` с помощью `range(N)`. Так ты получишь ровно нужные номера: от `0` до `N - 1`. Для каждого номера:

1. вычисли соответствующий угол;
2. передай этот угол функции `euler`;
3. добавь полученное комплексное число в список.

Угол должен быть в радианах, поэтому используй `math.pi`, а не число градусов. Обрати внимание и на порядок операций: сначала умножение на `k`, затем деление на `N`.

В конце верни весь список, а не последний вычисленный корень. Для `N = 1` список тоже должен содержать один элемент. Случай `N = 0` пока можно не обрабатывать: считай, что на вход приходит положительное целое число.

> 🎒 **На пальцах.** Представь автомат, который расставляет `N` флажков по круглому торту. Счётчик `k` выбирает место очередного флажка, вычисленный угол поворачивает поднос, а `euler` записывает координаты места. Если прокрутить счётчик ровно от `0` до `N - 1`, автомат поставит нужное число флажков и не продублирует начальную позицию.
