Представь, что у тебя не одно комплексное число, а 128 результатов измерения. Вызывать для каждого модуль, угол и сопряжение вручную быстро надоест. NumPy принимает весь массив сразу и возвращает массив ответов той же формы:

```python
import numpy as np

z = np.array([1 + 2j, 3 + 4j, 5 + 6j])

lengths = np.abs(z)
angles = np.angle(z)
mirrored = np.conj(z)
x = np.real(z)
y = np.imag(z)
```

Суффикс `j` здесь тот же, что во встроенных комплексных числах Python из [шага 44](#step-44). Разница в масштабе: `np.abs(z)` применяет модуль сразу ко всем трём элементам, а `np.real(z)` и `np.imag(z)` извлекают две координаты каждого числа.

Та же идея работает с преобразованием Фурье. Возьмём 128 отсчётов синусоиды частотой 5 Гц:

```python
t = np.arange(128) / 128
signal = np.sin(2 * np.pi * 5 * t)

spectrum = np.fft.fft(signal)
freqs = np.fft.fftfreq(128, d=1/128)
```

`np.fft.fft` выполняет DFT из [шага 40](#step-40), но тебе не приходится писать вложенные циклы и самостоятельно вычислять вращающиеся веса. На выходе получается комплексный массив `spectrum`: модуль его элементов показывает силу частот, а угол — фазу, как в [шаге 41](#step-41). Массив `freqs` сообщает, какой частоте соответствует каждая ячейка спектра.

Получается, изученная математика не исчезла: NumPy просто упаковал её в готовые операции над целыми наборами данных.

> 🎒 **На пальцах.** Представь линию сортировки с 128 посылками. Вместо того чтобы вскрывать каждую вручную, ты задаёшь машине одну операцию — «измерить вес» или «разложить по частотам». Машина обрабатывает всю ленту, но возвращает отдельный результат для каждой посылки. Массив NumPy — это лента, а `abs`, `angle` и `fft` — разные режимы сортировочной машины.
