Ты переносишь в Python число \(3+2i\), запускаешь код — и получаешь ошибку: имя `i` программе неизвестно. Python воспринимает букву без числа как название переменной. Для мнимой единицы здесь выбрано другое написание: суффикс `j`.

```python
z = 3 + 2j
w = 1 + 4j

print(type(z))  # <class 'complex'>
print(z + w)    # (4+6j)
print(z * w)    # (-5+14j)
print(abs(z))   # 3.605551275463989
```

Запись `2j` — это литерал, то есть значение, записанное прямо в коде. Суффикс сообщает Python: перед тобой мнимая часть комплексного числа. Поэтому нужна именно запись `1j`, а не просто `j`. Сам тип называется `complex`, а сложение, умножение и модуль работают по правилам из [шага 5](#step-5), [шага 7](#step-7) и [шага 13](#step-13).

Буква изменилась, но математика не изменилась: Python записывает через `j` ту же мнимую единицу, которую в формулах обозначают \(i\). Такое обозначение пришло из электротехники, где буквой \(i\) часто называют силу тока.

Для угла, экспоненты и других специальных операций есть встроенный модуль `cmath`:

```python
import cmath

print(cmath.phase(z))
print(cmath.exp(1j * cmath.pi))
```

Итак, перевод между учебником и Python короткий: математическое \(i\) превращается в программное `j`.

> 🎒 **На пальцах.** Представь ценник `2€`: суффикс `€` не меняет число два, а подсказывает, как его понимать. В записи `2j` буква играет похожую роль — сообщает Python, что двойка относится к мнимой оси. Если убрать суффикс, останется обычное вещественное число; если написать голую `j`, программа решит, что ты указал имя неизвестной переменной.
