title: Как превратить документы разной длины в числовые векторы
source_anchor: '## The Problem'
---

Перед тобой два сообщения: «скидка сегодня» и «большая скидка только сегодня для новых клиентов». В первом два слова, во втором — восемь. Просто передать их модели как списки чисел не получится: у строк будет разная длина, а классификатор ожидает одинаковое количество признаков.

Сначала ты собираешь **словарь** — общий перечень слов, встречающихся во всех документах. Это похоже на заранее подписанные ячейки анкеты: одна для слова «скидка», другая для «сегодня», третья для «клиент» и так далее. Затем каждое сообщение заполняет одну и ту же анкету.

Допустим, словарь состоит из четырёх слов: «скидка», «сегодня», «только», «клиент». Сообщение «скидка сегодня» превратится в вектор `[1, 1, 0, 0]`: первые два слова встретились по одному разу, остальных нет. Фраза «скидка только для клиента» даст `[1, 0, 1, 1]`. Если слово появилось трижды, в его позиции будет `3`.

Размер документа теперь не влияет на размер результата. Короткое сообщение и длинная статья получают векторы одинаковой длины — по одной позиции на каждое слово словаря. Модель видит не строку, а аккуратный ряд сопоставимых чисел: в каждой позиции всегда измеряется одно и то же.

> 🎒 **На пальцах.** Представь склад с фиксированным рядом подписанных коробок: «яблоки», «груши», «сливы». Один курьер привёз два пакета, другой — двадцать, но итог записывают одинаково: сколько предметов оказалось в каждой коробке. Поставки были разного размера, а складская ведомость у обеих получилась одной длины.
