У тебя уже есть словарь из функции `build_vocab`, написанной на [шаге 7](#step-7). Теперь попробуй превратить список документов в матрицу счётчиков по алгоритму из [шага 8](#step-8).

Напиши функцию с такой сигнатурой:

```python
def bag_of_words(docs, vocab):
    # твой код
```

Сначала создай матрицу из нулей: по одной отдельной строке на каждый документ и по одной ячейке на каждое слово словаря. Затем перебирай документы и токены внутри них. Если токен есть в `vocab`, словарь подскажет номер нужной ячейки — увеличь её на единицу. Незнакомые токены пропускай: для них в матрице нет столбца.

Проверь функцию на примере:

```python
docs = [["cat", "sat", "on", "mat"], ["cat", "cat", "ran"]]
vocab = build_vocab(docs)

print(bag_of_words(docs, vocab))
# [[1, 1, 1, 1, 0], [2, 0, 0, 0, 1]]
```

Обрати внимание на частую ловушку: строки матрицы должны быть независимыми списками. Если несколько строк ссылаются на один список, изменение счётчика в одном документе неожиданно изменит остальные.

Удобная самопроверка: сумма чисел в строке должна совпасть с количеством учтённых токенов соответствующего документа.

> 🎒 **На пальцах.** Представь, что каждому участнику викторины выдали отдельную карточку с одинаковым набором тем. Услышав ответ про кино, ты ставишь отметку в ячейке «кино» именно на карточке этого участника. Повторный ответ добавляет ещё одну отметку. Если карточка у всех одна общая, отметки смешаются — поэтому каждому документу нужна собственная строка.
