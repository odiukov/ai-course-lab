title: Качество команды как покрытие задач подходящими специалистами

Ты собираешь команду для запуска городского фестиваля. В ней есть сильный дизайнер, опытный ведущий и отличный фотограф. Список впечатляет — пока ты не замечаешь задачи «подключить сценическое электричество» и «оформить разрешение на перекрытие улицы». Общая талантливость команды здесь не спасает: важен специалист для каждой конкретной работы.

Возьми все задачи по очереди. Для каждой найди максимальную оценку компетентности среди ролей — так же, как при выборе роли в [шаге 8](#step-8). Получившееся число показывает, насколько хорошо команда покрывает именно эту задачу. Например, покрытия четырёх задач равны 1, 0,9, 0,8 и 0,2. Первые три обеспечены подходящими людьми, а четвёртая почти осталась без специалиста.

Сводное качество команды можно оценить средним покрытием: сложить лучшие оценки для всех задач и разделить на число задач. Но смотреть только на среднее опасно. Несколько единиц легко маскируют один провал, хотя именно он способен остановить весь проект. Поэтому рядом со сводной оценкой полезно сохранять покрытия отдельных задач.

Назначения из [шага 10](#step-10) отвечают на вопрос «кому отдать работу», а качество команды — на другой: «насколько удачно вообще можно раздать весь набор работ имеющимися ролями». Команда сильна не тогда, когда в ней много звёзд, а когда ни одна важная задача не остаётся в чужих руках.

> 🎒 **На пальцах.** Представь набор ключей для старого дома. Пять ключей идеально открывают пять дверей, а шестой замок ни одному не поддаётся. Полированная связка всё равно не даёт попасть в кладовую. Качество набора определяется не красотой ключей и не их количеством, а тем, для каждого ли замка нашёлся подходящий.
