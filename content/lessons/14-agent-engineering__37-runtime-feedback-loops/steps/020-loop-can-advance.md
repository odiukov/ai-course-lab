Перед циклом лежат три записи: у первой `exit_code` равен `0`, у второй — `2`, у третьей — `null`. Какой из этих результатов разрешает агенту перейти к следующему действию?

Напиши функцию `loop_can_advance`, которая получает feedback record из [шага 16](#step-16) и возвращает логическое решение: можно продолжать цикл или нужно остановиться. Проверь три случая отдельно:

- `exit_code: 0` — команда действительно завершилась успешно, поэтому функция возвращает `true`;
- любой ненулевой код — команда завершилась, но сообщила об ошибке, поэтому результат `false`;
- `exit_code: null` — раннер не получил код выхода, поэтому результат тоже `false`.

На последнем случае легко споткнуться: наличие поля `error` может подсказать причину сбоя, но не превращает неизвестный результат в успешный. Для решения достаточно самого `exit_code`.

Не проверяй значение через общую «истинность»: во многих языках число `0` считается ложным, хотя именно оно обозначает успех команды. Сравнение должно точно различать ноль, ненулевой код и отсутствие значения.

Проверь функцию как минимум на записях с `0`, `1` и `null`. Если хотя бы одна из двух последних позволяет пройти дальше, цикл сможет объявить прогресс без доказанного успеха.

> 🎒 **На пальцах.** Представь эстафету: следующий бегун стартует только после официально зафиксированной передачи палочки. Судья записал передачу — можно бежать. Записал нарушение — нельзя. Потерял момент из виду — тоже нельзя, даже если команда уверяет, что всё произошло. Отсутствующая отметка не становится разрешением только потому, что хочется продолжить.
