Возьми сигнатуру из задания и собери цикл инференса без подсказок из правильного ответа. Сначала encoder должен получить `src` и вернуть начальное состояние decoder. Затем создай по одному `bos_id` для каждой строки батча: форма `input_token` — `(batch_size, 1)`. Рядом понадобится булева маска `finished` той же формы — сначала в ней везде `False`.

На каждой итерации передавай текущий токен и `hidden` в decoder. Из его логитов выбери `argmax` по измерению словаря — это и будет `next_token`, знакомый по [шагу 28](#step-28). Сохраняй новое состояние: следующий вызов decoder должен продолжать ту же последовательность, а не начинать её заново.

Особенно внимательно расставь операции после получения токена. Сначала отметь строки, где появился `eos_id`. Потом проверь, завершился ли весь батч. Только после этого добавляй результат в список, заменив токены уже завершённых строк на `pad_id`. Благодаря такому порядку сам `<EOS>` не попадёт в возвращаемые последовательности.

Следующим входом становится предсказанный токен, а цикл ограничивается `max_len`, чтобы генерация не могла идти бесконечно. Оберни функцию в `@torch.no_grad()`: при инференсе граф для обратного распространения не нужен. В конце склей накопленные столбцы по измерению времени. Учти и случай, когда список пуст: результат всё равно должен иметь две оси и форму `(batch_size, 0)`.

> 🎒 **На пальцах.** Представь несколько чековых принтеров, запущенных одновременно. Каждый печатает позиции, пока не встретит команду «ИТОГО». Эту команду в список покупок не включают, а закончившийся принтер дальше выдаёт только пустые строки, пока допечатывают остальные. Когда «ИТОГО» получили все принтеры, продолжать цикл больше незачем.
