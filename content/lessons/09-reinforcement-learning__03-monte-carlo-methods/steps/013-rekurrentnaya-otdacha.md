В эпизоде с наградами `[0, 2, 0, 1]` тебе нужны четыре отдачи — по одной для каждого момента. Можно каждый раз заново просматривать весь оставшийся хвост: сначала четыре награды, затем три, две и одну. Для короткой траектории это терпимо. Но при длине \(T\) получится примерно \(T+(T-1)+\dots+1\) операций — работа растёт как \(O(T^2)\).

Здесь помогает наблюдение из [шага 12](#step-12): соседние отдачи почти одинаковы. Отдача в текущий момент состоит из ближайшей награды и уже подсчитанной отдачи следующего момента:

$$G_t=r_{t+1}+\gamma G_{t+1}$$

Здесь \(G_t\) — отдача с момента \(t\), \(r_{t+1}\) — следующая полученная награда, \(\gamma\) — коэффициент дисконтирования, а \(G_{t+1}\) — отдача, которую мы только что вычислили для следующего момента.

Поэтому двигаться удобно с конца. При \(\gamma=0{,}5\) для `[0, 2, 0, 1]` ты последовательно получишь: \(1\), затем \(0{,}5\), затем \(2{,}25\), затем \(1{,}125\). Результаты возникли в обратном порядке, поэтому перед использованием их нужно расположить обратно: `[1.125, 2.25, 0.5, 1]`.

Каждая награда обрабатывается ровно один раз. Значит, все отдачи для траектории длины \(T\) вычисляются за \(O(T)\), без повторного пересчёта одних и тех же хвостов.

> 🎒 **На пальцах.** Представь стопку коробок, на каждой написан её собственный вес. Тебе нужен вес стопки начиная с каждой коробки. Если каждый раз заново взвешивать весь остаток, работа повторяется. Проще идти снизу вверх: берёшь вес текущей коробки и прибавляешь уже известный вес всего, что под ней. Один подъём по стопке — и готовы все ответы.
