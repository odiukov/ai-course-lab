Возьми один вектор из residual stream — скажем, после десятого блока, длиной 512 чисел. Посмотри на них: где-то −0.3, где-то 47, где-то 120. Каждый блок что-то подсыпал в сумму из [шага 5](#step-5), и разброс уехал. Именно с этим ты боролся в [шаге 7](#step-7). Теперь надо написать функцию, которая приводит такой вектор в порядок.

Твоя `layer_norm` получает тензор формы `(batch, seq, d_model)` и возвращает тензор ровно такой же формы. Внутри — две операции:

$$\hat{x}_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \varepsilon}}, \qquad y_i = \gamma_i \hat{x}_i + \beta_i$$

Здесь $x_i$ — одно число из вектора, $\mu$ — среднее всех его чисел, $\sigma^2$ — их дисперсия (насколько сильно они разбегаются от среднего), $\varepsilon$ — крошечная добавка вроде `1e-5`, чтобы не делить на ноль, если все числа совпали. А $\gamma$ и $\beta$ — два обучаемых вектора длиной `d_model`: масштаб и сдвиг, которые модель подкручивает сама.

Главная развилка — по какой оси считать $\mu$ и $\sigma$.

Считай **только по последней** — по 512 признакам одной позиции. Каждый токен нормализуется сам по себе, независимо от соседей по батчу и по последовательности. Если случайно усреднишь по батчу, соседние примеры начнут влиять друг на друга, и на инференсе с батчем в один пример всё развалится.

Дальше — мелочи, на которых спотыкаются: при вычислении среднего оставляй размерность (`keepdim=True`), иначе вычитание не сойдётся по формам; $\varepsilon$ прибавляй **внутри** корня, а не после; инициализируй $\gamma$ единицами, а $\beta$ нулями — на старте слой ничего не портит.

Проверь себя так: подай вектор `[1, 2, 3, 4]`, посчитай среднее и стандартное отклонение результата. Если вышло 0 и почти 1 — функция работает.

> 🎒 **На пальцах.** Склеиваешь панораму из четырёх снимков: один пересвечен, другой в тени. Прежде чем сшивать, каждый кадр выравнивают по яркости — отдельно, по его собственной гистограмме, не подглядывая в соседний. Это $\mu$ и $\sigma$ по последней оси. А $\gamma$ и $\beta$ — два ползунка «контраст» и «яркость» поверх: модель сама решит, если ей нужен кадр потемнее.
