Ты передаёшь функции признаки трёх изображений, у каждого — по два числа. На выходе появляется таблица два на два. Но что именно должно попасть в каждую ячейку?

Возьми средний вектор, который ты уже научился вычислять в [шаге 6](#step-6). Для каждого изображения найди отклонение каждого признака от соответствующего среднего. Затем перебери все пары признаков: умножай их отклонения у одного изображения, складывай результаты по всей выборке и в конце дели каждую сумму на `N - 1`, где `N` — число изображений. Это программная запись правила из [шага 7](#step-7).

Начни с такого каркаса:

```python
def covariance_matrix(features, mean):
    n = len(features)
    dimensions = len(mean)

    covariance = [
        [0.0] * dimensions
        for _ in range(dimensions)
    ]
```

Строка и столбец матрицы соответствуют признакам. Поэтому при двух признаках результат должен иметь две строки и два столбца, даже если изображений гораздо больше. Ячейки на диагонали показывают разброс отдельного признака, остальные — как два признака меняются вместе.

Проверь две детали: матрица должна получиться симметричной, а для выборки из одного изображения вычисление невозможно — делить придётся на ноль. Если эти проверки проходят, функция действительно собрала форму облака, а не просто ещё один список средних.

> 🎒 **На пальцах.** Представь журнал парка аттракционов: каждый день записаны температура, число посетителей и продажи воды. Ты сравниваешь каждый день со средним, а затем заполняешь таблицу связей между всеми парами показателей. Связь температуры с продажами воды попадёт в две зеркальные ячейки, поэтому итоговая таблица симметрична.
