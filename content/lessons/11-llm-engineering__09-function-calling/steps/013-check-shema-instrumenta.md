type: check
title: 'Проверка: что модель прочитает в схеме'
source_anchor: '### Tool Definitions: The JSON Schema Contract'
check:
  - question: >-
      В схеме get_weather у поля units стоит enum со значениями celsius и
      fahrenheit. Пользователь просит температуру в кельвинах. Что произойдёт?
    options:
      - >-
        Модель добавит третье значение kelvin, потому что пользователь его
        попросил
      - >-
        Модель выберет одно из двух разрешённых значений — третьего варианта в
        схеме для неё нет
      - >-
        Модель откажется вызывать инструмент вообще, потому что запрос не совпал
        со схемой
      - 'Модель оставит units пустым и код сам решит, что подставить'
    correct: 1
    explanation: >-
      enum перечисляет допустимые значения аргумента, и выбор ограничен этим
      списком: кельвинов в нём нет, поэтому вызов уйдёт с celsius или
      fahrenheit.
  - question: >-
      Ты переписал description инструмента с «gets weather» на «Get current
      weather for a city. Returns temperature in Celsius and conditions.». Что
      от этого улучшится?
    options:
      - Скорость выполнения самой функции в коде
      - >-
        Точность выбора: модель яснее понимает, когда именно этот инструмент
        подходит и что он вернёт
      - 'Модель начнёт сама вызывать API погоды, минуя код'
      - Аргумент city станет обязательным без указания required
    correct: 1
    explanation: >-
      description — это текст, по которому модель решает, брать инструмент или
      нет; конкретная формулировка уменьшает промахи в выборе.
---

После [шагов 10](#step-10)–[12](#step-12) ты должен уметь смотреть на схему не как на технический бланк, а глазами модели: читать `description` инструмента и его аргументов, видеть, какие значения разрешает `enum`, и понимать, что даёт `required`.

Спотыкаются обычно на двух вещах. Первая — думают, что схема нужна только для проверки данных, а модель «и так поймёт», о чём инструмент. Нет: кроме этих описаний, у неё ничего нет. Вторая — считают `enum` подсказкой, из которой можно выйти, если очень надо. Это не подсказка, а границы выбора.

Проверь оба места на вопросах ниже.
