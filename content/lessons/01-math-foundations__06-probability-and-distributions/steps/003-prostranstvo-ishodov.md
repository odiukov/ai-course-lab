title: Пространство исходов и событие

Модель выдаёт число вроде 0,91 — но число всегда прицеплено к чему-то. К чему именно? Прежде чем считать вероятности, надо договориться, о каких вариантах вообще идёт речь. Иначе «вероятность 0,91» — это как цена без товара.

Начинают со списка всех возможных результатов — его называют **пространством исходов** и обозначают буквой $S$. Для монетки $S$ = {орёл, решка}. Для одного броска кубика $S = \{1, 2, 3, 4, 5, 6\}$ — фигурные скобки просто значат «набор из этих шести вариантов». Важное требование: варианты в списке не пересекаются и покрывают всё, что может случиться. Один бросок не может дать одновременно 3 и 5, и не может не дать ничего.

**Событие** — это любой набор вариантов из этого списка, который тебе интересен. Не обязательно один. «Выпало 4» — событие из одного варианта. «Выпало больше четырёх» — событие из двух: {5, 6}. «Выпало хоть что-то» — событие из всех шести.

И вот теперь вероятность становится осмысленной: это число от 0 до 1, которое приписывается **событию**, а не воздуху. P(событие) = 0,91 читается как «этот набор вариантов сбудется в 91 случае из 100».

> 🎒 **На пальцах.** Меню в столовой: полный список блюд — это пространство исходов, каждое блюдо в нём одно, и обед ты берёшь только из него. «Что-нибудь с сыром» — не отдельное блюдо, а обведённая карандашом группа строк меню. Вот это обведённое и есть событие. Спрашивать «а какова вероятность чего-то, чего в меню нет?» бессмысленно — сначала меню, потом обводка, потом числа.
