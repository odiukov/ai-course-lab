Ты добавил слой — сеть заработала, но ручной подсчёт параметров сразу устарел. Хочется задать модели простой вопрос: «Сколько настраиваемых чисел ты сейчас хранишь?» Этим и займётся метод `count_parameters`.

Метод должен пройти по `self.layers` и собрать общий счётчик. В каждом слое учитывай две группы:

- все элементы матрицы весов;
- все элементы вектора смещений.

Для массива NumPy количество элементов хранится в `.size`. Не путай его с `.shape`: форма описывает размеры массива, а не даёт готовое количество чисел. Активации и промежуточные выходы считать не нужно — они появляются во время прямого прохода и не являются параметрами.

Заполни пропуск:

```python
def count_parameters(self):
    total = 0

    for layer in self.layers:
        # Прибавь количество весов и смещений этого слоя.
        ...

    return total
```

Используй названия полей весов и смещений, принятые в твоём классе слоя. Логику подсчёта одного слоя ты разбирал в [шаге 44](#step-44), а сеть `2-3-1` даёт удобную проверку: метод должен вернуть `13`, как в [шаге 7](#step-7).

Обрати внимание: результат зависит только от архитектуры сети. Переданные данные и прямой проход не должны его менять.

> 🎒 **На пальцах.** Представь несколько чемоданов. В каждом есть большое отделение с одеждой и маленький карман с мелочами. Тебе нужно узнать общее число вещей: ты обходишь чемоданы, считаешь содержимое обоих отделений и прибавляешь к общей сумме. Весы — большое отделение слоя, смещения — маленький карман. Пропустить карман легко, но тогда итог окажется заниженным.
