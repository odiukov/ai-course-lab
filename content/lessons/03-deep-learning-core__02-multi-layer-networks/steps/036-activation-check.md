check:
  - question: >-
      Ты сравниваешь две многослойные сети: в первой между слоями нет функций
      активации, а во второй между слоями применяется сигмоида. Какая сеть
      способна строить нелинейную границу решения?
    options:
      - >-
        Первая, потому что последовательность нескольких слоёв сама создаёт
        нелинейность
      - 'Вторая, потому что сигмоида вносит нелинейное преобразование'
      - 'Обе, если сделать веса достаточно большими'
      - 'Обе, потому что любое умножение на веса изгибает границу'
    correct: 1
    explanation: >-
      Последовательность аффинных преобразований без активаций сводится к одному
      аффинному преобразованию. Нелинейная сигмоида между слоями препятствует
      такому сведению и позволяет сети строить нелинейную границу решения.
---

Представь две сети с одинаковым числом слоёв. В одной между слоями нет активации, а в другой есть сигмоида. Количество вычислений выросло в обеих, но только вторая получила новый способ преобразовывать пространство.

Здесь легко спутать причину с внешними признаками: ни дополнительные веса, ни большие числа, ни сами по себе новые слои не изгибают границу. Как показал [шаг 35](#step-35), без нелинейности вся цепочка остаётся одним линейным преобразованием. Проверь, можешь ли ты связать изгиб именно с активацией между слоями.
