title: Выход каждого слоя нужно передать следующему без изменений порядка

Скрытый слой выдал три числа: например, \(0{,}2\), \(0{,}8\) и \(0{,}1\). Может показаться удобным сначала отсортировать их или передать по одному. Но тогда следующий слой получит уже не тот вход, под который настроены его веса.

Позиция каждого числа имеет значение. Первый вес следующего нейрона относится именно к первому выходу предыдущего слоя, второй — ко второму, третий — к третьему. Совпадения размеров из [шага 16](#step-16) недостаточно: три числа действительно поместятся во вход из трёх чисел, но перестановка незаметно изменит смысл вычисления.

Поэтому сеть обрабатывает один текущий набор данных. Сначала им служит исходный вход. Первый слой преобразует его, и весь получившийся набор становится текущим. Следующий слой получает этот набор ровно в том порядке, в котором тот был создан, а затем заменяет его своим выходом. Так продолжается по упорядоченному списку слоёв из [шага 23](#step-23).

«Передать без изменений» здесь не означает сохранить сами числа навсегда: следующий слой как раз вычислит из них новые. Неизменной остаётся передача между слоями — ничего не сортируется, не пропускается и не добавляется. После последнего слоя текущий набор и есть ответ сети.

> 🎒 **На пальцах.** Представь стопку из трёх театральных команд: «свет», «занавес», «звук». Следующий сотрудник знает, что первая карточка управляет светом, вторая — занавесом, третья — звуком. Он может выполнить команды и подготовить новую стопку, но если по дороге переставить карточки, всё сработает не там. В сети числа передаются так же: содержание меняется на каждом этапе, порядок при передаче — нет.
