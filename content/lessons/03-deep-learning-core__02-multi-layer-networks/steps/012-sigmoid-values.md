  - question: Что можно сказать о результатах sigmoid для −2 и 2?
    options:

      - Один из них отрицательный

      - Оба результата больше 0.5
    correct: 2
    explanation: >-
      Получаются примерно 0.12 и 0.88: эти значения находятся по разные стороны

Проверь, умеешь ли ты читать результат функции из [шага 11](#step-11), а не принимать вход за готовый ответ. Частая ловушка — ожидать отрицательное значение для −2. Но сигмоида из [шага 9](#step-9) всегда оставляет результат между 0 и 1.

> 🎒 **На пальцах.** Представь весы с отметкой 0.5 посередине. Число −2 наклоняет чашу к ответу «нет» и даёт около 0.12, а 2 настолько же наклоняет её к «да» и даёт около 0.88. При нуле весы стоят ровно: получается 0.5.
