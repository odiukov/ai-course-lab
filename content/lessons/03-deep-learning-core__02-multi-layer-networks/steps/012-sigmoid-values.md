    options:

      - Сигмоида является возрастающей функцией
      - Сигмоида округляет отрицательные входы вниз

    explanation: >-
      Сигмоида монотонно возрастает, поэтому −2 < 0 < 2 приводит к sigmoid(−2) <

  - question: Как точнее всего описать связь между результатами sigmoid для −2 и 2?
    options:

      - Они находятся по одну сторону от середины диапазона
      - Положительный результат по модулю вдвое больше отрицательного
      - При смене знака входа выход тоже меняет знак
    correct: 0
    explanation: >-
      Для противоположных входов значения сигмоиды симметричны относительно 0.5:
      примерно 0.12 и 0.88. Поэтому их отклонения от 0.5 равны по модулю и

Проверь, умеешь ли ты читать результат функции из [шага 11](#step-11), а не принимать вход за готовый ответ. Частая ловушка — ожидать отрицательное значение для −2. Но сигмоида из [шага 9](#step-9) всегда оставляет результат между 0 и 1.

> 🎒 **На пальцах.** Представь весы с отметкой 0.5 посередине. Число −2 наклоняет чашу к ответу «нет» и даёт около 0.12, а 2 настолько же наклоняет её к «да» и даёт около 0.88. При нуле весы стоят ровно: получается 0.5.
