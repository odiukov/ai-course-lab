Ты передаёшь функции архитектуру `[2, 8, 1]`. Но одних чисел недостаточно для прямого прохода: каждому соединению нужно начальное значение, а каждому нейрону — смещение. Именно эти данные должна собрать `init_network`.

```python
def init_network(layer_sizes, seed=42):
    # Создай и верни список слоёв
    ...
```

Пройди по соседним размерам в `layer_sizes`. Пара `2, 8` описывает первый слой: он получает два числа и содержит восемь нейронов. Значит, ему нужны восемь строк весов по два числа и восемь смещений. Следующая пара `8, 1` создаёт слой с одной строкой из восьми весов и одним смещением. Ориентацию матрицы можно сверить с [шагом 16](#step-16).

Заполни веса небольшими случайными числами, а смещения — нулями. Параметр `seed` должен обеспечивать воспроизводимость: два вызова с одинаковой архитектурой и одинаковым `seed` создают одинаковую сеть. Удобнее завести отдельный генератор `random.Random(seed)`, чтобы функция не меняла случайность во всей программе.

Верни слои в том же формате и порядке, которые принимает `network_forward` из [шага 25](#step-25). Проверь не отдельные значения весов, а структуру результата: для `[2, 8, 1]` должны появиться ровно два слоя с формами `(8, 2)` и `(1, 8)`.

> 🎒 **На пальцах.** Представь начало настольной игры. Список `[2, 8, 1]` задаёт раскладку стола: сколько мест и карт должно быть на каждом этапе. `init_network` действительно раскладывает карты по этим местам. Случайные веса похожи на перетасованную колоду, а `seed` — на записанный порядок тасовки: повторишь его и получишь ту же стартовую позицию.
