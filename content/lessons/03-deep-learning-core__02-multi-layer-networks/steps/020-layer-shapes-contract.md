Ты готовишь для сети 2–3–1 вход из двух чисел, но случайно добавляешь третье: например, вместе с возрастом и доходом передаёшь ещё номер строки. Все значения сами по себе допустимы. Ошибка прячется не в числах, а в их количестве — и искать её после длинной цепочки вычислений было бы неудобно.

Здесь помогает описание форм слоя. Оно работает как договор: сколько чисел слой принимает, сколько нейронов содержит и сколько чисел обязан вернуть. Из [шага 16](#step-16) у первого слоя есть матрица весов формы `(3, 2)`: три строки для трёх нейронов и два столбца для двух входов. Значит, вход должен иметь форму `(2,)`. Если у него форма `(3,)`, несовместимость видна сразу: слой ждёт два числа, а получает три. Значения даже не нужно подставлять.

Так же проверяется вся цепочка. Первый слой обещает результат формы `(3,)`, поэтому второй слой с весами формы `(1, 3)` может его принять. Его результат имеет форму `(1,)`. Смещения тоже участвуют в договоре: первому слою нужно три смещения, второму — одно.

Описание форм не доказывает, что сеть даст правильный ответ. Зато оно отделяет ошибку устройства от ошибки в данных или обучении. Если размеры не стыкуются, к вычислению переходить ещё рано.

> 🎒 **На пальцах.** Представь пункт проката, где на каждой полке заранее подписано число ячеек. На первой полке три ряда по две ячейки: в каждый ряд нужно положить ровно два предмета. Ты приносишь набор из трёх — и сотрудник замечает несоответствие по этикетке, не открывая упаковку. Форма слоя — такая этикетка: она ловит неподходящий набор ещё до обработки.
