  - question: >-
      Скрытый слой получает 2 числа и содержит 3 нейрона. Какие формы подходят
      его весам и смещениям?
    options:
      - 'Веса: 3 строки на 2 столбца; смещения: 3 числа'
      - 'Веса: 2 строки на 3 столбца; смещения: 3 числа'
      - 'Веса: 3 строки на 2 столбца; смещения: 2 числа'
    correct: 0
    explanation: >-
      Каждому из трёх нейронов нужна строка из двух весов и одно собственное
      смещение.
  - question: >-
      Выходной слой получает 3 числа от скрытого слоя и содержит 1 нейрон. Какие
      формы состыкуются?
    options:
      - 'Веса: 3 строки на 1 столбец; смещение: 1 число; результат: 3 числа'
      - 'Веса: 1 строка на 3 столбца; смещение: 3 числа; результат: 1 число'
      - 'Веса: 1 строка на 3 столбца; смещение: 1 число; результат: 1 число'
    correct: 2
    explanation: >-
      Единственный выходной нейрон получает три входа, поэтому ему нужны три
      веса, одно смещение и он выдаёт одно число.
---

Здесь тебе нужно уверенно пройти маршрут сети: 2 входных числа превращаются в 3 скрытых, а затем в 1 выходное. Используй правило из [шага 16](#step-16): строки весов отвечают текущим нейронам, столбцы — значениям с предыдущего слоя. Чаще всего спотыкаются, когда меняют эти числа местами или дают смещению размер предыдущего слоя.

> 🎒 **На пальцах.** Представь стол с тремя поварами. Перед каждым лежат два ингредиента, поэтому в журнале три строки по две ячейки. Затем один шеф пробует три готовых блюда: у него одна строка с тремя ячейками. Число строк показывает, кто сейчас работает, а число столбцов — сколько результатов он получает.
