У тебя уже есть все детали: параметры XOR из [шага 31](#step-31), `layer_forward` из [шага 19](#step-19) и `network_forward` из [шага 25](#step-25). Осталось собрать их в одну функцию, чтобы не настраивать сеть заново для каждого из четырёх входов.

Напиши `xor_forward`, которая принимает список `inputs` из двух чисел. Внутри задай два слоя сети 2-2-1: скрытый с двумя нейронами и выходной с одним. Используй именно подобранные веса и смещения из [шага 31](#step-31), сохраняя порядок нейронов: сначала приближение OR, затем приближение NAND. Если поменять строки весов местами, но оставить смещения на прежних местах, параметры перемешаются и сеть даст другой результат.

Передай описание обоих слоёв вместе с `inputs` в `network_forward`. Функция должна вернуть мягкий выход сети — число сигмоиды от 0 до 1. Не применяй здесь порог и не возвращай готовую метку: превращением мягкого ответа в `0` или `1` уже занимается `predict_binary` из [шага 29](#step-29).

Проверь ещё две детали: слои должны идти в порядке «скрытый, выходной», а наружу нужно вернуть результат полного прохода, не промежуточные значения скрытого слоя. Теперь один вызов запускает весь маршрут XOR от двух входов до одного мягкого ответа.

> 🎒 **На пальцах.** Представь двухэтапную эстафету. На первом этапе два бегуна получают одну и ту же пару сигналов, но обрабатывают её по-разному. Их результаты становятся двумя эстафетными палочками для последнего бегуна. `xor_forward` расставляет участников по местам и запускает забег; она возвращает время на финише, а не решение судьи «победа» или «поражение».
