Ты передаёшь функции слой с матрицей весов формы `(3, 2)` и смещением формы `(3,)`. Числа выглядят знакомо, но функции нельзя просто вернуть заготовленный ответ «2 входа и 3 нейрона»: следующий слой может иметь совсем другие размеры.

Твоя задача — написать `layer_shapes`, которая читает форму полученных массивов и описывает устройство слоя. Ориентируйся на правило из [шага 16](#step-16): первая размерность матрицы весов показывает количество нейронов, а вторая — количество входов для каждого нейрона. Размер смещения должен соответствовать количеству нейронов.

Посмотри на атрибут `.shape`. Из него нужно извлечь нужные числа и сформировать результат в том виде, который указан в заготовке функции. Не привязывай решение к сети 2-3-1: для весов формы `(5, 4)` та же функция должна распознать четыре входа и пять нейронов.

Здесь легко перепутать строки и столбцы. Полезная самопроверка: спроси себя, сколько отдельных результатов должен выдать слой. Именно столько строк у матрицы весов и столько элементов ожидается в смещении.

`layer_shapes` ничего не умножает и не запускает прямой проход. Она только читает размеры — но благодаря этому несовместимость можно заметить ещё до вычислений.

> 🎒 **На пальцах.** Представь контролёра перед кинозалом. Он не смотрит фильм и не рассаживает зрителей, а сверяет план: сколько рядов и сколько мест в каждом ряду. Ряды похожи на нейроны, места в ряду — на входы. Если для трёх рядов подготовили только две таблички с номерами, контролёр сразу замечает несоответствие.
