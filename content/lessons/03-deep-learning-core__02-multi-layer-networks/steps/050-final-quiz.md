  - question: >-
      Слой получает два числа и содержит три нейрона. Какие формы позволят
      выполнить прямой проход?
    options:
      - 'Матрица весов: 3 строки на 2 столбца; смещения: 3 числа; выход: 3 числа'
      - 'Матрица весов: 2 строки на 3 столбца; смещения: 2 числа; выход: 3 числа'
      - 'Матрица весов: 3 строки на 3 столбца; смещения: 2 числа; выход: 2 числа'
    correct: 0
    explanation: >-
      Каждому из трёх нейронов нужны два входных веса и одно смещение. Поэтому
      матрица весов имеет форму 3 × 2, а выход и вектор смещений содержат по три
      числа.
  - question: Какой порядок действий описывает прямой проход многослойной сети?
    options:
      - >-
        Сначала изменить веса, затем вычислить все смещения и только потом
        передать вход
      - >-
        На каждом слое вычислить взвешенные суммы со смещениями, применить
        активацию и передать результат следующему слою
      - >-
        Один раз применить активацию ко входу, а затем одновременно умножить его
        на матрицы всех слоёв
    correct: 1
    explanation: >-
      Прямой проход последовательно проталкивает данные через слои: каждый слой
      выполняет своё преобразование и передаёт выход следующему. Параметры при
      этом не изменяются.
  - question: >-
      Что позволяет многослойной сети представить XOR, хотя один линейный
      пороговый нейрон с этим не справляется?
    options:
      - Увеличение модулей весов без добавления скрытого слоя
      - Добавление нескольких линейных слоёв без функций активации
      - 'Скрытый слой с нелинейной активацией, формирующий промежуточные признаки'
      - Замена пары входов их средним значением
    correct: 2
    explanation: >-
      Нелинейные скрытые нейроны создают промежуточное представление, в котором
      выходной нейрон может объединить нужные области. Линейные слои без
      нелинейности схлопнулись бы в одно линейное преобразование.
  - question: >-
      Сколько обучаемых параметров содержит полносвязная сеть с архитектурой
      2-3-1, если у каждого нейрона есть отдельное смещение?
    options:
      - '9'
      - '10'
      - '12'
      - '13'
    correct: 3
    explanation: >-
      Переход 2 → 3 содержит 6 весов и 3 смещения, а переход 3 → 1 — 3 веса и 1
      смещение. Итого: 6 + 3 + 3 + 1 = 13.

Дальше тебе понадобится быстро проверять сеть ещё до запуска: состыкуются ли формы, куда движутся данные и какие числа обучение будет менять. Чаще всего ошибка прячется не в вычислении, а в перепутанной ориентации матрицы, пропущенной активации или смещениях, забытых при подсчёте параметров. Вспомни также XOR из [шага 30](#step-30): несколько слоёв полезны именно потому, что нелинейность не даёт им схлопнуться в один.

> 🎒 **На пальцах.** Представь эстафету с контрольными воротами. Каждый участник принимает палочку подходящей формы, преобразует её и передаёт дальше. Если размер не совпал, передача сорвётся; если убрать все повороты трассы, маршрут станет прямым и XOR останется недоступен. А число регулируемых ремешков и застёжек на палочках — это число параметров сети.
