title: Форма матрицы весов задаётся числом входов и нейронов
source_anchor: '### Matrix Dimensions'

Ты собираешь первый слой сети 2–3–1 и видишь два похожих варианта для матрицы весов: \(3 \times 2\) и \(2 \times 3\). Числа те же, но переставить их местами нельзя. Как выбрать правильный порядок?

Посмотри на один нейрон скрытого слоя. Он получает два входных числа, поэтому ему нужны два веса — по одному для каждого входа. Таких нейронов три, значит, нужно записать три набора по два веса. Получается матрица \(W_1\) формы \((3, 2)\): три строки для трёх нейронов и два столбца для двух входов.

Удобно читать форму так: **сколько нейронов считает слой, столько строк; сколько чисел входит в слой, столько столбцов**. Поэтому матрица весов всегда имеет форму

\[
(\text{число нейронов слоя},\ \text{число входов слоя})
\]

При вычислении из [шага 15](#step-15) вектор из двух входов состыкуется с двумя столбцами \(W_1\), а результатом станут три числа — по одному от каждой строки.

У выходного слоя другая ситуация: в него приходят уже три значения скрытого слоя, а нейрон там один. Поэтому \(W_2\) имеет форму \((1, 3)\). Если перепутать строки и столбцы, веса не совпадут с входами, и вычисление остановится с ошибкой размерностей.

> 🎒 **На пальцах.** Представь ведомость для трёх дегустаторов. Каждый оценивает два напитка, поэтому у тебя три строки — по одной на дегустатора — и два столбца — по одному на напиток. Если развернуть ведомость в форму \(2 \times 3\), получится уже другая задача: два дегустатора оценивают по три напитка. Числа те же, смысл — нет.
