Здесь легко принять две строки за два входа. Но по правилу из [шага 16](#step-16) входам соответствуют столбцы. В матрице формы (2, 3) каждая строка содержит три веса и ждёт три числа. Во входе их только два, поэтому третьему весу не находится пары и вычисление останавливается с ошибкой размерности.

Для трёх нейронов и двух входов нужна форма (3, 2): три строки создают три результата, два столбца принимают два числа.

> 🎒 **На пальцах.** Представь два бланка, и в каждом по три пустых поля. Ты принёс только два значения. Заполнить оба бланка не получится: в каждом останется пустым третье поле. Если же взять три бланка по два поля, твои два значения подойдут каждому, а на выходе получатся три заполненных бланка.
