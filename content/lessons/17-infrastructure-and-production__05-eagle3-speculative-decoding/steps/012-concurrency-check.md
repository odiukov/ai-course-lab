id: 012-concurrency-check
type: check
title: Почему одна alpha=0.5 может помочь при батче 1 и навредить при батче 256?
source_anchor: '### Why alpha is the only metric that matters'
check:
  - question: >-
      Почему увеличение decode-батча может превратить ускорение от speculative
      decoding в замедление при неизменной alpha?
    options:
      - Draft-модель неизбежно начинает предлагать менее точные токены
      - >-
        Target-only decode эффективнее делит чтение весов между
        последовательностями, а проверка черновиков начинает конкурировать с
        полезной работой
      - >-
        Target-модель загружает отдельную копию весов для каждой
        последовательности
    correct: 1
    explanation: >-
      При batch 1 у GPU может оставаться свободный ресурс для спекуляции. При
      batch 256 чтение весов target-модели уже амортизировано по большому числу
      последовательностей, поэтому проверка и повторные проходы добавляют
      заметную конкурирующую работу.
  - question: >-
      Почему одну и ту же alpha нельзя считать универсальным признаком
      выгодности speculative decoding?
    options:
      - >-
        Выгодность также зависит от загрузки GPU и стоимости дополнительной
        проверки при целевой одновременности
      - Alpha описывает только размер весов draft-модели
      - При увеличении батча значение alpha автоматически становится ошибочным
    correct: 0
    explanation: >-
      Alpha показывает долю принятых предложений, но не цену их получения и
      проверки. Поэтому alpha 0.5 может помочь при batch 1 и навредить при batch
      256, где GPU уже занят обработкой большого decode-батча.
---

Ты видишь одну и ту же alpha — 0.5 — и получаешь противоположные результаты. Здесь легко принять alpha за универсальный переключатель. Но из [шага 11](#step-11) следует: с ростом батча меняется цена дополнительной проверки. При batch 1 она может занять свободный ресурс GPU; при batch 256 карта уже загружена, поэтому та же проверка отнимает время у полезной работы.

> 🎒 **На пальцах.** В пустом автобусе курьерские коробки можно поставить на свободные сиденья почти без помех. В переполненном автобусе те же коробки загораживают проход и задерживают всех. Коробки не изменились — изменилась занятость транспорта.
