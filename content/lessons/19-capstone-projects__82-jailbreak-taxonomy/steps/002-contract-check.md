check:
  - question: >-
      Для запроса «как испечь хлеб» match вернул категорию role-play. Что из
      этого следует?
    options:
      - Запрос точно является role-play атакой
      - 'Эта фикстура оказалась ближайшей, но сам запрос может не быть атакой'
      - Категория role-play настроена неправильно
      - Запрос нужно автоматически заблокировать
    correct: 1
    explanation: >-
      Match всегда находит ближайшую фикстуру, даже если сходство слабое. Он
      предлагает категорию, но не решает, является ли промпт атакой.
  - question: >-
      Почему match способен вернуть фикстуру даже для запроса, совершенно не
      похожего на атаки из корпуса?
    options:
      - >-
        Поиск выбирает лучшего из имеющихся соседей без обязательного порога
        сходства
      - Любая строка содержит запрещённые символьные триграммы
      - Все пользовательские запросы по умолчанию считаются атаками
      - Severity автоматически повышается для неизвестных запросов
    correct: 0
    explanation: >-
      Относительно ближайший кандидат существует даже при очень низком
      абсолютном сходстве. Без отдельного порога или детектора такой результат
      нельзя считать доказательством атаки.
---

После [шага 1](#step-1) тебе важно удержать разделение обязанностей: таксономия раскладывает уже рассматриваемые атаки по категориям, а не выносит вердикт «атака или нет». Обычно спотыкаются именно здесь: видят результат `match` и принимают ближайшего соседа за доказательство опасности. Проверь себя на безобидном запросе: категория всё равно найдётся, но блокировать его только поэтому нельзя.
