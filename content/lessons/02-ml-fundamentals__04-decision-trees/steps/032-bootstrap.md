title: Bootstrap создаёт выборку того же размера с повторами

Возьми таблицу из пяти клиентов: Аня, Борис, Вера, Глеб и Даша. Для нового дерева нужно собрать другую обучающую выборку — но строк в ней по-прежнему должно быть пять. Ты случайно выбираешь клиента, записываешь его и сразу возвращаешь карточку обратно. Поэтому на следующем ходе может снова выпасть тот же человек.

Например, получится так: Борис, Даша, Борис, Аня, Даша. Это и есть **bootstrap-выборка**: случайный набор того же размера, составленный **с возвращением**. «С возвращением» означает, что после каждого выбора строка снова участвует в розыгрыше.

Здесь легко спутать две вещи. Пять мест в новой выборке не означают пять разных клиентов. Борис занял два места, Даша — ещё два, а Вера и Глеб не попали вовсе. Повторы — не ошибка и не лишние копии, которые нужно удалить. Именно они делают набор для каждого дерева немного другим.

После [шага 30](#step-30) ты знаешь, что дерево чувствительно к изменениям обучающих данных. Bootstrap намеренно создаёт такие изменения: одному дереву чаще показывают одни строки, другому — другие. При этом размер выборки не меняется, поэтому каждое дерево получает одинаковое число примеров для обучения. Так появляется разнообразие, необходимое для последующего голосования из [шага 31](#step-31).

> 🎒 **На пальцах.** Представь коробку с карточками участников розыгрыша. Ты вытаскиваешь карточку, переписываешь имя и кладёшь её обратно, пока не заполнишь пять строк протокола. Одно имя может встретиться несколько раз, другое — ни разу. Протокол всё равно содержит ровно пять записей: bootstrap сохраняет размер набора, но не состав уникальных участников.
