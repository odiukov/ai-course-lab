Возьми четыре квартиры: площади 30, 35, 70 и 75 м², цены — 100, 110, 400 и 420. Если разрешить дереву только одно разбиение, хороший порог отделит первые две квартиры от последних. Тогда листья будут предсказывать 105 и 410 — средние цены внутри своих групп.

Именно такое поведение должна собрать `build_regression_tree`. По устройству она похожа на классификационную `build_tree` из [шага 23](#step-23), но меняются две детали: качество разбиения оценивается через `variance_reduction` из [шага 49](#step-49), а значение листа равно среднему целевых значений, как в [шаге 47](#step-47).

В каждом вызове функции тебе нужно решить: остановиться или продолжить деление. Создай лист, если достигнута максимальная глубина, примеров осталось слишком мало, все целевые значения совпадают или подходящего разбиения нет. В листе сохрани среднее значение цели для текущей группы.

Если рост можно продолжить, перебери признаки и пороги между соседними различающимися значениями — этот принцип разобран в [шаге 16](#step-16). Для каждого кандидата раздели строки на две непустые группы и вычисли уменьшение дисперсии. Запомни вариант с наибольшим положительным результатом.

После выбора порога создай внутренний узел с признаком и порогом, а затем рекурсивно построй левое и правое поддеревья. Следи, чтобы глубина увеличивалась при каждом таком вызове. Если лучший результат равен нулю, дальнейшее ветвление ничего не улучшит: текущая группа должна стать листом.

> 🎒 **На пальцах.** Представь организатора мастерской, который рассаживает участников по столам согласно опыту. За каждым столом выбирают общий темп — средний для сидящих там людей. Организатор продолжает делить столы, пока группы действительно становятся ровнее; если новое рассаживание не уменьшает различия, он оставляет стол как есть. В коде стол — узел, рассаживание — разбиение, а общий темп — предсказание листа.
