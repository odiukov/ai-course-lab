Ты передаёшь функции метки родительского узла и двух дочерних, а в ответ ждёшь одно число: насколько удачным оказалось разбиение. Например, аргументы могут выглядеть так:

```python
parent_labels = [0, 0, 0, 1, 1]
left_labels = [0, 0]
right_labels = [0, 1, 1]
```

Напиши `information_gain(parent_labels, left_labels, right_labels, criterion="gini")`. Сначала выбери функцию измерения примеси: `gini_impurity` из [шага 7](#step-7), если `criterion` равен `"gini"`, иначе `entropy` из [шага 9](#step-9).

Затем посчитай размеры родителя и обоих потомков. Если хотя бы один дочерний узел пуст, верни `0.0`: такое «разбиение» ничего не разделило.

Для остальных случаев вычисли примесь родителя и примеси потомков. Результаты детей нельзя просто сложить или усреднить пополам: умножь примесь каждого узла на его долю от числа родительских примеров. После этого вычти полученную дочернюю примесь из родительской — именно это сравнение было разобрано в [шаге 11](#step-11).

Проверь направление вычитания. Хорошее разбиение должно давать положительный результат, а не отрицательный. Ещё убедись, что функция возвращает число, а исходные списки меток не изменяет.

> 🎒 **На пальцах.** Представь две корзины после сбора яблок. В маленькой лежат два идеальных яблока, а в большой — восемь вперемешку с испорченными. Оценивать корзины поровну нечестно: большая влияет на весь урожай сильнее. Поэтому ты учитываешь и качество каждой корзины, и количество яблок в ней, а затем сравниваешь результат с исходной общей корзиной.
