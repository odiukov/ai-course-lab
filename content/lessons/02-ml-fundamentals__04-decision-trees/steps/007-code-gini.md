Ты передаёшь функции метки классов, например `[0, 0, 1, 0, 1]`, и ждёшь одно число — степень их перемешанности. Но Python пока не знает, сколько раз встретилась каждая метка. Значит, сначала тебе понадобится словарь-счётчик: ключом будет метка, а значением — число её появлений.

Допиши функцию:

```python
def gini_impurity(labels):
    # твой код
```

Работай в три этапа. Сначала найди общее количество меток. Если список пуст, сразу верни `0.0`: в пустом узле нет смешанных классов, а делить на ноль нельзя.

Затем пройди по `labels` циклом и собери количества в словаре. Не рассчитывай только на метки `0` и `1`: функция должна одинаково работать со строками, числами и любым количеством классов. Например, для `["кот", "пёс", "кот"]` словарь должен содержать две метки с количествами `2` и `1`.

Наконец, преврати каждое количество в долю и используй вычисление Gini из [шага 6](#step-6). На этом этапе тебе нужны только значения словаря — сами названия классов уже не влияют на результат.

Проверь функцию на трёх случаях:

```python
gini_impurity([])              # 0.0
gini_impurity([1, 1, 1, 1])    # 0.0
gini_impurity([0, 1])          # 0.5
```

Если эти результаты совпали, функция правильно различает пустой, чистый и максимально смешанный узел из двух классов.

> 🎒 **На пальцах.** Представь урну с бюллетенями разных цветов. Сначала ты считаешь все бюллетени, затем записываешь, сколько среди них зелёных, жёлтых и синих. После этого названия цветов уже не важны — важны их доли. `gini_impurity` проделывает ровно такую инвентаризацию и сворачивает получившиеся доли в одно число.
