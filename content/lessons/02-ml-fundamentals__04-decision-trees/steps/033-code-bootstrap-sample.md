В таблице четыре строки, а генератор случайно выбрал индексы `2, 0, 2, 3`. Строка `2` попадёт в новую выборку дважды, строка `1` — ни разу. Это не ошибка: именно так работает bootstrap из [шага 32](#step-32).

Тебе нужно написать функцию `bootstrap_sample(X, y)`. Она должна создать выборку того же размера, что и исходная:

1. Узнать количество строк `n`.
2. Случайно выбрать `n` индексов от `0` до `n - 1`. Каждый новый выбор независим, поэтому один индекс может встретиться несколько раз.
3. По этим индексам собрать новые `X_boot` и `y_boot`.
4. Вернуть обе выборки.

Особенно следи за соответствием признаков и ответов. Если выбран индекс `2`, в `X_boot` должна попасть строка `X[2]`, а в `y_boot` — именно метка `y[2]`. Нельзя отдельно выбирать случайные строки для `X` и для `y`: тогда признаки одного объекта могут получить чужую метку.

Проверяй не конкретные случайные значения, а свойства результата: длины `X_boot` и `y_boot` равны `n`, каждая новая пара взята из одной исходной строки, а повторы разрешены. Если используешь `random.randint`, помни: обе его границы включаются, поэтому верхняя граница — `n - 1`.

> 🎒 **На пальцах.** Представь барабан с карточками участников. Ты вытаскиваешь карточку, записываешь имя и возвращаешь её обратно, а затем крутишь барабан снова. Поэтому один участник может появиться в списке несколько раз, а другой — не появиться вовсе. Важно каждый раз переписывать имя вместе с его результатом, не перемешивая две колонки независимо.
