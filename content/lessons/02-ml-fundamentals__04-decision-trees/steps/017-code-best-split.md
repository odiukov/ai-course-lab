Перед тобой таблица с двумя признаками: возрастом и суммой покупки. Для возраста нашлось четыре возможных порога, для суммы — ещё пять. Одного удачного разбиения недостаточно: тебе нужно проверить все девять кандидатов и запомнить победителя.

Напиши функцию `best_split`. Она должна перебрать признаки по очереди, а внутри каждого признака — пороги между соседними уникальными значениями, как в [шаге 16](#step-16). Для каждого кандидата раздели данные с помощью `split_dataset` из [шага 15](#step-15), затем передай метки двух получившихся групп в `information_gain` из [шага 12](#step-12).

Главная трудность здесь не в вычислении gain, а в аккуратном хранении лучшего результата. До начала перебора подготовь переменные для лучшего номера признака, порога и gain. После каждой проверки сравни новый gain с сохранённым. Если он больше — обнови все три значения одновременно. Иначе продолжай поиск.

Следи за двумя деталями. Повторяющиеся значения признака не должны порождать одинаковые пороги, а пустая левая или правая группа не может стать полезным разбиением. `information_gain` уже умеет безопасно обрабатывать пустую группу, но такой кандидат всё равно не должен победить содержательный вариант.

В конце функция должна вернуть достаточно информации, чтобы позже можно было повторить найденное разделение: номер признака, порог и достигнутый gain. Проверь себя на маленькой таблице вручную: победителем должна оказаться именно та пара «признак + порог», у которой gain максимален среди всех проверенных пар.

> 🎒 **На пальцах.** Представь конкурс ключей для одного замка. Ты по очереди пробуешь ключи из нескольких связок и записываешь, какой повернулся дальше остальных. Недостаточно запомнить только лучший результат: нужно сохранить и связку, и сам ключ. Здесь связка — признак, ключ — порог, а глубина поворота — information gain.
