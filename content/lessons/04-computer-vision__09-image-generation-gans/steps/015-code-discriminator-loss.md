Перед тобой два набора ответов discriminator: `real_logits` для настоящих изображений и `fake_logits` для созданных. Функция должна превратить их в одно число — ошибку, по которой будет обучаться discriminator.

Сначала назначь правильные ответы. Для каждого элемента из `real_logits` целевая метка равна `1`: discriminator должен признать изображение настоящим. Для каждого элемента из `fake_logits` метка равна `0`: подделка должна быть отвергнута. Здесь легко случайно поменять метки местами — тогда сеть станет уверенно учиться противоположному.

Обе части посчитай через написанную в [шаге 11](#step-11) функцию `bce_with_logits`. Не применяй `sigmoid` заранее: эта функция специально принимает исходные логиты и сама выполняет вычисление устойчиво, как обсуждалось в [шаге 10](#step-10).

Усредни ошибки настоящих примеров, отдельно усредни ошибки поддельных, затем сложи два результата — именно такую структуру потери мы разобрали в [шаге 14](#step-14). Обрати внимание: нужно сложение, а не выбор одной из частей. Иначе discriminator сможет улучшать ответы только на одной группе.

Проверь себя мысленно: большой положительный `real_logit` должен давать маленькую ошибку, как и большой отрицательный `fake_logit`. Если любой из них увеличивает потерю, проверь целевые метки.

> 🎒 **На пальцах.** Представь турникет с двумя пачками пропусков: действующие должны открыть проход, просроченные — оставить его закрытым. Ты отдельно считаешь ошибки на каждой пачке, а затем складываешь штрафы. Если проверить только действующие пропуска, турникет может научиться открываться всегда; если только просроченные — всегда оставаться закрытым. Нужны обе проверки одновременно.
