У тебя есть батч из 10 примеров и 3 виртуальные GPU. Если просто отрезать каждой по `10 // 3` элемента, один пример останется без работы. В [шаге 15](#step-15) ты уже разобрал правило честного разбиения; теперь преврати его в функцию `shard_batch`.

Функция получает батч и число GPU, а возвращает список шардов — по одному на каждую GPU. Для 10 примеров размеры должны получиться `[4, 3, 3]`: остаток раздаётся первым устройствам по одному элементу. При этом порядок примеров сохраняется.

Смотри не только на размеры. После объединения шардов должен восстановиться исходный батч: без пропусков, повторов и перестановок. Удобно двигать границу начала следующего среза после создания каждого шарда. Тогда один и тот же элемент не попадёт сразу двум GPU.

Проверь как минимум три случая:

- батч делится поровну;
- остаётся ненулевой остаток;
- GPU больше, чем примеров — часть шардов тогда будет пустой.

Не отбрасывай пустые шарды: число элементов в результате должно совпадать с числом GPU. Это сохраняет однозначное соответствие «индекс шарда → номер GPU».

> 🎒 **На пальцах.** Представь рулон из десяти пронумерованных билетов и три кассы. Ты отрезаешь кассам последовательные куски: четыре, три и три билета. После каждого разреза сдвигаешь руку к началу ещё не выданной части. Если развернуть выданные куски обратно по порядку, рулон должен собраться целиком — ни один билет не исчез и не оказался в двух кассах.
