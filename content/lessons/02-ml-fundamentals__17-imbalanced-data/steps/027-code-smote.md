Ты передаёшь функции четыре объекта редкого класса с двумя признаками и просишь создать шесть новых. На выходе должен появиться массив размером 6 на 2 — не изменённые исходные данные и не объединённая выборка, а только синтетические точки.

Напиши `smote(X_minority, k=5, n_synthetic=100, seed=42)`. Внутри создай генератор случайных чисел с указанным `seed`, чтобы повторный запуск с теми же аргументами давал тот же результат. Затем ограничь `k`: у точки не может быть больше соседей, чем остальных объектов редкого класса. Для работы нужны хотя бы две исходные точки.

На каждой итерации выбери случайный индекс `idx`, найди для него соседей функцией `k_nearest` из [шага 25](#step-25), а затем случайно возьми одного из найденных соседей. Сгенерируй число `t` от 0 до 1 и поставь новую точку на отрезке, как в [шаге 23](#step-23). Добавь её в список и повторяй, пока не получишь `n_synthetic` объектов.

В конце преврати список в NumPy-массив. Проверь три вещи: число строк равно `n_synthetic`, число столбцов совпадает с `X_minority`, а одинаковый `seed` воспроизводит одинаковые точки. Исходный массив функция менять не должна.

Обрати внимание: соседи ищутся заново для выбранной исходной точки, но среди уже созданных объектов искать нельзя. Иначе синтетические точки начнут порождать следующие поколения и незаметно изменят задуманный алгоритм.

> 🎒 **На пальцах.** Представь координатора фотосъёмки: на полу уже стоят несколько участников, а тебе нужно расставить ещё шестерых. Для каждого нового человека ты случайно выбираешь участника, находишь ближайших к нему, выбираешь одного соседа и ставишь новичка где-то между ними. Новички пока не становятся ориентирами — вся расстановка опирается только на исходную группу.
