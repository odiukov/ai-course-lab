Пройди по строкам `X`, кроме строки `idx`. Для каждой оставшейся точки вычисли евклидово расстояние до `X[idx]`, сохрани её индекс вместе с расстоянием, затем отсортируй результаты от меньшего расстояния к большему. Вернуть нужно только индексы первых `k` точек, а не расстояния и не сами координаты.

Проверь себя на маленьком примере:

```python
X = np.array([
    [0, 0],
    [3, 4],
    [1, 0],
    [0, 2],
])

print(k_nearest(X, idx=0, k=2))
# ожидается: [2, 3]
```

Точка `2` находится на расстоянии `1`, точка `3` — на расстоянии `2`, а далёкая точка `1` в ответ не попадает. Здесь `X` должен содержать только редкий класс, как обсуждалось в [шаге 24](#step-24). Пока считай, что `k` меньше количества точек: обработка полного процесса SMOTE будет дальше.
