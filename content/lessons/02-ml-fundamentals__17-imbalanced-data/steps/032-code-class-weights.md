Перед тобой метки шести примеров: четыре нуля и две единицы. Функция должна выдать не два числа «для классов», а шесть весов — по одному для каждой исходной строки. Поэтому результат для меток `[0, 0, 1, 0, 1, 0]` должен сохранить тот же порядок: вес нулевого класса, вес нулевого, вес единичного и так далее.

Сначала найди уникальные классы и посчитай, сколько раз встречается каждый. Здесь удобно получить обе величины одновременно через `np.unique` с подсчётом повторений. Затем для каждого класса вычисли сбалансированный вес по правилу из [шага 31](#step-31) и сохрани соответствие «метка → вес». Не полагайся на то, что метками обязательно будут `0` и `1`: функция должна так же работать, например, со строками `"обычный"` и `"редкий"`.

Последний проход — самый важный: замени каждую метку из `y` весом её класса. Возвращаемый массив должен иметь ту же длину и тот же порядок, что и `y`, иначе при обучении веса прикрепятся не к тем примерам.

Проверь себя на двух случаях. При одинаковом количестве объектов классов все веса должны стать равны `1`. При дисбалансе редкий класс должен получить больший вес, но исходные метки и строки данных при этом не добавляются и не удаляются.

> 🎒 **На пальцах.** Представь гардероб, где каждому посетителю выдают жетон с коэффициентом внимания. Сначала ты считаешь, сколько людей пришло из каждой группы, и записываешь коэффициент для группы. Но гардеробщику нужен жетон для каждого человека, а не короткая таблица групп. Поэтому ты проходишь по очереди ещё раз и выдаёшь каждому коэффициент его группы, не меняя порядок людей.
