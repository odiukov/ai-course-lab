Обрати внимание на три особых случая:

- если модель не предсказала ни одного положительного объекта, `precision` должен стать `0.0`;
- если в данных нет ни одного действительно положительного объекта, `recall` должен стать `0.0`;

Такие проверки делают функцию пригодной не только для удобных примеров, но и для крайних случаев.
