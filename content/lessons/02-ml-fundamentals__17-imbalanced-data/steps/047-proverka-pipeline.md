Здесь важно заметить не просто неверный порядок, а скрытую связь между частями данных. Если выполнить SMOTE до разделения, синтетический обучающий пример может быть создан с участием точки, которая позже окажется в validation или test. Оценка тогда выглядит лучше, потому что модель косвенно получила подсказку из будущей проверки. Честный порядок из [шага 45](#step-45): сначала разделение, затем SMOTE только на train.

> 🎒 **На пальцах.** Представь экзамен по рисунку: преподаватель сначала смешал экзаменационные работы с учебными и сделал по ним новые тренировочные образцы. Даже если потом работы разложить по разным папкам, подсказки из экзамена уже проникли в тренировку. Папки нужно разделить заранее, а новые образцы создавать только по учебной папке.
