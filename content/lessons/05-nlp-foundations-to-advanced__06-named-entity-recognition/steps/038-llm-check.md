Теперь тебе нужно различать три рычага, рассмотренные в [шагах 35](#step-35)–[37](#step-37). Zero-shot даёт отправную точку без размеченных примеров. RAG полезен, когда небольшой размеченный набор уже есть и из него можно подобрать похожие случаи. Проход по каждому типу решает другую проблему: потерю полноты, когда модель ищет слишком многое одновременно. Частая ловушка — считать RAG поиском любых сведений; здесь он достаёт именно примеры разметки.

> 🎒 **На пальцах.** Представь реставратора перед незнакомой вазой. Он может работать только по перечню дефектов — это zero-shot. Может открыть карточки похожих ваз — это RAG. А может осматривать вазу несколько раз, каждый раз выискивая только один дефект: сначала трещины, потом сколы, затем следы краски. Это проход по каждому типу.
