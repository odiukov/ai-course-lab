На каждом токене у тебя есть оценки для всех тегов. Но если просто брать самый высокий балл в каждом столбце, может получиться запрещённая BIO-цепочка. Твоя функция `constrained_decode` должна найти допустимую последовательность с максимальной суммой оценок.

Перебирать все комбинации не стоит: при десяти токенах и пяти тегах это уже почти десять миллионов вариантов. Вместо этого собирай путь слева направо. Для каждой позиции и каждого возможного текущего тега храни лучший суммарный балл допустимой цепочки, которая заканчивается этим тегом.

На первой позиции разреши только корректные начала: `O` и `B-*`. Недопустимым вариантам назначь значение `-inf` — тогда они никогда не победят. На следующих позициях перебирай предыдущие теги, отбрасывай запрещённые переходы по правилам из [шага 11](#step-11) и прибавляй локальную оценку текущего тега. Вместе с лучшим баллом запоминай, из какого предыдущего тега ты пришёл.

После последнего токена выбери тег с максимальным накопленным баллом и пройди по сохранённым указателям назад. Так ты восстановишь всю цепочку; не забудь развернуть её перед возвратом.

Обрати внимание на три края: пустой вход должен дать пустой список, `I-ORG` нельзя поставить в начало, а после `B-PER` нельзя продолжить `I-ORG`. Результат удобно дополнительно проверить функцией `is_valid_bio` из [шага 12](#step-12).

> 🎒 **На пальцах.** Представь поход по размеченным тропам. На каждом перекрёстке разные направления обещают разное число баллов, но часть переходов закрыта. Ты записываешь для каждой доступной точки лучший маршрут до неё и предыдущую остановку. У финиша выбираешь самый выгодный результат, а затем идёшь по записям назад — получаешь лучший маршрут, ни разу не свернув на запрещённую тропу.
