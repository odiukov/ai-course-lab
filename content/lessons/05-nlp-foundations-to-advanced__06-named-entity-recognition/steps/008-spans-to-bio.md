Возьми четыре токена:

```python
tokens = ["New", "York", "hosts", "OpenAI"]
spans = [(0, 2, "LOC"), (3, 4, "ORG")]
```

Твоя функция должна вернуть:

```python
["B-LOC", "I-LOC", "O", "B-ORG"]
```

Начни со списка меток `O`, длина которого равна числу токенов. Затем перебирай каждый span как тройку `start, end, label`. Границы работают как полуинтервал из [шага 7](#step-7): токен `start` входит в сущность, а токен `end` — уже нет.

Но не спеши записывать `B-` и `I-`. Сначала проверь весь диапазон от `start` до `end`: остались ли там только метки `O`? Например, spans `(0, 2, "LOC")` и `(1, 3, "ORG")` претендуют на токен с индексом `1`. BIO не может сохранить на нём сразу две метки, поэтому функция должна вызвать `ValueError`, а не молча затереть первую сущность.

Если пересечения нет, поставь `B-{label}` на позицию `start`. Всем следующим позициям до `end` присвой `I-{label}`. Для span длиной в один токен цикл продолжения просто не выполнится — останется только `B-`, что и требуется.

Проследи ещё за двумя деталями: проверка пересечения должна происходить до изменения меток, а `return` — после обработки всех spans. Иначе функция либо оставит наполовину записанную сущность, либо вернёт результат после первой найденной сущности.

> 🎒 **На пальцах.** Представь лист с клетками, который ты раскрашиваешь маркерами. Сначала все клетки белые — это `O`. Первый штрих получает отметку `B`, продолжение — `I`. Перед новым штрихом ты проводишь пальцем по всему его пути: если хоть одна клетка уже закрашена, останавливаешься. Закрасить поверх означало бы потерять прежнюю разметку.
