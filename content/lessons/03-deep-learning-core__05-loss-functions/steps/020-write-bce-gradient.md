На репетиции общий штраф BCE сообщает, насколько плохо выставлен весь свет, но не говорит, какую именно ручку повернуть. Для обучения нужен отдельный градиент для каждого предсказания. Функция `bce_gradient(predictions, targets, eps=1e-15)` должна вернуть список таких поправок.

Для каждой пары `p` и `t` возьми производную из [шага 19](#step-19). Перед вычислением ограничь вероятность тем же способом, что и в `binary_cross_entropy` из [шага 18](#step-18): значение должно попасть в диапазон от `eps` до `1 - eps`. В обоих знаменателях используй именно ограниченное значение, иначе крайние вероятности снова приведут к делению на ноль.

Обрати внимание на три детали:

- здесь не нужны логарифмы — после дифференцирования их в выражении уже нет;
- каждый вычисленный градиент добавляется в список в том же порядке, что и предсказания;
- делить значения на количество примеров не нужно: эта функция возвращает производные отдельных потерь. Для градиента среднего BCE потребовался бы дополнительный множитель `1 / n`.

Для самопроверки можно взять `predictions = [0.8, 0.2]` и `targets = [1, 0]`. Должны получиться значения около `[-1.25, 1.25]`. Отрицательное значение подталкивает первое предсказание вверх, а положительное — второе вниз. Так функция выдаёт каждой вероятности собственное направление исправления.

> 🎒 **На пальцах.** Представь два прожектора с отдельными ручками яркости. Режиссёр не ограничивается фразой «сцена освещена плохо»: первому технику он велит прибавить свет, второму — убавить. `bce_gradient` составляет такой список указаний. Clipping здесь похож на стопоры ручек: технику нельзя выкрутить регулятор в положение, где механизм перестанет работать.
