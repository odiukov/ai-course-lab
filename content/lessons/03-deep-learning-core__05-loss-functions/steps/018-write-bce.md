У тебя есть четыре прогноза: `[0.9, 0.2, 0.8, 0.1]` — и правильные ответы `[1, 0, 1, 0]`. Нужно превратить их в одно число: средний штраф для всей группы.

Напиши функцию `binary_cross_entropy(predictions, targets, eps=1e-15)`. Она должна пройти по парам «вероятность — ответ», вычислить для каждой пары BCE из [шага 16](#step-16), сложить потери и разделить сумму на количество примеров.

Но сначала обработай каждую вероятность с помощью clipping из [шага 17](#step-17): ограничь её диапазоном от `eps` до `1 - eps`. Для этого удобно вложить `min` внутрь `max`. В логарифмы должна попадать именно ограниченная вероятность, иначе значения `0` и `1` снова приведут к `log(0)`.

Используй `math.log`, то есть натуральный логарифм. Обрати внимание ещё на две детали: переменная общей потери начинается с `0.0`, а деление выполняется только после обработки всех пар.

Проверь функцию на уверенных правильных прогнозах: потеря должна получиться маленькой. Затем замени один прогноз на уверенно неправильный — среднее должно заметно вырасти. Наконец, передай вероятность `0.0`: результат обязан остаться конечным числом.

> 🎒 **На пальцах.** Представь контролёра, который проверяет стопку билетов и записывает штраф за каждый. Перед записью он заменяет невозможные крайние отметки — ровно 0 и ровно 1 — ближайшими допустимыми. Затем складывает штрафы и делит на число билетов. Так один испорченный крайний штамп не ломает весь отчёт.
