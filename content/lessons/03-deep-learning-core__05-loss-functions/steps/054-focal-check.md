title: 'Проверка: веса лёгкого и трудного примеров при gamma 2'
source_anchor: '### Focal Loss'
check:
  - question: >-
      Почему при gamma 2 трудный пример с p_t = 0,1 получает больший
      модулирующий множитель, чем лёгкий пример с p_t = 0,9?
    options:
      - >-
        В квадрат возводится 1 − p_t: у трудного примера эта величина близка к
        единице, а у лёгкого — к нулю
      - >-
        В квадрат возводится p_t, поэтому меньшая вероятность истинного класса
        даёт больший результат
      - Gamma меняет местами вероятности истинного и ошибочного классов
    correct: 0
    explanation: >-
      Множитель равен (1 − p_t)^2. Поэтому для лёгкого примера получается (1 −
      0,9)^2 = 0,01, а для трудного — (1 − 0,1)^2 = 0,81.
  - question: >-
      Какой вывод корректно сделать, сравнив модулирующие множители лёгкого и
      трудного примеров?
    options:
      - >-
        Сильнее отличается именно модулирующий множитель; для сравнения полных
        focal loss нужно также учесть логарифмический штраф и alpha
      - >-
        Отношение полных focal loss автоматически равно отношению модулирующих
        множителей
      - >-
        Модулирующий множитель трудного примера уже является его готовым
        значением loss
    correct: 0
    explanation: >-
      Числа 0,01 и 0,81 стоят перед логарифмическим штрафом. Полный loss равен
      -alpha · (1 − p_t)^gamma · log(p_t), поэтому даже при одинаковом alpha
      нужно учитывать, что значения log(p_t) у примеров различаются.
---

Проверь, можешь ли ты применить множитель из [шага 53](#step-53), не перепутав вероятность истинного класса с вероятностью ошибки. Главная ловушка здесь — принять вес за итоговый loss: он лишь усиливает или ослабляет логарифмический штраф. При одинаковом $\alpha$ трудный пример получает множитель в 81 раз больше лёгкого.

> 🎒 **На пальцах.** Представь редактора со стопкой текстов. Почти готовой статье он оставляет одну короткую пометку, а сырой черновик покрывает замечаниями почти целиком. Числа 0,01 и 0,81 показывают не итоговую оценку текста, а то, сколько внимания редактор добавляет каждому случаю.
