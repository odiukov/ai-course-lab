Проверь себя после [шага 33](#step-33): при десяти классах доля 0,1 распределяется между всеми классами, включая истинный. Поэтому его цель равна не 0,9, а 0,91: к сохранённым 0,9 добавляется 0,01. Девять остальных классов получают по 0,01, а сумма целей остаётся равной единице.

Частая ловушка — поделить 0,1 только между неверными классами. Это уже была бы другая схема сглаживания.

> 🎒 **На пальцах.** Представь десять стаканов. Сначала ты наливаешь 0,9 литра в стакан правильного класса. Затем ещё 0,1 литра поровну разливаешь по всем десяти стаканам. Первый получает дополнительную сотую и доходит до 0,91; в каждом из остальных остаётся по 0,01.
