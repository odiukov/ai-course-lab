Посмотри на две цели для задачи с десятью классами. В жёсткой цели вся единица лежит на правильном классе: у него 1, у остальных — 0. Модель получает недвусмысленную команду: «сюда всё, в другие классы ничего».

После сглаживания единица не исчезает и не становится меньше — она иначе распределяется. При $\alpha=0{,}1$ правильный класс получает 0,91, а каждый из девяти остальных — по 0,01. Сумма по-прежнему равна 1.

Здесь легко споткнуться: кажется, будто правильному классу оставили 0,9, а всю десятую часть раздали только конкурентам. Но в [шаге 33](#step-33) сглаживающая доля распределяется между **всеми** десятью классами. Поэтому правильный класс тоже получает из неё 0,01: к его 0,9 добавляется ещё 0,01. Именно так получается проверенное в [шаге 37](#step-37) значение 0,91, а конкурентам вместе достаётся 0,09.

Направление обучения при этом не меняется: правильный класс всё ещё должен быть намного вероятнее остальных. Меняется жёсткость требования. Вместо «добейся 100% против 0%» модель видит «сделай этот класс главным, но не выталкивай остальные в абсолютный ноль».

> 🎒 **На пальцах.** Представь 100 граммов глазури и десять пирожных. При жёсткой цели ты выливаешь всё на одно пирожное. При сглаженной сначала отдаёшь ему 90 граммов, а оставшиеся 10 делишь поровну между всеми десятью — включая его. В итоге главное пирожное получает 91 грамм, остальные по одному, а общее количество глазури остаётся прежним.
