Ты получил от `softmax` три вероятности и теперь должен превратить их в три поправки для логитов. Здесь легко сделать лишнее: например, вычесть `1` из каждого элемента. Но `target_index` указывает только на один истинный класс, поэтому особая поправка нужна только ему.

Напиши `cce_gradient(logits, target_index)` в три действия:

1. Передай `logits` в уже готовую функцию `softmax`.
2. Скопируй полученные вероятности в отдельный список градиентов.
3. Уменьши на `1.0` элемент с индексом `target_index` и верни список.

Именно так код реализует результат из [шага 29](#step-29): для неверных классов градиенты остаются равны их вероятностям, а для истинного класса из вероятности вычитается единица.

Обрати внимание на индексы: если `target_index` равен `0`, изменить нужно первый элемент, а не элемент со значением `0`. И не пересчитывай softmax вручную внутри новой функции — иначе одна и та же логика окажется продублирована в двух местах.

> 🎒 **На пальцах.** Представь ведомость с оценками трёх участников. Ты сначала переписываешь все оценки на новый лист без изменений. Затем судья показывает номер настоящего победителя, и только в его строке ты делаешь поправку `−1`. Номер строки — это `target_index`, исходные оценки — вероятности, а исправленный лист — готовый градиент.
