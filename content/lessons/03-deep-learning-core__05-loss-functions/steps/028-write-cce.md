Тебе передали логиты `[2, 1, 0]` и сказали, что правильный класс имеет индекс `0`. Нужен один итоговый штраф. Но логиты ещё не вероятности, поэтому брать логарифм прямо от числа `2` нельзя.

Допиши функцию `categorical_cross_entropy(logits, target_index, eps=1e-15)`. Она должна:

1. Передать `logits` в `softmax` из [шага 25](#step-25).
2. Взять из полученного списка только вероятность с индексом `target_index`.
3. Ограничить её снизу значением `eps`, чтобы не вычислять `log(0)`.
4. Вернуть отрицательный натуральный логарифм этой вероятности — именно такой штраф разобран в [шаге 27](#step-27).

`target_index` — это номер правильного класса, а не one-hot-список. Например, `target_index=2` означает, что истинным считается третий элемент.

Проверь функцию на логитах `[2, 1, 0]`: при правильном классе `0` результат должен быть примерно `0.408`. Затем укажи класс `2` — штраф станет заметно больше, потому что модель дала ему гораздо меньшую вероятность.

Обрати внимание: функция возвращает одно число, а не список потерь по всем классам. Сейчас тебе нужен только штраф; градиент появится на следующем шаге.

> 🎒 **На пальцах.** Представь конкурс с тремя участниками. После голосования у каждого есть доля голосов, но жюри заранее знает настоящего победителя. Ты находишь долю именно этого участника и превращаешь её в штраф: высокая доля даёт маленький штраф, низкая — большой. `eps` здесь как правило конкурса: даже нулевой результат записывают крошечным числом, чтобы расчёт не сломался.
