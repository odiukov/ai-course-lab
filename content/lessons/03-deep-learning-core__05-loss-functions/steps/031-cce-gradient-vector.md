На картинке лиса, но модель распределила уверенность так: 55% — «кот», 30% — «собака» и только 15% — «лиса». Одного общего сигнала «ответ неверный» здесь мало: нужно понять, какой из трёх логитов двигать и насколько.

Градиент из [шага 29](#step-29) даёт для этих классов значения `0,55`, `0,30` и `−0,85`. Важно не перепутать их с новыми вероятностями: это команды для изменения логитов. Оптимизатор вычитает градиент, поэтому положительные значения уменьшают логиты ошибочных классов, а отрицательное значение увеличивает логит истинного класса.

Если шаг обучения равен `0,1`, поправки составят `−0,055` для «кота», `−0,030` для «собаки» и `+0,085` для «лисы». Самый опасный соперник — «кот» — получает самое сильное понижение. «Собака», которой модель доверяла меньше, отступает слабее. А истинный класс получает особенно сильный толчок, потому что ему пока не хватает `1 − 0,15 = 0,85` уверенности.

После нового softmax вероятности пересчитаются вместе: столбик «лисы» вырастет, остальные уменьшатся. Градиент не просто сообщает об ошибке — он показывает, откуда забрать уверенность и куда её направить.

> 🎒 **На пальцах.** Представь три очереди к стойкам «кот», «собака» и «лиса». Люди по ошибке встали не туда. Сотрудник сильнее разворачивает самую длинную неверную очередь, слабее — короткую, а всех перенаправляет к правильной стойке «лиса». Градиент задаёт направление движения, а шаг обучения — насколько далеко очередь сдвинется за один раз.
