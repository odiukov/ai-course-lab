Перед тобой изменение на 37 файлов, зелёные проверки и пустое поле для комментария. С чего начать? Снова читать постановку, искать границы задачи, восстанавливать допущения исполнителя, сопоставлять тесты с результатом. Значительная часть внимания уходит не на решение, а на сбор исходной картины.

Готовый отчёт меняет точку старта. Ревьюер уже разложил работу по пяти измерениям рубрики из [шага 8](#step-8), выставил отдельные оценки и применил правило вердикта из [шага 12](#step-12). В структурированном отчёте из [шага 15](#step-15) рядом лежат утверждения, подтверждающие артефакты, найденные риски и уровень уверенности. Человеку не приходится сначала превращать разрозненные следы в вопросы: можно сразу разбирать уже сформулированные выводы.

Это не передача последнего слова агенту. Отчёт — подготовленная позиция, с которой можно спорить. Если вывод выглядит сомнительно, видно, на каком основании он сделан. Если сработал confidence floor из [шага 17](#step-17), неопределённость не спрятана за уверенным `pass`, а вынесена человеку явно. Даже несогласие становится предметным: не «мне что-то не нравится», а «этот вывод не следует из указанного свидетельства».

Пустая страница заставляет человека сначала быть исследователем, секретарём и только потом судьёй. Готовый отчёт оставляет ему самую ценную работу — принять осмысленное решение.

> 🎒 **На пальцах.** Представь редактора, которому принесли рукопись на 200 страниц. Без записки он сначала сам ищет героев, сюжетные провалы и спорные места. С редакторским мемо перед ним уже есть список находок с номерами страниц и степенью уверенности. Он может не согласиться с каждой пометкой, но начинает не с поисков по всей книге, а с проверки ясных тезисов.
