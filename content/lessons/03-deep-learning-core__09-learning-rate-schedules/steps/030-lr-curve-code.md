У тебя уже есть функции расписаний из [шагов 6](#step-6), [9](#step-9), [13](#step-13), [18](#step-18), [21](#step-21) и [25](#step-25). Но отдельные числа не показывают форму изменения: по значениям на шагах 0 и 499 легко пропустить пик или резкий спад между ними. Теперь собери из этих чисел текстовую кривую.

Функция `lr_curve` должна принять название расписания, саму функцию расписания, общее число шагов и её дополнительные параметры. Выбери примерно 20 равномерно распределённых шагов, начиная с нулевого. Последний шаг `total_steps - 1` добавь отдельно, если он не попал в выборку: конец обучения особенно важен.

Для каждого выбранного шага вызови расписание и сохрани learning rate. Затем найди максимальное значение среди полученных результатов. Оно станет масштабом: максимум получает полоску из 40 решёток, половина максимума — примерно 20. Длину каждой полоски округляй вниз до целого числа.

Напечатай название, а затем для каждого шага — его номер, learning rate с шестью знаками после запятой и полоску. Учти случай, когда все значения равны нулю: делить на ноль нельзя, поэтому используй безопасный масштаб `1.0`.

Обрати внимание: дополнительные параметры нужно передать расписанию без изменений через `**kwargs`.

> 🎒 **На пальцах.** Представь монтажёра, который выбирает из длинного фильма около двадцати кадров и раскладывает их на столе. Один кадр не расскажет, как развивалась сцена, а последовательность уже покажет ускорение и затухание. Решётки работают так же: превращают разрозненные значения learning rate в быстро читаемую ленту изменений.
