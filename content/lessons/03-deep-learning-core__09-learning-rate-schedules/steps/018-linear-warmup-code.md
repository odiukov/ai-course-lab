Ты запускаешь функцию на шагах 0, 500 и 2000. Она должна вернуть соответственно ноль, четверть пикового learning rate и сам пик. Но если передать шаг 2500, простое умножение продолжит рост и даст значение выше пика — хотя разогрев уже закончился.

Напиши `linear_warmup`, которая принимает текущий номер шага, `warmup_steps` и `lr_max`. Сначала найди долю пройденного разогрева: раздели текущий шаг на число шагов warmup. Затем ограничь эту долю единицей, чтобы после завершения разогрева learning rate оставался на уровне `lr_max`, а не рос дальше. Само вычисление использует зависимость из [шага 17](#step-17).

Проверь три опорные точки:

- на шаге `0` результат равен `0`;
- на половине warmup результат равен половине `lr_max`;
- на последующих шагах результат не превышает `lr_max`.

Обрати внимание на порядок операций: ограничивать нужно долю разогрева, а уже затем умножать её на пиковое значение. Так функция отделяет две ситуации: «ещё набираем скорость» и «пик уже достигнут».

> 🎒 **На пальцах.** Представь кран, который наполняет мерный стакан до отметки 1 литр. На половине времени поток должен дать пол-литра, к концу — ровно литр. Если таймер продолжает считать секунды после наполнения, стакан не должен воображаемо становиться двухлитровым: ограничение фиксирует результат на верхней отметке.
