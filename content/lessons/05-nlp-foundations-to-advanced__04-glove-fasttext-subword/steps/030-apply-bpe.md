Ты получил слово `abc` и список слияний:

```python
[("a", "b"), ("ab", "c"), ("abc", "</w>")]
```

Начни с отдельных символов и маркера конца слова: `["a", "b", "c", "</w>"]`. После первого правила появится `["ab", "c", "</w>"]`, после второго — `["abc", "</w>"]`, после третьего — `["abc</w>"]`. Переставлять правила по частоте нельзя: в [шаге 29](#step-29) ты видел, почему важен именно выученный порядок.

Твоя задача — дописать `apply_bpe(word, merges)`. Для каждого слияния проходи по текущему списку токенов слева направо. Если два соседних токена совпали с парой `(a, b)`, замени их одним токеном `a + b` и перескочи сразу через оба. Иначе перенеси текущий токен без изменений. Результат прохода становится входом для следующего правила.

Особенно внимательно следи за индексом. Для токенов `["a", "a", "a"]` и правила `("a", "a")` должен получиться список `["aa", "a"]`: первый символ нельзя сразу использовать повторно во втором слиянии. Не забудь также, что `"</w>"` вначале является самостоятельным токеном, но последующее правило может приклеить его к окончанию слова.

Функция должна вернуть токены после применения всех правил, даже если ни одно слияние не подошло.

> 🎒 **На пальцах.** Представь линию пассажиров и список команд: сначала объединить стоящих рядом Анну и Бориса, затем — получившуюся пару с Виктором. Ты идёшь вдоль линии и выполняешь одну команду за проход. Объединённых пассажиров во время этого прохода второй раз не трогаешь. Перед следующей командой линия уже новая — поэтому поздние объединения могут использовать результат ранних.
