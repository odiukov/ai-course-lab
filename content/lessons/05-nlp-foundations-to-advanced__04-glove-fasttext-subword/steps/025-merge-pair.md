Ты выбрал пару `("e", "s")` и смотришь на слово, разбитое на части:

```python
("n", "e", "w", "e", "s", "t", "</w>")
```

Функция `merge_pair(tokens, pair)` должна пройти по ним слева направо и вернуть новые части, где каждое соседнее совпадение с `pair` заменено их склейкой. Для этого примера результатом будет:

```python
("n", "e", "w", "es", "t", "</w>")
```

Самое важное здесь — правильно двигать позицию. Если текущая и следующая части образуют нужную пару, добавь их объединение и перескочи сразу через обе. Если совпадения нет, перенеси текущую часть без изменений и сдвинься на одну позицию.

Посмотри на случай с перекрытием:

```python
tokens = ("a", "a", "a")
pair = ("a", "a")
```

Результат должен быть `("aa", "a")`, а не один токен `"aaa"`: первое слияние уже забрало две исходные части. Новую часть нельзя повторно использовать в том же проходе.

Не забудь и о конце слова из [шага 23](#step-23). Пара `("t", "</w>")` превращается в `"t</w>"` точно так же, как две буквы. Если нужной пары нет, функция возвращает те же части в том же порядке. Частоты ей не нужны: её задача — выполнить одно уже выбранное слияние для одной последовательности.

> 🎒 **На пальцах.** Представь кассира, который связывает товары на ленте попарно. Увидев рядом две нужные упаковки, он стягивает их резинкой и сразу переводит взгляд за обе. Третья упаковка не может присоединиться к уже связанным в этом проходе. Поэтому из трёх одинаковых коробок получится одна связка и одна отдельная коробка.
