Допустим, ты хочешь получить восемь кадров. Легко случайно написать два цикла: внешний — по шагам шумоподавления, внутренний — по кадрам. Но тогда каждый кадр снова окажется один на один со своим шумом, и совместная обработка из [шага 16](#step-16) исчезнет.

В `sample_frames` начинай сразу со всей последовательности случайных значений: один элемент соответствует одному будущему кадру. Позиции кадров подготовь один раз и не изменяй — первый кадр должен оставаться первым на каждом шаге.

Дальше нужен цикл только по шагам шумоподавления. На каждой итерации:

1. Объедини текущие значения всех кадров с их позиционными кодировками.
2. Передай получившийся общий вход в denoiser одним вызовом.
3. Получи предсказанный шум сразу для всей последовательности.
4. Одновременно обнови значения всех кадров по заданному в заготовке правилу.

Следи за формами: предсказанный шум должен содержать ровно столько значений, сколько кадров ты генерируешь. Не добавляй цикл по отдельным кадрам и не пересоздавай позиции внутри цикла. В конце верни очищенную последовательность целиком.

Главная проверка проста: один шаг цикла — один вызов denoiser для всех кадров, а не несколько независимых вызовов.

> 🎒 **На пальцах.** Представь звукорежиссёра, который убирает шум из короткой фразы. Если чистить каждый слог отдельно, границы могут получиться рваными. Поэтому он каждый раз слушает всю фразу, отмечая порядок слогов, и поправляет их вместе. `sample_frames` поступает так же: позиции остаются на местах, а шум постепенно уходит из всей последовательности одновременно.
