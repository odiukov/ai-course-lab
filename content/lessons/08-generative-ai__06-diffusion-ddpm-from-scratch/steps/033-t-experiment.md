check:
  - question: >-
      Почему при сильном уменьшении T два пика на гистограмме сэмплов могут
      слиться?
    options:
      - >-
        Каждый обратный переход становится слишком крупным и хуже соответствует
        предположению о почти гауссовом переходе
      - Модель при малом T обязана выдавать одинаковое значение для всех входов
      - Количество сгенерированных сэмплов автоматически уменьшается вместе с T
    correct: 0
    explanation: >-
      При T=10 обратная цепочка состоит из более крупных переходов, чем при
      T=40. Их сложнее аппроксимировать гауссовыми шагами, поэтому две моды
      могут превратиться в один размытый пик.
  - question: >-
      Зачем оценивать сохранение мод по гистограмме большой серии сэмплов, а не
      по нескольким отдельным результатам?
    options:
      - >-
        Большая выборка надёжнее показывает форму распределения и уменьшает
        влияние случайных удачных или неудачных сэмплов
      - Большая выборка исправляет параметры уже обученной модели
      - Любая достаточно большая выборка гарантированно образует два пика
    correct: 0
    explanation: >-
      Гистограмма по 1000 сэмплам показывает устойчивую форму выходного
      распределения. Несколько отдельных значений могут случайно создать ложное
      впечатление, что обе моды сохранились или исчезли.
---

Возьми несколько значений \(T\), для каждого сгенерируй 1000 сэмплов и построй гистограммы с одинаковыми границами и корзинами. Ориентир из [шага 32](#step-32) — два раздельных скопления. При \(T=40\) ожидай два заметных пика, а около \(T=10\) они, скорее всего, сольются. Твой порог — первое проверенное \(T\), где разделение перестаёт устойчиво читаться. Не определяй его по паре удачных сэмплов: случайность легко обманывает глаз.

> 🎒 **На пальцах.** Представь две группы людей у соседних стоек. По фотографии пяти человек трудно понять, две это очереди или одна. С высоты, когда видны 1000 человек, форма становится ясной: два скопления означают сохранённые моды, а одна размазанная толпа — их исчезновение.
