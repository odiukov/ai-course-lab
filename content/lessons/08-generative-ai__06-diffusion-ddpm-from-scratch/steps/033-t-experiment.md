  - question: >-
      При T=40 гистограмма имеет два чётких пика, а при T=10 — один широкий.
      Какой вывод лучше всего подтверждают эти наблюдения?
    options:
      - При уменьшении T модель всегда генерирует меньше значений
      - При T=10 модель перестала надёжно воспроизводить две моды распределения
      - 'Один широкий пик доказывает, что обучение прошло быстрее'
    correct: 1
    explanation: >-
      Два пика соответствуют двум модам из шага 32. Их слияние означает потерю
      структуры исходного распределения.
  - question: >-
      Почему для сравнения разных T стоит строить гистограмму именно по 1000
      сэмплам?
    options:
      - >-
        Большая выборка позволяет увидеть форму распределения, а не судить по
        нескольким случайным значениям
      - Ровно 1000 сэмплов гарантируют два пика при любом T
      - Количество сэмплов заменяет обучение модели
    correct: 0
    explanation: >-
      Отдельные результаты могут выглядеть удачно или неудачно случайно.
      Гистограмма большой выборки показывает, сохраняются ли обе моды в целом.

Возьми несколько значений \(T\), для каждого сгенерируй 1000 сэмплов и построй гистограммы с одинаковыми границами и корзинами. Ориентир из [шага 32](#step-32) — два раздельных скопления. При \(T=40\) ожидай два заметных пика, а около \(T=10\) они, скорее всего, сольются. Твой порог — первое проверенное \(T\), где разделение перестаёт устойчиво читаться. Не определяй его по паре удачных сэмплов: случайность легко обманывает глаз.

> 🎒 **На пальцах.** Представь две группы людей у соседних стоек. По фотографии пяти человек трудно понять, две это очереди или одна. С высоты, когда видны 1000 человек, форма становится ясной: два скопления означают сохранённые моды, а одна размазанная толпа — их исчезновение.
