Ты получил два коротких размеченных предложения:

```python
train_examples = [
    (["The", "dog", "runs"], ["DT", "NN", "VBZ"]),
    (["A", "dog", "sleeps"], ["DT", "NN", "VBZ"]),
]
```

Нужно превратить эти примеры в память baseline из [шага 13](#step-13). Напиши функцию:

```python
def train_mft(train_examples):
    # твой код
    pass
```

Функция должна вернуть пару `word_best, default_tag`. В `word_best` каждому слову соответствует его самый частый тег: здесь для `dog` это `NN`. Приводи токены к нижнему регистру, иначе `The` и `the` попадут в разные ячейки статистики.

Удобно завести два счётчика. Первый хранит частоты тегов отдельно для каждого слова: например, сколько раз `dog` встретилось как `NN`, `VB` и так далее. Второй считает теги по всему корпусу — из него получится `default_tag`, то есть самый частый тег среди всех обучающих примеров.

Проходи по парам `(tokens, tags)`, а внутри соединяй соответствующие элементы через `zip`: первый токен с первым тегом, второй — со вторым. Затем для каждого словарного счётчика выбери лидера по частоте. Проверь, что функция именно возвращает результат, а не только печатает его.

> 🎒 **На пальцах.** Представь избирательную комиссию с отдельной урной для каждого слова. Каждый обучающий пример кладёт в урну бюллетень с тегом. После подсчёта на урне пишут победивший тег — так появляется `word_best`. Параллельно комиссия складывает копии всех бюллетеней в общую урну: победитель общего подсчёта становится `default_tag`.
