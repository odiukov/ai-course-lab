После обучения у тебя есть словарь из [шага 14](#step-14):

```python
word_best = {
    "the": "DT",
    "bank": "NN",
    "runs": "VBZ",
}
default_tag = "NN"
```

Теперь попробуй разметить `["The", "BANK", "quietly"]`. Первые два слова знакомы модели, хотя регистр букв отличается. Третьего слова в словаре нет — значит, для него нужен `default_tag`, как разобрано в [шаге 15](#step-15). Ожидаемый результат:

```python
["DT", "NN", "NN"]
```

Напиши тело `predict_mft`. Функция принимает список токенов, словарь `word_best` и запасной тег `default_tag`, а возвращает список предсказаний в том же порядке. Для каждого токена нужно:

1. привести его к нижнему регистру;
2. найти получившийся ключ в `word_best`;
3. взять сохранённый тег или `default_tag`, если ключа нет.

Проверь три свойства: число тегов совпадает с числом токенов, порядок не меняется, а исходный список `tokens` остаётся прежним. Отдельно протестируй пустой ввод: для `[]` правильный результат тоже `[]`.

```python
assert predict_mft(
    ["The", "BANK", "quietly"],
    word_best,
    default_tag,
) == ["DT", "NN", "NN"]

assert predict_mft([], word_best, default_tag) == []
```

Если `The` не находится, проверь, где именно ты вызываешь `lower()`: искать нужно уже нормализованную строку. Здесь вся работа функции — аккуратно повторить одно и то же решение для каждого токена.

> 🎒 **На пальцах.** Представь гардеробщика со списком постоянных посетителей: напротив каждого имени указан привычный номер вешалки. Имя на билете может быть написано заглавными буквами, поэтому сначала гардеробщик приводит запись к единому виду. Если посетителя в списке нет, он выдаёт стандартную свободную вешалку. Билеты обрабатываются по очереди — столько билетов, столько номеров на выходе.
