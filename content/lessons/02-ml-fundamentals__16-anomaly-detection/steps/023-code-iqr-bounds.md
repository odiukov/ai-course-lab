Перед тобой таблица наблюдений: в строках — отдельные случаи, в столбцах — признаки, например температура, давление и скорость. Нужно подготовить для каждого столбца собственный допустимый коридор. Одна общая пара границ здесь не подойдёт: у температуры и скорости разные масштабы.

Напиши функцию `iqr_bounds(X, factor=1.5)`. Она должна вернуть два массива: нижние и верхние границы для всех признаков. Вспомни устойчивый коридор из [шага 22](#step-22): сначала для каждого столбца найди 25-й и 75-й перцентили, затем получи IQR и расширь центральный диапазон в обе стороны на `factor` таких расстояний.

Обрати внимание на `axis=0` при вычислении перцентилей. Он означает: двигаться вниз по строкам и считать границы отдельно для каждого столбца. Если у `X` три признака, в каждом возвращаемом массиве тоже должно быть три числа.

Есть важный крайний случай: все значения признака могут совпадать. Тогда его IQR равен нулю, а коридор сжимается в одну точку. Перед вычислением границ замени нулевые значения IQR на `1.0`. Это защитное правило не даёт неизменному признаку создать чрезмерно узкий коридор.

Проверь себя на форме результата: функция пока только строит границы. Она ещё не решает, какие строки считать аномальными.

> 🎒 **На пальцах.** Представь портного, который хранит три стопки мерок: длину рукава, обхват груди и рост. Для каждой стопки он отдельно отмечает среднюю половину значений, а затем немного раздвигает границы. В итоге получается не один универсальный размер, а три пары отметок — по паре для каждой мерки. Именно такими парами должны стать массивы `lower` и `upper`.
