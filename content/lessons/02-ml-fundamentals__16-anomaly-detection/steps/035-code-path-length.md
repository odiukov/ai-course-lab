Ты запускаешь одну строку данных в дерево и видишь первый порог. Например, дерево проверяет признак с индексом `1`, а его порог равен `10`. Если `x[1]` равно `7`, точка уходит в левую ветвь. Но одного выбора мало: нужно продолжать спуск, считать пройденные разрезы и правильно обработать лист.

Допиши функцию `path_length(x, tree, depth=0)`. Она получает одну точку `x`, текущий узел `tree` и уже накопленную глубину `depth`. Внутренний узел хранит `feature` и `threshold`: сравни значение нужного признака с порогом и вызови функцию для подходящего дочернего узла, увеличив глубину на один.

Особенно внимательно отнесись к равенству. В функции из [шага 31](#step-31) налево уходили только значения строго меньше порога. Значит, значение, равное порогу, должно отправляться направо — иначе построение дерева и проход по нему будут следовать разным правилам.

В листе дальнейших порогов уже нет. Если лист содержит несколько точек, дерево остановилось раньше полной изоляции, поэтому к текущей глубине нужно добавить результат `expected_path_length(tree.size)` из [шага 33](#step-33). Не увеличивай глубину перед этой поправкой: лист не является ещё одним разрезом.

Проверь себя на простом маршруте: один переход из корня в лист размера `4` должен дать глубину `1` плюс ожидаемое продолжение для четырёх точек. Так функция измеряет весь путь — пройденный и недостроенный.

> 🎒 **На пальцах.** Представь развилки в оранжерее: на каждой двери написано условие по температуре или влажности. Каждый раз, проходя через дверь, ты прибавляешь один шаг. Если попадаешь в зал, где осталось несколько похожих растений, двери закончились, но поиск ещё не завершён полностью. Тогда к сделанным шагам добавляется ожидаемая длина оставшегося поиска.
