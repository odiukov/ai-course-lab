Перед тобой таблица измерений: каждая строка — один объект, каждый столбец — отдельный признак. Границы для столбцов уже умеет находить `iqr_bounds` из [шага 23](#step-23). Теперь нужно превратить эти границы в один ответ для каждой строки: тревога или норма.

Напиши функцию `iqr_flags(X, factor=1.5)`. Сначала получи нижнюю и верхнюю границы для каждого признака. Затем сравни с ними все ячейки `X`: значение считается вышедшим из коридора, если оно строго меньше нижней границы или строго больше верхней. Значение, совпавшее с границей, остаётся нормальным.

После сравнения получится булева таблица той же формы, что и `X`. Но вернуть нужно не её, а одномерный массив: по одному флагу на строку. Как договорились в [шаге 24](#step-24), достаточно выхода хотя бы одного признака. Поэтому объединяй результаты вдоль столбцов, а не вдоль строк.

Проверь формы массивов. Если `X` содержит 6 строк и 3 признака, границы должны содержать по 3 значения, промежуточная маска — иметь форму 6 на 3, а результат — 6 флагов. NumPy сам сопоставит границы со столбцами, если их формы сохранены правильно.

Главная ловушка здесь — случайно спросить «есть ли выброс в каждом столбце?» вместо «есть ли выброс в этой строке?».

> 🎒 **На пальцах.** Представь контрольную панель теплицы: одна строка хранит температуру, влажность и уровень света за минуту. Для каждого датчика есть свой допустимый коридор. Ты сначала отмечаешь отдельные показания, вышедшие за пределы, а затем зажигаешь одну лампу для всей минуты. Если отклонился хотя бы один датчик, лампа горит.
