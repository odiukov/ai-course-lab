На входе у тебя несколько деревьев и таблица объектов. Каждое дерево выдаёт длину пути для одной строки, но итог нужен другой: по одной сопоставимой оценке аномальности на каждую строку. Значит, нельзя просто сложить все результаты в один длинный список.

Дополни функцию:

```python
def isolation_scores(trees, X, sample_size):
    # Для каждой строки X:
    # 1. найди длину пути во всех деревьях;
    # 2. усредни эти длины;
    # 3. нормируй средний путь;
    # 4. преобразуй его в anomaly score.
    pass
```

Здесь пригодятся уже написанные `path_length` из [шага 35](#step-35) и `expected_path_length` из [шага 33](#step-33). Формулу преобразования среднего пути в оценку бери из [шага 36](#step-36), не выводя её заново.

Сначала пройди по строкам `X`. Для каждой строки собери длины путей по всем деревьям и вычисли их среднее. Затем используй `expected_path_length(sample_size)` как нормировочную величину. Важно передать фактический размер подвыборки: если во всём наборе только 80 строк, значение `max_samples=256` не превращает подвыборку в 256 строк.

Проверь форму результата: для таблицы из 20 строк функция должна вернуть 20 чисел — не по числу деревьев и не по числу пар «строка — дерево». Порядок оценок должен совпадать с порядком строк в `X`.

Ещё одна частая ошибка — усреднить готовые оценки отдельных деревьев. Здесь сначала усредняются длины путей, и только потом применяется преобразование из [шага 36](#step-36). Так весь лес даёт один согласованный вердикт для каждого объекта.

> 🎒 **На пальцах.** Представь письмо, которое проходит через несколько сортировочных центров. В каждом считают, сколько ворот оно миновало до отдельной корзины. Ты записываешь число ворот в каждом центре, находишь среднее и переводишь его в общий балл необычности. Ярко-фиолетовый конверт почти везде отделят рано, поэтому его средний путь окажется коротким, а итоговый балл — высоким.
