Перед тобой таблица наблюдений: каждая строка — один объект, а столбцы — его признаки. Функция `zscore_flags(X, threshold=3.0)` должна вернуть по одному ответу для каждой строки: `True`, если она подозрительна, и `False`, если нет.

Сначала вычисли среднее и стандартное отклонение отдельно для каждого столбца. Здесь легко перепутать направление: нужен `axis=0`, чтобы сравнивать температуру с другими температурами, а скорость — с другими скоростями. Затем преврати значения в абсолютные Z-score по правилу из [шага 16](#step-16). Абсолютное значение важно: одинаково подозрительны и слишком большое, и слишком маленькое отклонение.

Есть неприятный крайний случай. Если целый столбец состоит из одного значения, его стандартное отклонение равно нулю. Делить на него нельзя, поэтому перед расчётом замени нулевые значения `std` на `1.0`. Такой постоянный признак всё равно не создаст ложного отклонения: разница со средним у него равна нулю.

После расчёта у каждой строки будет несколько Z-score — по одному на признак. Строка получает флаг, если хотя бы один из них строго больше `threshold`. Поэтому сверни столбцы через максимум с `axis=1`, а затем сравни результат с порогом.

Проверь форму ответа: для таблицы из 20 строк функция должна вернуть одномерный булев массив длины 20, а не новую таблицу.

> 🎒 **На пальцах.** Представь звукорежиссёра, который проверяет каждого музыканта по громкости, темпу и высоте ноты. Он сравнивает громкость только с громкостью, а темп — только с темпом. Если хотя бы один показатель музыканта вышел за допустимую границу, напротив его имени появляется флажок. Ровная колонка вроде одинаковой длительности выступления не должна ломать всю проверку.
