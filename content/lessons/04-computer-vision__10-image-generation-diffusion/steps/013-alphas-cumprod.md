Проверь себя на коротком примере:

```python
betas = torch.tensor([0.1, 0.2, 0.3])
result = alphas_cumprod(betas)

expected = torch.tensor([0.9, 0.72, 0.504])
assert torch.allclose(result, expected)
assert result.shape == betas.shape
```

Посмотри внимательно на второе число. Это не просто `0.8`, соответствующее второй `beta`: к этому моменту сигнал уже прошёл два шага, поэтому получается `0.9 × 0.8 = 0.72`. Третье значение продолжает ту же цепочку: `0.72 × 0.7 = 0.504`.

Для накопленного произведения в PyTorch есть операция `torch.cumprod`. Параметр `dim=0` говорит ей двигаться по последовательности шагов. Не используй обычный `torch.prod`: он свернёт весь тензор в одно итоговое число, а нам нужна таблица значений для каждого момента.

> 🎒 **На пальцах.** Представь дисконтную карту, которая каждый месяц сохраняет лишь часть накопленных бонусов. После первого месяца осталось 90%, после второго сохраняется 80% уже от этого остатка, после третьего — 70% от нового остатка. Тебе нужна не только последняя сумма, а выписка после каждого месяца. `cumprod` как раз составляет такую выписку.
