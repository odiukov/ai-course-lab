Попробуй вручную составить расписание для пяти шагов. Первое значение должно быть `0.0001`, последнее — `0.02`, а три числа между ними должны увеличиваться с одинаковым интервалом. Считать их самостоятельно неудобно, особенно когда шагов уже тысяча.

Напиши функцию `linear_beta_schedule` с тремя параметрами: количеством шагов `T`, начальным значением `beta_start` и конечным `beta_end`. По умолчанию используй значения из исходного примера: `1000`, `1e-4` и `2e-2`.

Внутри пригодится `torch.linspace`. Эта операция создаёт заданное количество равномерно расположенных чисел между двумя границами, включая обе границы. Функция должна вернуть одномерный тензор длины `T`, а не список Python и не одно число.

На что посмотреть после реализации? Вызови функцию с `T=5` и проверь три свойства:

- элементов получилось ровно пять;
- первый элемент равен `beta_start`, последний — `beta_end`;
- разница между каждой парой соседних элементов одинакова.

Так ты превратишь идею beta schedule из [шага 6](#step-6) в конкретную таблицу: индекс обозначает номер шага, а значение по этому индексу — назначенную ему порцию шума. Пока функция лишь строит расписание; применять его к изображению будем позже.

> 🎒 **На пальцах.** Представь регулятор яркости с пятью фиксированными делениями. Ты задаёшь минимальную и максимальную яркость, а мастер должен равномерно поставить между ними остальные отметки. `torch.linspace` и есть такой мастер: получает две крайние отметки и их общее количество, а возвращает готовую линейку без пропусков и скачков.
