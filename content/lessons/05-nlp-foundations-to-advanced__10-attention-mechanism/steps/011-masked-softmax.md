В батче первая последовательность занимает четыре позиции, а вторая — только две. Но таблица оценок прямоугольная, поэтому у второй строки есть ещё две служебные позиции. Если передать её обычной функции из [шага 9](#step-9), padding тоже получит часть внимания.

Твоя функция должна принять оценки `scores` и булеву маску `mask`, где `True` означает настоящий токен, а `False` — padding:

```python
def masked_softmax(scores, mask):
    # замени оценки padding-позиций
    # примени softmax по последней оси
    pass
```

Работай в два действия. Сначала создай изменённые оценки: настоящие оставь как есть, а на месте padding поставь очень большое отрицательное число, например `-1e9`. Удобно выбрать значения по маске, не меняя исходный массив. Затем передай результат в уже написанный `softmax`.

Важно именно такое расписание: сначала маскирование, потом нормализация. Если вызвать `softmax` раньше и лишь затем обнулить запрещённые веса, padding уже успеет забрать часть общей доли. Оставшиеся веса окажутся уменьшенными.

Проверь также технические детали: вычисления должны идти с вещественными числами, а `softmax` — по оси позиций, обычно последней. Для батча формы `scores` и `mask` должны совпадать либо корректно расширяться по правилам библиотеки. Значение `False` не удаляет столбец: оно только запрещает соответствующей позиции участвовать в распределении внимания.

Значит, маска здесь не исправляет готовые веса — она заранее убирает padding из числа претендентов.

> 🎒 **На пальцах.** Представь конкурс с четырьмя табличками участников, но во втором туре за двумя табличками никто не стоит. Если сначала разделить призовой фонд между всеми четырьмя, а потом забрать деньги у пустых мест, часть фонда пропадёт. Поэтому пустым табличкам заранее ставят оценку настолько низкую, что они не получают ничего, и весь фонд делят только реальные участники.
