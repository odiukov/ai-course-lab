title: Self-attention разделяет обучаемые проекции Key и Value

Представь фразу: «Лиса заметила зайца, когда он выбежал на поляну». Чтобы понять слово «он», модели полезно сравнить его с другими словами. Но признаки для поиска подходящего слова и информация, которую потом стоит забрать, — не обязательно одно и то же.

В классическом attention из [шага 30](#step-30) состояние энкодера одновременно служило Key и Value. Self-attention работает внутри одной последовательности: каждое слово обращается к словам этой же фразы. При этом из одного представления слова \(x_i\) получаются две версии:

\[
k_i=x_iW_K,\qquad v_i=x_iW_V
\]

Здесь \(x_i\) — исходное представление слова, \(W_K\) и \(W_V\) — разные обучаемые матрицы, \(k_i\) — Key, а \(v_i\) — Value.

Key участвует в сравнении с Query и влияет на вес внимания. Например, его проекция может подчёркивать признаки, помогающие связать «он» с существительным мужского рода. Value в сравнении не участвует: именно его содержимое попадёт во взвешенную сумму после вычисления весов. Его проекция может сохранить другие полезные свойства слова — например, смысл «заяц» как живого участника события.

Матрицы сначала не знают, какие признаки важны. Во время обучения модель подстраивает их отдельно: одну — для удачного поиска, другую — для полезного ответа. Поэтому разделение Key и Value — не две копии слова, а две выученные роли одного представления.

> 🎒 **На пальцах.** Представь видеoархив. На каждой записи есть поисковая карточка и сам подготовленный фрагмент. Запрос сравнивают с карточкой: по ней решают, какую запись открыть. Но в монтаж отправляют не карточку, а фрагмент. Архив учится отдельно составлять удобные карточки и готовить полезные фрагменты — именно так из одного входа получаются разные Key и Value.
