Ты запускаешь обучение на батче из 32 примеров. Если всем выдать одно и то же время, модель увидит лишь один участок траектории; если случайно брать время только равномерно, нельзя управлять тем, где примеры будут скапливаться. После выбора распределения на [шаге 28](#step-28) осталось превратить его в функцию `logit_normal_t`.

Сначала функция должна получить по одному обычному нормальному числу \(z\) для каждого элемента батча. Затем оно масштабируется и сдвигается, после чего проходит через сигмоиду:

\[
t=\operatorname{sigmoid}(\mu+\sigma z).
\]

Здесь \(z\) — случайное число из стандартного нормального распределения, \(\mu\) задаёт положение скопления времён, \(\sigma\) — их разброс, а \(t\) — результат внутри интервала от 0 до 1. Именно сигмоида «сжимает» неограниченные значения вроде \(-3.2\) или \(1.7\) в допустимое время.

При реализации проверь три вещи. Число полученных значений должно совпадать с размером батча. Тензор нужно сразу создавать на том же устройстве, где находятся данные. Наконец, при передаче времени в модель добавь столько единичных измерений, сколько требуется для broadcasting с `x`: например, изображениям обычно нужна форма с одним значением времени на пример и единицами по пространственным осям.

Не ограничивай результат вручную через `clamp`: сигмоида уже сохраняет порядок значений и помещает их в нужный диапазон.

> 🎒 **На пальцах.** Представь длинную линейку без краёв, на которой случайно ставят отметки. Сигмоида похожа на резиновую ленту: ты сжимаешь всю линейку между делениями 0 и 1, не меняя порядок отметок. \(\mu\) сдвигает их кучку, а \(\sigma\) растягивает или собирает её плотнее. Каждый пример батча получает собственную отметку времени.
