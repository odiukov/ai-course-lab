Возьми список деталей из [шага 7](#step-7) и задай ему один вопрос: что из этого вообще меняется во время обучения?

Softmax из [шага 11](#step-11) — не меняется. Он делит экспоненты на их сумму, подкручивать там нечего. Нормализация делит вектор на его длину — тоже жёсткая арифметика. Attention считает скалярные произведения — операция без единого настраиваемого числа.

Тогда где живут те самые 155 000 параметров, которые модель выучивает?

Все до единого — в линейном слое. Это единственная деталь конструкции, у которой есть внутренние числа, и единственное место, куда обучение вообще может что-то записать.

Устроен он до обидного просто. На вход приходит вектор — скажем, 64 числа. На выходе нужен вектор другой длины, пусть 256. Каждое выходное число — это сумма всех 64 входных, взятых с разными коэффициентами, плюс сдвиг:

$$y = xW + b$$

Здесь $x$ — входной вектор, $W$ — таблица коэффициентов размером 64 на 256 (вот они, 16 384 обучаемых числа), $b$ — вектор сдвигов, $y$ — результат.

А теперь посмотри, сколько раз этот кусок понадобится. Проекции Q, K, V внутри attention — линейные слои. SwiGLU — линейные. Финальная голова, которая превращает вектор в 65 оценок по числу символов из [шага 2](#step-2), — тоже линейный.

Один кусок кода, разные размеры матриц. Напишешь его один раз — а дальше вся модель будет собрана из его копий.

> 🎒 **На пальцах.** Микшерный пульт: восемь микрофонов на входе, одна колонка на выходе. У каждого канала свой фейдер. Двигаешь фейдеры — меняется, чей голос слышен громче; сама схема пульта при этом не трогается, меняются только положения ручек. Линейный слой — ровно такой пульт: вход, выход и решётка фейдеров между ними. Обучение — это подбор их положений, больше ничего.
