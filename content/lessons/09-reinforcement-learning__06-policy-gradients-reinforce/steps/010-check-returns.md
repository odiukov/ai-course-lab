title: 'Проверяем возвраты 0,81, 0,9 и 1 при γ = 0,9'
source_anchor: '## The Concept'
check:
  - question: >-
      Для наград 0, 0, 1 и γ = 0,9 функция вернула возвраты 1; 0,9; 0,81. Какая
      ошибка лучше всего объясняет такой результат?
    options:
      - >-
        Возвраты вычислили с конца эпизода, но не развернули список в исходный
        временной порядок
      - Последнюю награду ошибочно дисконтировали дважды
      - Вместо γ использовали величину 1 − γ
      - Все промежуточные награды приняли равными единице
    correct: 0
    explanation: >-
      Сами значения верные: обратный проход выдаёт их в порядке 1, затем 0,9,
      затем 0,81. Ошибка только в порядке — для сопоставления с действиями
      список нужно развернуть, тогда получится 0,81; 0,9; 1. Признак: возврат
      растёт к концу эпизода, хотя награда одна и стоит в конце.
  - question: >-
      В эпизоде с наградами 0, 0, 1 и γ = 0,9 почему возврат последнего шага
      равен 1, а не 0,9?
    options:
      - >-
        Награда входит в возврат своего шага с нулевой задержкой, то есть с
        множителем γ⁰
      - Возврат последнего шага эпизода по определению всегда равен 1
      - Дисконтирование применяется только к нулевым наградам
      - На последнем шаге значение γ автоматически заменяется на 1
    correct: 0
    explanation: >-
      Дисконт наказывает задержку: множитель равен γ в степени числа шагов между
      действием и наградой. Для последнего шага задержка нулевая, γ⁰ = 1,
      поэтому награда входит целиком. Множитель 0,9 появляется только на шаг
      раньше.
---

Здесь ты проверяешь результат функции из [шага 9](#step-9): возвраты считаются с конца эпизода к началу. Сначала берёшь последнюю награду без скидки — получаешь 1. Отступаешь на один шаг и умножаешь будущий результат на 0,9 — выходит 0,9. Ещё один шаг назад даёт 0,81.

Чаще всего спотыкаются в двух местах: сразу уменьшают последнюю награду до 0,9 или записывают результаты в обратном порядке. Проверка простая: ближе к единственной награде возврат должен быть больше, поэтому правильный порядок — 0,81, затем 0,9, затем 1.
