Перед тобой список наград за один эпизод. Для каждой позиции нужно узнать, сколько будущей пользы «видно» из неё с учётом дисконтирования. Пересчитывать хвост списка с нуля для каждого шага можно, но получится много повторной работы.

Используй результат из [шага 8](#step-8), двигаясь по наградам справа налево. Держи накопленный возврат: сначала он равен нулю, а на каждой позиции складывается из текущей награды и уже накопленного будущего возврата, умноженного на `gamma`. Получившееся число сохрани на той же позиции выходного списка.

Обрати внимание на три детали:

- результат должен иметь ту же длину и тот же порядок, что и список наград;
- последняя позиция не имеет будущих наград, поэтому начинается только с последней награды;
- пустой список должен дать пустой результат.

Главная ловушка — пройти справа налево, записать числа подряд, но забыть вернуть их в исходный временной порядок. Тогда значения окажутся правильными, однако будут соответствовать не тем действиям. Ещё одна частая ошибка — умножать текущую награду на `gamma`. Дисконтируется накопленное будущее, а награда текущего шага входит целиком.

После реализации проверь не только итоговый список, но и один промежуточный шаг: накопленный возврат должен передаваться от более позднего действия к более раннему.

> 🎒 **На пальцах.** Представь ряд конвертов, разложенных по дням. В каждом лежит награда этого дня, а ценность следующего конверта немного выцветает при переносе назад. Ты начинаешь с последнего конверта и идёшь к первому: добавляешь его содержимое к уже посчитанной, слегка обесцененной сумме будущих конвертов. Поэтому каждый день получает свой возврат без повторного пересчёта всего хвоста.
