Дальше в курсе тебе понадобится именно этот контракт: извлечь кандидат из ответа модели, ограниченно исполнить его, превратить исход запуска в балл и причину, а затем собрать pass@k по задачам. Чаще всего здесь спотыкаются, смешивая две разные вещи: устойчивую метрику и настоящую защитную песочницу. Ограничения из [шагов 2](#step-2)–[7](#step-7) делают запуск предсказуемым, но не превращают чужой код в безопасный.

> 🎒 **На пальцах.** Представь испытательный стенд для фейерверков: есть таймер, ограничитель размера заряда и журнал результатов. Он помогает одинаково сравнивать изделия. Но неизвестную коробку с улицы ты не понесёшь на этот стенд — для неё нужен изолированный бункер. Метрика задаёт честные правила испытания; контейнер задаёт уровень защиты.
