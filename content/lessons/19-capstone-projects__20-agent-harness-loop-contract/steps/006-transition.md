Реализуй `HarnessLoop._transition`. Опиши разрешённые следующие состояния для каждого значения `State`, проверь запрошенную цель и только после проверки обнови `self.state`.

При незаконном ребре брось `RuntimeError`, в сообщении оставь исходное и целевое состояния. Не меняй состояние до проверки: после ошибки объект должен оставаться пригодным для диагностики.

Учти переходы в `IDLE` из активных состояний — так бюджет превращается в паузу. Из `DONE` разрешённых переходов нет: новая сессия создаётся новым экземпляром цикла.
