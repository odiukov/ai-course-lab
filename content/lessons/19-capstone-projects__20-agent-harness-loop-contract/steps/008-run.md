Реализуй `HarnessLoop.run`. Разреши запуск только из `State.IDLE`; иначе брось `RuntimeError` с текущим состоянием. Для законного запуска сохрани `goal`, сбрось `budget.started_at` на текущее время, запиши событие `session.start` с целью и верни результат `_step()`.

Не обнуляй счётчики бюджета и историю: этот метод открывает сессию, а политика повторного использования объекта задаётся отдельно. Не переходи в `PLANNING` вручную — `_step` видит `IDLE` и делает это через проверенный `_transition`.
