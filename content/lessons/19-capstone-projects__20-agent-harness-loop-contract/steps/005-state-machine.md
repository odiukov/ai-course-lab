Шесть состояний описывают жизненный цикл сессии. `IDLE` — единственный вход, `DONE` — терминал. Планирование передаёт управление выполнению или завершает пустой план. Выполнение либо запрашивает инструмент, либо переходит к осмыслению результата. После осмысления цикл продолжает план, перепланирует или завершает цель.

Особенно важны отрицательные правила: нельзя начать выполнение прямо из `IDLE`, нельзя уйти из `DONE`, нельзя принять результат инструмента вне `AWAITING_TOOL`. Если эти ограничения размазать по вызывающим методам, один забытый guard создаст невозможную для воспроизведения сессию.

Поэтому состояние меняет только `_transition`.
