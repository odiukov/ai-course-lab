Перед тобой список языков-кандидатов. У одного много размеченных текстов, другой типологически ближе к целевому, третий принадлежит к той же языковой семье. Если выбрать кандидата только по одному признаку, победитель будет меняться вместе с критерием.

Функция `rank_source_languages` должна собрать эти сигналы в одну оценку. Для каждого кандидата:

1. вызови `language_similarity` из [шага 35](#step-35), чтобы оценить типологическую близость к целевому языку;
2. добавь бонус за генетическое родство, если языки принадлежат к одной семье;
3. учти объём доступных данных, но не позволяй огромному корпусу полностью заглушить остальные признаки;
4. объедини компоненты с заданными весами;
5. верни кандидатов от наибольшей итоговой оценки к наименьшей.

Следи за направлением сортировки: лучший исходный язык должен оказаться первым. Не перепутай также сходство с расстоянием — большее значение `language_similarity` означает более подходящего кандидата. Если оценки совпали, сохрани исходный порядок: так результат останется предсказуемым.

Здесь ты реализуешь механику LANGRANK, разобранную в [шаге 36](#step-36): функция не объявляет победителя по одному громкому показателю, а составляет очередь кандидатов для последующей проверки на реальной задаче.

> 🎒 **На пальцах.** Ты выбираешь курьера для доставки в горную деревню. Большая компания привезла миллионы посылок, местный курьер знает дороги, а третий ездит на подходящей машине. Ты начисляешь баллы за каждый полезный признак и сортируешь курьеров по сумме. Размер компании важен, но сам по себе ещё не гарантирует первое место.
