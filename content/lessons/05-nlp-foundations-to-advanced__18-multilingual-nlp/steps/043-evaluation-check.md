check:
  - question: >-
      У 18 языков точность равна 90%, а у двух — 45%. Средняя точность
      составляет 85,5%. Как следует интерпретировать этот результат?
    options:
      - Среднее подтверждает приемлемое качество модели на каждом языке
      - Среднее скрывает существенный провал качества на двух языках
      - >-
        Низкая точность двух языков не имеет значения, если среднее превышает
        80%
    correct: 1
    explanation: >-
      Среднее не показывает разброс по языкам. Значение 85,5% выглядит высоким,
      хотя на двух языках модель достигает лишь 45% и фактически не обеспечивает
      требуемого покрытия.
  - question: >-
      Какой отчёт позволит обнаружить языки, качество модели на которых сильно
      ниже среднего?
    options:
      - Таблица с accuracy на отдельном отложенном наборе каждого языка
      - Одно значение accuracy по всем примерам без указания языка
      - 'Общее число языков, которые поддерживает модель'
    correct: 0
    explanation: >-
      Разбивка accuracy по языкам сохраняет различия между ними и показывает
      длинный хвост. Единый агрегат может скрыть два языка с точностью 45% за
      средним значением 85,5%.
---

Ты видишь в отчёте 85,5% и почти готов принять модель. Остановись: это среднее получилось из 18 языков с точностью 90% и двух с точностью 45%. Одно число спрятало именно те языки, ради которых нужна многоязычная система.

Проверь, умеешь ли ты отличать приятный агрегат от реального покрытия: сначала смотри accuracy по каждому языку, как в [шаге 40](#step-40), а затем уточняй причину проверками из [шага 42](#step-42).

> 🎒 **На пальцах.** Представь гирлянду из двадцати ламп: восемнадцать светят ярко, две едва мерцают. Средняя яркость кажется высокой, но в двух местах комната остаётся тёмной. Отчёт по средней яркости успокаивает; проверка каждой лампы показывает, где гирлянда не выполняет свою работу.
