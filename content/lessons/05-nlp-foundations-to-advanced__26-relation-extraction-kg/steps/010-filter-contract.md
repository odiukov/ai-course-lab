title: Triple попадает дальше только после проверки всех обязательных спанов

---

Модель вернула факт: `(Tim Cook, became CEO of, Apple)`. Спан для `Tim Cook` совпал с исходным текстом, а спан для `Apple` захватил лишний пробел. Можно ли сохранить triple, ведь смысл всё равно понятен?

Нет. Triple здесь проходит проверку целиком или не проходит вовсе. Как ты видел в [шаге 2](#step-2), subject, relation и object вместе выражают один факт. Если обязательный спан хотя бы одной сущности не подтвердился, уже нельзя доказать, что весь факт привязан к исходному предложению.

Для каждого обязательного спана выполняется проверка из [шага 9](#step-9): фрагмент `text[start:end]` должен в точности совпасть с заявленным значением. В формате из промпта спаны обязательны у subject и object. Значит, triple можно передать дальше только при двух успешных проверках.

Важно не пытаться «починить» сомнительный результат догадкой. Если спан объекта неверен, нельзя оставить subject и самостоятельно подобрать границы для object: это снова добавит вывод, которого модель явно не подтвердила. По той же причине не существует «наполовину проверенного» triple. Один подтверждённый участник отношения не подтверждает второго.

Так строгая проверка превращает набор отдельных совпадений в единый пропуск: все обязательные привязки верны — факт продолжает путь; хотя бы одна неверна — весь факт останавливается.

> 🎒 **На пальцах.** Представь курьера, который привёз запечатанный комплект из двух пробирок. На первой этикетка совпадает с накладной, а на второй номер размазан. Лаборатория не принимает «половину анализа»: вывод строится по паре образцов. Пока нельзя подтвердить обе пробирки, весь комплект остаётся за дверью — даже если первая оформлена безупречно.
