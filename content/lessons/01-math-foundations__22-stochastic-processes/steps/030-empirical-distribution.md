Тебе передали траекторию цепи: `[0, 0, 2, 1, 0]`. Состояние `0` встретилось три раза, а `1` и `2` — по одному. Значит, `empirical_distribution` должна вернуть массив долей: `[0.6, 0.2, 0.2]`.

Функция получает последовательность посещённых состояний и общее число возможных состояний. Сначала посчитай, сколько раз встретился каждый номер, затем раздели все счётчики на длину траектории — именно эту операцию мы разобрали в [шаге 29](#step-29). Порядок элементов важен: элемент с индексом `i` относится к состоянию `i`.

Обрати внимание на состояние, которое не встретилось ни разу. Например, для траектории `[0, 0, 1]` при трёх возможных состояниях результат всё равно должен содержать три элемента: `[2/3, 1/3, 0]`. Иначе массив станет короче, а индексы перестанут надёжно соответствовать состояниям.

Не считай переходы между соседними элементами: здесь нас интересует, сколько времени цепь провела в каждом состоянии. Проверь результат по двум признакам: его длина совпадает с числом состояний, а сумма долей равна единице с учётом небольшой погрешности вычислений.

> 🎒 **На пальцах.** Представь журнал дежурного, который каждый час записывает номер занятого кабинета. `empirical_distribution` не выясняет, из какого кабинета человек перешёл в следующий. Она просто подсчитывает записи для каждого кабинета и превращает их в доли всего журнала. Если кабинет ни разу не появился, его строка остаётся на месте — с нулём.
