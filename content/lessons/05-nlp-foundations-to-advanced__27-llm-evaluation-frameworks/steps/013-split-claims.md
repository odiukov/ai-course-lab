Возьми ответ: «Компания открыла офис в Лиссабоне и наняла 20 сотрудников. Руководителем стала Анна». Здесь две строки не означают два проверяемых факта: первое предложение содержит сразу два утверждения. Если передать его целиком следующему этапу, частично верная фраза получит одну общую оценку.

Напиши функцию `split_claims(text)`, которая возвращает список коротких утверждений — тех самых атомарных фактов из [шага 12](#step-12). Сначала раздели текст по границам предложений, затем попробуй разрезать составные предложения по союзам вроде «и», если по обе стороны находятся самостоятельные сообщения. Убирай пробелы и пустые элементы, но сохраняй исходный порядок.

Проверь функцию минимум на трёх случаях:

- обычный текст из нескольких предложений;
- предложение с двумя фактами, соединёнными союзом;
- пустая строка.

Для примера выше ожидаются три отдельных элемента: офис открыт в Лиссабоне, наняты 20 сотрудников, руководителем стала Анна. Не стремись построить идеальный лингвистический анализатор: правило может ошибаться, например в перечислении «чай и кофе». Сейчас важнее получить понятную, воспроизводимую заготовку, ограничения которой ты видишь сам.

> 🎒 **На пальцах.** Представь коробку с наклейкой «посуда», где лежат чашка, тарелка и треснувший бокал. Проверять коробку целиком неудобно: ответ «всё цело» скроет дефект. Ты раскладываешь предметы по одному и осматриваешь каждый отдельно. `split_claims` делает то же с ответом: превращает связный абзац в факты, которые можно проверять независимо.
