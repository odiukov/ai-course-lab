Модель обработала два изображения и вернула не две строки, а тензор формы `(T, N, C)`: временные шаги, объекты в пакете и классы. Твоя функция `greedy_ctc_decode` должна превратить его в список последовательностей индексов — по одной на каждый объект.

Сначала выбери класс с наибольшим значением на каждом временном шаге с помощью `argmax` по последнему измерению. Получится форма `(T, N)`. Но декодировать удобнее объект за объектом, поэтому переставь измерения в `(N, T)`, перенеси результат на CPU и преобразуй в обычные списки Python.

Дальше примени к каждой последовательности правила из [шага 13](#step-13): объединяй соседние повторы и удаляй `blank`. Например, индексы `[1, 1, 0, 2, 2, 0, 2]` должны превратиться в `[1, 2, 2]`. Последние две двойки сохраняются обе, потому что между ними стоял `blank`.

Следи за переменной `prev`: обновляй её после каждого индекса, включая `blank`. Иначе разделитель потеряется, а одинаковые символы по разные стороны от него ошибочно сольются. Для пакета из трёх изображений функция должна вернуть три списка индексов. В символы их пока не переводи — этим займётся следующий шаг.

> 🎒 **На пальцах.** Представь три аудиозаписи, на которых каждую секунду несколько радиостанций спорят, чей сигнал сильнее. Сначала ты для каждой секунды оставляешь только победителя. Затем раскладываешь результаты по отдельным записям и вырезаешь непрерывный гул одной станции. Пауза между двумя одинаковыми сигналами важна: она показывает, что станция прозвучала дважды, а не просто тянулась дольше.
