title: Все параметры обновляются после подсчёта общих градиентов
source_anchor: '### Gradient Descent for Logistic Regression'
---

Представь: модель обработала три примера. Первый «просит» увеличить вес, второй — уменьшить, третий — почти ничего не менять. Если послушаться первого сразу, параметры изменятся, и следующие два примера будут оценивать уже другую версию модели. В одном общем подсчёте смешаются сигналы, полученные при разных настройках.

Поэтому сначала параметры будто ставят на паузу. Для всех примеров считают вероятности, затем ошибки и градиенты из [шага 27](#step-27). Функция из [шага 28](#step-28) возвращает уже собранный результат: отдельный общий градиент для каждого веса и один для смещения. Только после этого выполняются обновления:

$$
w_j \leftarrow w_j-\eta\frac{\partial J}{\partial w_j},
\qquad
b \leftarrow b-\eta\frac{\partial J}{\partial b}.
$$

Здесь $w_j$ — один из весов, $b$ — смещение, соответствующие производные — подсчитанные общие градиенты, а $\eta$ — шаг обучения: насколько сильно разрешено сдвинуть параметры за раз.

Слово «все» здесь важно. Новый первый вес не должен участвовать в вычислении обновления второго веса: оба градиента относятся к одной и той же исходной версии модели. Сначала ты полностью собираешь указания, а затем одним согласованным движением обновляешь веса и смещение. Так каждый набор градиентов честно описывает одно состояние модели.

> 🎒 **На пальцах.** Представь повара, который дал попробовать суп пяти гостям. Один просит больше соли, двое — меньше, остальные довольны. Повар не досаливает суп после каждого ответа: иначе поздние гости пробуют уже другой суп. Он сначала собирает все мнения, сводит их вместе и лишь затем одновременно корректирует соль, перец и кислоту. У одной дегустации — одна версия рецепта и одно согласованное обновление.
