Возьми точку с двумя признаками и попробуй отнести её к одному из трёх классов. Одного набора весов здесь недостаточно: он дал бы только один балл, а softmax нужны три балла для сравнения — по одному на каждый возможный ответ.

Поэтому модель хранит три независимых набора параметров. Если признаков два, у каждого класса есть два собственных веса и своё смещение. Получается не один вектор весов, а таблица из трёх строк: первая строка отвечает за класс 0, вторая — за класс 1, третья — за класс 2.

Для одной и той же точки каждая строка выполняет знакомый расчёт из [шага 11](#step-11), но оценивает её со своей позиции. Например, большой первый признак может повышать балл класса 1 и одновременно понижать балл класса 0. Затем softmax из [шага 42](#step-42) превращает три полученных балла в согласованные вероятности.

При обучении эти строки тоже меняются отдельно. Если правильный ответ — класс 2, модель старается увеличить его балл и уменьшить баллы конкурентов. One-hot метка из [шага 45](#step-45) как раз показывает, какую строку нужно поддержать: напротив верного класса стоит 1, напротив остальных — 0.

Так каждый класс постепенно учится узнавать собственную область признаков, а не делит один общий набор весов с соперниками.

> 🎒 **На пальцах.** Представь трёх скаутов, выбирающих спортсмена для разных дисциплин: спринта, плавания и баскетбола. Все смотрят на одни данные — рост и выносливость, — но ценят их по-разному. У каждого своя записная книжка с коэффициентами. Softmax собирает выставленные ими баллы и превращает их в одно общее распределение шансов.
