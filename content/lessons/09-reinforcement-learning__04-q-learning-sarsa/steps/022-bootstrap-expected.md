Ты запускаешь функцию несколько раз с одними и теми же оценками действий — и вдруг получаешь разные ответы. Значит, внутри случайно выбирается одно действие, как в SARSA из [шага 19](#step-19). Expected SARSA должна вернуть одно и то же среднее: случайный выбор здесь вообще не нужен.

Возьми ε-жадную стратегию из [шага 13](#step-13), но вместо выбора действия восстанови её вероятности. Сначала найди жадное действие, соблюдая то же правило для одинаковых максимумов. Затем каждому действию назначь долю исследования: `epsilon`, делённую на количество действий. Жадному действию дополнительно достаётся вероятность `1 - epsilon`.

Проверь себя: сумма всех вероятностей должна равняться единице. После этого умножь оценку каждого действия на его вероятность и сложи результаты. Это и есть бутстрэп \(B\), введённый в [шаге 21](#step-21). Для примера оттуда функция должна всегда возвращать `6.25`.

Обрати внимание на границы:

- при `epsilon = 0` результат совпадает с max-бутстрэпом из [шага 16](#step-16);
- при `epsilon = 1` получается обычное среднее всех оценок.

Функция возвращает только бутстрэп. Награда, `gamma`, TD-ошибка и обновление Q-таблицы появятся снаружи. Если результат прыгает между запусками, ты снова написал SARSA.

> 🎒 **На пальцах.** Представь лаборанта, который смешивает четыре образца краски. Можно наугад взять одну банку — цвет каждого опыта будет меняться. А можно заранее отмерить долю каждой банки по заданным вероятностям и получить устойчивый оттенок. Expected SARSA делает именно такое смешивание оценок, не бросая жребий.
