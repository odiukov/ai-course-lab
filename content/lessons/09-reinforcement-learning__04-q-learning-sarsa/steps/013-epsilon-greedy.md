В состоянии `state` перед тобой одна строка таблицы `Q`: по одному значению на каждое действие. Функция `epsilon_greedy_action` должна вернуть не само Q-значение, а **индекс выбранного действия**.

Выбор состоит из двух веток, описанных в [шаге 12](#step-12). Сначала получи случайное число от 0 до 1 и сравни его с `epsilon`. Если оно меньше `epsilon`, выбери случайный индекс равновероятно среди всех доступных действий. Важно считать именно действия — например, через длину строки `Q[state]`, а не количество состояний во всей таблице.

В остальных случаях найди индекс максимального значения в строке `Q[state]`. Не ищи максимум по всей таблице: тогда действие могло бы определяться оценками совершенно другого состояния. Если несколько значений одинаково максимальны, обычный `argmax` выберет первое из них — для этой реализации такое поведение допустимо.

Проверь крайние случаи мысленно:

- при `epsilon = 0` функция всегда выбирает жадное действие;
- при `epsilon = 1` она всегда выбирает случайное действие;
- для строки `[2, 7, 1, 3]` жадная ветка возвращает индекс `1`, а не значение `7`.

Главный ориентир: результат функции — одно целое число, которым можно обратиться к списку действий.

> 🎒 **На пальцах.** Представь диджея с четырьмя пластинками. Обычно он ставит ту, у которой лучший рейтинг, но иногда монетка велит попробовать любую пластинку наугад. `epsilon` задаёт частоту таких экспериментов. Функция возвращает не рейтинг и не пластинку целиком, а номер выбранной ячейки на полке.
