У тебя на руках уже шесть рабочих деталей: `make_tool` из [шага 12](#step-12), `describe_registry` из [шага 14](#step-14), фальшивый решатель из [шага 16](#step-16), `validate_arguments` из [шага 24](#step-24), `execute_call` из [шага 27](#step-27) и `needs_confirmation` из [шага 32](#step-32). Каждая проверена по отдельности. А агента всё ещё нет — запускать нечего.

Потому что никто не держит историю. Каждая из деталей отвечает за один такт, но кто-то должен помнить, что было сказано на предыдущем ходу, и решать, пора ли остановиться. Модель не помнит ничего — это [шаг 29](#step-29).

Этим и занимается `run_loop`. Она принимает начальный список сообщений, реестр и ограничитель ходов — в `code/main.py` он равен пяти — и внутри одного `while` проходит порядок из [шага 36](#step-36). На каждом ходу собери объявления реестром, отдай их решателю вместе со всей накопленной историей и посмотри, что он вернул. Текст — дописала сообщение с ролью assistant и вышла: цикл закончен. Список вызовов — дописала сообщение с вызовами, а потом по каждому вызову отдельно: проверить необратимость, провалидировать аргументы, запустить исполнитель, добавить сообщение с ролью tool и тем самым `id` ([шаг 28](#step-28)).

Смотри на две вещи. Первая — как растёт `messages`: за один ход с двумя параллельными вызовами ([шаг 17](#step-17)) прибавляется три сообщения, не два. Вторая — что происходит, когда пять ходов исчерпаны, а решатель всё ещё просит вызовы. Ты обязана что-то вернуть: не бросай исключение молча, а верни историю с честной отметкой «лимит ходов кончился».

Цикл заканчивается не тогда, когда работа сделана, а тогда, когда одно из двух условий сработало — и оба условия пишешь ты.

> 🎒 **На пальцах.** Игра «горячо–холодно». Ты называешь место, тебе отвечают одним словом, ты называешь следующее — и держишь в голове все прежние ответы, иначе ходишь по кругу. Игра кончается двумя способами: ты угадал или попытки вышли. `run_loop` — это и есть тот, кто ведёт счёт попыток и хранит список подсказок. Без него отдельные вопросы есть, а игры нет.
