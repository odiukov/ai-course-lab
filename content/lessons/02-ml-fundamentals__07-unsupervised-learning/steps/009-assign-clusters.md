Перед тобой три точки: `[1, 1]`, `[9, 8]`, `[2, 3]`. Рядом стоят два центроида. Ты уже умеешь вычислять расстояние функцией `euclidean_distance` из [шага 7](#step-7) и знаешь правило выбора из [шага 8](#step-8). Теперь нужно применить это правило не к одной точке, а ко всему набору.

Функция `assign_clusters` принимает список точек `data` и список `centroids`. Для каждой точки она должна:

1. вычислить расстояние до каждого центроида;
2. найти наименьшее расстояние;
3. сохранить индекс ближайшего центроида.

Результат — список назначений в том же порядке, что и точки. Например, ответ `[0, 1, 0]` означает: первая точка выбрала центроид с индексом `0`, вторая — с индексом `1`, третья — снова с индексом `0`. Сами координаты в результат записывать не нужно.

Обрати внимание на две детали. Индексы начинаются с нуля, поэтому первый центроид имеет индекс `0`. Если два центроида находятся на одинаковом расстоянии, выбирай первый из них — с меньшим индексом. Так результат останется предсказуемым.

Не изменяй точки и центроиды внутри функции. Её задача заканчивается сразу после назначения: пересчитывать положения центроидов пока не нужно.

> 🎒 **На пальцах.** Представь почтовый стол с несколькими пронумерованными ячейками. Ты берёшь письма по очереди и для каждого записываешь номер ближайшей ячейки. В итоговом списке лежат не сами письма и не расстояния, а только номера: например, `[0, 2, 2, 1]`. По позиции номера всегда можно понять, к какому письму он относится.
