Перед тобой печенье из двух печей, но на противнях нет подписей. Ты хочешь восстановить средний размер и разброс для каждой партии. Проблема замыкается в круг: чтобы понять, из какой печи печенье, нужны параметры партий; чтобы уточнить параметры, нужно знать, какое печенье к какой партии относится.

EM разрывает этот круг чередованием двух временных решений.

Сначала идёт **E-шаг** — оценка принадлежностей. Текущие центры, разбросы и доли групп из [шага 40](#step-40) пока считаются верными. Для каждого объекта модель вычисляет мягкие принадлежности, знакомые по [шагу 39](#step-39): например, печенье могло с вероятностью 0,8 прийти из первой печи и с вероятностью 0,2 — из второй.

Затем наступает **M-шаг** — обновление параметров. Модель использует эти числа как веса: объект с принадлежностью 0,8 сильно влияет на параметры первой группы и слабее — на параметры второй. Так пересчитываются центр, разброс и доля каждой группы.

Но новые параметры меняют оценки принадлежности. Поэтому модель снова выполняет E-шаг, затем M-шаг и продолжает чередование. Когда очередное обновление почти не сдвигает параметры, цикл останавливается. EM не угадывает всё за один раз: каждая половина цикла улучшает данные для другой.

> 🎒 **На пальцах.** Ты сортируешь печенье между двумя печами не категорично, а дробными голосами. Сначала каждое печенье голосует за обе печи: крупное — на 80% за первую и на 20% за вторую. Затем по сумме этих голосов ты уточняешь портрет каждой партии. С обновлёнными портретами голоса становятся точнее — и круг повторяется.
