После `assign_clusters` из [шага 9](#step-9) у тебя есть несколько списков точек. Теперь представь, что в первом оказались `[1, 3]` и `[3, 5]`. Новый центр этой группы должен стать `[2, 4]`: отдельно усредняются первые координаты, затем вторые — именно этот принцип разобран в [шаге 10](#step-10).

Твоя задача — написать `update_centroids`. Функция получает кластеры, исходные данные и количество признаков `n_features`, а возвращает список новых центроидов. Порядок важен: первый центроид рассчитывается по первому кластеру, второй — по второму и так далее.

Для каждого непустого кластера собери новый список координат. Перебирай номера признаков от `0` до `n_features - 1`, складывай соответствующие координаты всех точек и дели сумму на количество точек в кластере. Не усредняй точки целиком одним числом: у каждого признака должно получиться собственное среднее.

Есть неприятный случай: кластер может оказаться пустым. Тогда делить не на что, и программа завершится ошибкой. Для такого кластера выбери случайную точку из `data` и используй её как новый центроид. Так у группы снова появится центр, к которому на следующем проходе смогут присоединиться точки.

Проверь две вещи: функция возвращает ровно столько центроидов, сколько получила кластеров, а каждый центроид содержит ровно `n_features` координат.

> 🎒 **На пальцах.** Представь несколько столиков для команд на викторине. После пересадки ты ставишь табличку каждой команды в среднюю точку между её участниками. Если за столиком никого не осталось, среднюю точку найти нельзя — поэтому ты временно переносишь табличку к случайному участнику в зале. Пустой столик снова получает ориентир.
