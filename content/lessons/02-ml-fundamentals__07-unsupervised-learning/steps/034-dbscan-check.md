  - question: >-
      В собственной eps-окрестности точки A достаточно точек для выполнения
      min_samples. Точке B собственной плотности не хватает, но она находится в
      eps-окрестности A. Точке C собственной плотности тоже не хватает, и рядом
      с core-точками её нет. Какие роли получат точки?
    options:
      - 'A — core, B — border, C — noise'
      - 'A — core, B — noise, C — border'
      - 'A — border, B — core, C — noise'
    correct: 0
    explanation: >-
      A становится core благодаря плотной собственной окрестности. B не является
      core, но примыкает к core-точке, поэтому это border. C не является ни
      core, ни соседом core-точки, поэтому это noise.
  - question: >-
      Точку, отмеченную как noise, переместили в eps-окрестность core-точки. В
      её собственной окрестности по-прежнему недостаточно точек для выполнения
      min_samples. Какой станет её роль?
    options:
      - Core
      - Border
      - Noise
      - Она образует отдельный кластер
    correct: 1
    explanation: >-
      Собственной плотности недостаточно для роли core, однако нахождение в
      eps-окрестности core-точки делает эту точку border.

Здесь важно применять роли из [шага 29](#step-29) в правильном порядке: сначала проверь собственную окрестность точки, затем — близость к core-точке. Частая ошибка — считать любую точку с малым числом соседей border. Без core-точки рядом она остаётся noise.

> 🎒 **На пальцах.** Представь оживлённый рынок. В плотном ряду прилавков продавец — core. Продавец у самого края ряда, вокруг которого людей меньше, — border, если он всё ещё рядом с плотной частью. Одинокий торговец далеко от остальных — noise. Важна не внешняя позиция, а соседи в заданном радиусе.
