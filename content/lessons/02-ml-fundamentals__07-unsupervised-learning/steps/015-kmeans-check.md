Здесь важно проследить именно полную итерацию: сначала каждая точка выбирает ближайший центроид по правилу из [шага 8](#step-8), а затем центроиды пересчитываются по правилу из [шага 10](#step-10). Частая ошибка — мысленно передвинуть первый центроид и тут же заново распределить точки. Это уже начало следующей итерации, а не продолжение текущей.

Держи два снимка отдельно: назначения сделаны по старым центроидам, новые центроиды появляются только после этого. Именно такое чередование составляет алгоритм из [шага 12](#step-12).
