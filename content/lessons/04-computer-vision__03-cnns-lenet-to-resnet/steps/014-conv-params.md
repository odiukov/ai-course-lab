Ты запускаешь функцию для первого слоя LeNet-5 и получаешь `150`. Число выглядит правдоподобно: шесть фильтров, в каждом по 25 весов. Но в `nn.Conv2d` есть ещё шесть обучаемых смещений — по одному для каждого выходного канала. Правильный результат поэтому равен `156`.

Перенеси правило из [шага 13](#step-13) в функцию `conv_params`. Она принимает:

- `in_channels` — число входных каналов;
- `out_channels` — число выходных каналов, а значит и фильтров;
- `kernel_size` — сторону квадратного ядра.

Функция должна вернуть общее число обучаемых параметров: веса всех фильтров вместе с их смещениями.

```python
def conv_params(in_channels, out_channels, kernel_size):
    # Посчитай веса всех фильтров.
    # Затем добавь по одному смещению на выходной канал.
    pass
```

Проверь реализацию на двух свёртках LeNet-5:

```python
assert conv_params(1, 6, 5) == 156
assert conv_params(6, 16, 5) == 2416
```

Следи за двумя частыми ошибками. Ядро `5 × 5` содержит 25 весов, а не 10. Кроме того, каждый фильтр проходит через **все** входные каналы: во второй свёртке один фильтр состоит уже не из одного, а из шести ядер `5 × 5`.

Если обе проверки проходят, функция считает именно параметры слоя, а не только его ядра.

> 🎒 **На пальцах.** Представь набор штампов для цветной печати. Каждый готовый рисунок требует отдельного штампа для каждого входного цвета, поэтому деталей становится больше вместе с числом каналов. А к каждому рисунку прилагается ещё одна ручка настройки яркости — смещение. Посчитать только пластины и забыть ручки значит получить те самые ошибочные `150` вместо `156`.
