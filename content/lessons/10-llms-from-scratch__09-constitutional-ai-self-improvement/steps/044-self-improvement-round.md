Перед тобой три промпта, и для каждого модель восемь раз выдаёт ответ. Отдельные функции уже умеют оценивать ответы и считать групповые преимущества, но пока результаты лежат разрозненно. Тебе нужно собрать один раунд, который превратит их в данные для будущего обновления модели.

Напиши `self_improvement_round(prompts, policy_sampler, group_size=8)`. Для каждого промпта функция должна:

1. Вызвать `policy_sampler(prompt)` ровно `group_size` раз.
2. Рассчитать итоговую награду каждого ответа по правилу из [шага 27](#step-27).
3. Передать список наград в `group_relative_advantage` из [шага 32](#step-32).
4. Найти ответ с максимальной наградой.
5. Сохранить запись с промптом, средним, максимальным и стандартным отклонением наград, лучшим ответом и списком преимуществ.

Верни словарь с двумя полями: `per_prompt` содержит записи для отдельных промптов, а `overall_mean` — среднее значение `mean_reward` по всем промптам. Числа NumPy преобразуй в обычные `float`, а массив преимуществ — в список: тогда результат можно будет без проблем сериализовать и вывести.

Проследи, чтобы лучший ответ выбирался по индексу максимальной награды, а не по максимальному преимуществу. Обычно индексы совпадут, но именно награда определяет победителя; преимущество показывает его положение относительно текущей группы.

Здесь функция ничего не обучает. Она готовит один согласованный пакет: ответы, оценки и относительный обучающий сигнал, спроектированный в [шаге 43](#step-43). Оптимизатор сможет использовать его позже — сейчас важно не потерять соответствие между ответом, наградой и преимуществом.

> 🎒 **На пальцах.** Представь разведку месторождения: для каждого участка ты берёшь восемь проб грунта, измеряешь содержание металла и отмечаешь лучшую. Затем сравниваешь каждую пробу со средним именно этого участка. `self_improvement_round` — журнал экспедиции: он ещё не запускает добычу, но собирает измерения так, чтобы следующая команда точно знала, где и насколько сильным оказался сигнал.
