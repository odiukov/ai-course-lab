    options:
      - 'Примерно 1, 1, −1 и −1'
      - '1, 1, 0 и 0'

  - question: >-

    options:
      - >-
        Нулевые преимущества для обеих: первая задача уже освоена, а вторая пока

      - Положительные преимущества для первой и отрицательные для второй
      - >-
        Нули только для первой, потому что верные ответы больше не нужно

      - 'Нули только для второй, потому что среди ошибок нельзя выбрать лучшую'
    correct: 0

Теперь тебе нужно связать нормирование из [шага 31](#step-31) с крайними случаями функции из [шага 32](#step-32). Главная ловушка — принять нулевое преимущество за оценку качества ответа. Оно говорит не «ответ нейтральный», а «в этой группе нет различий, по которым можно учиться».

Если часть попыток успешна, положительные и отрицательные преимущества показывают направление обновления. Если верны все или не верна ни одна, направление исчезает. При этом одинаковые нули требуют разной диагностики: промпт либо уже освоен, либо пока слишком труден для текущей модели.
