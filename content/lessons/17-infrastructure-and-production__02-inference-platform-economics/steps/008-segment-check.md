Проверь, можешь ли ты выбирать сегмент не по названию компании, а по главному ограничению задачи. Для мгновенного диалога решающей становится задержка из [шага 5](#step-5), для управляемого развёртывания — инфраструктурная работа из [шага 6](#step-6), а для быстрого доступа к разным моделям — удобство каталога из [шага 7](#step-7).

Частая ловушка — считать эти сегменты жёсткими коробками. Продукты могут пересекаться по функциям; граница проходит по их основному экономическому предложению. Сначала назови главное ограничение нагрузки, затем ищи сегмент, который снимает именно его.
