Ты запускаешь модель для 12 аудиофрагментов. Одно предсказание стоит €0,04, поэтому ожидаемый расход — €0,48. Затем меняешь количество запусков на ноль: теперь функция должна вернуть ноль, а не стоимость одного запуска.

Напиши функцию `per_prediction_cost`, которая принимает:

- `price_per_prediction` — цену одного предсказания;
- `prediction_count` — количество предсказаний.

Верни общую стоимость числом. Правило расчёта уже разобрано в [шаге 20](#step-20), поэтому здесь твоя задача — аккуратно превратить его в функцию:

```python
def per_prediction_cost(
    price_per_prediction: float,
    prediction_count: int,
) -> float:
    # Напиши вычисление здесь
```

Проверь себя на нескольких случаях:

```python
per_prediction_cost(0.04, 12)  # ожидается 0.48
per_prediction_cost(1.25, 1)   # ожидается 1.25
per_prediction_cost(0.04, 0)   # ожидается 0.0
```

Обрати внимание на порядок аргументов: сначала цена одной операции, затем их количество. Не подставляй конкретные числа внутрь функции — она должна одинаково работать и для аудио, и для изображения, и для видео.

Если результат вроде `0.48000000000000004` немного отличается внешне, это не ошибка твоего расчёта, а особенность хранения дробных чисел в Python. Пока не округляй значение внутри функции: точность отображения и сам расчёт — разные задачи.
