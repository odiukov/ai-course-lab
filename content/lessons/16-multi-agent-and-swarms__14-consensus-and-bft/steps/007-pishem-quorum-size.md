Ты вызываешь `quorum_size(n)` для сети из десяти узлов и получаешь `6`. Похоже на обычное большинство, но для PBFT это неверный порог: шесть голосов могут не образовать сертификат, достаточный при допустимом числе нарушителей.

Здесь важно не считать половину узлов. Функция должна связать две уже готовые идеи:

- определить допустимое число византийских узлов с помощью `max_faulty(n)`, написанной в [шаге 5](#step-5);
- по найденному `f` вернуть число совместимых голосов, необходимое сертификату из [шага 6](#step-6).

Не копируй внутрь новой функции вычисления из `max_faulty`: вызови её. Тогда правило допустимых сбоев останется в одном месте, а `quorum_size` будет отвечать только за порог голосов.

Проверь три вещи: функция принимает общее число узлов `n`, использует результат `max_faulty(n)` и возвращает целое число. Для десяти узлов допустимы три нарушителя, поэтому сертификату нужны семь совместимых голосов. Если получилось шесть или десять, ты, вероятно, посчитал простое большинство либо потребовал согласия всех.

> 🎒 **На пальцах.** Представь сейф с двумя настройками. Первая определяет, сколько держателей ключей могут оказаться вредителями; её уже выставляет `max_faulty`. Вторая решает, сколько совместимых ключей откроют сейф. `quorum_size` не пересчитывает первую настройку, а берёт её результат и устанавливает безопасный порог открытия.
