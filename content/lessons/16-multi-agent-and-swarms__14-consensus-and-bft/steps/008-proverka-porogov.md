check:
  - question: >-
      Почему quorum_size должна получать допустимое число сбоев через вызов
      max_faulty(n), а не повторять тот же расчёт внутри себя?
    options:
      - >-
        Чтобы правило определения допустимых сбоев оставалось в одном месте и
        функции не расходились при изменениях
      - Чтобы quorum_size всегда возвращала общее число узлов
      - Чтобы max_faulty могла проверять цифровые подписи
      - Чтобы заменить кворум единогласным решением
    correct: 0
    explanation: >-
      max_faulty отвечает за бюджет византийских сбоев, а quorum_size использует
      найденный f для вычисления порога сертификата. Такое разделение не
      дублирует одно правило в двух функциях.
  - question: >-
      Почему в реализации PBFT нельзя заменить результат quorum_size обычным
      большинством голосов?
    options:
      - >-
        Обычное большинство не учитывает допустимый бюджет византийских
        участников и может быть меньше требуемого порога сертификата
      - PBFT принимает решение только при единогласии всех участников
      - Обычное большинство нельзя вычислить для нечётного числа узлов
      - Цифровые подписи работают только при чётном размере кворума
    correct: 0
    explanation: >-
      Порог PBFT выводится из допустимого числа византийских сбоев. Поэтому для
      четырёх узлов нужны три совместимых голоса, а для семи — пять, хотя
      обычное большинство во втором случае составило бы четыре.
---

Здесь важно состыковать две написанные функции: `max_faulty` из [шага 5](#step-5) определяет бюджет сбоев, а `quorum_size` из [шага 7](#step-7) — нужное число совместимых голосов. Частая ошибка — взять простое большинство: для семи узлов это четыре голоса, но PBFT требует пять. Проверь пары: 4 узла дают 1 сбой и кворум 3; 7 узлов — 2 сбоя и кворум 5.
