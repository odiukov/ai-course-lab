Ты дочитал [шаги 2](#step-2)–[4](#step-4) и, скорее всего, унёс из них ощущение: три провайдера — три отдельных мира, и в каждом надо жить заново. Давай проверим это ощущение числом. Сведём все расхождения в одну таблицу и посмотрим, сколько их на самом деле.

| Что сравниваем | OpenAI | Anthropic | Gemini |
|--------|--------|-----------|--------|
| Оболочка объявления | `{type: "function", function: {...}}` | `{name, description, input_schema}` | `{functionDeclarations: [{...}]}` |
| Поле схемы | `parameters` | `input_schema` | `parameters` |
| Контейнер ответа | `tool_calls[]` в сообщении ассистента | `content[]` с типом `tool_use` | `parts[]` с типом `functionCall` |
| Тип аргументов | JSON строкой | разобранный объект | разобранный объект |
| Формат id | `call_...` | `toolu_...` | UUID (Gemini 3+) |
| Блок результата | роль `tool`, `tool_call_id` | `user` с `tool_result`, `tool_use_id` | `functionResponse` с совпадающим `id` |
| Заставить вызвать инструмент | `tool_choice: {type: "function", function: {name}}` | `tool_choice: {type: "tool", name}` | `tool_config: {function_calling_config: {mode: "ANY"}}` |
| Запретить инструменты | `tool_choice: "none"` | `tool_choice: {type: "none"}` | `mode: "NONE"` |
| Строгая схема | `strict: true` | схема и есть контракт | `responseSchema` на уровне запроса |

Девять строк. Не девяносто.

И теперь главное: почти каждая строка — это одна строчка кода в трансляторе. Строку «Поле схемы» ты уже прошёл руками в [шаге 11](#step-11): один и тот же объект, только ключ зовётся то `parameters`, то `input_schema`. Одна замена ключа.

Посмотри на строку «Формат id». Три разных вида — `call_...`, `toolu_...`, UUID — и ни один из них ты не придумываешь сам: id генерирует провайдер, тебе остаётся положить его обратно в результат нетронутым. То есть строка различий есть, а работы по ней — ноль.

Так и с остальными: «Тип аргументов» — один `json.loads` (об этом был [шаг 6](#step-6)), «Оболочка объявления» — обернуть словарь в нужную обёртку. Страшным казался не объём различий, а то, что их не пересчитали.

> 🎒 **На пальцах.** Ты снял квартиру, и прежний жилец оставил записку из девяти пунктов: горячая вода — левый кран, мусор — по вторникам, свет в кладовке — тумблер в коридоре. Жизнь та же самая, просто девять поправок. Пока пунктов не пересчитали, кажется, что придётся учиться жить заново. После пересчёта — это листок на холодильнике.
