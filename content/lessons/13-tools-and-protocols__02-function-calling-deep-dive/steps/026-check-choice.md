check:
  - question: >-
      Агент снова вызывает инструмент, хотя все необходимые данные уже собраны.
      Какой режим следует установить на финальном ходе?
    options:
      - Auto — модель сама обязательно решит перейти к тексту
      - None — вызовы инструментов будут запрещены на этом ходе
      - Required — модель выполнит заключительный обязательный вызов
      - VALIDATED — любой вызов автоматически превратится в текст
    correct: 1
    explanation: >-
      В режиме Auto модель всё ещё может выбрать инструмент, а Required требует
      хотя бы одного вызова. None запрещает вызовы на финальном ходе и тем самым
      направляет модель к текстовому ответу.
  - question: >-
      Нужно заставить модель вызвать конкретный инструмент get_weather по имени.
      Какие провайдеры поддерживают описанный в уроке режим выбора инструмента
      по имени?
    options:
      - Только OpenAI
      - OpenAI и Anthropic
      - Anthropic и Gemini
      - Все три провайдера
    correct: 1
    explanation: >-
      OpenAI и Anthropic позволяют указать имя требуемого инструмента.
      Уникальный дополнительный режим Gemini — VALIDATED: он проверяет ответ по
      схеме, а не выбирает конкретный инструмент по имени.

Три режима из [шага 22](#step-22) и по одному «своему» у каждого провайдера из [шага 23](#step-23) складываются в сетку, по которой ты теперь должен уметь ходить в обе стороны: от задачи — к режиму и к имени поля, и обратно.

Спотыкаются обычно на двух местах. Первое: None путают с «не передавать инструменты вообще». Инструменты остаются в запросе, модель их видит — ей просто запрещено их вызывать на этом ходу. Второе: думают, что Required и «вызови вот этот по имени» — одно и то же. Required говорит «хоть один», имя говорит «ровно этот». Разница видна как раз тогда, когда инструментов у тебя двадцать.
