title: 'Предельный вклад: добавляем агентов по одному в заданном порядке'
source_anchor: '### Shapley-value credit attribution'
---

Три агента готовят ответ о новом рынке: A собирает данные, B проверяет факты, C превращает материалы в понятный вывод. Из [шага 11](#step-11) у тебя уже есть оценки разных коалиций. Теперь выбери один порядок: A → C → B — и мысленно запускай агентов по очереди.

Сначала никого нет, поэтому оценка результата равна 0. После добавления A она становится 0,35. Предельный вклад A в этом порядке — прирост на 0,35.

Затем приходит C. Вместе A и C получают оценку 0,50. Не записывай C все 0,50: часть результата уже создал A. Вклад C равен разнице между новым и прежним состоянием: 0,50 − 0,35 = 0,15.

Последним добавляется B, и оценка полной команды поднимается до 0,80. Значит, вклад B здесь равен 0,80 − 0,50 = 0,30.

Получились три вклада: 0,35, 0,15 и 0,30. Их сумма равна итоговым 0,80, потому что каждый скачок учитывается ровно один раз. Но это не «личные качества» агентов навсегда. Число показывает, сколько агент добавил именно к уже собранной перед ним команде. В другом порядке перед ним окажутся другие возможности — и скачок может измениться.

> 🎒 **На пальцах.** Представь сборку музейного аудиогида. Первый участник приносит записи интервью, второй вырезает шум, третий добавляет музыку. Ты после каждого входа слушаешь текущую версию и отмечаешь, насколько она стала лучше. Монтажёр получает заслугу не за всё звучание готового гида, а только за улучшение относительно версии, которую получил на входе. Предельный вклад — это разница между двумя соседними прослушиваниями.
