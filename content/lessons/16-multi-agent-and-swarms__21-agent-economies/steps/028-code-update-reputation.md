У агента репутация `0.8`, а качество нового подтверждённого вклада — `0.4`. Если просто заменить первое число вторым, один неудачный результат мгновенно уничтожит накопленное доверие. Твоя функция должна обновлять оценку мягче — по правилу из [шага 27](#step-27).

Напиши `update_reputation(old_rep, quality, alpha)`. Она получает:

- `old_rep` — прежнюю репутацию;
- `quality` — качество нового вклада;
- `alpha` — долю прежней истории в новой оценке.

Верни одно число: обновлённую репутацию. Не округляй результат внутри функции — иначе при последовательных обновлениях маленькие ошибки начнут накапливаться.

Проверь себя на значениях `old_rep = 0.6`, `quality = 0.2`, `alpha = 0.75`. Старая оценка должна дать `0.45`, новая — `0.05`, поэтому результат равен `0.5`.

Особенно полезны две крайние проверки. При `alpha = 1` новый вклад вообще не влияет на репутацию. При `alpha = 0` история полностью отбрасывается, и результат совпадает с `quality`. Если эти случаи работают наоборот, значит, веса перепутаны местами.

> 🎒 **На пальцах.** Представь банку кофейной смеси: в ней уже есть зёрна старой обжарки, а ты досыпаешь немного новой. `alpha` показывает, какую долю прежней смеси ты сохраняешь. Если он близок к единице, одна горсть почти не изменит вкус. Функция делает то же с доверием: смешивает накопленную оценку с новым подтверждённым результатом.
