Допустим, у тебя восемь агентов. Полный `shapley` из [шага 15](#step-15) пытается перебрать все порядки, хотя для приближения достаточно взять лишь несколько случайных. Твоя новая функция `shapley_sampled` должна вернуть такой же словарь «агент → средний вклад», но работать с заданным числом выборок `K`.

Сначала создай накопитель: каждому агенту соответствует ноль. Затем `K` раз получай новый случайный порядок всех агентов. Для каждого порядка вызови `marginal_contributions` из [шага 13](#step-13) и прибавь найденные вклады к накопителю. Когда все выборки обработаны, раздели сумму каждого агента на `K`.

Следи за тремя деталями. В каждой итерации нужен новый случайный порядок, иначе функция просто повторит один и тот же расчёт. Исходный список агентов лучше не перемешивать на месте: его неожиданное изменение может повлиять на код снаружи. Наконец, усредняй только после завершения цикла — так проще не потерять вклад и не разделить его дважды.

Для воспроизводимого теста генератор случайных чисел можно зафиксировать одним и тем же `seed`: тогда при каждом запуске будут выбираться одинаковые порядки. Проверь также связь с [шагом 16](#step-16): сумма возвращённых значений должна совпадать с общей созданной ценностью, если `marginal_contributions` обрабатывает каждого агента в каждом выбранном порядке.

> 🎒 **На пальцах.** Представь контролёра, который несколько раз тасует очередь выступающих на школьной ярмарке. После каждого запуска он записывает, насколько каждый новый участник увеличил выручку стенда. Одной очереди доверять нельзя, поэтому записи складываются по именам, а в конце для каждого участника считается среднее. `shapley_sampled` делает именно эту бухгалтерию случайных очередей.
