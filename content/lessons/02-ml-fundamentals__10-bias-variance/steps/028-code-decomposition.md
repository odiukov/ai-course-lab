Перед тобой таблица предсказаний: каждая строка получена отдельной моделью, каждый столбец относится к одной тестовой точке. Одно среднее по всей таблице уничтожило бы важное различие: модели могут дружно ошибаться в одном направлении или сильно расходиться между собой.

Напиши функцию `bias_variance_decomposition(predictions, y_true)`. `predictions` — двумерный массив формы «число моделей × число точек», а `y_true` — правильные значения в этих точках.

Функция должна вернуть три числа:

- `bias_sq`: сначала собери среднее предсказание для каждой точки, затем найди средний квадрат его отклонения от `y_true`;
- `variance`: для каждой точки измерь разброс предсказаний разных моделей, затем усредни полученные значения;
- `total_error`: найди средний квадрат всех отклонений `predictions` от `y_true`.

Здесь удобно использовать методы `mean` и `var` с параметром `axis`, а NumPy сам растянет `y_true` на все строки при вычитании. Следи за формами промежуточных массивов: среднее предсказание должно содержать по одному числу на тестовую точку, а итоговые характеристики — быть отдельными числами.

Сравни результат с разложением из [шага 11](#step-11): если `y_true` содержит истинные значения без случайного шума, `total_error` должен практически совпасть с суммой `bias_sq` и `variance`. Значит, три вычисления действительно описывают одну ошибку с разных сторон.

> 🎒 **На пальцах.** Представь, что 200 геодезистов независимо отмечают на карте одни и те же ориентиры. Для каждого ориентира ты сначала находишь среднюю отметку и сравниваешь её с настоящей координатой — это даёт bias². Затем смотришь, насколько отметки разбросаны вокруг средней, — это variance. Общая ошибка учитывает сразу все отметки относительно настоящих координат.
