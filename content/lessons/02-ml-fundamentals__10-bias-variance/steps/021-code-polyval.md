У тебя есть коэффициенты полинома из [шага 20](#step-20): например, `[3, 2, -1]`. Теперь нужно получить предсказания для точек `x`. Здесь легко перепутать порядок: в нашей функции первый элемент — свободный член, второй умножается на `x`, третий — на `x` в квадрате. Поэтому для `x = 2` результат будет `3 + 2·2 − 1·4 = 3`.

Напиши функцию `polyval(x, w)`, которая принимает число или массив точек `x` и коэффициенты `w`, а возвращает значения полинома во всех этих точках. Функция ничего не обучает и не меняет коэффициенты — она только превращает уже заданную модель в предсказания.

Начни с результата, заполненного нулями той же формы, что и `x`. Затем перебери коэффициенты вместе с их индексами: индекс подсказывает, в какую степень возводить `x`. Каждый получившийся вклад прибавляй к общему результату.

Проверь себя на простых случаях. Коэффициенты `[5]` должны давать `5` для любого `x`. Коэффициенты `[1, 2]` на точках `[0, 1, 3]` должны вернуть `[1, 3, 7]`. Обрати внимание и на тип данных: результату может понадобиться хранить дробные числа, даже если точки заданы целыми.

Главная ловушка здесь не в вычислениях, а в соглашении о порядке коэффициентов: `w[0]` отвечает за степень ноль, `w[1]` — за первую степень и так далее.

> 🎒 **На пальцах.** Представь автомат для смешивания краски. Первая ёмкость всегда добавляет фиксированную порцию, вторая дозирует краску пропорционально положению ручки `x`, третья — пропорционально `x²`. Коэффициенты задают размер каждой порции, а `polyval` лишь поворачивает ручку в нужные положения и складывает добавки. Настраивать ёмкости этот автомат пока не умеет.
