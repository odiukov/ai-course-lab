Ты только что собрал `rerank` руками — на эвристиках из [шага 37](#step-37). Работает, но балл там придуман тобой: совпадения слов, длина, немного вкуса. И вот вопрос, который наверняка уже вертится: чтобы заменить эту самоделку на настоящий cross-encoder из [шага 33](#step-33), надо переписывать пол-конвейера?

Нет. Меняется одна строка — та, где берётся балл.

```python
from sentence_transformers import CrossEncoder

reranker = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2")

def rerank_with_cross_encoder(query, candidates, chunks, top_k=5):
    pairs = [(query, chunks[doc_id]) for doc_id, _ in candidates]
    scores = reranker.predict(pairs)
    scored = list(zip([doc_id for doc_id, _ in candidates], scores))
    scored.sort(key=lambda x: x[1], reverse=True)
    return scored[:top_k]
```

Посмотри на подпись: `query`, `candidates`, `chunks`, `top_k` — ровно те же аргументы, что у твоей функции, и на выходе тот же список пар «id, балл». Значит `hybrid_search` из [шага 29](#step-29) не трогаем вообще: он как отдавал 50 кандидатов, так и отдаёт.

Внутри — `pairs`: 50 штук вида «запрос + текст чанка», склеенных в один вход, потому что cross-encoder иначе смотреть не умеет. Дальше `predict` прогоняет всю пачку разом, а не по одной: это единственное место, где спрятана та самая цена из [шага 34](#step-34). Первый запуск ещё скачает модель — десятки мегабайт, потом она лежит локально.

Три строки логики, и балл больше не твоя догадка, а обученная модель.

> 🎒 **На пальцах.** Это как сменить объектив на камере. Байонет тот же, тушка та же, кнопка спуска на месте — ты не пересобираешь фотоаппарат. Меняется только стекло, через которое он смотрит на сцену: раньше мутновато, теперь видно, кто в кадре главный. `hybrid_search` — тушка, `rerank` — объектив.
