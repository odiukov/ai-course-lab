Ты передаёшь функции три веса: положительный, отрицательный и нулевой. На выходе должны получиться три отдельные L2-добавки к градиенту — в том же порядке. Если случайно сложить их в одно число, оптимизатор уже не поймёт, какой вес и насколько нужно изменить.

Напиши `l2_gradient(weights, lambda_reg)`. Функция получает список весов и коэффициент регуляризации, а возвращает новый список такой же длины. Для каждого веса вычисли его вклад в градиент по правилу из [шага 22](#step-22): умножь вес на `lambda_reg`.

Проверь себя на примере: для весов `2.0`, `-0.5` и `0.0` при `lambda_reg = 0.1` результат должен содержать `0.2`, `-0.05` и `0.0`.

Обрати внимание на знаки. Отрицательный вес даёт отрицательную добавку, а не положительную: здесь нет возведения в квадрат. Квадраты использовались при вычислении штрафа в функции из [шага 21](#step-21), но её градиент уже имеет другую форму. Нулевой вес остаётся нулевым.

Ещё одна полезная проверка: исходный список весов не должен измениться. Функция лишь создаёт значения, которые позже прибавят к градиенту основной задачи. Значит, каждому входному весу соответствует ровно одно выходное число.

> 🎒 **На пальцах.** Представь ряд пружин, прикреплённых к отметке ноль. Чем дальше груз отклонился вправо или влево, тем сильнее пружина тянет его обратно. `lambda_reg` задаёт жёсткость пружин, а каждый вес — текущее отклонение своего груза. Тебе нужно записать силу для каждого груза отдельно, сохранив направление отклонения.
