Ты получаешь вектор `x` — например, активации одного токена — и отдельный множитель `gamma` для каждой его координаты. Напиши функцию:

```python
def rms_norm(x, gamma, eps=1e-6):
    # твоя реализация
```

Сначала найди RMS всего вектора по правилу из [шага 41](#step-41). Обрати внимание: среднее значение элементов вычитать не нужно. Затем раздели каждый `x[j]` на общий RMS и умножь результат на соответствующий `gamma[j]`.

Здесь легко случайно применить один `gamma` ко всему вектору. Но `gamma` — список: у первой координаты свой множитель, у второй свой и так далее. Поэтому `x` и `gamma` должны иметь одинаковую длину.

Проверь функцию на трёх случаях:

- при `gamma`, состоящем из единиц, меняется только масштаб вектора;
- разные значения `gamma` по-разному растягивают координаты;
- нулевой вектор не вызывает деления на ноль благодаря `eps` и остаётся нулевым.

Функция должна вернуть новый список и не изменять входной `x`.

> 🎒 **На пальцах.** Представь ряд ползунков громкости. Сначала ты измеряешь общий уровень сигнала и одним движением приводишь всю запись к устойчивой громкости. Затем проходишь по ползункам отдельно: первый оставляешь как есть, второй усиливаешь, третий приглушаешь. Общий RMS задаёт единую опору, а элементы `gamma` возвращают каждой координате собственную настройку.
