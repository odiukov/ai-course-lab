title: BatchNorm нормализует каждый признак по примерам батча

---

Ты подаёшь слою четыре фотографии. Для каждой он выдаёт несколько чисел: один признак реагирует на яркость, другой — на вертикальные границы, третий — на цвет. Признак здесь можно представить как отдельный измерительный прибор: для каждой фотографии он показывает своё значение.

Возникает неудобство. У одного такого «прибора» значения могут лежать примерно между 0 и 2, а у другого — между 80 и 200. Причём после обновления весов эти диапазоны способны заметно измениться. Следующему слою приходится постоянно приспосабливаться к движущимся шкалам.

Batch Normalization, или BatchNorm, берёт мини-батч — небольшую группу примеров, обрабатываемую вместе, — и приводит значения к сопоставимому масштабу. Но он не сваливает все числа в одну общую корзину. Значения яркости сравниваются с яркостью остальных фотографий батча, значения границ — с границами, значения цвета — с цветом.

В результате каждое число начинает описывать не просто «сколько получилось», а положение примера относительно других примеров по тому же признаку. Сами фотографии при этом не смешиваются, и один признак не подменяется другим. BatchNorm лишь заново настраивает отдельную шкалу каждого признака по текущей группе примеров.

> 🎒 **На пальцах.** Представь соревнование, где участников оценивают отдельно по скорости, точности и выносливости. Результат в секундах нельзя напрямую сравнивать с числом попаданий. Поэтому ты сначала приводишь оценки скорости к общей шкале среди участников, затем отдельно делаешь то же для точности и выносливости. BatchNorm поступает так же: одна шкала — один признак, а сравнение идёт между примерами батча.
