Перед тобой батч: каждая строка — один пример, каждый столбец — отдельный признак. Если посчитать одно среднее сразу по всем числам, признаки смешаются: высокий доход повлияет на нормализацию возраста. Поэтому функция `batch_norm` должна обрабатывать каждый столбец независимо, как в [шаге 28](#step-28).

Сначала создай выход той же формы, что и вход. Затем для каждого признака:

1. Собери его значения из всех примеров батча.
2. Найди среднее и дисперсию по правилам из [шага 29](#step-29).
3. Нормализуй каждое значение и положи результат на прежнее место.

Обрати внимание на две частые ошибки. Дисперсию здесь нужно делить на размер батча, а не на размер батча минус один. А `eps` добавляется к дисперсии перед извлечением квадратного корня: если все значения признака одинаковы, без этой маленькой добавки возникнет деление на ноль.

Проверь результат не по отдельным числам, а по свойствам каждого столбца. Его среднее должно получиться близким к нулю, а дисперсия — близкой к единице. Из-за `eps` и округления совпадение может быть не идеальным. Исходный `batch` лучше не изменять: верни новую таблицу той же формы.

Пока не добавляй обучаемые коэффициенты и накопленную статистику — здесь ты реализуешь только три вычисления из [шага 29](#step-29).

> 🎒 **На пальцах.** Представь несколько линеек с разными шкалами: одна измеряет сантиметры, другая — километры. Ты не складываешь все отметки в одну кучу. Для каждой линейки отдельно находишь её центр и типичный разброс, а затем переносишь отметки на общую шкалу. Так же `batch_norm` проходит по столбцам, не смешивая разные признаки.
