Допустим, в слое 6 нейронов, а `p = 0.25`. Нельзя просто выключить первые один-два: тогда одни позиции всегда будут выпадать, а другие — всегда оставаться. Маска должна принять отдельное случайное решение для каждой позиции.

Напиши `dropout_mask`, которая возвращает список из нулей и единиц нужной длины:

- `0` означает «нейрон выключен»;
- `1` означает «нейрон оставлен»;
- вероятность получить `0` равна `p`.

Для каждой позиции сгенерируй новое случайное число от 0 до 1. Если оно меньше `p`, добавь в маску `0`, иначе — `1`. Обрати внимание: `p` — вероятность выключения, а не сохранения. При `p = 0.2` в длинной маске должно быть примерно 20% нулей, хотя в одном коротком запуске их может оказаться больше или меньше.

Проверь три вещи: длина результата совпадает с запрошенной, внутри есть только `0` и `1`, а повторные вызовы обычно дают разные маски. Здесь функция создаёт только маску — применять её к значениям пока не нужно.

Каждая позиция получает собственный случайный выбор, поэтому ни один нейрон не становится «назначенным на вылет».

> 🎒 **На пальцах.** Представь панель из шести лампочек. Для каждой лампочки ты отдельно тянешь жетон из мешка: чёрный выключает её, белый оставляет включённой. После каждого вытягивания жетон возвращается в мешок, поэтому решение для следующей лампочки начинается заново. Список состояний лампочек — и есть dropout-маска.
