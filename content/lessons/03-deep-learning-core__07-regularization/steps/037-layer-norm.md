Тебе приходит один пример с тремя признаками: `[1.0, 2.0, 3.0]`. Нельзя нормализовать каждый элемент отдельно — тогда у каждого единственного числа среднее совпадёт с ним самим и вся информация исчезнет. В `LayerNorm.forward` нужно рассматривать весь список как одну группу признаков, как в [шаге 36](#step-36).

Сначала вычисли среднее всех элементов `x`, затем variance — средний квадрат отклонения от этого среднего. Здесь делить нужно на число признаков, без поправки `-1`: это вычисление для нормализации, а не статистическая оценка по выборке.

После этого пройди по каждому признаку и:

1. Получи его нормализованное значение `x_h`, используя `eps` внутри квадратного корня.
2. Сохрани `x_h` в `self.x_hat` — эти значения понадобятся при дальнейшем вычислении градиентов.
3. Примени отдельные `gamma[j]` и `beta[j]`, знакомые по [шагу 31](#step-31).
4. Добавь результат в выходной список.

Проверь себя на `[1.0, 2.0, 3.0]` при `gamma = [1, 1, 1]` и `beta = [0, 0, 0]`: средний элемент должен превратиться в `0`, крайние — стать примерно `-1.225` и `1.225`. Их сумма будет близка к нулю, а порядок элементов сохранится.

Особенно внимательно следи за скобками: `eps` прибавляется к variance **до** извлечения корня. Если поместить его снаружи, защита от деления на ноль перестанет работать как задумано.

> 🎒 **На пальцах.** Представь три книги разной высоты на одной полке. Ты отмечаешь среднюю высоту, а затем для каждой книги записываешь, насколько она ниже или выше этой отметки в единицах общего разброса. `Gamma` позволяет отдельно растянуть каждую такую отметку, а `beta` — сдвинуть её. Книги остаются разными, но теперь их удобно сравнивать по общей шкале.
