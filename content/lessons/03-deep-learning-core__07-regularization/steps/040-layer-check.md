check:
  - question: >-
      Один и тот же вектор признаков подают непосредственно на LayerNorm сначала
      при обучении в составе батча, а затем отдельно при инференсе. Параметры
      gamma и beta не изменились. Каким будет выход слоя?
    options:
      - 'Другим: при инференсе слой использует статистики всего обучающего набора'
      - >-
        Тем же: среднее и дисперсия вычисляются заново по признакам этого
        вектора
      - 'Нулевым: нормализация при инференсе отключается'
      - 'Другим: статистики зависят от количества примеров в батче'
    correct: 1
    explanation: >-
      LayerNorm вычисляет среднее и дисперсию по признакам текущего
      представления. При одинаковых входе, gamma и beta его результат не зависит
      от режима модели и размера батча.
  - question: >-
      Почему для LayerNorm при переходе от обучения к инференсу не требуется
      переключаться на running mean и running variance?
    options:
      - Потому что LayerNorm перестаёт выполнять нормализацию
      - Потому что gamma и beta заменяют среднее и дисперсию
      - Потому что LayerNorm использует статистики первого обучающего батча
      - >-
        Потому что LayerNorm получает нужные статистики из текущего
        представления, а не накапливает их по батчам
    correct: 3
    explanation: >-
      Running statistics нужны BatchNorm, который при обучении оценивает
      статистики по батчу. LayerNorm нормализует каждое представление по его
      собственным признакам, поэтому накопленные статистики ему не нужны.
---

Проверь, можешь ли ты связать два факта: из [шага 36](#step-36) — статистики считаются по признакам одного примера, а из [шага 38](#step-38) — соседи по батчу не нужны. Частая ошибка здесь — перенести на LayerNorm поведение BatchNorm из [шага 32](#step-32) и искать у него накопленные статистики. Их нет: если входной вектор и параметры слоя одинаковы, результат LayerNorm тоже одинаков при train и inference.

> 🎒 **На пальцах.** Ты настраиваешь яркость одной фотографии по её собственным светлым и тёмным участкам. Неважно, лежит рядом ещё 31 снимок или фотография открыта одна: расчёт для неё не меняется. Поэтому отдельный режим обработки для одиночного просмотра не нужен.
