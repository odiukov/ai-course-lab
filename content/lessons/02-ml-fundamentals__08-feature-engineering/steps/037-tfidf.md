Ты запускаешь `tfidf()` на нескольких отзывах и получаешь странность: повторённое пять раз слово будто встречается в пяти документах. Значит, редкость посчитана неверно. Здесь важно различать два счётчика: сколько раз слово встретилось внутри одного текста и в скольких разных текстах оно появилось.

Напиши функцию `tfidf(documents)`, которая возвращает `vectors` и `vocab`. Сначала приведи слова к нижнему регистру и собери словарь: каждому слову назначь постоянный индекс. Именно по этому индексу его вес будет лежать во всех векторах.

Затем посчитай документную частоту. Для каждого документа создай новый `set` уже замеченных слов: если слово повторяется в одном тексте, документную частоту увеличивай только один раз. Типичная ошибка — хранить один общий `set`; тогда после первого документа счётчик почти перестанет расти.

При построении вектора отдельно обработай каждый документ:

- посчитай число появлений каждого слова;
- раздели его на общее количество слов в этом документе — получишь TF;
- вычисли IDF по правилу из [шага 36](#step-36);
- запиши произведение TF и IDF в позицию слова из `vocab`.

Проверь результат: длина каждого вектора совпадает с размером словаря, повторение слова повышает его TF, а слово из всех документов получает нулевой вес. Значит, вектор хранит не просто количество, а характерность слова.

> 🎒 **На пальцах.** Представь редактора, который выделяет маркером важные слова в письмах. Внутри одного письма повторение делает слово заметнее, но редактор не считает каждое повторение новым письмом. Затем он сравнивает всю стопку: слово из каждого письма перестаёт быть отличительным, а редкое получает яркое выделение. Позиция цвета в общей палитре — это индекс слова в `vocab`.
