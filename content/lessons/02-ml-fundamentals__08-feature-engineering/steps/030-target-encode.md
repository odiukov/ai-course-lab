
Сначала вычисли среднее всех ответов — оно понадобится как общая опорная величина. Затем одним проходом по парам категории и ответа собери словарь статистики. Для каждой категории храни две вещи: сумму её ответов и количество встреч.

Во втором проходе по словарю рассчитай средний ответ каждой категории. Параметр `smoothing` участвуй в весе категории: раздели количество её объектов на это же количество плюс `smoothing`. Итоговое значение категории составь из её среднего и общего среднего с помощью этого веса. Зачем нужна такая смесь, разберём отдельно; сейчас сосредоточься на последовательности вычислений.

Функция должна вернуть два результата:

- список закодированных значений в исходном порядке;
- словарь, по которому категорию можно заменить её числом.

Проверь три свойства: длина списка не изменилась, одинаковые категории получили одинаковые значения, а ключи словаря совпадают с уникальными категориями. Ещё посмотри, что ты не перепутал `feature_values` и `target_values` внутри `zip`: категория служит ключом, ответ прибавляется к сумме.
