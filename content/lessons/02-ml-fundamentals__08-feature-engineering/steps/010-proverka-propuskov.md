check:
  - question: >-
      В столбце с зарплатами есть пропуск, а среди известных значений
      встречается один аномально большой доход. Чем разумнее заполнить пропуск?
    options:
      - Средним значением
      - Медианой
      - Самой большой зарплатой
    correct: 1
    explanation: >-
      Аномально большой доход сильно сдвигает среднее, но почти не влияет на
      медиану. Поэтому медиана лучше отражает типичную зарплату.
  - question: >-
      В столбце с названиями городов пропущено значение. Какой способ заполнения
      подходит для такого признака?
    options:
      - Заполнить медианой
      - Заполнить средним
      - Заполнить самым частым городом
    correct: 2
    explanation: >-
      Город — категориальный признак: среднее и медиана для его значений не
      определены. Пропуск можно заполнить модой — самым частым городом.
---

Теперь тебе нужно выбирать заполнение не по привычке, а по смыслу столбца. Для чисел с выбросами пригодится медиана из [шага 8](#step-8), для категорий — самое частое значение. Главная ловушка: считать пропуск просто пустой ячейкой и применять один способ ко всем колонкам. Сначала спроси себя, какие значения здесь вообще возможны и что может исказить замену.

> 🎒 **На пальцах.** Представь ящик с инструментами: молоток хорош для гвоздя, но бесполезен для винта. Так же и заполнение пропуска: медиана подходит числам, а самое частое значение — категориям. Выбирай инструмент по материалу, а не по форме дырки.
