title: 'Проверка: честно ли закодированы категории'
source_anchor: '### Categorical Features'
check:
  - question: >-
      В признаке «район» четыре категории без естественного порядка. Какое
      кодирование честнее для обычной модели?
    options:
      - Присвоить районам числа от 0 до 3
      - Создать отдельный бинарный признак для каждого района
      - Заменить районы их позициями в алфавитном списке
    correct: 1
    explanation: >-
      Отдельные бинарные признаки не создают искусственного порядка между
      районами. Любая нумерация номинальных категорий может заставить модель
      воспринимать коды как упорядоченные величины.
  - question: >-
      Ты применяешь target encoding и хочешь честно оценить модель на тестовой
      выборке. Как поступить?
    options:
      - >-
        Посчитать средние целевой переменной по обучающей и тестовой выборкам
        вместе
      - Посчитать средние целевой переменной отдельно по тестовой выборке
      - >-
        Посчитать средние только по обучающей выборке и применить полученную
        кодировку к тестовой
    correct: 2
    explanation: >-
      Целевые значения тестовой выборки не должны участвовать в построении
      признаков. Иначе возникает утечка: кодировка содержит информацию об
      ответах, недоступную для новых объектов.
---

Теперь ты проверяешь не само умение превратить категории в числа, а честность результата. Для небольшого числа равноправных категорий флажки из [шага 24](#step-24) не выдумывают отношения между ними. Числовые метки из [шага 27](#step-27), напротив, незаметно создают порядок. У target encoding другая ловушка: среднее нельзя вычислять с участием ответов из тестовой выборки — это утечка из [шага 33](#step-33).

> 🎒 **На пальцах.** Представь дегустацию вслепую. Пронумеровать вкусы от 0 до 3 — всё равно что намекнуть судье, будто вкус 3 сильнее вкуса 1. А заранее показать среднюю оценку тестируемого напитка — уже подсмотреть в судейский лист. Честная маркировка не добавляет ни вымышленного порядка, ни знания будущего ответа.
