После `rle_encode` у тебя осталась строка `"0x3;1x2;0x1"` и форма `(2, 3)`. Если просто раскрыть серии, получится плоская последовательность из шести значений: три нуля, две единицы и ещё один ноль. Но пайплайну нужна исходная маска — две строки по три пикселя:

```text
0 0 0
1 1 0
```

Напиши функцию с таким контрактом:

```python
def rle_decode(encoded, shape):
    # восстанови плоский массив и верни его в форме shape
    ...
```

Сначала раздели `encoded` по `";"`, чтобы получить отдельные серии. В каждой серии символ `"x"` отделяет значение пикселя от количества повторений: у `"1x2"` значение равно `1`, а длина серии — `2`. Обе части приходят как текст, поэтому перед восстановлением их нужно превратить в целые числа.

Затем собери плоский массив: для каждой пары добавь указанное количество нулей или единиц. Используй тип `uint8`, как в `rle_encode` из [шага 19](#step-19). До `reshape` сравни число восстановленных элементов с произведением размеров `shape`. Например, форма `(2, 3)` требует ровно шесть значений; несовпадение означает повреждённый RLE, и функция должна явно сообщить об ошибке.

Пустая строка означает отсутствие серий. Она корректна только для формы с нулём элементов. Наконец, вызови `reshape(shape)`: порядок элементов совпадёт с тем, в котором `flatten()` развернул маску при кодировании.

> 🎒 **На пальцах.** Представь инструкцию для укладки мозаики: «три белые плитки, две чёрные, одна белая». Ты выкладываешь плитки в одну длинную полосу, но заранее знаешь, что рамка имеет две строки по три места. Если плиток оказалось пять или семь, в рамку их честно не уложить — значит, инструкция повреждена.
