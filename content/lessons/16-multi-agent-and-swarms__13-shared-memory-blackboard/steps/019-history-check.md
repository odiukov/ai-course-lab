title: Чем активный вид отличается от полной цепочки происхождения?
source_anchor: '### Why this is structural'
check:
  - question: >-
      В журнале запись B замещает A, запись C замещает B, а D ни с чем не
      связана. Что ты увидишь в активном виде и в цепочке происхождения для C?
    options:
      - 'Активный вид: C и D; цепочка для C: C, B, A'
      - 'Активный вид: A, B, C и D; цепочка для C: C и D'
      - 'Активный вид: C; цепочка для C: весь журнал'
    correct: 0
    explanation: >-
      Активный вид оставляет текущие незамещённые записи, а цепочка идёт только
      по предшественникам выбранной записи.
  - question: >-
      Тебе нужно понять, на основании какой исходной записи появилось текущее
      исправление. К чему ты обратишься?
    options:
      - Только к активному виду
      - К полной цепочке происхождения
      - К списку авторов всех активных записей
    correct: 1
    explanation: >-
      Активный вид показывает текущее состояние, но путь исправлений
      восстанавливает именно цепочка происхождения.
---

Проверь, различаешь ли ты два разных вопроса к одной памяти: «что считается актуальным сейчас?» и «как эта версия появилась?». На первый отвечает активный вид из [шага 15](#step-15), на второй — цепочка provenance из [шага 17](#step-17). Здесь чаще всего спотыкаются, принимая скрытую версию за удалённую или ожидая увидеть в цепочке весь журнал. Но активный вид скрывает прошлое, не уничтожая его, а цепочка выбирает только предков конкретной записи.

> 🎒 **На пальцах.** Представь табло прогноза погоды и архив правок синоптика. На табло ты видишь только сегодняшний прогноз. В архиве можешь пройти от него к вчерашней корректировке, а затем к первоначальному расчёту. Табло отвечает «что сейчас», архивная нить — «откуда это взялось».
