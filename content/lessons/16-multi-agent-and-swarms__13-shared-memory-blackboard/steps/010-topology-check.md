title: Где разместить пять руководителей и сотни однотипных воркеров?

check:
  - question: >-
      Пять руководителей совместно планируют долгую работу сотен однотипных
      воркеров. Как их лучше разместить?
    options:
      - Всех агентов поместить в один полный пул сообщений
      - >-
        Руководителей поместить в небольшой полный пул, а воркеров распределить
        по тематическим доскам
      - Каждому руководителю и воркеру выделить отдельную изолированную память
    correct: 1
    explanation: >-
      Руководителям полезен общий контекст для согласования плана, а воркерам
      достаточно записей по своей теме. Так сохраняется координация без
      перегрузки сотен контекстов.
  - question: >-
      Что произойдёт, если заставить каждого из сотни воркеров читать весь общий
      разговор?
    options:
      - 'Контекст станет чище, потому что все увидят одинаковые сообщения'
      - Руководителям больше не придётся согласовывать решения
      - >-
        В контексты воркеров попадёт много чужих записей, а расход токенов
        вырастет
    correct: 2
    explanation: >-
      Большинство сообщений не относится к задаче конкретного воркера, но всё
      равно занимает его контекст. Тематическая доска отсекает этот шум.
---

Здесь важно уметь выбирать размещение не только по числу агентов. Пять руководителей могут оставаться в небольшом полном пуле: им нужно видеть общий ход обсуждения. Сотни однотипных воркеров лучше распределить по тематическим доскам, где каждый получает только относящиеся к его работе записи.

Частая ошибка — считать, что одна команда требует одного способа обмена. Но параметры её частей различаются: наверху мало участников и тесная координация, внизу — массовая долгая работа. Именно поэтому гибрид из [шага 9](#step-9) точнее выбора одной топологии для всех.
