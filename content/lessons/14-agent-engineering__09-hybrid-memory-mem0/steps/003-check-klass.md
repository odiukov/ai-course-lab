Тебе дают фразу пользователя — и надо за секунду решить, к какому из трёх классов из [шага 1](#step-1) она относится и какое хранилище её закроет. Именно этот навык дальше держит всё остальное: без него разговор про три хранилища превращается в заучивание названий.

Спотыкаются обычно на двух вещах. Первая — определяют класс по теме вопроса, а не по форме нужного ответа: «расскажи про клиента X» звучит как поиск по смыслу, а на деле там может быть нужен один точный факт. Вторая — путают «хранилище что-то вернёт» и «хранилище тут выигрывает». Вектор ответит почти на любой вопрос, только ответ будет мимо: об этом и был [шаг 2](#step-2).
