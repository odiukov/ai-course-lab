check:
  - question: >-
      Вход имеет размер 28, ядро — 5, padding — 0, stride — 1. Какой получится
      выход?
    options:
      - '28'
      - '25'
      - '24'
      - '14'
    correct: 2
    explanation: >-
      По формуле получаем floor((28 − 5 + 0) / 1) + 1 = 24. Без padding режим
      valid уменьшает размер.
  - question: >-
      Вход имеет размер 28, ядро — 5, padding — 2, stride — 2. Какой получится
      выход?
    options:
      - '28'
      - '24'
      - '13'
      - '14'
    correct: 3
    explanation: >-
      По формуле получаем floor((28 − 5 + 4) / 2) + 1 = floor(27 / 2) + 1 = 14.
      Padding компенсирует края, а stride 2 уменьшает число позиций вдвое.
---

Проверь, умеешь ли ты по параметрам отличить три результата: `valid` уменьшает размер, `same` сохраняет его при stride 1, а stride 2 может уменьшить размер вдвое. Используй формулу из [шага 9](#step-9) или функцию из [шага 10](#step-10). Чаще всего здесь забывают прибавить единицу либо считают `same` обещанием сохранить размер при любом stride.
