check:
  - question: >-
      Вход имеет размер 7, ядро — 3, padding — 1, stride — 2. Сколько положений
      ядра останется вдоль одной оси?
    options:
      - '3'
      - '4'
      - '5'
    correct: 1
    explanation: >-
      Padding добавляет по одной позиции с каждой стороны, поэтому рабочий
      размер равен 9. Ядро помещается в четырёх положениях с шагом 2.
  - question: >-
      Вход имеет размер 6, ядро — 3, padding — 0, stride — 2. Какой получится
      размер выхода вдоль одной оси?
    options:
      - '2'
      - '3'
      - '4'
    correct: 0
    explanation: >-
      Ядро стартует только в позициях 0 и 2. Следующий старт в позиции 4 вывел
      бы ядро за границу входа, поэтому выходной размер равен 2.
---

Здесь ты соединяешь три уже знакомых действия: учитываешь рамку из [шага 13](#step-13), применяешь stride из [шага 17](#step-17) и считаешь допустимые положения по формуле из [шага 9](#step-9). Чаще всего ошибка возникает дважды: padding прибавляют только с одной стороны или забывают отбросить неполное последнее перемещение. Ядро считается лишь там, где помещается целиком.

> 🎒 **На пальцах.** Представь вагонетку, которая останавливается у платформ одинаковой длины. Padding достраивает платформу с обоих концов пути, а stride задаёт, через сколько отметок вагонетка останавливается. Если последняя остановка оставляет часть вагонетки без платформы, такой позиции в расписании нет.
