  - question: >-
      В корпусе из 100 документов слово «инструкция» встречается в 80
      документах, а код «XR17» — в 2. Какое совпадение сильнее указывает на
      нужный документ?
    options:
      - Совпадение по слову «инструкция»
      - Совпадение по коду «XR17»
      - Оба совпадения одинаково полезны
    correct: 1
    explanation: >-
      Код встречается лишь в двух документах, поэтому его IDF выше: такое
      совпадение сильнее сужает круг кандидатов.
  - question: >-
      Почему многократное повторение термина в одном документе не увеличивает n
      в формуле IDF после первого вхождения?
    options:
      - 'IDF учитывает число документов с термином, а не число его вхождений'
      - IDF учитывает только первое слово каждого документа
      - Повторы полностью удаляются из корпуса при токенизации
    correct: 0
    explanation: >-
      В IDF величина n — документная частота. Если термин встретился 20 раз на
      одной странице и больше нигде, документ с термином всё равно только один;
      повторы учитываются отдельно как частота термина внутри документа.

Здесь тебе понадобится смысл IDF из [шага 10](#step-10) и поведение функции из [шага 11](#step-11). Смотри не на то, сколько раз слово напечатано вообще, а на то, в скольких документах оно встречается. Частое слово даёт слабую подсказку: оно подходит слишком многим кандидатам. Редкий термин заметно сужает поиск и потому получает больший вес.

Типичная ловушка — перепутать число документов с числом повторов внутри одного документа. Если редкий код двадцать раз указан на одной странице, для IDF это всё ещё один документ.
