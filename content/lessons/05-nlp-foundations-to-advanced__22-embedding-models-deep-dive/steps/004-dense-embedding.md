title: Dense embedding сжимает смысл всего текста в один нормализованный вектор
source_anchor: '### Step 1: baseline — dense embeddings with Sentence-BERT'
---

Возьми два фрагмента: короткое «iPhone вышел в 2007 году» и целый абзац об истории смартфонов. На входе у них разная длина, но dense-модель выдаёт для каждого одинаковое количество чисел — например, несколько сотен. Это и есть dense-представление из [шага 3](#step-3): один фрагмент превращается в один вектор фиксированного размера.

Куда же исчезли отдельные слова и даты? Они не раскладываются по координатам по принципу «одно слово — одно число». Смысл распределяется сразу по всему вектору: каждая координата полезна только вместе с остальными. Поэтому нельзя открыть координату 17 и прочитать там «iPhone». Модель сжимает общий смысл текста, неизбежно теряя часть мелких деталей.

После сжатия вектор нормализуют — словно сохраняют его направление, но приводят длину ровно к 1. Теперь величина вектора не зависит от того, насколько большие числа модель выдала изначально. Информация для поиска остаётся в направлении: тексты с похожим смыслом должны указывать примерно в одну сторону.

Получается важный обмен: ты теряешь возможность рассматривать слова по отдельности, зато получаешь компактный смысловой «адрес» одинакового формата для любого текста.

> 🎒 **На пальцах.** Представь, что после долгой прогулки ты ставишь одну отметку на компасе: «в основном шёл на северо-восток». В отметке уже нет каждого поворота и каждой остановки, но общее направление маршрута сохранилось. Нормализация делает стрелки одинаковой длины, чтобы длинная прогулка не выглядела важнее короткой только из-за масштаба.
