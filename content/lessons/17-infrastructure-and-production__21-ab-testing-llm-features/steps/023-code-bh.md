У тебя есть четыре эксперимента с p-value в таком порядке: `0,20`, `0,004`, `0,031`, `0,018`. Функция `benjamini_hochberg` должна определить, какие результаты считать открытиями при заданном `alpha`, но вернуть ответы в исходном порядке.

Сначала сохрани индекс каждого p-value и отсортируй значения по возрастанию. Для `alpha = 0,05` пороги из [шага 22](#step-22) будут расти вместе с позицией: `0,0125`, `0,025`, `0,0375`, `0,05`. Найди **последнюю**, то есть самую большую позицию, где p-value не превышает соответствующий порог. В примере это третья позиция: `0,031 ≤ 0,0375`.

После этого значимыми считаются все значения от первого до найденной позиции. Не проверяй каждое сравнение независимо: метод делает один общий «срез» по последней подходящей позиции. Наконец, восстанови исходный порядок. Для примера результат должен быть `false, true, true, true`.

Обрати внимание на граничные случаи: пустой список должен давать пустой результат, а если ни одно значение не прошло порог — все ответы будут `false`. Проверь также, что p-value находятся от `0` до `1`, а `alpha` — строго между `0` и `1`. Сортировка нужна только для решения; пользователь функции должен получить ответ, сопоставленный с первоначальными экспериментами.

> 🎒 **На пальцах.** Представь гардеробную с перепутанными номерками заявок. Ты раскладываешь их по величине, двигаешь планку допуска до последнего подходящего номерка и принимаешь все заявки слева от неё. Затем возвращаешь решения владельцам в прежнем порядке. Если забыть исходные места, решение будет статистически верным, но достанется не тем экспериментам.
