Ты получил \(z=1\) из расчёта на [шаге 5](#step-5). Само число ещё не отвечает на главный вопрос: какая доля нормального распределения находится левее этой точки? Это и должна вычислять функция `normal_cdf`.

Функция принимает одно число — z-значение — и возвращает вероятность от 0 до 1. Например, для нуля результат должен быть `0.5`: ровно половина симметричного нормального распределения лежит слева от центра. Для положительного аргумента результат больше `0.5`, для отрицательного — меньше.

Площадь под кривой не придётся складывать вручную. В стандартном модуле `math` есть функция `erf`, через которую выражается нормальная CDF. Твоя задача — применить её с нужным преобразованием аргумента и результата. Обрати внимание на квадратный корень из двух: если потерять его или поставить не туда, функция по-прежнему будет выдавать правдоподобные числа, но вероятности окажутся неверными.

Проверь реализацию по трём свойствам:

- `normal_cdf(0)` равна `0.5`;
- результат всегда находится между 0 и 1;
- значения растут вместе с аргументом, а результаты для `z` и `-z` в сумме дают примерно 1.

Последняя проверка особенно полезна: она ловит ошибки со знаком и напоминает, что кривая симметрична.

> 🎒 **На пальцах.** Представь длинную очередь бегунов, расставленных по времени финиша: быстрые слева, медленные справа. Ты указываешь время, а `normal_cdf` сообщает, какая доля бегунов уже оказалась левее этой отметки. В центре это половина, далеко справа — почти все, далеко слева — почти никто.
