Лемматизация — это приведение слова к словарной форме: той, что стоит в словаре. `was`, `is`, `were` — все они про `be`. Нужно это затем, чтобы поиск по «be» находил текст, где написано «was», а счётчик слов не считал четыре формы одного глагола четырьмя разными словами.

Беда в том, что язык устроен нечестно. Часть слов меняется по правилу (`cats` → `cat`), а часть — как сложилось исторически (`better` → `good`, и никакое правило до этого не додумается). Поэтому учебный лемматизатор собирают из двух половин.

Первая половина — таблица лемм: готовый список исключений, где ответ просто записан заранее. Вторая — запасное правило, которое срабатывает, когда слова в таблице нет:

```python
if pos == "VERB" and word.endswith("ing"):
    return word[:-3]
if pos == "NOUN" and word.endswith("s"):
    return word[:-1]
```

Таблица закрывает неправильные формы, правило — массовые регулярные. Но между ними остаётся дыра: `watched` не попал в таблицу, а правило знает только `ing`. Функция вернёт `watched` неизменным — не ошибку, а тихий неверный ответ. Именно размер этой дыры и отличает учебную игрушку от WordNet или spaCy.

> 🎒 **На пальцах.** Как памятка у нового кассира. На листке — цены на десяток нестандартных товаров, которые ни из чего не выводятся. Всё остальное считается по правилу: цена за килограмм умножить на вес. Пока товар либо в списке, либо обычный, касса работает. Приносят развесной товар, которого в списке нет и который правилу не подчиняется, — кассир уверенно пробивает неправильную сумму и даже не замечает этого.
