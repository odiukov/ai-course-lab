После обучения stump сохранил `feature_idx = 0`, `threshold = 50` и `polarity = 1`. Ты передаёшь ему три объекта со значениями признака 42, 50 и 71. Какие метки должны вернуться?

Функция `predict_stump` применяет к каждой строке параметры, найденные `fit_stump` в [шаге 17](#step-17). Сначала подготовь массив ответов длиной по числу строк в `X` и заполни его метками `+1`. Затем возьми только столбец `feature_idx` и найди строки, для которых выполняется правило из [шага 18](#step-18):

`polarity * значение < polarity * threshold`

Этим строкам нужно заменить ответ на `-1`. При `polarity = 1` получится `[-1, +1, +1]`: значение 42 находится ниже порога, а 50 и 71 — нет.

Обрати внимание на строгое сравнение `<`. Объект, значение которого равно порогу, остаётся в классе `+1`. Замена `<` на `<=` незаметно изменит поведение обученной модели.

Теперь мысленно поставь `polarity = -1`. Умножение обеих сторон на `-1` разворачивает направление проверки: метку `-1` получат значения выше 50. Результат станет `[+1, +1, -1]`. Отдельное условие для каждого значения `polarity` не требуется — один и тот же расчёт создаёт нужную булеву маску. На выходе проверь две вещи: число предсказаний совпадает с числом строк `X`, а среди ответов встречаются только `-1` и `+1`.

> 🎒 **На пальцах.** Представь фильтр в таблице: сначала ты помечаешь все строки зелёным `+1`, затем условие выделяет часть строк, и ты перекрашиваешь их в красный `-1`. `polarity` меняет сторону отбора, но строка ровно на границе фильтр не проходит из-за строгого `<`. Поэтому она сохраняет исходную зелёную метку.
