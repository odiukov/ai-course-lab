Тебе нужно собрать bootstrap-выборку из таблицы на 6 строк. Можно сразу копировать строки, но тогда функция окажется привязана к конкретным данным. Удобнее вернуть их номера: `[4, 1, 4, 0, 5, 1]`. По этим индексам потом можно выбрать строки из любой таблицы, массива признаков или списка ответов.

Напиши функцию `bootstrap_indices`, которая принимает число объектов `n_samples` и возвращает одномерный массив из `n_samples` случайных индексов. Каждый индекс должен находиться в диапазоне от `0` до `n_samples - 1`.

Главное условие из [шага 11](#step-11) — выбор происходит с возвращением. После каждого случайного выбора индекс снова остаётся доступным, поэтому одно и то же число может выпасть несколько раз. Не используй случайную перестановку: она включает каждый индекс ровно один раз и не создаёт bootstrap-выборку.

Проверь три свойства результата:

- длина массива равна `n_samples`;
- все элементы — допустимые индексы;
- повторяющиеся значения разрешены.

Если в заготовке функции передан генератор случайных чисел или `seed`, используй его: так один и тот же запуск можно воспроизвести в тестах. И обрати внимание на правую границу диапазона — индекс `n_samples` уже выходит за пределы данных.

Функция не обязана возвращать все исходные номера. Её задача — выполнить ровно `n_samples` независимых вытягиваний.

> 🎒 **На пальцах.** Представь диджея, который собирает сет из шести позиций и каждый раз случайно выбирает трек из каталога с номерами от 0 до 5. После выбора трек не исчезает из каталога, поэтому он может прозвучать снова. `bootstrap_indices` составляет именно список номеров треков, а не копирует сами аудиофайлы.
