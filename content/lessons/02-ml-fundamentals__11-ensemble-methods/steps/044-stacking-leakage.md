title: Мета-признаки нужно получать вне обучающего fold
source_anchor: '### Stacking (Meta-Learning)'
---

Ты обучаешь две базовые модели на 100 клиентах, а затем просишь их предсказать ответы для тех же самых клиентов. Получаются впечатляющие мета-признаки: первая модель почти везде уверена на 99%, вторая тоже редко ошибается. Мета-модель быстро решает, кому доверять.

Но на новых клиентах ансамбль внезапно слабеет. Почему? Базовые модели уже видели правильные ответы и могли подстроиться под них. Мета-модель училась не на честных прогнозах, а на подсказках из прошлого — произошла утечка данных.

Поэтому обучающую выборку делят, например, на пять частей — **fold**. Для первой части прогнозы строят модели, обученные только на остальных четырёх. Затем откладывают вторую часть, снова обучают модели без неё и получают прогнозы для неё. Так повторяют пять раз. В итоге у каждой строки появляется набор прогнозов базовых моделей, но ни одна из них не была обучена на этой строке. Такие прогнозы называют **out-of-fold**, то есть полученными вне обучающего fold.

Именно собранные out-of-fold прогнозы вместе с правильными ответами передают мета-модели из [шага 43](#step-43). Когда она обучена, базовые модели можно заново обучить уже на всей обучающей выборке: для действительно нового объекта они всё равно будут делать прогноз впервые.

Значит, мета-модель должна видеть базовые модели такими, какими они окажутся в реальной работе, — без заранее известных ответов.

> 🎒 **На пальцах.** Представь дегустатора, который учится выбирать лучшего пекаря. Если оценивать пекарей по пирогам, рецепт которых им заранее показали вместе с эталоном, оба покажутся мастерами. Честнее каждому дать несколько неизвестных рецептов, записать результаты и уже по этим записям учить дегустатора. Скрытый рецепт здесь и есть строка вне обучающего fold.
