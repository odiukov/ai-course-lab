title: Bootstrap выбирает индексы с возвращением
source_anchor: '### Bagging (Bootstrap Aggregating)'
---

Представь таблицу из шести наблюдений. Можно было бы перемешать её строки и раздать моделям разные куски, но тогда каждой модели досталась бы лишь часть данных. В bagging из [шага 10](#step-10) нужен другой трюк: собрать новую обучающую выборку того же размера, не создавая новых наблюдений.

Для этого каждой строке дают номер — индекс. У шести строк это могут быть индексы от 0 до 5. Затем шесть раз случайно выбирают один индекс. Например, может получиться последовательность: `4, 1, 4, 0, 2, 4`.

Ключевой момент происходит после каждого выбора: индекс возвращается в общий набор. Поэтому на следующем ходу снова доступны все числа от 0 до 5, включая только что выпавшее `4`. Это и означает «выбор с возвращением». У любой строки на каждом ходу остаётся одинаковый шанс попасть в выборку.

Мы выбираем именно индексы, а не переписываем содержимое таблицы. Затем по полученным номерам берём соответствующие строки исходных данных. Так признаки и правильные ответы остаются согласованными: если выбран индекс `4`, берутся и данные строки 4, и её целевая метка.

Одна bootstrap-выборка содержит столько же позиций, сколько исходная таблица, но её состав определяется независимыми случайными вытягиваниями.

> 🎒 **На пальцах.** Представь гардероб с шестью номерками в коробке. Ты вытягиваешь номерок, записываешь его и сразу кладёшь обратно. После шести вытягиваний у тебя есть список из шести номеров, по которому гардеробщик выдаст вещи. Возвращение номерка важно: один и тот же номер может снова участвовать в каждом следующем вытягивании.
