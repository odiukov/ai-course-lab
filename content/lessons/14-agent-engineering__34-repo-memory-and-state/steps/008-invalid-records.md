  - question: >-
      Схема принимает только id с T- и минимум тремя цифрами, массив tasks и

    options:

      - 'id T-007, tasks null, status done'

    explanation: >-

Здесь важно отличить «JSON удалось прочитать» от «состояние соответствует контракту». Проверка из [шага 7](#step-7) применяет три независимых правила схемы из [шага 6](#step-6): `T-7` нарушает шаблон идентификатора, `null` не является массивом, а неизвестный `status` не входит в разрешённый список. Частая ошибка — считать эти значения «почти подходящими» и пытаться исправить их молча.

> 🎒 **На пальцах.** Представь сортировочный центр: посылке нужны индекс из шести цифр, коробка с перечнем вложений и одна из известных наклеек доставки. Пятизначный индекс, отсутствие коробки вместо пустой коробки и наклейка «когда-нибудь» понятны человеку, но конвейер не умеет додумывать. Он останавливает каждую такую посылку до отправки.
