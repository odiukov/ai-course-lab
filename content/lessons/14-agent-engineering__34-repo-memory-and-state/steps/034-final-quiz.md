Дальше тебе понадобится собирать надёжное состояние из уже знакомых деталей: контракта из [шага 6](#step-6), атомарной записи из [шага 10](#step-10), миграций из [шага 21](#step-21) и защиты внешних эффектов из [шага 28](#step-28). Главная ловушка — считать успешное сохранение доказательством корректности. Проверяй весь путь: утвердить снимок, записать, заново загрузить и получить то же состояние.

> 🎒 **На пальцах.** Представь нотариуса, который готовит новую страницу реестра. Если клиент только что внёс исправление, нотариус не подмешивает старую копию, а отказывает в замене. Бланк старого образца он переводит по известным правилам, новый оставляет как есть, а незнакомый не угадывает. В реестр попадает одна целая, проверенная страница.
