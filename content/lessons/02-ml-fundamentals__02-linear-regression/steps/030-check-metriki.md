check:
  - question: >-
      Почему при непостоянных целевых значениях коэффициент R² не может быть
      выше единицы?
    options:
      - >-
        Сумма квадратов остатков неотрицательна, поэтому из единицы вычитается
        неотрицательное отношение
      - MSE любой модели всегда меньше разброса целевых значений
      - >-
        Перед расчётом R² все предсказания автоматически ограничиваются
        единичным интервалом
    correct: 0
    explanation: >-
      В формуле R² = 1 − SS_res / SS_tot числитель SS_res неотрицателен, а для
      непостоянной цели SS_tot положителен. Поэтому вычитаемое отношение не
      может быть отрицательным.
  - question: У модели R² равен нулю. Как это понять?
    options:
      - Модель предсказывает без ошибок
      - Модель не лучше постоянного предсказания среднего
      - Модель обязательно хуже постоянного предсказания среднего
    correct: 1
    explanation: >-
      Нулевой R² означает, что сумма квадратов ошибок модели равна сумме
      квадратов отклонений целей от среднего. Поэтому модель не превосходит
      постоянный прогноз среднего значения.
---

Теперь тебе нужно выбирать метрику под задачу. MSE из [шага 8](#step-8) показывает размер ошибок в масштабе целевой величины: это удобно, когда важно понимать, насколько далеко промахнулась модель. R² из [шага 27](#step-27) отвечает на другой вопрос — насколько модель полезнее предсказания среднего. Поэтому маленький MSE без контекста ещё не доказывает хорошее качество, а R² позволяет сравнивать результаты при разных масштабах.

> 🎒 **На пальцах.** Представь две мишени: одна размером с монету, другая — с дверь. Промах в два сантиметра означает разное качество стрельбы. MSE сообщает сами два сантиметра, а R² учитывает размер разброса попаданий и показывает, насколько твой результат хорош относительно простого ориентира.
