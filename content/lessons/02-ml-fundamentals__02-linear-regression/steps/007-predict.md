Допустим, в `X` лежат площади трёх домов: `[40, 60, 80]`. Метод получает сразу весь список, но параметры модели — `self.w` и `self.b` — описывают предсказание только для одного значения. Значит, тебе нужно применить правило из [шага 6](#step-6) по очереди к каждой площади.

Например, при `self.w = 3` и `self.b = 7` для `X = [10, 20]` метод должен вернуть `[37, 67]`. Порядок важен: первое предсказание относится к первому объекту, второе — ко второму.

Напиши тело `predict` так, чтобы оно:

- перебирало все значения `x` в `X`;
- для каждого `x` вычисляло результат с текущими `self.w` и `self.b`;
- собирало результаты в новый список;
- возвращало этот список через `return`.

Здесь удобно использовать списковое включение — короткую запись цикла, который создаёт список. Но следи за смыслом: метод не должен менять `X`, `self.w` или `self.b`. Он только читает их и выдаёт предсказания.

Частая ошибка — напечатать результат через `print` вместо того, чтобы вернуть его. Тогда число появится на экране, но другие методы класса не смогут его получить. Ещё одна ловушка — обработать только первый элемент `X`. Быстрая проверка: длина результата должна совпадать с длиной входного списка.

> 🎒 **На пальцах.** Представь автомат для наклеивания ценников. Ты кладёшь на ленту несколько товаров, а автомат по одной настройке рассчитывает цену каждого и складывает готовые ценники в том же порядке. `predict` работает так же: берёт значения по одному, применяет текущие настройки модели и возвращает целую пачку результатов.
