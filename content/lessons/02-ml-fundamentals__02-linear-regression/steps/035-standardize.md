Перед тобой таблица `X`: каждая строка — один дом, а столбцы — площадь, число спален и возраст. Функция `standardize(X)` должна обработать каждый столбец отдельно. Если смешать все числа в одну общую стопку, огромные значения площади исказят среднее для остальных признаков.

Сначала определи количество столбцов. Затем для каждого столбца найди собственное среднее и стандартное отклонение. Само преобразование уже разобрано в [шаге 34](#step-34): здесь твоя задача — аккуратно применить его к каждой ячейке, используя характеристики именно её столбца.

Собирай результат построчно, сохраняя исходную форму таблицы. На месте площади должна остаться стандартизированная площадь, на месте возраста — стандартизированный возраст. Функция должна вернуть три результата: новую таблицу, список средних и список стандартных отклонений. Последние два понадобятся, чтобы позже преобразовывать новые дома по тем же правилам, что и обучающие данные.

Учти особый случай: у столбца может не быть разброса — например, у всех домов ровно три спальни. Его стандартное отклонение равно нулю, поэтому делить на него нельзя. Для такого столбца записывай `0`.

После реализации проверь две вещи: размеры таблицы не изменились, а у каждого непостоянного столбца среднее стало близко к `0`, стандартное отклонение — к `1`. Небольшая погрешность допустима из-за вычислений с дробными числами.

> 🎒 **На пальцах.** Представь судью десятиборья: метры прыжка нельзя напрямую сравнить с секундами забега. Поэтому для каждой дисциплины он отдельно смотрит типичный результат и разброс, а затем переводит выступление спортсмена в отклонение от нормы. `standardize` делает то же со столбцами таблицы, не смешивая их шкалы.
