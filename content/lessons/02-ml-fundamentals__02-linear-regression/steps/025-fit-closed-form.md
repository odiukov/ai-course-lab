Ты вызываешь `fit_closed_form(X, y)`, а затем смотришь на `model.w` и `model.b`. До вызова там нули, после — параметры прямой, найденные по всем парам данных. В отличие от функции из [шага 20](#step-20), здесь не будет ни эпох, ни постепенных обновлений.

Оставь себе такой каркас:

```python
def fit_closed_form(self, X, y):
    # 1. Найди количество наблюдений и средние X и y
    # 2. Вычисли числитель и знаменатель для наклона
    # 3. Сохрани наклон в self.w
    # 4. Сохрани смещение в self.b
    # 5. Верни обученную модель
```

Перенеси в код две формулы из [шага 24](#step-24). Сначала вычисли `n`, `x_mean` и `y_mean`. Затем пройди по индексам от `0` до `n - 1`: значения `X[i]` и `y[i]` должны оставаться одной парой. Из этих пар отдельно собери `numerator` и `denominator`, после чего запиши результат в `self.w`. Только затем вычисляй `self.b`, потому что для него уже нужен найденный наклон.

Обрати внимание: функция не должна возвращать пару `(w, b)`. Она меняет состояние самой модели — `self.w` и `self.b`. Вернув `self`, ты сможешь продолжить работу с обученным объектом, а `predict` из [шага 7](#step-7) сразу воспользуется сохранёнными параметрами.

Проверь функцию на данных с известным ответом из [шага 5](#step-5). Если параметры совпали с задуманными или отличаются лишь на крошечную погрешность вычислений, перевод формул в код сработал.

> 🎒 **На пальцах.** Представь закройщика с таблицей парных мерок: рост одного человека нельзя случайно совместить с обхватом другого. Он обрабатывает всю таблицу, один раз настраивает лекало и сохраняет две настройки. `fit_closed_form` делает то же самое: берёт связанные пары `X` и `y`, рассчитывает `w` и `b` и фиксирует их внутри модели.
