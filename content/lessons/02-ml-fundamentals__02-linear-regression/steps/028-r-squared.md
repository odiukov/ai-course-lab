У тебя есть две одинаковые по длине последовательности: настоящие значения `y_true` и предсказания `y_pred`. Нужно превратить их в одну оценку, но просто вызвать `mse` из [шага 9](#step-9) недостаточно: R² сравнивает ошибки модели с разбросом самих настоящих значений.

В функции `r_squared` сначала найди среднее значение `y_true`. Затем посчитай две суммы:

- для `SS_res` сложи квадраты разностей между каждым предсказанием и соответствующим настоящим значением;
- для `SS_tot` сложи квадраты отклонений настоящих значений от их среднего.

После этого верни результат сравнения этих сумм по формуле из [шага 27](#step-27). Обрати внимание: среднее вычисляется только по `y_true`. Предсказания не должны влиять на точку отсчёта, иначе модель начнёт сама выбирать, с чем её сравнивать.

Проверь функцию на двух понятных случаях. Если `y_pred` полностью совпадает с `y_true`, результат должен быть `1.0`. Если каждое предсказание равно среднему настоящих значений, должен получиться `0.0`. Эти проверки хорошо ловят перепутанные суммы и неверно найденное среднее.

Есть и особый случай: если все настоящие значения одинаковы, `SS_tot` равна нулю и обычное деление невозможно. Посмотри, какое поведение ожидают тесты или заготовка задания, и обработай его явно, а не оставляй случайную ошибку деления.

> 🎒 **На пальцах.** Представь реставратора выцветшей фотографии. Можно просто закрасить весь снимок одним средним оттенком — это исходная точка сравнения. Твоя модель пытается восстановить светлые и тёмные участки точнее. `r_squared` сопоставляет оставшиеся ошибки реставрации с тем, сколько различий было на фотографии изначально. Совпадение пиксель в пиксель даёт `1.0`, а сплошной средний оттенок — `0.0`.
