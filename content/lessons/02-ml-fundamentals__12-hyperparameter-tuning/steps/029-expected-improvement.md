Ты получил от суррогата прогнозы для трёх кандидатов: `mu` говорит, какого качества ждать, а `var` — насколько прогноз неопределён. Теперь нужно вернуть по одному числу EI для каждого кандидата, чтобы их можно было сравнить.

Дополни функцию:

```python
def expected_improvement(mu, var, best_y):

    exploration = ...
    ei = ...

```

`mu` и `var` — массивы одинаковой длины, а `best_y` — лучшая уже измеренная оценка. Результат `ei` тоже должен быть массивом: никакого усреднения между кандидатами.

Сначала преврати дисперсию `var` в стандартное отклонение `sigma`. Затем вычисли, насколько прогноз превосходит `best_y`, в единицах `sigma`. В знаменатель добавь маленькое число вроде `1e-10`: без него точка с почти нулевой неопределённостью может вызвать деление на ноль.

Дальше собери две части. Эксплуатация учитывает разницу `mu - best_y`, умноженную на `norm_cdf(z)`. Эта функция показывает вероятность оказаться ниже заданного `z`. Разведка использует `sigma * norm_pdf(z)`, где `norm_pdf` показывает плотность нормального распределения в этой точке. Сложи части поэлементно — это и будет вычислительная версия EI из [шага 28](#step-28).

Проверь форму результата и знак: здесь большее качество считается лучшим, поэтому улучшение направлено от `best_y` к `mu`, а не наоборот.

> 🎒 **На пальцах.** Ты выбираешь закрытую коробку на аукционе. У одной высокая ожидаемая цена содержимого — это эксплуатация. О другой известно мало, зато внутри может оказаться редкость — это разведка. EI присваивает каждой коробке общий балл, не смешивая их между собой: потом ты просто выбираешь коробку с самым большим баллом.
