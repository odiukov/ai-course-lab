title: Random search независимо покрывает каждое измерение

У тебя осталось девять запусков и два гиперпараметра: `learning_rate` и `max_depth`. В сетке из [шага 9](#step-9) каждый из них получал лишь три разных значения: остальные запуски повторяли эти значения в новых сочетаниях.

Random search действует иначе. Перед каждым запуском он случайно выбирает новое значение для каждого гиперпараметра из заданного распределения — правила, которое описывает допустимый диапазон и шансы разных значений попасть в выборку. Выборы независимы: выпавший `learning_rate` не заставляет алгоритм брать какой-то определённый `max_depth`.

Поэтому за девять запусков ты обычно проверишь девять разных значений `learning_rate` и девять разных значений `max_depth`. Это не 81 комбинация: модель всё ещё обучается только девять раз. Просто каждый запуск приносит по одному новому наблюдению в каждом измерении.

Зачем это полезно? Допустим, результат почти целиком зависит от `learning_rate`, а `max_depth` влияет слабо. Сетка дала бы тебе только три полезных значения важной настройки. Random search даст девять — при том же бюджете. Ты заранее не знаешь, какое измерение окажется главным, поэтому независимое случайное покрытие не ставит всё на несколько фиксированных значений.

> 🎒 **На пальцах.** Представь пульт фотостудии с двумя ползунками: яркостью и насыщенностью. У тебя девять кадров. Для каждого кадра ты независимо передвигаешь оба ползунка в новые случайные положения. Если позже выяснится, что качество сильнее всего зависело от яркости, у тебя будет девять проверенных уровней яркости, а не три уровня, многократно повторённых с разной насыщенностью.
