Перед тобой пять раундов из [шага 39](#step-39). Здесь легко посмотреть только на финальные 81 эпоху и забыть работу остальных участников. Считай затраты каждого раунда отдельно: число оставшихся конфигураций умножай на их бюджет, затем складывай результаты. Получится 405 эпох.

Для полного обучения турнирного отбора нет: каждая из 81 конфигурации получает все 81 эпоху. Это уже 6561 эпоха — примерно в 16 раз больше.
