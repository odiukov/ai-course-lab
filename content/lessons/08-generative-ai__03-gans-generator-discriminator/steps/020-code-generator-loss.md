`d_fake` содержит вероятности, которые дискриминатор присвоил подделкам. Для каждого `p` вычисли штраф по non-saturating формуле из [шага 19](#step-19), затем верни среднее по батчу. Именно среднее позволяет честно сравнивать результаты батчей разного размера.

Обрати внимание на крайний случай: если дискриминатор вернёт `p = 0`, попытка вычислить логарифм закончится математической бесконечностью и может испортить дальнейшие вычисления. Поэтому перед `math.log` ограничь вероятность снизу небольшим числом `1e-8`. Значения выше этого порога оставляй без изменений.

Проверь смысл результата на двух примерах: при `p = 0.9` отдельный штраф должен быть маленьким — около `0.105`; при `p = 0.01` большим — около `4.605`. Значит, функция сильнее штрафует генератор именно за те подделки, которые дискриминатор уверенно отверг.

А нижний порог — это запасная отметка вместо невозможной оценки «меньше нуля навсегда».
