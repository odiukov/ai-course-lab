  - question: >-
      Почему на более просторной решётке разрыв между независимыми агентами и
      вариантом с централизованной оценкой может увеличиться?
    options:
      - >-
        Появляется больше маршрутов, на которых агенты могут дублировать работу
        или мешать друг другу
      - Локальные наблюдения автоматически превращаются в глобальное состояние
      - Централизованный критик сокращает размер решётки
      - Независимые политики начинают совместно перебирать все действия
    correct: 0
    explanation: >-
      С ростом пространства увеличивается число способов неудачной координации.
      Совместная информация при обучении помогает учитывать действия напарников
      и уменьшать цену таких ошибок.
  - question: >-
      В состязательной задаче награду получает только агент, который первым
      достиг общего ресурса. Какой паттерн исторически применяли к подобным
      сценариям?
    options:
      - MADDPG
      - QMIX с обязательной общей наградой
      - Независимый жадный выбор из монотонного миксера
      - Полный перебор совместных действий при каждом исполнении
    correct: 0
    explanation: >-
      MADDPG создавался в том числе для смешанных кооперативно-состязательных
      сред: централизованный критик может учитывать совместные действия, тогда
      как акторы исполняются раздельно.
  - question: >-
      Какое выражение корректно задаёт Bellman-цель для обновления критика
      агента в MADDPG?
    options:
      - 'y_i = r_i + γQ_i^{target}(x'', μ_1^{target}(o''_1), …, μ_N^{target}(o''_N))'
      - 'y_i = Q_i(x, a_i) без награды и следующего состояния'
      - 'y_i = r_i + γ max_{a_i} Q_i(o_i, a_i), без действий остальных агентов'
      - 'y_i = −∇_{a_i}Q_i(x, a_1, …, a_N)'
    correct: 0
    explanation: >-
      Критик регрессирует к награде плюс дисконтированной оценке следующего
      совместного действия, полученного целевыми акторами. Обычно минимизируется
      квадрат TD-ошибки между текущей оценкой и этой целью.
  - question: >-
      Какой набор аргументов лучше всего объясняет, почему MAPPO может
      превосходить off-policy MARL на командных бенчмарках?
    options:
      - >-
        Централизованная ценность использует командный контекст, PPO
        ограничивает резкость обновлений, а свежие on-policy траектории не
        устаревают в replay-буфере при изменении партнёров
      - >-
        MAPPO перебирает все совместные действия, устраняет частичную
        наблюдаемость при исполнении и не нуждается в награде
      - >-
        PPO делает среду стационарной, отменяет необходимость критика и
        гарантирует глобальный оптимум
      - >-
        MAPPO всегда требует меньше данных, чем любой off-policy метод,
        независимо от среды
    correct: 0
    explanation: >-
      Централизованная оценка помогает обучению на командном контексте,
      ограниченные обновления PPO повышают устойчивость, а on-policy данные
      соответствуют текущим политикам других агентов. Это объясняет результаты
      на конкретных бенчмарках, но не даёт универсальной гарантии.

Дальше тебе понадобится не запоминание трёх названий, а умение восстановить всю цепочку решения: какая информация доступна, какие действия выбирают агенты, где оценивается совместный результат и не создаёт ли награда лазейку. Особенно легко перепутать централизованное обучение с централизованным исполнением — вернись к [шагу 6](#step-6), если эта граница ещё плавает. Ограничение QMIX сверяй с [шагом 32](#step-32), а выбор метода — с [шагом 37](#step-37).

> 🎒 **На пальцах.** Ты комплектуешь экспедицию: внедорожник, лодка и вертолёт хороши не сами по себе, а на подходящей местности. Сначала смотришь на маршрут, доступную связь и груз, затем выбираешь транспорт. Так же и здесь: MADDPG, QMIX и MAPPO — не пьедестал победителей, а разные инструменты для разных ограничений.
