Пишем epsilon_greedy

В состоянии s у агента четыре оценки: например, вверх: 1.2, вниз: -0.4, влево: 0.7, вправо: 0.1. Если всегда брать максимум, агент выберет вверх и перестанет проверять остальные действия. Но иногда ему нужно исследовать среду — именно этот выбор ты разбирал в шаге 28.

Твоя функция epsilon_greedy(Q, s, epsilon) должна сначала случайно решить, какой режим включить:

  • с вероятностью epsilon — исследование: равновероятно выбрать любое действие из Q[s];
  • в остальных случаях — использование знаний: вернуть действие с наибольшим значением в Q[s].

Обрати внимание: случайный выбор делается среди действий, то есть ключей внутреннего словаря Q[s], а сравнивать нужно их Q-значения. Не перепутай действие с самой оценкой: функция должна вернуть, например, 2, а не 1.2.

Проверь крайние случаи. При epsilon = 0 результатом всегда должно быть действие с максимальной оценкой. При epsilon = 1 функция всегда исследует, хотя случайно всё равно может выбрать текущее лучшее действие. Поэтому доля выбора лучшего действия при исследовании не обязана быть нулевой.

Если несколько действий делят максимум, стандартный поиск максимума может постоянно возвращать первое из них. Для этого упражнения это допустимо, если тесты не требуют случайного разрешения ничьей. Сейчас функция только выбирает действие; изменение Q-таблицы начнётся на следующем шаге.

🎒 На пальцах. Представь стойку с четырьмя сортами мороженого. Обычно ты берёшь сорт с самой высокой личной оценкой. Но иногда подбрасываешь монетку и пробуешь случайный вкус — даже тот, который уже считаешь лучшим. epsilon задаёт, как часто решение отдаётся такой дегустации, а функция возвращает выбранный вкус, не меняя твои оценки.
