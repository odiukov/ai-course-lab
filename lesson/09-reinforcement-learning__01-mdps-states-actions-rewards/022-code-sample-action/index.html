Пишем sample_action

Тебе передали политику:

{
    "up": 0.1,
    "right": 0.7,
    "down": 0.2,
    "left": 0.0,
}

Если применить random.choice к её ключам, каждое действие получит шанс 25%. Числа политики потеряются, и агент будет вести себя совсем не так, как задумано в шаге 21.

Напиши функцию sample_action(probabilities), которая получает словарь вида «действие → вероятность» и возвращает одно выбранное действие. Используй одно случайное число от 0 включительно до 1 не включительно. Затем проходи по парам словаря, накапливая вероятности. Первое действие, после добавления которого накопленная сумма стала больше случайного числа, и будет результатом.

Проверь функцию на двух случаях:

  • если одно действие имеет вероятность 1.0, оно должно выпадать всегда;
  • если запустить выбор много раз для вероятностей 0.1, 0.7, 0.2 и 0.0, частоты должны быть примерно такими же.

Именно примерно: десять вызовов легко дадут неровный результат. Смотри на несколько тысяч повторений. Действие с нулевой вероятностью при этом не должно появляться ни разу.

Учти небольшую погрешность чисел с плавающей точкой: после прохода полезно иметь запасной возврат последнего действия. Это не меняет распределение, а защищает функцию от редкого случая, когда сумма в памяти получилась чуть меньше 1.0.

🎒 На пальцах. Представь метровую ленту: первым действием заняты 10 сантиметров, вторым — следующие 70, третьим — последние 20. Ты вслепую ставишь палец в случайную точку. Функция не выбирает надпись наугад — она возвращает действие с того участка, куда попал палец. Чем длиннее участок, тем чаще результат.

Практика: sample_action

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
