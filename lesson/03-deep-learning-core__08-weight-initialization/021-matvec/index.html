Пишем matvec

У тебя есть матрица весов из двух строк и вектор входов:

weights = [
    [1.0, 2.0, -1.0],
    [0.5, 0.0, 2.0],
]
vector = [3.0, 1.0, 2.0]

Напиши функцию matvec(weights, vector), которая вернёт один результат для каждой строки матрицы. Механику взвешенной суммы ты уже разобрал в шаге 20.

Для первой строки результат равен 1·3 + 2·1 + (-1)·2 = 3. Для второй — 0.5·3 + 0·1 + 2·2 = 5.5. Значит, ожидаемый ответ:

[3.0, 5.5]

Тебе понадобятся два цикла. Внешний перебирает строки весов, то есть нейроны. Внутренний перемножает элементы текущей строки с соответствующими элементами vector и складывает произведения.

Обрати внимание на переменную суммы: для каждой новой строки её нужно снова обнулять. Добавляй результат в выходной список только после того, как обработана вся строка. Если сделать это внутри вложенного цикла, функция вернёт промежуточные суммы вместо одного числа на нейрон.

Можешь начать с заготовки:

def matvec(weights, vector):
    outputs = []
    # перебери строки weights
    # для каждой строки посчитай взвешенную сумму
    # добавь готовую сумму в outputs
    return outputs

Количество элементов в каждой строке должно совпадать с длиной входного вектора: иначе некоторым весам или входам не найдётся пары.

🎒 На пальцах. Представь несколько рецептов смузи: строка весов — один рецепт, а вектор — доступные количества ингредиентов. Ты берёшь каждый ингредиент в указанной рецептом доле и складываешь вклад в итоговый вкус. Закончив один рецепт, записываешь одну оценку и начинаешь считать следующий с нуля. Поэтому из каждой строки получается ровно одно число.
