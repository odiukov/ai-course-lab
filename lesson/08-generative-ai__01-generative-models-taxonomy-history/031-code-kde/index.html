Пишем ядерную оценку плотности

На числовой оси лежат 2000 образцов, но сами по себе они не отвечают на вопрос: насколько плотна область около нуля? Представь, что каждый образец оставляет вокруг себя размытое пятно: ближе к центру оно ярче, дальше — слабее. Тебе нужно сложить яркость всех пятен в каждой проверяемой точке.

Реализуй функцию kde_density(samples, points, bandwidth). Она должна вернуть отдельную оценку плотности для каждого значения из points, используя гауссово ядро и выражение из шага 30.

Для каждой проверяемой точки:

  1. Вычисли её расстояние до каждого образца.
  2. Раздели расстояния на bandwidth.
  3. Примени к результатам гауссово ядро.
  4. Сложи вклады и выполни нормировку из формулы KDE.

Проследи, чтобы bandwidth был положительным. При маленьком значении оценка получится колючей: почти каждый образец образует отдельный пик. При большом два пика смеси могут расплыться в один широкий холм. Для этого примера используй ширину 0.3.

Затем вычисли плотность на частой сетке внутри [-0.5, 0.5] и проинтегрируй её способом из шага 27. Должно получиться примерно 0.033. Это вероятность интервала, а не значение плотности в одной точке.

Если результат заметно больше единицы, первым делом проверь нормировку: часто забывают деление на число образцов или на bandwidth.

🎒 На пальцах. Представь длинную бумажную ленту, на которую в местах образцов капнули чернила. Каждая капля немного растеклась, а ширину пятна задаёт bandwidth. KDE спрашивает, насколько тёмной стала лента в выбранной точке. Чтобы узнать вероятность целого отрезка, ты собираешь не одну яркость, а всю краску на этом участке.

Практика: kde_density

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
