Пишем combined_loss

У тебя уже есть две функции: pixel_cross_entropy из шага 24 и dice_loss из шага 29. Теперь представь, что ты вычислил обе потери, но вернул только одну из них. Код запустится, однако модель будет учиться не по той общей цели, которую мы выбрали в шаге 30.

Функция combined_loss должна принять логиты модели, правильную маску и коэффициент lambda_dice. Затем ей нужно отдельно получить pixel cross-entropy и Dice loss, умножить вторую потерю на коэффициент и вернуть их сумму.

Обрати внимание на три детали:

  • Передавай в обе функции исходные логиты. Не применяй softmax заранее, если функции из предыдущих шагов уже делают необходимое преобразование.
  • Не используй .item() при сложении. Он превращает тензор в обычное число и обрывает путь, по которому обучение вычисляет градиенты.
  • Результатом должен быть один скалярный тензор. Именно для него затем вызывают backward().

При lambda_dice = 1 обе составляющие входят в результат с обычным весом. Если коэффициент увеличить, ошибки перекрытия будут влиять сильнее; если поставить 0, останется только кросс-энтропия. Твоя задача сейчас — не вычислять новые метрики вручную, а аккуратно соединить две уже написанные функции без потери градиентов.

🎒 На пальцах. Представь звукорежиссёра с двумя дорожками: голосом и музыкой. lambda_dice — регулятор громкости второй дорожки. Он не переписывает музыку, а только меняет её вклад в общий микс. Если сохранить каждую дорожку как число на бумаге, пульт уже не сможет автоматически подстроить звук — так же .item() лишает модель возможности обучаться.
