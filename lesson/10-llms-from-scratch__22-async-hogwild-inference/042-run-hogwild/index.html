Пишем run_hogwild

Две детали у тебя уже лежат на столе: visible_counts из шага 38 умеет посмотреть на общий кэш и посчитать, чего там сколько, а next_category из шага 40 по этим числам решает, куда идти дальше. Осталось понять, кто их зовёт.

И тут легко свернуть не туда. Хочется написать функцию, которая заранее раздаёт воркерам роли: первый пишет работу, второй наблюдения, третий координацию. Но это ровно та развилка, о которой шла речь в шаге 4 — как только роли розданы снаружи, общий кэш перестаёт быть каналом связи и остаются старые топологии.

Поэтому run_hogwild не раздаёт ничего. Она крутит цикл.

На вход ей нужны число воркеров, сколько шагов делает каждый, и порог K для эвристики. Внутри — общий список токенов, изначально пустой. Дальше по шагам: воркер читает текущее состояние списка, зовёт next_category, дописывает один токен в конец. Потом ход переходит к следующему воркеру. Возвращает функция итоговый список — и полезно вернуть заодно, кто какую запись сделал, чтобы потом было что разглядывать.

Три вещи, на которые смотри при написании. Первое: состояние читается заново на каждом шаге, а не один раз в начале — если поднять чтение выше цикла, координация исчезнет и все воркеры будут писать одно и то же. Второе: за один свой ход воркер добавляет ровно один токен, не пачку. Третье: воркеры ходят по кругу — это и есть игрушечная модель гонки записей из шага 6.

Никакого обмена сообщениями в коде не появится. Его негде написать: аргументов, через которые один воркер что-то передал бы другому, просто нет.

🎒 На пальцах. Пятеро разбирают стол после застолья, молча. Каждый смотрит на кухню: тарелок в раковине гора, а мусор ещё не вынесен — значит, беру мешок. Сделал одно действие, снова посмотрел, картина уже другая. Договариваться не пришлось: все читают одну и ту же кухню. Единственное, что нужно, — не хвататься вдвоём за одну тарелку.

Практика: run_hogwild

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
