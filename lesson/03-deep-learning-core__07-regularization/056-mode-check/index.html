Проверка: что случится без model.eval перед тестированием

После переключателей из шага 55 ты должен уметь распознать пропущенный model.eval() по симптомам: один пример получает разные ответы при повторных запусках, а результат BatchNorm зависит от состава тестового батча. Частая ошибка — решить, что тестовые данные сами оказались нестабильными. На деле модель просто продолжает вести себя так, будто обучение ещё идёт.

🎒 На пальцах. Представь фотографа, который оценивает готовый снимок, но забывает выключить режим случайных пробных фильтров и автонастройку по соседним фотографиям. Один кадр каждый раз выглядит иначе — изменилась не фотография, а режим обработки.
