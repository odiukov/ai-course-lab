Стадия 1: среднее по префиксу как матрица

Возьми последовательность из четырёх токенов и попробуй сделать для каждой позиции честную сводку прошлого — без единой хитрости. Самое тупое, что вообще можно придумать: пусть позиция будет средним всего, что до неё уже прочитано, включая её саму. Позиция 0 — это просто она сама. Позиция 3 — среднее четырёх.

В виде цикла это одна строчка: out[i] = X[:i+1].mean(0). Идёшь по позициям, для каждой берёшь срез от начала и усредняешь. Работает. Но ты перебираешь позиции по очереди, и для каждой заново режешь массив — а треугольник из шага 5 выглядел как одна цельная картинка, а не как четыре отдельных среза.

А что, если посчитать все позиции разом?

Оказывается, весь этот цикл — одно матричное умножение. Собери матрицу AAA размера n×nn \times nn×n, где nnn — длина последовательности. Правило простое:

Aij=1i+1 при j≤i,Aij=0 при j>iA_{ij} = \frac{1}{i+1} \text{ при } j \le i, \quad A_{ij} = 0 \text{ при } j > iAij​=i+11​ при j≤i,Aij​=0 при j>i

Здесь iii — номер строки (позиция, для которой считаем результат), jjj — номер столбца (позиция, из которой берём вклад). Строка 0 = [1, 0, 0, 0]. Строка 3 при n = 4 = [0.25, 0.25, 0.25, 0.25]. Каждая строка говорит: с какими весами сложить все позиции последовательности, чтобы получить результат для этой позиции.

И теперь посмотри, где в этой матрице нули. Над диагональю. Ровно тот же треугольник, что в шаге 3 — только мы его не рисовали и ничего не запрещали. Будущее не маскировали: его просто не было в сумме.

🎒 На пальцах. Часы на пробежке показывают средний темп с начала дистанции. На первом километре это один замер, на пятом — среднее пяти. Часы не «скрывают» от тебя километры, которые ты ещё не пробежал: их нечего скрывать, они не существуют. Запиши веса каждого показания в строку — и километры впереди получат ноль сами собой. Не запрет, а пустота.
