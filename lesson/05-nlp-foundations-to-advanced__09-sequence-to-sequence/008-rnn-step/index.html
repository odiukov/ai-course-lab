Пишем rnn_step

Возьми один токен из середины предложения. У тебя есть его вектор x_t и память, оставшаяся после предыдущего токена, h_prev. Нужно получить новую память — только для одного шага, без обработки всей последовательности.

Напиши функцию:

def rnn_step(x_t, h_prev, W_xh, W_hh, b):
    # твой код
    pass

Она должна выполнить обновление состояния из шага 7. Собери результат из двух частей: информации текущего входа и преобразованного предыдущего состояния. Затем прибавь смещение b и примени torch.tanh.

Ориентируйся на формы:

  • x_t: [batch, input_dim];
  • h_prev: [batch, hidden_dim];
  • W_xh: [input_dim, hidden_dim];
  • W_hh: [hidden_dim, hidden_dim];
  • b: [hidden_dim];
  • результат: [batch, hidden_dim].

Для умножения матриц используй оператор @. Вектор b не содержит отдельной строки для каждого примера: PyTorch сам прибавит его ко всем строкам батча. Такое автоматическое повторение называется broadcasting.

Частая ошибка — применить tanh отдельно к двум частям, а затем сложить их. Здесь порядок другой: сначала все слагаемые образуют одно число для каждого элемента состояния, и лишь потом tanh ограничивает результат диапазоном от −1 до 1.

Не используй готовую nn.RNNCell: смысл упражнения — руками собрать один переход памяти и увидеть, какие формы должны состыковаться.

🎒 На пальцах. Представь навигатор на перекрёстке. x_t — дорожный знак прямо перед тобой, а h_prev — записка о том, откуда ты приехал. Две матрицы переводят знак и записку в общий формат, b добавляет небольшую постоянную поправку. Только после сложения всех подсказок навигатор выдаёт одно обновлённое направление — новое состояние.
