Три пути поиска навыков

Ты написал навык — папка pdf-fill, внутри SKILL.md. Положил в ~/.claude/skills/, у себя проверил: агент его подхватывает. Коллега клонирует репозиторий, запускает агента — навыка нет. Ничего не сломалось: файл лежит в твоей домашней папке, а домашнюю папку никто не клонирует.

Куда тогда класть, чтобы навык уехал вместе с кодом?

Рантайм смотрит ровно в три места, и каждое — по маске */SKILL.md, то есть на один уровень вглубь:

  • ~/.anthropic/skills/*/SKILL.md
  • ./skills/*/SKILL.md
  • ~/.claude/skills/*/SKILL.md

Посмотри на первый символ каждого пути — он и есть ответ. Средний начинается с точки: это текущий проект, папка внутри репозитория. Что туда положил — то закоммитилось и досталось всем, кто сделает clone. Два других начинаются с тильды, а тильда — домашняя папка: ~/.anthropic/skills/ работает у тебя во всех проектах сразу, ~/.claude/skills/ — личная папка твоего Claude Code. Обе видны только тебе и никуда не уедут.

Это те самые три области видимости из шага 12, но теперь у каждой есть конкретный адрес.

И приятная деталь: Claude Code, Anthropic Agent SDK и SkillKit сканируют по одному и тому же шаблону. Написал папку с SKILL.md один раз — её подберёт любой из них.

Так что с твоим pdf-fill делать нечего сложного: перенеси папку из ~/.claude/skills/ в ./skills/, закоммить — и у коллеги он появится сам, без установки.

🎒 На пальцах. Пометки карандашом на полях библиотечной книги уедут к следующему читателю вместе с книгой — хочешь ты того или нет. Те же пометки в собственном блокноте останутся с тобой и будут под рукой в любой книге, которую возьмёшь потом. ./skills/ — поля библиотечной книги, домашние папки — твой блокнот. Кому достанется навык, решает не содержимое файла, а место, куда ты его положил.
