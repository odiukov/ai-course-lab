Находим байты, которые разрушают кэшируемый префикс

Теперь ты должен уметь искать не «похожий текст», а первое различие в точной последовательности байтов. Сравни два сериализованных запроса слева направо и отметь, попало ли различие до границы кэша. Чаще всего мешают время, ID запроса, случайный порядок блоков, пробел или перенос строки. Перенос динамики вниз из шага 26 помогает только тогда, когда верх действительно остаётся неизменным.

🎒 На пальцах. Представь две гирлянды, которые проверяют лампочка за лампочкой слева направо. Пока цвета совпадают, общий участок можно использовать повторно. Первая другая лампочка завершает совпадение: одинаковые лампы дальше уже не спасают этот префикс.
