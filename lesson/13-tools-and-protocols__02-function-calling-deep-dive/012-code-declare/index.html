Пишем declare

Перед тобой один объект Tool с именем get_weather, описанием и схемой аргументов — и три провайдера, которым его надо отдать. Первое желание: написать одну функцию declare(tool, provider) и внутри развилку if provider == "openai" ... elif .... Работать будет. Но через месяц у тебя пять инструментов, у одного из них появилось поле, и ты правишь три ветки одного if, глядя на общий отступ и надеясь, что не перепутал.

Поэтому пиши три отдельные крошечные функции: declare_openai(tool), declare_anthropic(tool), declare_gemini(tool). Каждая берёт канонический Tool и возвращает готовый словарь в форме своего провайдера. Никаких аргументов-переключателей, никакой развилки внутри.

Что должна делать каждая из них? Ровно одно: разложить те же пять граф из шага 8 по местам, где их ждёт этот провайдер, — обёртку и переименование ключа схемы ты уже разобрал в шаге 11. Если у провайдера какого-то поля просто нет — например, strict понимает не каждый, — поле не подставляется пустышкой, а не попадает в результат вовсе.

И вот главная ловушка, на которую смотри в первую очередь. Соблазнительно переименовать ключ прямо в tool.input_schema. Но это тот же самый словарь в памяти: declare_openai его испортит, а declare_anthropic, вызванный следом, получит уже сломанный вход. Собирай новый словарь, исходный не трогай.

Проверка простая: прогони один и тот же Tool через все три функции, распечатай результаты и сравни. Отличаться должны только обёртка и названия ключей — само описание аргументов во всех трёх обязано быть одинаковым по содержанию.

Если внутри declare_* завелась хоть какая-то логика сложнее «взять поле и положить рядом» — значит, часть описания инструмента живёт не в каноническом объекте, а спряталась в переводчике, и синхронизировать снова придётся руками.

🎒 На пальцах. Тесто ты замешиваешь один раз. Дальше берёшь три вырубки: звезда, ёлочка, кружок. Каждая формочка ничего не добавляет и ничего не отнимает — она только придаёт краю нужный контур. И вырубать надо из раскатанного пласта, а не переминать один и тот же комок под каждую форму: помнёшь — следующая формочка получит уже испорченное тесто.
