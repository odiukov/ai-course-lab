Пишем reward_score

Ты запускаешь модель на ответе «точно, точно, выдумка». Веса слов уже заданы: у «точно» — 0.7, у «выдумка» — -1.1. Как получить один итоговый балл?

Напиши функцию reward_score: она принимает веса w и ответ y, а возвращает число — оценку этого ответа по правилу из шага 9. Сначала представь ответ как мешок слов: порядок не важен, зато повторения важны. Затем для каждого слова возьми его вес, умножь на количество появлений и прибавь к общей сумме.

В нашем примере «точно» встречается дважды и приносит 1.4, а «выдумка» отнимает 1.1. Итог — 0.3.

Обрати внимание на три края задачи:

  • незнакомого слова может не быть в w — считай, что его вклад равен нулю;
  • повторяющееся слово должно повлиять на результат несколько раз;
  • пустой ответ должен получить нулевой балл.

Не добавляй сигмоиду из шага 8: reward_score возвращает именно сырой скалярный балл. Превращение разницы двух таких баллов в вероятность — отдельная операция.

🎒 На пальцах. Представь автомат, который считает жетоны из игрового автомата. Синий жетон стоит 0.7 очка, красный — -1.1. Ты опускаешь два синих и один красный: счётчик показывает 0.3. Жетон неизвестного цвета не меняет показание. reward_score работает так же, только вместо жетонов получает слова ответа.
