Пишем mse_gradient

Ты получаешь два списка: предсказания модели и правильные ответы. Функция mse_gradient должна вернуть третий список — по одному градиенту для каждого предсказания. Порядок сохраняется: первый градиент относится к первому предсказанию, второй — ко второму и так далее.

Внутри цикла тебе понадобятся три действия: найти разность между предсказанием и целью, учесть множитель 2.0 и разделить результат на n. Именно n делает градиент согласованным с усреднением в функции mse из шага 6.

Проверь себя на таком примере:

predictions = [4.0, 1.0]
targets = [1.0, 3.0]

Функция должна вернуть:

[3.0, -2.0]

Смотри не только на числа, но и на знаки. Для первого предсказания градиент положительный: модель дала слишком большое значение. Для второго — отрицательный: значение оказалось слишком маленьким. Частая ошибка здесь — перепутать p - t с t - p; тогда оба знака развернутся и оптимизатор поведёт предсказания не в ту сторону.

🎒 На пальцах. Представь диспетчера, который выписывает каждому из двух водителей поправку к маршруту. Один проехал на 3 километра дальше, другой не доехал 2 километра. Поправки должны указывать разные направления, поэтому у них разные знаки. А поскольку общий результат усредняется между водителями, каждая поправка получает свою долю масштаба.
