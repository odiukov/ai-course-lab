Пишем mean_squared_error

Ты получил три точных значения: 3, 5, 8. Модель предсказала 2, 7, 8. Глазами видно, что она ошиблась на 1, 2 и 0, но для сравнения моделей нужен один итоговый показатель.

Напиши функцию mean_squared_error(y_true, y_pred). Она принимает два массива одинаковой длины:

  • y_true — правильные значения;
  • y_pred — предсказания модели.

Внутри функции нужно выполнить три действия из шага 15: найти ошибку для каждой пары значений, возвести каждую ошибку в квадрат и усреднить квадраты. Функция должна вернуть одно число, а не массив промежуточных результатов.

Для примера выше квадраты ошибок равны 1, 4, 0, поэтому результат должен быть примерно 1.67. Проверь также случай идеальных предсказаний: если оба массива совпадают, функция должна вернуть 0.

Здесь легко споткнуться о порядок действий. Если сначала усреднить обычные ошибки, положительные и отрицательные промахи могут взаимно уничтожиться. Поэтому сначала работает возведение в квадрат — отдельно для каждого элемента — и только потом среднее. В NumPy все эти операции можно выполнить сразу над массивами, без ручного перебора элементов.

Считай, что на вход приходят непустые массивы одинаковой длины. Сосредоточься на самом вычислении и проследи, чтобы mean применялся к квадратам всех ошибок.

🎒 На пальцах. Представь три счета в кафе: в одном ты недоплатил 1 евро, в другом переплатил 2, а третий оплатил точно. Если просто сложить отклонения, переплата частично скроет недоплату. Квадраты не дают промахам погасить друг друга: каждый сначала превращается в положительный штраф, а затем ты находишь средний штраф.
