Пишем make_dataset

Ты запускаешь эксперимент дважды и вдруг получаешь разные точки. Это не ошибка: каждый датасет должен немного отличаться, иначе мы не увидим чувствительность модели к выборке. Но для проверки кода иногда нужен в точности тот же результат. Поэтому make_dataset должна совмещать случайность с возможностью её повторить.

Функция принимает число наблюдений n_samples, величину шума noise_std, границы x_range и необязательный seed. Сначала создай отдельный генератор случайных чисел из seed. Затем получи n_samples значений x, равномерно распределённых между левой и правой границами диапазона.

Для каждого x вычисли значение известной истинной зависимости из шага 17: sin(1.5 * x) + 0.5 * x. Но это пока идеально чистые ответы. Добавь к ним независимый гауссовский шум: его среднее равно нулю, стандартное отклонение задаёт noise_std, а количество значений совпадает с n_samples. Функция должна вернуть пару массивов x и y одинаковой длины.

Проверь два свойства. С одинаковым seed повторные вызовы дают одинаковые массивы. С другим seed точки меняются, хотя остаются порождены тем же правилом. И не добавляй шум к x: случайная погрешность относится только к наблюдаемым ответам y.

🎒 На пальцах. Представь автомат, который раскладывает бусины вдоль волнистой направляющей, а затем слегка сдвигает каждую вверх или вниз. seed — номер настройки автомата: тот же номер воспроизводит то же расположение бусин. Другой номер создаёт новую россыпь, но направляющая и сила случайных сдвигов остаются прежними.

Практика: make_dataset

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
