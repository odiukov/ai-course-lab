Пишем dot

Ты передаёшь функции два профиля: предпочтения слушателя [2, -1, 3] и характеристики трека [4, 5, 1]. Если случайно перемножить сами списки или сначала сложить каждый из них, получится совсем не та оценка. Здесь важно не потерять соответствие позиций: первый признак работает только с первым, второй — со вторым, третий — с третьим.

Напиши функцию dot(a, b), которая принимает два числовых списка одинаковой длины и возвращает одно число. Возьми правило скалярного произведения из шага 7: для каждой позиции перемножь пару значений, а затем сложи получившиеся произведения.

Проверь себя на примерах:

dot([2, -1, 3], [4, 5, 1])  # 6
dot([3, 0], [1, 0])          # 3
dot([1, 2], [0, 0])          # 0

Особенно внимательно посмотри на отрицательные числа: произведение -1 и 5 должно уменьшить итог на 5. Ещё одна ловушка — списки разной длины. Попарный обход может незаметно проигнорировать лишние координаты, хотя такие векторы нельзя корректно сопоставить. Поэтому функция должна явно отклонять входы разной длины. Для двух пустых списков естественный результат — 0: пар нет, складывать нечего.

🎒 На пальцах. Представь пульт звукорежиссёра: на нём одинаково расположены ручки баса, голоса и ударных. Ты сравниваешь настройки двух записей ручка к ручке, получаешь вклад каждой пары и складываешь их. Если на одном пульте есть лишняя ручка, молча пропустить её нельзя — пульты описывают разные наборы признаков.
