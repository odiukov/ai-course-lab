Пишем train_lr

В начале все веса равны нулю, поэтому каждый отзыв получает logit 0, а sigmoid из шага 18 возвращает 0.5. Модель пока одинаково сомневается во всех примерах. Твоя задача — написать train_lr, которая будет много раз измерять ошибку и понемногу корректировать параметры.

Сначала возьми число признаков из X.shape[1], создай вектор w такой длины и отдельное число b — свободный член. Затем повтори обучение epochs раз. На каждой эпохе нужны четыре действия:

  1. Получить logits сразу для всех строк: матрица X умножается на веса, после чего добавляется b.
  2. Превратить logits в вероятности функцией sigmoid.
  3. Вычислить err как разницу между вероятностями и правильными метками y.
  4. Посчитать градиенты и сдвинуть параметры в противоположную им сторону.

Для grad_w используй выражение из шага 19: ошибка проходит обратно через X.T, усредняется по числу примеров и получает L2-добавку l2 * w. Градиент для b проще: это средняя ошибка err.mean(). L2 к нему здесь не применяется, потому что b не соответствует отдельному слову.

Обрати внимание на знак обновления: из w и b нужно вычитать градиент, умноженный на lr. Сложение отправило бы модель в сторону большей ошибки. После последней эпохи верни оба обученных параметра: w и b.

🎒 На пальцах. Представь настройщика печатного станка. Он печатает пробный лист, сравнивает цвета с образцом и слегка поворачивает регуляторы. Затем печатает снова. lr задаёт размер одного поворота, epochs — число пробных листов, а L2 работает как пружина на регуляторах: не мешает настройке, но не позволяет одному из них без веской причины выкрутиться до упора.
