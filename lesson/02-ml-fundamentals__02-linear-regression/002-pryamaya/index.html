Модель y = wx + b

Представь тариф курьера: за сам вызов берут 3 €, а за каждый километр — ещё 2 €. Доставка на 4 км стоит 11 €, на 5 км — 13 €. Тебе не нужна отдельная таблица для всех расстояний: достаточно двух чисел, описывающих правило.

Линейная модель записывает его так:

y=wx+by = wx + by=wx+b

Здесь xxx — известный вход, например расстояние; yyy — предсказанный результат, то есть цена доставки. Число www показывает, насколько изменится предсказание, если xxx увеличить на единицу. В нашем тарифе w=2w=2w=2: каждый следующий километр добавляет 2 €. Число bbb — результат при x=0x=0x=0. Здесь b=3b=3b=3: даже поездка нулевой длины не бесплатна, потому что остаётся плата за вызов.

Подставь 7 км: модель берёт семь раз по 2 € и добавляет базовые 3 €, получая 17 €. Если заменить www, изменится доплата за каждый километр. Если заменить bbb, одинаковая сумма прибавится к прогнозу для любого расстояния.

Для цен домов из шага 1 смысл тот же: модель подбирает www и bbb так, чтобы её предсказания были близки к известным ценам из примеров. Эти два числа — не готовые истины, а настраиваемые параметры модели.

🎒 На пальцах. Представь счётчик в такси. При посадке на нём уже есть стартовая сумма — это bbb. Затем каждый километр добавляет одну и ту же плату — её задаёт www. Расстояние меняется, итоговая цена меняется, но правило остаётся прежним: повторяющаяся прибавка плюс фиксированный старт.
