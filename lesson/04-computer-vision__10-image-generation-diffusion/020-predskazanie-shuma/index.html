Epsilon prediction превращает обучение диффузии в обычную MSE-задачу

Ты берёшь чистую фотографию, сам накладываешь на неё случайное зерно, а затем показываешь сети только испорченный результат. Кажется, возникает проблема: откуда взять правильный ответ для обучения? Но зерно добавлял ты — значит, его точный рисунок уже сохранён в переменной ϵ\epsilonϵ.

Для каждого изображения выбирается случайный момент ttt, как в шаге 19, и сразу получается соответствующее xtx_txt​ по формуле из шага 14. Сеть получает xtx_txt​ вместе с номером шага и выдаёт свою версию шума: ϵθ(xt,t)\epsilon_\theta(x_t,t)ϵθ​(xt​,t). Здесь θ\thetaθ обозначает настраиваемые параметры сети.

Теперь предсказание можно напрямую сравнить с шумом, который действительно был добавлен:

L=mean⁡((ϵ−ϵθ(xt,t))2)L=\operatorname{mean}\left((\epsilon-\epsilon_\theta(x_t,t))^2\right)L=mean((ϵ−ϵθ​(xt​,t))2)

LLL — ошибка обучения; ϵ\epsilonϵ — настоящий добавленный шум; ϵθ\epsilon_\thetaϵθ​ — предсказание сети. Для каждого элемента изображения берётся разница, возводится в квадрат, а затем все значения усредняются. Это и есть MSE — средняя квадратичная ошибка.

Если сеть промахнулась сильно, квадрат заметно увеличит штраф. Затем параметры немного меняются так, чтобы при похожем уровне зашумления ошибка стала меньше. Повторяя это с разными изображениями, шумом и шагами, одна сеть осваивает все уровни процесса.

Случайное повреждение перестаёт быть помехой: поскольку ты создал его сам, оно становится готовой учебной меткой.

🎒 На пальцах. Представь фоторедактора, который добавляет к снимку известный слой цифрового зерна, а ученику отдаёт только итоговую картинку. У редактора остался исходный слой, поэтому работу легко проверить: сравнить каждую предсказанную крупинку с настоящей и усреднить квадраты ошибок. Ученику не нужно спорить с другим художником — он просто раз за разом уменьшает измеримый промах.
