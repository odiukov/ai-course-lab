Контур обучения DQN из четырёх взаимодействующих частей

Ты нажимаешь «вправо»: герой видит новый кадр, получает награду и продолжает игру. Куда теперь отправить этот короткий опыт? Если сразу учить на нём сеть, соседние кадры потянут её в одну сторону — та самая нестабильность из шага 4. Поэтому на схеме опыт проходит не по прямой, а по замкнутому контуру из четырёх частей.

Среда принимает действие и возвращает переход: прежнее состояние, действие, награду и новое состояние. Этот переход попадает в replay-буфер — хранилище прошлых эпизодов. Для очередного обучения оттуда случайно берут небольшую пачку: рядом оказываются события из разных моментов, а полезный редкий опыт можно использовать повторно.

Online-сеть — рабочая версия Q-сети из шага 3. Она оценивает действия, помогает выбирать следующее и меняет свои веса, учась на пачке переходов. Но ей нужен ориентир: насколько хорошим считать полученный результат?

Его вычисляет target-сеть — отдельная, временно замороженная копия online-сети. Пока online-сеть делает много маленьких обновлений, target-сеть сохраняет прежние оценки. Через несколько тысяч шагов в неё копируют свежие веса online-сети, и ориентир обновляется одним контролируемым скачком.

Так каждая часть сдерживает другую: среда даёт опыт, буфер перемешивает его, online-сеть учится, а target-сеть не позволяет учебной цели уезжать после каждого движения весов.

🎒 На пальцах. Представь курсанта в автосимуляторе. Симулятор создаёт дорожные ситуации, бортжурнал сохраняет каждую поездку, курсант разбирает случайные записи и меняет стиль вождения. Инструктор оценивает разбор по правилам, которые не переписывает после каждой ошибки. Лишь иногда он обновляет памятку по улучшившимся навыкам курсанта — поэтому обучение движется вперёд, не превращаясь в погоню за меняющимися требованиями.
