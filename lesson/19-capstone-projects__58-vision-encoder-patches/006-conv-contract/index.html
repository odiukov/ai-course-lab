Используем Conv2d как пакетную линейную проекцию патчей

У тебя уже есть картинка размером 224×224224 \times 224224×224, а модели нужны числовые представления её патчей. Можно вырезать все области 16×1616 \times 1616×16, распрямить каждую и по очереди пропустить через один линейный слой. Но зачем вручную собирать 196 отдельных кусочков, если Conv2d умеет выполнить те же вычисления сразу для всего батча?

Настроим свёртку так: kernel_size=16, stride=16, без padding. Ядро — это набор обучаемых весов, который прикладывается к небольшой области изображения. Поскольку размер шага совпадает с размером ядра, после каждого вычисления оно перескакивает ровно на следующий патч. Области не перекрываются и между ними не остаётся щелей.

Каждый из hidden выходных каналов получает собственное ядро размером 3×16×163 \times 16 \times 163×16×16: три цветовых канала и пиксели одного патча. Оно умножает эти значения на веса, складывает результаты и добавляет смещение. Это в точности одна координата обычной линейной проекции распрямлённого патча. Все ядра вместе дают полный вектор патча.

По каждой стороне помещается 14 окон, поэтому из входа формы [batch, 3, 224, 224] получается [batch, hidden, 14, 14]. Conv2d не меняет смысл операции — лишь выполняет одинаковую линейную проекцию для всех патчей пакетно и эффективно.

🎒 На пальцах. Представь пресс для шоколадной плитки: одна форма одновременно прижимает каждый квадрат и оставляет на нём набор признаков. Если форма шириной 16 миллиметров каждый раз сдвигается ровно на 16, отпечатки не накладываются. Меняя набор выступов формы, ты получаешь hidden разных чисел для каждого квадрата — именно так ядра превращают патч в вектор.
