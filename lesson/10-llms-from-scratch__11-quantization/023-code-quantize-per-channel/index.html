Пишем quantize_per_channel

Ты запускаешь функцию на матрице из двух строк и ожидаешь два масштаба — по одному на строку. Но если случайно искать максимум по той же оси, которую назвал axis=0, получатся масштабы столбцов. Здесь легко перепутать: параметр задаёт каналы, а максимум нужно брать по измерению внутри каждого канала, как разобрано в шаге 22.

Дополни quantize_per_channel(tensor, num_bits=8, axis=0). Сначала определи границы целых кодов для выбранной битности — так же, как в функции из шага 12. Затем найди максимальное абсолютное значение отдельно для каждого канала:

  • при axis=0 каналами считаются строки, поэтому максимум ищется внутри каждой строки;
  • при другом поддерживаемом значении каналами считаются столбцы, поэтому максимум ищется внутри каждого столбца.

Сохрани у результата измерение длины 1: оно понадобится, чтобы каждый элемент матрицы делился именно на масштаб своего канала. Сам механизм такого совмещения разберём отдельно; сейчас проверь прежде всего формы массивов.

Нулевой канал требует защиты: замени его нулевой максимум на 1.0, иначе появится деление на ноль. После этого вычисли масштабы, округли и ограничь коды допустимым диапазоном, преобразуй их в int32. Функция должна вернуть матрицу кодов прежней формы и одномерный массив масштабов — по одному числу на канал.

🎒 На пальцах. Представь микшерный пульт: каждая дорожка записана со своей громкостью. Ты отдельно находишь пик каждой дорожки и выставляешь ей чувствительность. Если дорожка полностью молчит, ручку всё равно оставляешь в безопасном положении, а не делишь настройки на ноль. В итоге дорожки получают разные масштабы, но их отсчёты остаются на прежних местах.
