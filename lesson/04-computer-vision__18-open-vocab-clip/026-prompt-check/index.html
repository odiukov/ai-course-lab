Проверка: число prompts, формы embedding и усреднение по классу

Здесь проверь, связываешь ли ты результат build_prompts из шага 23 с усреднением из шага 25. Чаще всего путают две оси: количество классов и количество шаблонов. До усреднения строк столько, сколько всех prompts; после — столько, сколько классов. Размерность каждого embedding при этом не меняется.

Затем ты отдельно сводишь четыре карточки синей краски, четыре зелёной и четыре красной. Получаются три итоговых образца — по одному на цвет, а не один средний цвет всей коробки.
