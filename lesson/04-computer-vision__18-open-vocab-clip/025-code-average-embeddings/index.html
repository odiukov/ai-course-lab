Пишем average_class_embeddings

У тебя есть три класса и по четыре шаблона для каждого. Текстовый энкодер вернул 12 строк, но классификатору нужны только три: по одному устойчивому представлению класса. Если усреднить сразу все строки, классы смешаются, и получится один бесполезный embedding.

Функция average_class_embeddings должна собрать вместе варианты, относящиеся к одному классу, и усреднить их по оси шаблонов. Ориентируйся на порядок строк, созданный функцией build_prompts из шага 23: после группировки должна появиться форма «число классов × число шаблонов × размерность embedding». Затем среднее убирает только измерение шаблонов, оставляя форму «число классов × размерность embedding».

Обрати внимание на две нормализации. Сначала примени написанную в шаге 7 функцию normalize_rows к каждому embedding отдельного prompt. Иначе длинная строка-вектор получит больший вес просто из-за масштаба. После усреднения нормализуй уже получившиеся embeddings классов: среднее нескольких единичных векторов обычно само не имеет единичной длины.

Не усредняй по размерности embedding — это превратит каждую строку в одно число. Не смешивай классы и не возвращай отдельные шаблоны. Итог функции — ровно один нормализованный вектор на класс, готовый к сравнению с изображением.

🎒 На пальцах. Представь, что ты выбираешь эталонный оттенок краски по нескольким образцам одного цвета, снятым при разном освещении. Сначала приводишь каждый образец к одинаковой яркости, затем смешиваешь только образцы одного цвета и снова выравниваешь яркость результата. Так «синий» не смешается с «зелёным», а один слишком яркий снимок не перетянет эталон на себя.

Практика: average_class_embeddings

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
