Пишем softmax

Твоя функция получает не одно число, а список логитов — например, оценки трёх классов. Если обработать каждую оценку независимо, получится набор чисел, которые ничего не знают друг о друге. Но в шаге 39 softmax распределял между вариантами одну общую вероятность.

Напиши функцию softmax(xs), которая возвращает список той же длины. Сначала для каждого элемента вычисли экспоненту. Затем сложи все получившиеся значения. Наконец, раздели каждую экспоненту на эту общую сумму.

Здесь важен именно порядок действий: знаменатель должен быть один для всего списка. Если пересчитывать сумму отдельно не требуется — она от этого не изменится, а функция лишь выполнит лишнюю работу.

Проверь себя на одинаковых логитах, например [0.0, 0.0, 0.0]. Ни у одного варианта нет преимущества, поэтому выходные вероятности тоже должны быть одинаковыми — примерно по 0.333. Их сумма должна получиться равной 1 с учётом небольшой погрешности вычислений.

Функция не выбирает победителя и не возвращает только наибольшую вероятность. Она сохраняет отдельную вероятность для каждого исходного логита: первый выход соответствует первому входу, второй — второму и так далее.

🎒 На пальцах. Представь три пустых стакана и один кувшин воды. Логиты определяют, какая доля достанется каждому стакану, но весь кувшин нужно распределить целиком. Сначала ты определяешь относительный «вес» каждого стакана, затем делишь каждый вес на их общую сумму. Поэтому доли могут различаться, но вместе всегда дают один полный кувшин.
