Пишем probe_state_freshness

Ты запускаешь стенд утром, а файл состояния лежит на месте. Простая проверка существования говорит: всё хорошо. Но последняя запись сделана три дня назад — агент получит не память о текущей работе, а аккуратно сохранённое прошлое. Поэтому в probe_state_freshness важны две проверки: файл существует и он достаточно свежий по контракту из шага 13.

Собери функцию по такой последовательности:

  1. Получи путь к файлу состояния и допустимый возраст.
  2. Если файла нет, сразу верни результат пробы со статусом block. В detail укажи, какой путь проверялся.
  3. Для существующего файла прочитай время последнего изменения.
  4. Вычисли возраст: из текущего времени вычти время изменения файла.
  5. Сравни возраст с допустимым пределом. Если предел превышен, верни block; иначе — pass.
  6. В обоих случаях сохрани единый контракт (name, status, detail) из шага 5.

Обрати внимание на границу: файл с возрастом ровно в допустимый предел ещё проходит проверку, а более старый — уже нет. Не прячь числа за расплывчатым сообщением «state is stale». В detail полезно показать фактический и допустимый возраст: тогда человек сразу понимает масштаб расхождения.

Проверь функцию минимум на трёх случаях: файла нет, файл свежий, файл устарел. Для тестов удобнее передавать путь и предел параметрами, а не зашивать их внутрь: так ты сможешь создать временный файл и управлять его временем изменения.

Здесь наличие файла отвечает только на вопрос «память найдена», а его возраст — «этой памяти ещё можно доверять».

🎒 На пальцах. Представь ценник на витрине обменного пункта. Он висит на нужном месте и выглядит исправно, но рядом мелко указано время обновления. Если курс выставили три дня назад, само наличие ценника ничего не гарантирует. probe_state_freshness так же смотрит не только на файл, но и на его «время обновления», после которого данные перестают быть основанием для работы.

Практика: probe_state_freshness

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
