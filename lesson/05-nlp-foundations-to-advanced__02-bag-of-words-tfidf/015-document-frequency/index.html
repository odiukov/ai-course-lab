Пишем document_frequency

Возьми BoW-матрицу из функции, написанной на шаге 9. Например, её строки выглядят так:

[
    [2, 0, 1],
    [1, 3, 0],
    [0, 1, 1],
]

Тебе нужно написать document_frequency(bow_matrix), которая вернёт один результат для каждого столбца:

[2, 2, 2]

Легко получить неверные числа, если складывать значения ячеек. Первая колонка содержит 2 + 1 + 0, но ответ для неё равен не 3, а 2: слово встретилось в двух документах. Разницу между повторами и присутствием мы разобрали на шаге 14.

Сначала подготовь список нулей — по одному нулю на каждый столбец матрицы. Затем пройди по строкам. Внутри каждой строки проверяй каждую ячейку: если счётчик больше нуля, увеличивай результат соответствующего столбца ровно на единицу. Само значение счётчика не прибавляй.

Обрати внимание на связь индексов: ячейка с индексом j должна менять элемент результата с тем же индексом j. Удобно получать индекс и значение одновременно при переборе строки.

Проверь функцию ещё на таком случае:

[
    [5, 0],
    [0, 1],
    [0, 0],
]

Ожидаемый результат — [1, 1]. Пять повторов первого слова всё ещё принадлежат одному документу.

🎒 На пальцах. Представь турникет на трёх станциях метро. Тебе важно узнать не число пассажиров, а на скольких станциях сегодня был поток. Сто человек на одной станции дают ей одну отметку «работала». Так и функция ставит слову не столько отметок, сколько было повторов, а по одной за каждый документ, где оно встретилось.
