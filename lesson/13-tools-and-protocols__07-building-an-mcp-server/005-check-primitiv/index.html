Проверка: tool, resource или prompt

К этому моменту ты должен уметь взять любую новую возможность сервера заметок и, не заглядывая в спецификацию, сказать, в какой из трёх ящиков она ложится, — по разбору из шага 4.

Спотыкаются обычно на двух местах. Первое: наличие аргумента путают с изменением состояния. «Ей нужен номер заметки, значит это ресурс» — нет; спрашивать надо, изменился ли мир после вызова. Второе: чтение записывают в инструменты, потому что «сервер же что-то делает». Делает, но ничего не меняет — и тогда это адрес вида notes://14, а не notes_read.

Проверь себя на двух вопросах ниже.

  1. Ты добавляешь в сервер заметок возможность «notes_delete» — удалить заметку по номеру. В какой ящик она ложится?

  2. Клиент хочет получить текст заметки номер 14 и ничего в ней не менять. Какая форма для этого правильная?
