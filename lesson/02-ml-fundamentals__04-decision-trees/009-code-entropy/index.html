Пишем entropy

У тебя есть список меток: например, ["кот", "кот", "пёс"]. Функция entropy(labels) должна превратить его в одно число — меру неопределённости из шага 8. Самый важный вопрос здесь: как перейти от отдельных меток к долям классов?

Сначала найди общее количество элементов. Для пустого списка сразу верни 0.0: в узле без объектов нечего измерять, а деление на ноль сломает вычисление.

Затем собери словарь счётчиков. Проходя по списку, увеличивай число напротив каждой встреченной метки. Для примера выше получится два кота и один пёс. После этого каждый счётчик раздели на общее количество элементов — так ты получишь долю класса.

Останется применить к каждой доле выражение из формулы энтропии и сложить результаты. Для логарифма используй math.log2. Обрати внимание на минус перед всей суммой: сами логарифмы долей отрицательны, а итоговая энтропия должна быть неотрицательной.

Проверь крайние случаи. Для четырёх одинаковых меток функция должна вернуть 0.0, а для двух разных меток с равными долями — 1.0. Если первое число не ноль, ищи ошибку в подсчёте долей; если второе отрицательное — скорее всего, потерялся минус.

🎒 На пальцах. Представь библиотекаря, который разбирает стопку книг по жанрам. Сначала он считает всю стопку, затем отмечает, сколько в ней детективов, фантастики и биографий. После этого переводит количества в доли и для каждой делает один и тот же расчёт. entropy работает так же: не рассматривает метки по отдельности, а сначала превращает их в состав всей стопки.

Практика: функция entropy. Писать код — в локальном приложении курса.
