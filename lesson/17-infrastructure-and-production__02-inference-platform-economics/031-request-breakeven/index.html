Слово «сопоставимого» здесь решающее. Размер входа и ответа должен оставаться тем же, как в профиле нагрузки из шага 2. Кроме того, GPU должен физически успевать обработать рассчитанный объём с учётом пиков из шага 25. Иначе арифметическая окупаемость существует только на бумаге.
