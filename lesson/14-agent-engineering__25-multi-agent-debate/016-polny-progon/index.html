Полный прогон: начальные ответы, раунды и остановка

Ты запускаешь дебаты с лимитом в три раунда, но после первого все агенты уже выбрали один ответ. Продолжать ещё два раунда? Нет: лимит задаёт потолок, а не обязательную длину обсуждения.

Полный прогон начинается с независимых начальных ответов. Это важно: если агенты сразу увидят чужие версии, ты потеряешь разные исходные точки зрения. Затем запускается первый раунд из шага 14: каждый читает только своих соседей, критикует их позиции и пересматривает свою. Все изменения применяются одновременно, как в функции из шага 15, поэтому никто не получает преимущество из-за порядка обработки.

После каждого раунда ты проверяешь сходимость — стали ли ответы одинаковыми. Если да, дебаты останавливаются досрочно. Если нет, начинается следующий раунд, пока не исчерпан заданный лимит. Возможен и нулевой результат по раундам: агенты могли независимо дать одинаковый ответ с самого начала.

Но что вернуть, если лимит закончился, а мнения всё ещё различаются? Тогда обсуждение прекращается, а итог выбирает уже знакомое голосование — например, большинство из шага 4. Число выполненных раундов и операций критики нужно считать по фактическому прогону, а не по максимальному лимиту. Ранняя сходимость экономит работу только тогда, когда ты действительно остановился.

🎒 На пальцах. Представь совещание жильцов о цвете подъезда. Сначала каждый молча записывает вариант, затем участники обсуждают записи и снова голосуют. Если все выбрали синий уже после первого обсуждения, назначать ещё две встречи незачем. Если согласия нет и время вышло, решение принимают большинством — а в отчёте указывают только реально проведённые встречи.
