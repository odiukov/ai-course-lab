Cross-entropy — минус логарифм вероятности правильного класса

Из шага 2 у тебя уже есть мысль: loss измеряет, насколько предсказанное распределение разошлось с правильным. Теперь нужно превратить это в одно число, которое можно уменьшать. Cross-entropy и есть это число.

Правильный ответ — это распределение, где на верном классе стоит 1, а на всех остальных 0. Значит, из всего вектора модели важна ровно одна цифра: какую вероятность она дала верному классу. Если 0.91 — почти угадала, штраф должен быть крошечным. Если 0.01 — промазала, штраф должен быть большим.

L=−log⁡P(правильный класс)\mathcal{L} = -\log P(\text{правильный класс})L=−logP(правильный класс)

Здесь P(правильный класс)P(\text{правильный класс})P(правильный класс) — та самая вероятность, которую модель выдала для верного ответа (после softmax из шага 45), log⁡\loglog — натуральный логарифм, а минус впереди переворачивает знак: логарифм вероятности всегда отрицателен или ноль, а loss удобнее держать положительным.

Подставь числа. P=0.91P = 0.91P=0.91 даёт loss 0.090.090.09. P=0.5P = 0.5P=0.5 — уже 0.690.690.69. P=0.01P = 0.01P=0.01 — 4.64.64.6. Чем ниже уверенность в правильном классе, тем резче растёт штраф, и растёт он без потолка. При P=1P = 1P=1 штраф равен нулю.

Остальные классы в формулу не входят напрямую, но сумма вероятностей равна единице (шаг 16), поэтому поднять верный класс можно только опустив неверные.

Cross-entropy наказывает модель ровно по этому принципу.
