Пишем cross_modal_error_rate

Ты проверяешь пакет из четырёх ответов. У одного уверенность 0,93, но сходство с изображением всего 0,12. У другого сходство тоже низкое, однако уверенность лишь 0,54. Какой из них считать подозрительным? Только первый: ошибка CMER возникает, когда одновременно выполнены оба условия из шага 34.

Напиши cross_modal_error_rate. Функция получает эмбеддинги изображений и ответов, уверенность каждого ответа и два порога. Сначала нормализуй оба набора эмбеддингов по последней оси через F.normalize. Это важно: после нормализации скалярное произведение станет косинусной близостью, разобранной в шаге 32. Затем перемножь соответствующие компоненты image_emb и text_emb и сложи результат по последней оси. Должно получиться одно значение сходства на каждую пару «изображение — ответ».

Теперь создай булеву маску. В ней True стоит только там, где text_confidence строго выше conf_threshold, а сходство строго ниже sim_threshold. Проверь именно направление сравнений: высокая уверенность сама по себе не ошибка, как и слабое сходство у неуверенного ответа.

Осталось превратить маску в числа: True — в 1.0, False — в 0.0. Среднее этих чисел и есть доля подозрительных ответов во всём пакете. Верни обычное Python-число, а не тензор. Например, если условие выполнилось для 3 из 100 ответов, результат должен быть 0.03.

🎒 На пальцах. Представь контролёра на викторине: он поднимает красный флажок, только если участник говорит «я совершенно уверен» и одновременно не может показать подтверждение в книге. Неуверенный ответ без подтверждения флажка не получает. В конце ты делишь число поднятых флажков на число всех участников — так булева маска превращается в CMER.

Практика: cross_modal_error_rate

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
