Пишем box_iou

У тебя есть 300 рамок-кандидатов и 12 размеченных объектов. Сравнивать их по одной — значит делать 3600 одинаковых операций вручную. Функция box_iou должна сразу вернуть всю матрицу сравнений из шага 9: строки соответствуют кандидатам, столбцы — размеченным рамкам.

Будем считать, что каждая рамка записана как (x1, y1, x2, y2), где первая точка — левый верхний угол, а вторая — правый нижний. Заготовка выглядит так:

def box_iou(boxes1, boxes2):
    """
    boxes1: тензор формы (N, 4)
    boxes2: тензор формы (M, 4)

    returns: IoU формы (N, M)
    """
    # 1. Посчитай площади всех рамок
    # 2. Найди пересечение каждой рамки boxes1 с каждой рамкой boxes2
    # 3. Посчитай площадь пересечений
    # 4. Найди объединение и верни IoU

Главная трудность — получить не N отдельных значений, а все N × M пар. Добавь одной группе рамок размерность через boxes1[:, None, ...]. Тогда PyTorch сможет автоматически сопоставить каждую её рамку с каждой рамкой из второй группы.

Для левого верхнего угла пересечения выбирай большие координаты двух рамок, для правого нижнего — меньшие. Если рамки не соприкасаются, получившиеся ширина или высота окажутся отрицательными. Прижми их снизу к нулю с помощью clamp: иначе «отрицательное пересечение» превратится в ошибочную положительную площадь.

Проверь три случая: одинаковые рамки дают 1, непересекающиеся — 0, а результат для двух и трёх рамок имеет форму (2, 3). Ещё убедись, что ты делишь площадь пересечения на площадь объединения, а не просто на сумму площадей: пересечение уже входит в обе площади и должно учитываться только один раз.

🎒 На пальцах. Представь два набора прозрачных прямоугольных наклеек на световом столе. Ты по очереди накладываешь каждую наклейку первого набора на каждую из второго и записываешь долю совпавшей области в таблицу. box_iou делает то же самое одновременно: одна ось таблицы хранит первый набор, другая — второй, а каждая ячейка относится к своей паре.

Практика: box_iou

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
