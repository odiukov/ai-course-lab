В eval-режиме модель возвращает предсказания переменной длины

Ты подаёшь модели сразу две фотографии и пытаешься собрать ответ в один тензор. Но на первой она нашла 3 объекта, а на второй — 17. Единой формы вроде (2, N, 4) здесь нет: значение N разное для каждого изображения.

Поэтому в eval-режиме результат устроен как список:

predictions = model([image_a, image_b])
p_a, p_b = predictions

Каждый элемент списка — словарь boxes, labels, scores и masks, знакомый по шагу 30. Внутри одного словаря все поля согласованы по первой размерности. Если для изображения найдено N объектов, формы будут такими:

boxes:  (N, 4)
labels: (N,)
scores: (N,)
masks:  (N, 1, H, W)

Строка с индексом i во всех четырёх тензорах описывает один и тот же экземпляр. После порога маски можно получить (N, H, W), убрав одиночный канал:

binary_masks = (p_a["masks"] > 0.5).squeeze(1)

N зависит от изображения и настроек отбора предсказаний. Иногда он может быть даже нулём — тогда модель возвращает пустые тензоры правильной формы, а не None.

И не смешивай два переключателя: model.eval() включает поведение для инференса, а torch.no_grad() лишь отключает вычисление градиентов и экономит память. Для обычного предсказания нужны оба.

🎒 На пальцах. Представь кассовые чеки двух покупателей: у одного 3 товара, у другого 17. Ты не обрезаешь длинный чек и не дополняешь короткий пустыми покупками. Касса выдаёт список чеков переменной длины, но внутри каждого чека номер строки связывает название, цену, количество и скидку одного товара. Так же индекс связывает рамку, класс, уверенность и маску объекта.
