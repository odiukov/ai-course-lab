Пишем validate_detection

Ты получил детекцию с вполне убедительным score = 0.92, но её рамка выходит за границы изображения. Можно ли пропустить такую запись дальше? Нет: хорошее значение одного поля не компенсирует ошибку в другом.

Напиши validate_detection, которая принимает детекцию и размеры изображения. Она должна вернуть True только тогда, когда одновременно выполнены три условия из шага 8:

  • box проходит проверку функцией validate_box из шага 7;
  • score находится в диапазоне от 0 до 1, включая обе границы;
  • class_id — целое неотрицательное число.

Здесь важно не переписывать проверку координат внутри новой функции. Вызови уже готовую validate_box, передав ей рамку, ширину и высоту изображения. Тогда правила рамки останутся в одном месте: если контракт координат изменится, тебе не придётся искать его копии по всему проекту.

Соедини результаты проверок логическим «и». Например, детекция с правильной рамкой и score = 1.2 всё равно должна дать False. То же произойдёт при class_id = -1, даже если остальные значения корректны.

Обрати внимание на границы: score = 0 и score = 1 допустимы, как и class_id = 0. Частая ошибка — случайно исключить эти значения с помощью строгих сравнений.

🎒 На пальцах. Представь сотрудника на входе в закрытую студию. Он сверяет у пропуска три вещи: срок действия, уровень доступа и номер владельца. Две правильные отметки не перекрывают третью неверную. validate_detection работает так же: пропускает запись дальше только после трёх успешных проверок, причём сложную проверку рамки поручает уже обученному «контролёру» — validate_box.

Практика: validate_detection

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
