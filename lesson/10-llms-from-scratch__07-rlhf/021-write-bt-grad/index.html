Пишем bradley_terry_grad

Ты запускаешь обучение на одной паре: модель дала preferred награду 1,2, а rejected — 0,4. Разность уже направлена правильно, но веса сами по себе не изменятся: функции обучения нужны конкретные градиенты для обеих наград.

Напиши bradley_terry_grad(reward_preferred, reward_rejected). Она должна вернуть два числа: производную потери по reward_preferred и производную по reward_rejected.

Сначала найди разность наград и вычисли общий градиент по ней тем способом, который выведен в шаге 20. Затем учти, как каждая награда входит в разность:

  • для preferred верни общий градиент без изменения;
  • для rejected верни число с противоположным знаком.

Это важная проверка: сумма двух результатов должна равняться нулю. Обучение раздвигает оценки в разные стороны с одинаковой силой — повышает относительное положение preferred и понижает относительное положение rejected.

Не вставляй внутрь функции learning rate и не обновляй веса. Её единственная задача — посчитать и вернуть два градиента. Для самопроверки подставь одинаковые награды: вероятность предпочтения будет 0,5, поэтому градиент preferred должен получиться отрицательным, а rejected — положительным. Значит, последующий шаг градиентного спуска подтолкнёт первую награду вверх, а вторую вниз.

🎒 На пальцах. Представь два лифта: preferred нужно поднять, а rejected опустить. Один трос связывает их так, что движение симметрично. Функция градиента не нажимает кнопки лифтов — она лишь сообщает направления: для одного отрицательное число, для другого такое же положительное. Само перемещение произойдёт позже, когда обучение применит learning rate.
