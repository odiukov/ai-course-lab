Пишем bellman_sweep

У тебя есть словарь V с текущими ценностями. За один проход функция должна подготовить следующую версию этого словаря. Здесь легко случайно смешать старые и новые числа: обновить первое состояние, а при расчёте второго уже воспользоваться свежим результатом. Тогда получится in-place проход из шага 20, хотя сейчас нужен синхронный.

Напиши bellman_sweep(V, gamma). Сначала создай независимую копию V для результатов. Затем перебери все состояния. Терминальное состояние пропусти: его ценность не должна изменяться. Для каждого остальных состояний получи ценность каждого действия через q_value из шага 17 и выбери наибольшую. Запиши её в новый словарь.

Самая важная деталь: во всех вызовах q_value передавай исходный V, а не постепенно заполняемый новый словарь. Так каждое состояние рассчитывается по одному и тому же «снимку» ценностей, поэтому порядок обхода не влияет на результат прохода.

Когда все обновления готовы, найди delta с помощью sup_norm из шага 19. Функция должна вернуть и новый словарь, и delta: первый понадобится следующему проходу, второе число — для проверки остановки.

Проверь две частые ошибки: простое присваивание не создаёт независимую копию словаря, а максимум нужно брать по ценностям действий одного состояния, не по состояниям целиком.

🎒 На пальцах. Представь редактора, который выпускает исправленное издание справочника. Все правки он делает, сверяясь с одной вчерашней копией, а не с уже исправленными страницами сегодняшнего макета. Лишь закончив весь выпуск, он сравнивает две версии и находит самое заметное изменение. V — вчерашнее издание, новый словарь — сегодняшний макет, а delta — крупнейшая правка.
