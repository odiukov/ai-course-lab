Пишем normal_equations

Тебе передали 100 наблюдений и 3 неизвестных: A имеет форму (100, 3), а b — (100,). Функция gaussian_elimination из шага 22 решает квадратные системы, но исходная матрица не квадратная. Как состыковать их, не пытаясь удалить 97 строк?

Напиши функцию normal_equations(A, b). Она должна собрать нормальную систему, полученную в шаге 43, и передать её уже готовому решателю:

  1. Транспонируй A.
  2. Вычисли матрицу левой части. При форме A == (m, n) результат должен иметь форму (n, n).
  3. Вычисли правую часть формы (n,).
  4. Вызови gaussian_elimination для полученной квадратной системы и верни найденный вектор x.

Используй матричное умножение @. Не вычисляй обратную матрицу: здесь она не нужна.

После реализации проверь не только форму ответа. Посчитай невязку r = A @ x - b, а затем A.T @ r. Этот последний вектор должен быть близок к нулю: именно это условие функция превращает в квадратную систему. Для сравнения с плавающей точкой подойдёт np.allclose, а не точное ==.

🎒 На пальцах. Представь 100 заполненных анкет, из которых нужно оценить три параметра. Твой квадратный решатель принимает только три итоговых вопроса. Умножения с A.T аккуратно сводят все анкеты к таблице 3 × 3 и трём итогам — после этого прежний решатель снова подходит.

Практика: функция normal_equations. Писать код — в локальном приложении курса.
