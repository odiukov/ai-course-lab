Пишем forward_substitution

Ты запускаешь функцию и получаешь вектор правильной длины — но числа неверны. Частая причина: цикл идёт сверху вниз, а внутри берутся ещё не вычисленные значения. В прямой подстановке порядок важен не меньше самой арифметики.

Функция forward_substitution(L, b) должна найти y из системы Ly = b, где L — нижнетреугольная матрица, а b — правая часть. Сам способ разбирался в шаге 16; теперь переведём его в действия над массивами.

Создай вектор y длины len(b) и проходи строки L от первой к последней. Для строки с индексом i уже известны только элементы y с индексами меньше i. Умножь их на соответствующую часть строки L[i, :i] и сложи — это вклад ранее найденных неизвестных. Вычти его из b[i], затем раздели остаток на диагональный элемент L[i, i]. Полученное число запиши в y[i].

Обрати внимание на три детали:

  • массив для ответа лучше сразу создать с вещественным типом, иначе дробные результаты могут обрезаться;
  • в сумме должны участвовать только элементы левее диагонали;
  • не изменяй b: новая функция должна вернуть отдельный вектор y.

После реализации проверь результат умножением L @ y: он должен совпасть с исходным b. Эта проверка ловит и неверное направление цикла, и ошибочную границу среза.

🎒 На пальцах. Представь диспетчера, который рассаживает пассажиров по вагонам. Для первого вагона решение принимается сразу. Вместимость второго рассчитывается с учётом уже занятых мест в первом, третьего — с учётом первых двух. Заглядывать в ещё не обработанные вагоны бессмысленно: нужных чисел там пока нет. Поэтому список заполняется строго слева направо.
