Определяем ранг матрицы

Ты собрал матрицу поправки и хочешь выбрать ранг LoRA. Но по одним размерам матрицы ответ не виден: у неё может быть много строк и столбцов, хотя часть из них повторяет уже имеющиеся направления. Твоя функция должна определить, сколько в матрице действительно независимых направлений.

Для этого преврати копию матрицы в ступенчатый вид. Иди по столбцам слева направо и ищи строку с ненулевым элементом — опорным числом. Если такая строка нашлась, при необходимости поменяй её местами с текущей, а затем вычти её подходящие кратные из остальных строк. Так ты уберёшь повторяющуюся информацию. Каждый найденный опорный элемент увеличивает ранг на один.

Исходную матрицу не изменяй: она ещё понадобится для обучения и проверки LoRA. Также помни, что вычисления идут с дробными числами. Результат вроде 0.00000000003 обычно появляется из-за погрешности, а не обозначает новое направление. Поэтому считай элемент нулевым, если его модуль меньше заданного небольшого порога.

Проверь функцию на целевой дельте из задания. Она составлена из двух независимых внешних произведений, поэтому ты должен получить ранг 2. Это число связывает код с ограничением из шага 19: LoRA ранга 1 не сможет точно вместить такую поправку, а ранг 2 уже сможет.

🎒 На пальцах. Представь стопку прозрачных трафаретов. На одном проведена вертикальная полоса, на другом — горизонтальная. Копии этих полос не добавляют нового рисунка, сколько бы трафаретов ты ни положил сверху. Удаляя повторы, ты считаешь только уникальные полосы. Опорные элементы делают с матрицей то же самое: оставляют независимые направления, число которых и есть ранг.
