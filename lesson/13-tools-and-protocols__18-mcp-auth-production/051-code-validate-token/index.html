Пишем validate_token (версия из урока 16 плюс JWKS, iss, exp, скоуп)

Урок 16 оставил тебе один вызов на весь сервер: server.validate(bearer_token, required_scope="mcp:tools.invoke"). Три строки в main.py, и никакого if про конкретный инструмент. Всё, что нарастало последние двадцать шагов — кеш JWKS, список разрешённых issuer, канонический aud — должно уместиться внутрь этой одной функции. Начинается она там же, где и в уроке 16: разобрать JWT, взять подпись, сверить. Меняется то, откуда берётся ключ и сколько проверок идёт после подписи.

Первое, на чём спотыкаются: соблазн заглянуть в iss или exp до проверки подписи. Клеймы неподписанного токена — это просто текст, который прислал клиент; он может написать туда что угодно. Пока подпись не сошлась, ты не знаешь ничего. Поэтому порядок жёсткий: kid из заголовка → ключ через resolve_signing_key из шага 46 (он сам сходит за обновлением ровно один раз при промахе) → проверка подписи → и только потом клеймы.

Дальше четыре сверки, каждая возвращает свой челлендж и останавливает функцию. iss — через check_issuer_match из шага 49. aud — точное совпадение с каноническим URI ресурса из шага 31, без «почти такого же» со слешем на конце. exp — по текущему времени. Скоуп — содержит ли токен required_scope.

Возвращай не голое True/False, а словарь: valid, status, www_authenticate — форму челленджа ты собрал в шаге 36. Промах по подписи, iss, aud, exp — это 401 с invalid_token. Нехватка скоупа — 403 с insufficient_scope и указанием нужного скоупа: токен-то настоящий, прав мало.

И следи за тем, чтобы у инструментов не появилось второго входа мимо этой функции. Одна дверь работает, только пока она одна.

🎒 На пальцах. Электрощиток в квартире: все розетки заведены через один автомат. Замкнуло фен — выбило сразу, до пожара. Но если электрик протянет ветку в кладовку напрямую от счётчика, мимо автомата, — она будет исправно работать месяцами. Ровно до первого замыкания, которое некому оборвать. Проверка токена — тот же автомат: её ценность не в том, что она есть, а в том, что провода в обход неё не существует.

Практика: validate_token

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
