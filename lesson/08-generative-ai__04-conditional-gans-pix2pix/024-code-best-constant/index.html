Пишем best_constant

Тебе дают цели [1, 2, 100] и просят заменить их одним постоянным предсказанием. Среднее потянется к выбросу, но для L1 это не лучший выбор: результат должен быть 2.

Допиши best_constant: функция принимает набор чисел и возвращает одну константу, которая даёт наименьшую суммарную L1-ошибку. Нужное правило мы разобрали в шаге 23: ищи медиану, а не среднее арифметическое.

Обрати внимание на два случая:

  • при нечётном количестве значений медиана — центральный элемент после сортировки;
  • при чётном количестве любой результат между двумя центральными значениями минимизирует L1, но стандартная операция медианы обычно возвращает их полусумму.

Не прописывай сортировку и выбор центральных элементов вручную, если библиотека уже предоставляет вычисление медианы. Верни именно число, а не отсортированный массив или список из одного элемента. Для самопроверки сравни результаты на [1, 2, 100] и [1, 2, 8, 100]: большой выброс не должен утянуть ответ к себе так, как утянул бы среднее.

🎒 На пальцах. Ты выбираешь высоту общей полки для нескольких коробок и платишь за каждый сантиметр, на который коробку придётся поднять или опустить. Одна необычно высокая коробка не должна задрать полку почти к потолку. Медианная высота оставляет примерно поровну коробок сверху и снизу — поэтому суммарное перемещение минимально.
