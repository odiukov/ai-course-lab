Перед тобой два объекта: x = [1, 2] и z = [3, 4]. Функция должна вернуть одно число — значение полиномиального ядра для этой пары. Само правило мы разобрали на шаге 35; теперь важно аккуратно перенести порядок действий в Python.

Сначала получи скалярное произведение через уже имеющуюся функцию dot. Затем прибавь c ко всему результату и только после этого возведи сумму в степень degree.

Проверь себя на простых числах. Для векторов [1, 2] и [3, 4] скалярное произведение равно 11. Если c=1 и degree=2, функция должна вернуть 144: сначала получается 12, затем 12².

Здесь легко перепутать порядок и возвести в степень только c или отдельные координаты. Ещё одна частая ловушка: в Python степень записывается оператором **, а ^ выполняет совсем другую операцию.

Хорошая контрольная точка: при degree=1 и c=0 результат должен совпасть с linear_kernel. Если не совпадает, проверь, что прибавление и возведение в степень применяются ко всему значению dot(x, z).

🎒 На пальцах. Представь автомат в игровом зале. Сначала он считает базовые очки за совпадение твоих движений с образцом — это dot. Потом добавляет бонус c, а режим сложности усиливает уже общий счёт степенью degree. Если включить усиление до начисления бонуса, табло покажет другое число: порядок действий здесь является частью правила.
