Пишем rbf_kernel

Поставь рядом две одинаковые точки: [1, 2] и [1, 2]. Их сходство должно получиться равным 1. Теперь замени вторую точку на [2, 2] — сходство уменьшится. Твоя функция должна превратить именно это расстояние между точками в число от 0 до 1.

Используй формулу RBF-ядра из шага 37, но разбей вычисление на понятные действия. Сначала создай diff: список попарных разностей координат x и z. Затем передай diff дважды в уже имеющуюся функцию dot. Так ты получишь квадрат расстояния — без отдельного извлечения корня. После этого умножь результат на -gamma и вычисли экспоненту через math.exp.

def rbf_kernel(x, z, gamma=0.5):

    # найди квадрат расстояния
    # верни значение экспоненты

Проверь себя на трёх наблюдениях:

rbf_kernel([1, 2], [1, 2])              # 1.0
rbf_kernel([0, 0], [1, 0], gamma=0.5)   # примерно 0.6065
rbf_kernel([0, 0], [1, 0], gamma=2.0)   # примерно 0.1353

Если одинаковые точки дают не 1, проверь знак перед gamma: он должен быть отрицательным. Если далёкие точки получают большее сходство, вероятно, ты потерял этот минус. Координат у x и z должно быть поровну, иначе zip незаметно отбросит лишние.

🎒 На пальцах. Представь фонарь с круглым пятном света. Точка прямо под фонарём освещена полностью — это сходство 1. Чем дальше ты отходишь, тем слабее свет и тем ближе значение к нулю. gamma работает как фокусировка луча: при большом значении яркое пятно быстро сужается, поэтому даже небольшой отход резко уменьшает сходство.
