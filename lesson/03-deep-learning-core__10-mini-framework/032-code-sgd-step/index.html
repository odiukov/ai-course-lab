Пишем sgd_step

У тебя есть параметр со значением 2.0, его градиент равен 3.0, а скорость обучения — 0.1. После шага SGD параметр должен стать 1.7, причём измениться прямо внутри модели. Если вычислить новое число, но сохранить его только во временной переменной, обучение ничего не изменит.

Напиши функцию sgd_step(parameters, lr). Она получает тот же список описаний параметров, с которым работала zero_grads в шаге 29. Каждый элемент списка содержит четыре части: container, индексы i и j, а также grad_container.

Пройди по всем таким элементам и выполни обновление из шага 31. Здесь есть две формы хранения:

  • если j не равен None, параметр находится во вложенном контейнере по адресу [i][j];
  • если j равен None, параметр находится по адресу [i].

Особенно внимательно проверь условие. Нельзя писать просто if j: индекс 0 в Python считается ложным, хотя это настоящий индекс первого элемента. Сравнивай именно с None.

Функция должна менять container на месте и ничего не возвращать. Градиенты она не обнуляет: это отдельная обязанность zero_grads. Проверь себя на параметрах обеих форм и убедись, что каждый из них сдвигается против своего градиента ровно один раз.

🎒 На пальцах. Представь настройщика пианино со списком клавиш. Для каждой записи указаны нужная струна, её текущее натяжение и величина поправки. Где-то достаточно одного номера, а где-то нужны номер клавиши и номер струны. Настройщик не переписывает расчёт в блокнот — он сразу поворачивает соответствующий колок. sgd_step так же находит точное место параметра и изменяет его там, где он хранится.
