Пишем pick_format

Ты передаёшь функции параметры сервинга и замечаешь неудобный случай: сервер работает на Blackwell, запросы требуют рассуждений, а к модели подключают много LoRA. Подходят сразу несколько форматов. Если проверять условия в случайном порядке, ответ функции будет зависеть не от требований, а от расположения if.

Напиши pick_format, которая превращает дерево решений из шага 33 в однозначный выбор. Функция должна принять характеристики среды: CPU или GPU, наличие Blackwell, тип нагрузки, использование множества LoRA и подтверждено ли качество NVFP4. Верни название выбранного формата строкой.

Проверяй наиболее специальные случаи раньше общих:

  1. Blackwell с подтверждённым качеством — NVFP4 + FP8 KV.
  2. CPU или край сети — GGUF Q4_K_M.
  3. Нагрузка с рассуждениями — FP8.
  4. GPU с множеством LoRA — GPTQ + Marlin.
  5. Обычный GPU-чат без множества LoRA — AWQ.
  6. Если данных недостаточно или сочетание не поддержано правилами — результат, явно требующий сравнительного eval, а не случайный формат.

Обрати внимание на граничный случай: одного признака blackwell=True недостаточно для NVFP4. Без подтверждения качества функция должна продолжить проверку остальных условий. Не смешивай выбор формата с расчётом памяти из функции format_memory_gb, написанной на шаге 30: здесь ты только маршрутизируешь сценарий.

Проверь функцию на каждом отдельном маршруте и хотя бы на одном наборе пересекающихся признаков. Главный тест — одинаковые входные данные всегда приводят к одному объяснимому ответу.

🎒 На пальцах. Представь диспетчера на вокзале: пассажир одновременно может ехать с велосипедом, иметь билет первого класса и нуждаться в доступном вагоне. Диспетчер проверяет требования в установленном порядке, потому что самое специальное условие определяет подходящий поезд раньше общего «есть билет». pick_format делает то же самое: не угадывает лучший вариант, а последовательно направляет сценарий по правилам.

Практика: pick_format

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
