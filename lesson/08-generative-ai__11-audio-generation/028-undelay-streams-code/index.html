Пишем undelay_streams

После сдвига из шага 26 перед тобой более широкая таблица: у поздних потоков слева появились служебные позиции, а у ранних — справа. Если просто удалить все PAD, можно случайно потерять настоящий токен с таким же значением. Здесь важно не содержимое ячейки, а её координата.

Напиши undelay_streams, которая принимает сдвинутые потоки и возвращает их на общую временную ось, как обсуждалось в шаге 27. Сначала определи исходную длину: при K потоках и ширине сдвинутой таблицы D она равна D - K + 1. Затем для потока с индексом k оставь ровно этот отрезок, начиная с позиции k.

Например, после задержки двух потоков ты можешь увидеть:

[a,   b, c, PAD]
[PAD, x, y, z  ]

Результатом должны стать два одинаковых по длине потока: a, b, c и x, y, z.

Следи за двумя типичными ошибками: индекс первого потока равен нулю, поэтому его не нужно сдвигать; обрезать следует каждый поток по его индексу, а не одинаково всю таблицу. Функция должна сохранять порядок токенов и возвращать прямоугольную таблицу без служебных краёв.

🎒 На пальцах. Представь несколько бегунов, которые стартовали с разных отметок дорожки. После забега фотография показывает лишнее пустое пространство перед каждым поздним стартом. Ты не ищешь на снимке «пустой цвет», а отмеряешь для каждого бегуна его стартовую отметку и одинаковую дистанцию. Так дорожки снова совпадают по началу и длине.

Практика: undelay_streams

Здесь только функция этого шага — остальной файл упражнения подставится при запуске. Код выполняется прямо в твоём браузере: первый запуск качает Python, примерно двенадцать мегабайт, дальше из кэша.
