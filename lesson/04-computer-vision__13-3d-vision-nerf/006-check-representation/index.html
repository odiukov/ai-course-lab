Проверка: какое 3D-представление подходит задаче

Здесь важно выбирать не «самое современное» представление, а то, какой ответ нужен задаче. Для непосредственной работы с измеренной геометрией подходят явные формы из шага 4. Если нужно выучить сцену по снимкам и получать новые виды, полезно неявное представление из шага 5. Частая ошибка — предпочесть NeRF для любой 3D-задачи только потому, что это нейросеть.

🎒 На пальцах. Представь отдел реквизита перед съёмкой. Каскадёру нужны точные положения препятствий на площадке — он берёт измерения. Режиссёру нужен кадр с виртуальной камеры — ему нужна модель, способная показать сцену с нового места. Одна площадка, но разные задачи требуют разных представлений.

  1. Робот получает данные LIDAR и должен сразу оценивать положение препятствий. Какое представление разумнее взять за основу?

  2. У тебя есть снимки комнаты с известными позами камер, а результат должен показывать её с новых ракурсов. Что подходит лучше?
