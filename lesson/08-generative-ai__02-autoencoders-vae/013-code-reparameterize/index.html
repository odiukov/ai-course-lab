Пишем репараметризацию z = μ + σ·ε

Перед тобой три списка одинаковой длины: mu, log_sigma2 и будущий eps. Например, если латент состоит из четырёх чисел, в каждом списке тоже должно быть четыре элемента. Твоя функция reparameterize(mu, log_sigma2, rng) должна собрать из них один случайный латентный вектор z.

Репараметризацию мы разобрали в шаге 12; теперь преврати её в последовательность операций:

  1. Для каждого элемента mu получи через rng.gauss(0, 1) отдельное случайное число eps.
  2. Каждый элемент log_sigma2 преобразуй в sigma: используй math.exp и половину значения, как следует из связи логарифма дисперсии со стандартным отклонением.
  3. Соедини соответствующие элементы mu, sigma и eps, вычислив очередную координату z.
  4. Верни список координат z.

Следи именно за соответствием позиций: первая координата mu должна работать с первой координатой sigma и первым случайным числом. Для этого удобно перебирать списки параллельно.

Проверь функцию на одном измерении: при mu = 2, sigma = 0.5 и выпавшем eps = -1.2 результат должен быть 1.4. Затем вызови функцию несколько раз с одинаковыми mu и log_sigma2: значения z обычно будут различаться, потому что при каждом вызове создаётся новый eps.

🎒 На пальцах. Представь фишку в настольной игре. mu задаёт стартовую клетку, eps — случайное направление и величину хода, а sigma меняет масштаб этого хода. При маленькой sigma фишка остаётся рядом со стартом, при большой уходит дальше. Функция должна повторить такой ход отдельно для каждой координаты латента.
