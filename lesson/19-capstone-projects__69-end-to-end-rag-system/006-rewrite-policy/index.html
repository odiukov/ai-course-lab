Выбираем переписывание по форме запроса

Ты вводишь три запроса подряд: «Какой срок возврата товара?», «А для юридических лиц?» и «Сравни возврат и обмен». Если одинаково перефразировать каждый из них, поиск может стать хуже. Первый уже самодостаточен, во втором потерян предмет разговора, а третий содержит две связанные задачи.

Значит, смотреть нужно не на тему запроса, а на его форму. Самодостаточный вопрос можно передать дальше без изменений. Реплику с «это», «там», «а для них?» полезно развернуть с учётом диалога: например, восстановить, что речь всё ещё идёт о сроке возврата. Составной вопрос можно представить несколькими поисковыми формулировками, чтобы каждая искала свою часть.

Но переписывание опасно: модель способна незаметно добавить то, чего ты не спрашивал. Поэтому вместе с вариантами нужна гипотеза — явная запись принятого предположения. Если «для юридических лиц» истолковано как «срок возврата для юридических лиц», это предположение можно проверить, а не прятать внутри новой фразы.

Для пайплайна из шага 1 важна стабильная форма результата: список поисковых формулировок плюс гипотеза, даже если исходный запрос решено не менять. Тогда поиск из шага 5 получает удобные запросы, а смысл пользовательской реплики остаётся контролируемым. Переписывание здесь не украшает текст — оно восстанавливает недостающий поисковый смысл.

🎒 На пальцах. Представь сотрудника справочной в большом музее. На вопрос «Где зал импрессионистов?» он сразу показывает маршрут. Услышав следом «А где там гардероб?», сначала уточняет про себя: «там» означает рядом с этим залом. А просьбу «покажи кафе и выход» разбивает на два направления. Хороший сотрудник не придумывает цель посетителя — он лишь делает её пригодной для поиска.
