Проверка: какой вид спана здесь

Здесь проверяется одна связка: по описанию агента собрать имя спана и выбрать вид. Имя — из шага 8, вид — по границе процесса из шага 9.

Спотыкаются обычно на двух вещах. Первая: забывают префикс invoke_agent и пишут в имя просто «Researcher» — тогда спан не состыкуется с остальными по договору из шага 2. Вторая: путают «агент удалённый» с «агент сложный». Вид спана не про сложность и не про длительность, а ровно про то, ушёл ли вызов из твоего процесса по сети. Локальный ReAct-цикл может молотить полминуты и всё равно остаётся INTERNAL.

  1. Ты запускаешь агента с именем Researcher внутри CrewAI — он работает в том же процессе, что и твой код. Какое имя и вид спана правильные?

  2. Твой код обращается к OpenAI Assistants API: агент крутится на чужих серверах. Почему тут важно поставить именно CLIENT, а не INTERNAL?
