Верни только JSON-объект версии 1 в блоке ```json. Его формат:

```json
{
  "version": 1,
  "authorTest": "tests/test_main.py",
  "requirements": ["torch"],
  "network": false,
  "targets": [
    {
      "file": "main.py",
      "symbol": "Class.method",
      "instruction": "Короткое точное задание по-русски без готового решения.",
      "tests": ["test_exercise.py::TestClass::test_case"],
      "bench": false
    }
  ]
}
```

Если авторского pytest нет, используй вместо `authorTest`:

```json
"run": {"file": "main.py", "timeoutMs": 240000}
```

и не добавляй `tests` к целям такого урока.

Правила:

1. Выбирай только функции и методы, реально объявленные в приложенном коде.
   Метод записывай квалифицированно: `Class.method`. Конструкторы и простые
   свойства не выбирай. Главная логика урока важнее вспомогательной печати,
   сериализации и demo-функций.
2. У pytest-лаборатории каждая цель должна иметь один или несколько точных
   node ID. Путь в node ID всегда `test_exercise.py`: исходный авторский файл
   при переносе получает это имя. После пути дословно укажи класс unittest и
   имя метода либо имя pytest-функции из приложенного теста.
3. Тест цели должен становиться красным именно при заглушке этой цели и не
   должен зависеть от ещё не реализованных целей. Предпочитай узкие прямые
   тесты. Не назначай один и тот же тест двум целям.
4. Порядок targets — учебный порядок: от независимого основания к композиции.
5. `bench: false` обязателен для методов и для функций, которым нельзя передать
   репрезентативный ввод общим бенчмарком.
6. В requirements перечисляй только внешние импортируемые Python-модули:
   например, `torch`, `numpy`, `safetensors`, `h5py`, `zstandard`, `yaml`. Стандартную
   библиотеку и локальные модули не включай. Имя PyYAML здесь — `yaml`.
7. `network` true только если сама практика обязана ходить в сеть.
8. `resources` из подсказки перенеси дословно, если она не пуста. Других путей
   не выдумывай.
9. Для run-лаборатории выбери четыре центральных шва. Итоговый `main.py` обязан
   завершаться с ненулевым кодом, пока они остаются заглушками.
